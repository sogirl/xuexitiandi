一、单元概览

1.1 单元主题与核心定位

Unit 3 My Farm（我的农场）是剑桥 Power Up 1 Starter Level 的核心单元，主题围绕「农场动物 + 描述形容词 + have/has got 句型」展开。整册书前两单元（Unit 1 My Face / Unit 2 My Family）打好了身体部位、家庭成员的词汇基础，本单元首次把场景迁移到农场/动物世界，并系统引入 have got / has got 这一小学阶段最核心的「拥有」句型。

本单元结束时，孩子应当能够在以下场景中自如表达：

  • 认识 10 个农场动物词汇（goat / dog / cow / donkey / horse / spider / sheep / cat / chicken / duck）
  • 使用 14 个描述形容词（big / small / long / short / old / young / nice / funny / sad / happy / beautiful / ugly / angry / different / OK）
  • 掌握 have got / has got 的肯定、否定、一般疑问句结构
  • 识别 3 种颜色（brown / black / pink）+ 4 个身体部位（nose / tail / wings / legs）
  • 读懂"动物描述"类短文（Tom's Farm Visit Diary / Funny Animal Friends / Clever Little Goat）
  • 产出"My farm has got..."类型的口头/书面描述
📌 单元一句话定位：Unit 3 是从「家庭自我」过渡到「农场世界」的桥梁单元，have got 句型贯穿整个单元，是后续 Unit 4「My House」描述家具、Unit 5「My Town」描述地点的语法基石。

三、核心知识点详解（双步讲解法）

3.1 农场动物 10 词（Animals Vocabulary）

3.1.1 第一步：原理推导 + 框架定位

本组 10 个动物名词是英语儿童文学「动物世界」三大场景（农场 / 动物园 / 家养宠物）的农场子集。它们的可数性、单复数、拟声词、来源（动物 vs 产品）各不相同，是后续语法 have got 与阅读理解的基础语义库。

从认知框架看，可按"会动但不会跑（蜘蛛）→ 会跑不会飞（狗 / 猫 / 羊）→ 会跑也会飞（鸡 / 鸭）"三档分类；从语法框架看，可按"可数名词有复数（dogs / cats / ducks）+ 单复数同形（sheep / goat / chicken）"对照；从功能框架看，可按"给人类提供资源（cow → milk / chicken → eggs / sheep → wool / bee → honey）"四象限归位。

3.1.2 第二步：📌必背 + 🧠拓展 + 题型映射

📌 必背清单（按场景记忆）
  • 家禽类：chicken（鸡·单复数同形）/ duck（鸭子）
  • 家畜类：cow（奶牛）/ horse（马）/ sheep（绵羊·单复数同形）/ donkey（驴）/ goat（山羊·单复数同形）/ dog（狗）/ cat（猫）
  • 其他节肢：spider（蜘蛛）
  • 场景短语：on the farm（在农场）
🧠 思维拓展
  • 单复数同形：goat / sheep / chicken 单复数不变。一只山羊 = one goat，五只山羊 = five goats。
  • 拟声词拼配：cow — Moo / sheep — Baa / duck — Quack / dog — Woof / cat — Meow / rooster — Cock-a-doodle-doo。
  • 性别词延伸：hen（母鸡）+ rooster（公鸡）/ cow（母牛）+ bull（公牛）。PU2-3 会陆续出现。
🎯 题型映射
  • 听力题：听拟声词选动物（Moo → cow）
  • 选择题：The ______ gives us milk.（cow）
  • 阅读题：从 Tom's Farm Visit Diary 提取动物名 + 身体部位
  • 写作题：用 5+ 动物名写一段 "On my farm"
【核验来源：Power Up 1 2E Unit 3 Vocabulary I P14-15 + Cambridge 官方 Teacher's Book + 牛津 OXFORD 3000 词表对照】

3.2 描述形容词 14 词（Adjectives）

3.2.1 第一步：原理推导 + 框架定位

形容词是英语前置定语的核心载体——一律放在名词前（big dog / sad dog / funny dog），这与汉语「形容词+名词」语序一致，因此中国孩子学起来障碍较小；难点在于一词多义（如 short 既可表"短的"又可表"矮的"）与情绪 vs 外貌的区分。

本单元 14 个形容词按认知维度可分四组：物理属性（big / small / long / short / old / young）、评价属性（nice / funny / beautiful / ugly / different / OK）、情绪属性（sad / happy / angry）、行为属性（kind 与 smart 拓展）。它们共同支撑「主系表结构」——即 主语 + be + 形容词，本单元 is / are 句型的核心。

3.2.2 第二步：📌必背 + 🧠拓展 + 题型映射

📌 必背清单（按维度记忆）
维度词汇常见搭配
物理·大小big / smallbig horse / small spider
物理·长短long / shortlong tail / short tail
物理·年龄old / youngold cow / young cow
评价·外貌nice / funny / beautiful / uglynice cat / funny dog / ugly dog
评价·差异different / OKdifferent dogs / Are you OK?
情绪happy / sad / angryhappy dog / sad dog / angry cat
🧠 思维拓展
  • 反义词组：big ↔ small / long ↔ short / old ↔ young / happy ↔ sad / beautiful ↔ ugly。
  • 形容词位置：修饰名词时放在名词前（a small spider）；作表语时放在 be 后（The spider is small.）。
  • 程度副词：very / really / so / quite（PU2 拓展）—— 本单元掌握 very 即可。
  • 易错点：形容词的比较含义—— Gracie is not young. She is old.（用反义词改写）
🎯 题型映射
  • 选择题：My sister is ______, but my grandpa is ______.（young; old）
  • 改错题：This is a old book. → an old book.
  • 反义词：The opposite of "short" is ______.（long）
  • 写作：用 3+ 形容词描述自己养的宠物
【核验来源：Power Up 1 2E Unit 3 Story+Grammar I P16-17 + Cambridge Grammar in Use (Beginner) Ch.3】

3.3 have / has got 语法（核心句型）

3.3.1 第一步：原理推导 + 框架定位

have got / has got 是英语「拥有」语义的口语化英式表达（British English），相当于美式的 have / has。它的结构来自 have / has + got（完成体标记），语法功能相当于及物动词——后接宾语，表达"拥有某物"。

判定 have / has 的人称口诀：
「I 用 have，you 用 have，we 用 have，they 用 have；
he 用 has，she 用 has，it 用 has。」

三种基本句式结构：

  • 肯定：主语 + have / has + got + 宾语 → I have got a happy dog. / He has got a long tail.
  • 否定：主语 + have / has + not + got + 宾语 → I haven't got a short tail. / It hasn't got a short tail.
  • 一般疑问：Have / Has + 主语 + got + 宾语? → Have you got a brown nose? / Has it got a long tail?

3.3.2 第二步：📌必背 + 🧠拓展 + 题型映射

📌 必背口诀 + 简表
人称肯定否定疑问Yes 简答No 简答
I / You / We / Theyhave gothaven't gotHave … got?Yes, I have.No, I haven't.
He / She / Ithas gothasn't gotHas … got?Yes, it has.No, it hasn't.
🧠 思维拓展
  • 缩写：I have got = I've got / He has got = He's got / I have not got = I haven't got / He has not got = He hasn't got。
  • 与 is / are 区分：It has got a long tail.（强调"拥有"）vs It is long.（强调"属性"）。两者语义相近但侧重不同。
  • 替换关系：It has got = It has（英式 vs 美式）。但否定 / 疑问句中英式 don't / doesn't 仍可替换 haven't / hasn't——本题型初中再深入。
  • 易错点：Tom has got a dog. ✔ / Tom have got a dog. ✘（主谓一致！）
⚠️ 适用边界
  • 只表"拥有"：不用于"动作"（不能用 I have got a shower 表达"洗澡"）。
  • 不与进行时连用：不能写 I am having got a dog（have got 已含完成意味，不可再叠加 be -ing）。
  • 英美差异：英式英语在口语中几乎只用 have got；美式英语更喜欢 have。剑桥考试两者皆可，教材统一采用 have got。
🎯 题型映射
  • 选择：The dog ______ a long tail.（has）
  • 填空：______ the cat got a black tail?（Has）
  • 句型转换：He has got a happy dog. → ______ he ______ a happy dog?（Has / got）
  • 改写：She has a dog. → She ______ ______ a dog.（has got）
【核验来源：Power Up 1 2E Unit 3 Vocabulary+Grammar II P18-19 + Cambridge Grammar in Use (Beginner) Ch.6 + 牛津英语语法 Oxford Grammar for Schools 1 Unit 4】

3.4 is / are 系动词（主系表结构）

3.4.1 第一步：原理推导 + 框架定位

is / are 是英语 be 动词的两种现在时形式：is 用于单数第三人称和单数第一人称（I / he / she / it + 名词单数），are 用于复数和第二人称（you / we / they + 名词复数）。句型结构为 主语 + be + 表语（形容词 / 名词），本单元形容词作表语是核心。

3.4.2 第二步：📌必背 + 🧠拓展 + 题型映射

📌 必背口诀
  • is 用在：I / he / she / it + 名词单数（The cat is small.）
  • are 用在：you / we / they + 名词复数（These apples are small.）
  • 否定缩写：is not = isn't / are not = aren't
  • 疑问结构：Is the cat small? / Are these apples big?
🧠 思维拓展：is/are 与 have/has got 的区分
  • The dog is big.（描述属性）vs The dog has got a big body.（描述拥有）。
  • 前者不可换 have got（语法错误），后者可改 is（语义变属性）。
  • 缩写规则：is not → isn't / are not → aren't（缩写必背）。
🎯 题型映射：选择题（The babies ______ big. → are）/ 填空（Look at the ______ car! It ______ so cool. → new / is）

3.5 颜色 3 词 + 身体部位 4 词

3.5.1 第一步：原理推导 + 框架定位

颜色词与身体部位词在本单元是复合定语的核心——即"形容词+名词"组合（a brown nose / a long tail）。它们的搭配有"约定俗成"性，需通过阅读而非语法推导（如 duck + webbed feet 是生物学事实，不是语法规则）。

3.5.2 第二步：📌必背 + 🧠拓展 + 题型映射

📌 必背清单
  • 颜色：brown（棕色）/ black（黑色）/ pink（粉色）—— 注意 brown / black 既可作形容词也可作名词。
  • 部位：nose（鼻子）/ tail（尾巴）/ wings（翅膀·常用复数）/ legs（腿·常用复数）
  • 拓展部位：webbed feet（蹼足）/ horns（角）/ beaks（喙）/ fur（毛）/ spots（斑点）
🎯 题型映射：判断题（Chickens have webbed feet. → F，webbed feet 是鸭子的）/ 选择题（The dog has a ______ nose. → brown）

3.6 短语 + 拟声词

📌 必背短语
  • 地点：on the farm（在农场）/ in the park（在公园里）
  • 动作：cut the wool（剪羊毛）/ clean the wool（清理羊毛）/ make clothes（做衣服）/ lay eggs（下蛋）/ use your tail（用尾巴）
  • 描述：live with her mom（和妈妈生活在一起）/ black spots（黑色斑点）/ black mud（黑泥）

3.8 文学阅读（Literature）：品德 + 解决问题

3.8.1 第一步：原理推导 + 框架定位

本单元两篇文学短文 Cathy the White Cow（白奶牛身上的飞虫叮咬问题）与 The Clever Little Goat（小白羊 Billy 的白外套易脏问题），共享同一叙事结构：问题出现 → 朋友 / 自己想办法 → 解决问题 → 升华品德主题。这是英美小学文学阅读常见的「问题 - 解决 - 品德」三段式。

3.8.2 第二步：📌必背 + 🧠拓展 + 题型映射

📌 必背核心词
  • Cathy 主题：farm / horses / sheep / chickens / flies / tail / problem / bites / scared of / black mud / black spots / use your tail
  • Billy 主题：young white cow → white coat gets dirty → green stripes hide the dirt → coat looks clean
  • 祈使句：Go away! / Follow me! / Jump in! / Ouch!
🧠 思维拓展：品德升华
  • Cathy 的核心：遇到问题主动求助（One day she tells a friend about her problem.）
  • Billy 的核心：朋友之间相互帮助（"Thank you, Rosie!" says Billy.）
  • 通用主题：Friends should be nice to each other!
🎯 题型映射：主旨题 / 词义题 / 代词指代 / 细节判断

四、难点与易错点

编号易错点错误示范（✘）正确示范（✔）纠错技巧
1人称代词与 have / has 不一致Tom have got a dog.Tom has got a dog.三人单数+名词单数 → has；其他 → have
2缩写形式错误He hasn't got a cat.He hasn't got a cat.has not = hasn't；have not = haven't
3一般疑问句结构错误Does the cat got a tail?Has the cat got a tail?have got 句型用 Have / Has 提问，不用 Do / Does
4复数主语+单数动词The chickens lays eggs.The chickens lay eggs.复数主语 → 动词原形
5单复数同形词加 -sfive sheepsfive sheepsheep / goat / chicken / fish / deer 单复数同形
6不定冠词 a / an 用错a old book / an small spideran old book / a small spideran + 元音音素开头；a + 辅音音素开头
7be 与 have got 混用He is got a dog.He has got a dog.be 后接形容词（is big），不用 got
8形容词位置错误a cat nicea nice cat形容词修饰名词必须前置
9反义词改写时不换主系He is old. He is not old.He is old. He is not young.用反义词替换，不要只加 not
10Webbed feet 误归类Chickens have webbed feet.Ducks have webbed feet.蹼足是鸭子的特征，鸡有 beaks（喙）
11形容词比较级 -er 误用a biger balla bigger ball双写辅音 + -er：bigger（不规则本单元不展开）
12have got 简写漏写 gotHe has a dog.（在 got 语法题里）He has got a dog.教材统一 have got 形式，单元内不混用
⚠️ 高频易错 Top 3
  1. 主谓一致：The horses ______ long tails.（have / has → have）
  2. 缩写 vs 完整：写作必须用 hasn't / haven't（口头可缩写，书面必缩写）
  3. Webbed feet 是鸭子专属：干扰项最爱出 webbed feet，但课文明确为 ducks 而非 chickens

六、薄弱环节专项突破

基于输入文件内容，识别孩子薄弱环节如下（按优先级排列）：

突破 1：have / has got 三种句式的结构化理解（★ 最高优先级）

⚠️ 薄弱表现：孩子常常把 has / have 混用；分不清"动作"动词 lay / give 的第三人称单数 -s 规则与 have got 的 has 形式；缩写 hasn't 拼错。
✅ 突破策略·三步走
  1. 第一步·人称判定：看到主语先判断——I / you / we / they → have；he / she / it / 单数名词 → has。先圈主语再选动词。
  2. 第二步·句式模板：
    　肯定：主语 + have / has + got + 宾语
    　否定：主语 + have / has + not + got + 宾语
    　疑问：Have / Has + 主语 + got + 宾语?
  3. 第三步·句型转换：会写肯定→会写否定；会写肯定→会写疑问；会回答一般疑问句。

突破 2：单复数同形名词（sheep / goat / chicken）

⚠️ 薄弱表现：孩子容易按汉语思维加 -s，写出 five sheeps / three goats。
✅ 突破策略：记忆"单复数同形"的 4 个词表——sheep / goat / chicken / fish（PU2-3 会学 deer），配合"数词+同形"练习：one sheep / two sheep / ten sheep。

突破 3：a / an 用错（受汉语"一个"影响）

⚠️ 薄弱表现：This is a old book. / an small spider.
✅ 突破策略：听音判定——a 用于辅音音素开头，an 用于元音音素开头。让孩子大声朗读，根据第一个音判断而非第一个字母。

突破 4：阅读理解代词指代（They / She / Their）

⚠️ 薄弱表现：阅读时无法定位代词所指代的对象，导致主旨题与细节题失分。
✅ 突破策略：教孩子"指代三步法"——①找到代词所在句；②向前回溯最近的名词；③判定数与性是否一致。

突破 5：跨学科阅读的因果链推理

⚠️ 薄弱表现：跨学科短文涉及"动物→产品→人类用途"三段链，孩子抓不住主线。
✅ 突破策略：使用"动词链"圈画法——圈出每个句子的主语、动词、宾语，串成"动物 give / make / lay → 产品 → 人类用途"。遇到主旨题直接套"动物 gifts / products"。

十五、错题清零专卷（精选 10 大易错）

本卷只收录孩子最高频错题，每题含「原题+错因+正解+防错口诀」。

  1. 1. Tom ______ (have) got a dog.
    错因：人称混淆 → Tom 是单数三人称
    正解：has got a dog.
    口诀：三人单数用 has，其他用 have
  2. 2. The cat ______ (not has) a short tail.
    错因：缩写位置错 → 缩写必须在 not 后
    正解：The cat hasn't got a short tail.
    口诀：has not → hasn't；have not → haven't
  3. 3. ______ the dog got a long tail?
    错因：用 Do / Does 提问 → have got 句型用 Have / Has 提问
    正解：Has the dog got a long tail?
    口诀：have got 句型用 Have / Has 提问
  4. 4. The chickens ______ (lay) eggs every day.
    错因：主谓不一致 → 复数主语用动词原形
    正解：lay eggs every day.
    口诀：复数主语 + 动词原形
  5. 5. There are five ______ (sheep) on the farm.
    错因：单复数同形误加 -s
    正解：five sheep
    口诀：sheep / goat / chicken / fish / deer 单复数同形
  6. 6. This is ______ old book.
    错因：a / an 用错（看字母不看音）
    正解：This is an old book.
    口诀：an + 元音音素开头；a + 辅音音素开头
  7. 7. He ______ (is got) a dog.
    错因：be 与 got 混用
    正解：He has got a dog.
    口诀：got 不可与 be 动词连用
  8. 8. A cat nice ...
    错因：形容词位置错 → 必须放在名词前
    正解：A nice cat
    口诀：形容词修饰名词必须前置
  9. 9. Chickens have webbed feet.
    错因：Webbed feet 误归为鸡
    正解：Ducks have webbed feet.（鸡有 beaks）
    口诀：蹼足专属鸭子，喙专属鸡
  10. 10. The books is new.（主系一致错误）
    错因：复数主语误用单数 be
    正解：The books are new.
    口诀：复数主语 + are；单数主语 + is
