🍎 知识点 1：食物与饮料词汇归类

第一步：原理推导 + 框架定位

定义本源：英语把可「放进嘴里的东西」统称 food，再细分 drinks（液体）与 food（固体 / 半固体），二者界限明确：能倒进杯子的叫 drink，能用叉子 / 手拿着吃的叫 food。

推导：本单元 12 主词按「属性」二分 → 「食物 = rice / bread / chicken / burger / salad / cake / chocolate / banana / mango」+「饮料 = water / juice / lemonade」。中间灰色地带 salad（沙拉）虽是冷的，但属于固体食物。

适用边界：本分类只用于一年级初学；当学到二年级引入 fruit（水果集合名词）时，原 banana / mango 都归入 fruit。

知识框架：所属模块「Power Up 1 → Unit 4 → Vocabulary I」；前置：Starter 颜色数字动物词；后续：Unit 5「My Day」时间副词；横向：与数学「分类」概念互通。

📐 知识点 2：一般现在时 like/likes 的主谓一致

第一步：原理推导 + 框架定位

定义本源：英语一般现在时用于表达「习惯 / 事实 / 喜好」。动词随主语人称和数变化：复数 / 第一 / 第二 人称 → 原形；单数第三人称 → 加 -s / -es。

推导：

  • 三步判断法：① 找主语（I / you / we / they / he / she / it / Rocky / the cat…）；② 判断数（单数还是复数）；③ 决定动词形式：复数 / I / you → like；单数第三人称 → likes。
  • 特殊规则：以 s / x / sh / ch / o 结尾的第三人称单数动词加 -es（watches / washes）；以辅音 + y 结尾变 y 为 i 再加 -es（study → studies）；like 末尾是 e，加 -s 即可（likes）。

适用边界：本规则适用于除 be 动词 / 情态动词以外的所有实义动词（work / play / eat / read / see…）；遇到 be（am/is/are）与情态（can / would / do 作助动词）走另一套规则。

知识框架：前置：Starter + Unit 1-3 句型；后续：Unit 5 现在进行时 / 三年级一般过去时；横向：与数学「分类」、语文「主谓一致」暗合。

第二步：📌 必背内容

精确表述（陈述句 / 否定句 / 疑问句 / 回答）：

记忆口诀：「主语第三人称单数 + likes / doesn't / does + 其他」；「be / can / do / does，否定 don't / doesn't，疑问提前」。

🧠 思维拓展
  • 派生能力：一旦掌握 like → 同样套用 eat / drink / read / see / play / work 等所有实义动词。
  • 举一反三：They don't eat socks! = 「他们不吃袜子！」（变一般疑问：Do they eat socks? → No, they don't.）。
  • 培优衔接：二年级 Power Up 2 会引入 第三人称单数现在进行时（He is eating）和 一般过去时（He ate），本规则是地基。
⚡ 题型应用映射
  • 基础：填空 Rocky ___ (read) books. → reads。
  • 中档：改错 I doesn't like socks. → doesn't → don't。
  • 压轴：阅读中根据主语判断时态+正确动词，写作中 5 句以上描述人物喜好。

🙏 知识点 3：礼貌请求与提供的功能句

第一步：原理推导 + 框架定位

定义本源：英语「请求他人给东西」用 Can I have…?（我能要…吗？），「主动给他人东西」用 Would you like…?（你想要…吗？）。两者均为礼貌功能句，常伴随 please 与应答 Yes, please / No, thank you。

推导：

  • Can I have some…, please? = 「请给我来点…好吗？」→ 答：Here you are.（给你）/ Sorry, I don't have…
  • Would you like some…? = 「你想要点…吗？」→ 答：Yes, please. / No, thank you.
  • some 通用规则：some 用于肯定句与礼貌请求（Can I / Would you），不用 any；any 用于否定与一般疑问句。

适用边界：本单元限定食物 / 饮料；进入 Unit 7 后会拓展到玩具 / 文具；some 不与不可数名词连用时也可修饰可数名词（some apples / some juice）。

知识框架：前置：Unit 2「My Things」my / your 物主代词；后续：Unit 5「My Day」日常请求；横向：与语文「请教」互通，与道法「餐桌礼仪」挂钩。

第二步：📌 必背内容

请求模板（4 句常用）：

  1. Can I have some apples, please?
  2. Can I have some water, please?
  3. Would you like some juice?
  4. Would you like some salad?

应答模板（5 句固定）：

  1. 肯定请求：Here you are.（给你）/ Sure!（没问题）/ Yes, of course.
  2. 接受提供：Yes, please.
  3. 婉拒：No, thank you.
  4. 拒绝请求：Sorry, I don't have any.
  5. 自陈不喜：No, thanks. I don't like…

记忆方法：「Can I have 求东西，Would you like 给人要；please 加在请求尾，thank you 谢绝没烦恼」。

🧠 思维拓展
  • 中英对比：中文「请给我来点…」「你想不想来点…」语义上完全对应；区别在于中文省略 please 时仍可礼貌，英语省略则偏生硬。
  • 语用规则：接受请求必须立即执行（Here you are）；接受提供后对方立即倒 / 取；婉拒时语气柔和、不解释太多理由（一年级只需说 No, thank you）。
  • 举一反三：Can I have a hamburger, please?（a 用于可数单数）Can I have two hamburgers, please?（数词 + 复数）。
⚡ 题型应用映射
  • 基础：补全对话「—Can I have some water, please? —___」→ Here you are。
  • 中档：情景选择「在朋友家，主人问你 Would you like some cake? 你不想要时回答？」→ No, thank you。
  • 压轴：补全一段野餐场景对话（含请求 + 提供 + 接受 + 婉拒 + 分享共 6 轮）。

核验来源【Power Up 1 2E · Vocabulary+Grammar II · 礼貌功能句 + Cambridge English Vocabulary in Use (Beginner) Ch.5 食物 + 点餐功能章】

🍳 知识点 4：烹饪流程词汇与祈使句

第一步：原理推导 + 框架定位

定义本源：烹饪场景把 ingredients（食材）经过 cut / mix / cook / fold 等动作变成一道菜。描述流程用祈使句（动词原形开头），按时间先后用 First / Next / Then / Finally 连接。

推导：

  • 5 个核心动词：mix（混合，搅拌）+ cut（切）+ cook（烹饪）+ fold（折叠）+ show（展示 / 拿出）。
  • 6 个食材名词：eggs（鸡蛋）+ cheese（奶酪）+ onion（洋葱）+ tomatoes（番茄）+ flour（面粉，补充词）+ water（水，复用）。
  • 流程词：First（首先）→ Next（接下来）→ Then（然后）→ Finally（最后）。

适用边界：祈使句省略主语 You，仅用于指令 / 建议 / 邀请，不用于陈述；本单元动词全部以动词原形出现，不加 -s（祈使句无主谓一致问题）。

知识框架：前置：Unit 3「动作词」run / walk / jump；后续：Unit 6「方位」prep + 地点；横向：与数学「步骤排序」/ 语文「看图写话·做菜篇」互通。

第二步：📌 必背内容

祈使句模板：

  1. Mix the eggs and cheese.（把鸡蛋和奶酪搅在一起。）
  2. Cut the onion into small pieces.（把洋葱切成小块。）
  3. Cook everything for 10 minutes.（把所有东西煮 10 分钟。）
  4. Fold the omelette.（把蛋卷对折。）

复述模板（Cross-Curricular 课文）：

Today in cooking class, we learn to make omelets. First, Miss Li shows the ingredients: eggs, cheese, onion, and tomatoes. Next, we mix the eggs and cut the vegetables. Then we cook everything. Finally, we fold the omelette. It smells delicious!

记忆口诀：「cut 切 mix 搅 cook 煮 fold 折，First→Next→Then→Finally 串成歌」。

🧠 思维拓展
  • 举一反三：可替换食材做不同菜 → 煎蛋卷（omelette）/ 披萨（pizza）/ 沙拉（salad）→ 同一组动词复用。
  • 跨学科：食物 ingredients 与化学「反应物」、生物「细胞组成」概念相通 → 强调「由…组合而成」。
  • 语用迁移：祈使句可推广到游戏指令（Open your books.）、教室用语（Stand up.）、生活指引（Wash your hands.）。
⚡ 题型应用映射
  • 基础：补全 First, ___ the eggs. → mix。

🌳 知识点 5：阅读理解的「指代还原 + 故事要素定位」

第一步：原理推导 + 框架定位

定义本源：英语阅读中 they / she / he / it 等代词需向前找最近同集合名词还原。故事要素 = who（谁）+ what（做什么）+ where（在哪儿）+ when（何时）+ why（为什么）+ how（怎么样）。

推导：

  • 三步指代还原法：① 找到代词所在句；② 向前找最近的一个复数 / 单数同性名词短语；③ 验证一致性（数 / 性）。
  • 5W1H 提问法：阅读时心里画表格，逐句提取要素，回答问题 = 填表。

适用边界：本方法适用于叙事类（narrative）文本；说明文（expository）则需抓主旨句与细节支撑。

知识框架：前置：Unit 3 「My Family」人称代词；后续：Unit 5 「My Day」时间副词；横向：与语文「阅读理解六要素」互通。

第二步：📌 必背内容

  1. 「Mum prepares chicken, burgers, and fresh salad.」→ Mum = 妈妈（主语）。

四、难点与易错点

📛 本单元 TOP-6 易错点（按出错频率排序） 每条均含：错误示例 → 正确做法 → 原理归因 → 记忆口诀。

易错 1：主语第三人称单数漏加 -s

错误示例正确做法原理归因
She like cake.She likes cake.主语 she 是单数第三人称，动词必须加 -s。一年级学生受中文「她喜欢」无词形变化干扰，惯性照搬原形。
Rocky read books.Rocky reads books.Rocky 是单数人名，等价于 he；read → reads。
The cat eat fish.The cat eats fish.the cat 是第三人称单数，eat → eats。
🧠 原理归因：英语是「主语突出」语言，每个主语决定动词形式；中文是「主题突出」，动词无变化。这是中英思维差异在一年级英语学习中最典型的体现。
🎵 记忆口诀：「我你他她它（I/you/he/she/it），单数三人要加 s；其他主语用原形，记住 likes 不忘 -s」。

易错 2：do / does 选错（与主语不一致）

错误示例正确做法
Does Rocky likes books?Does Rocky like books?
Do she like mangoes?Does she like mangoes?
Does you like apples?Do you like apples?
🧠 原理归因：「Does 后面必须跟动词原形」；「主语第三人称单数 → does」。学生常犯两类错误：① does 后忘了把动词原形改成原形（仍写 likes）；② 主语是第三人称单数却写了 do。两者均为「主语–助动词」镜像关系未内化。
🎵 记忆口诀：「Does 助动词，动词回原形；主语第三人称单数，do 变成 does」。

易错 3：don't 与 doesn't 混用

错误示例正确做法
He don't like socks.He doesn't like socks.
She doesn't likes books.She doesn't like books.
Cameron don't like bread.Cameron doesn't like bread.
🧠 原理归因：否定式中 don't / doesn't 的选择完全镜像 do / does 的选择——主语决定。学生若把 do/does 规则学透了，don't/doesn't 自动跟上；反之亦成立。
🎵 记忆口诀：「don't 是 do 的否定，doesn't 是 does 的否定；看主语，定助词，don't/doesn't 自动选对」。

易错 4：some / any 用错

场景正确错误
礼貌请求 Can I have…Can I have some apples?Can I have any apples? ❌
礼貌提供 Would you like…Would you like some juice?Would you like any juice? ❌
否定句I don't have any apples.I don't have some apples. ❌
一般疑问句Do you have any apples?Do you have some apples?（勉强可，期望 any）
🧠 原理归因：「some 用于肯定句与礼貌请求（Can I / Would you）；any 用于否定与一般疑问」。一年级重点掌握礼貌句用 some，暂不深入一般疑问的 some/any 之争。

易错 5：可数名词漏加 -s / 不可数名词错加 -s

错误示例正确做法类别
I like mango.I like mangoes.mango 可数，多个加 -es
Some waters, please.Some water, please.water 不可数，无复数
Two breads.Two loaves of bread. / Some bread.bread 不可数
Some rice. ✅—rice 不可数（正确）
🧠 原理归因：英语区分可数（countable）与不可数（uncountable）。食物中水果 / 蛋糕 / 汉堡 / 鸡蛋可数；水 / 果汁 / 米饭 / 面包 / 巧克力不可数。一年级最易踩坑：「a bread / a water」是不存在的。
🎵 记忆口诀：「液体粉末谷物不可数，水米果汁巧克力；水果蛋糕汉堡鸡蛋可数，a piece of 表小份」。

易错 6：阅读中代词还原失误

原句错误还原正确还原
「The birds come near. They fly away.」The birds fly away.（仅看 they 直接译）✅此处答案正确，是学生常丢分的情况是 they 指代混淆到 Tom & Lily
「Tom and Lily plan a picnic. They pack sandwiches…」The birds pack…Tom and Lily pack sandwiches（they 向前找最近复数名词）
「Lucy enjoys sweet mangoes. She likes them.」Tom likes them.She = Lucy（向前找最近女性单数）
🧠 原理归因：阅读理解时遇到 they / she / he 必须回溯上一句甚至上两句找最近同集合名词；不能只看代词本身。
🎵 阅读三字诀：「指代词，向前找；同性同数才对号」。

六、薄弱环节专项突破

🎯 推断薄弱环节（基于孩子「中等偏上 85 分 + 视觉型学习者」）
  1. 第一梯队（高频出错，天天练）：主语第三人称单数漏加 -s / don't 与 doesn't 混用 / does 后漏原形

第一梯队 · 天天练

薄弱 1：主谓一致（likes / doesn't / does）

🧠 原理层面突破：把主语想象成「角色」，动词形式是「角色的口头禅」。单数三人称（he/she/it/Rocky/the cat…）是「独立的个体」，他的口头禅要「加 s 显得正式」；其他人是「我们/你们/他们」，口头禅保留原形。
📌 口诀：「独立个体（他她它）加 s，群体你我他们原形走；选 does 必还原，选 do 必直说」。

练习：每天 5 分钟「主谓一致填空 5 道」+ 家长口述判断题 5 道。

薄弱 2：don't / doesn't 选择

🧠 原理层面突破：don't / doesn't 与 do / does 是「同一颗硬币的两面」。三步判断：① 找主语；② 定单复数（决定用 do 还是 does）；③ 否定时直接把 do/does 换成 don't/doesn't。动词一律原形。
📌 口诀：「想否定，先找主语 → do/does 不离口 → 否定直接换 don't/doesn't」。

练习：每天 5 分钟「否定句填空 5 道」+ 「改错 3 道」（找 -s 错配 / don't 错配）。

第二梯队 · 隔天练

薄弱 3：some / any 用法

🧠 原理层面突破：「礼貌请求用 some，否定 + 一般疑问用 any」。一年级只锁定礼貌请求一定用 some：Can I have some…? / Would you like some…? —— 不用考虑是否还有其他场景。
📌 口诀：「礼貌请求固定 some，否定疑问才换 any；Can I / Would you 提前 some 已就位」。

练习：隔天 3 分钟「补全礼貌请求 3 道」+ 「判断正误 5 道」。

薄弱 4：阅读指代还原

🧠 原理层面突破：阅读代词 they / she / he 时不要「翻译」，要「回溯」。在文中画箭头，从代词向前指到最近同集合名词。
📌 口诀：「指代词，向前找；同性同数才对号」。

练习：隔天 5 分钟「指代还原 2 道 + 5W 提取 3 道」——直接用本报告阅读理解的 The Friendly Family / Happy Animals 两篇短文。

🆕 原理层面突破策略汇总

🧠 突破方法论（不仅说"怎么做"，还说"为什么这样做"）
  1. 主谓一致：源于英语「主语突出」语言学特征——动词必须随主语变化以避免歧义；中文「主题突出」无此约束。
  2. don't / doesn't：英语否定必须有助动词（do/does）来「扛住」否定词（not）；中文直接在动词前加「不」即可。这是英语「操作链语法」的体现。
  3. some / any：源于「礼貌语用原则」——some 给受话人「即将得到」的预期（积极预设），any 则表示「是否真的存在」的不确定性（中性 / 否定预设）。礼貌请求场景下用 some，给听话人积极心理预期。
  4. 指代还原：英语避免重复的文体偏好——同一名词反复出现会让文本笨重，故用代词替代。这与中文也类似，但英语代词密度更高。

📝 主栏 · 笔记正文

易错 1 · likes 漏 s：错误示例 She like cake → 正确 She likes cake。原理：she 是第三人称单数，动词必须加 s。中文「她喜欢」无词形变化干扰。

易错 2 · does 后漏原形：错误示例 Does Rocky likes books? → 正确 Does Rocky like books?。原理：助动词 does 已经「扛住」第三人称单数，后面的实义动词必须还原原形。

易错 3 · don't/doesn't 选错：错误示例 He don't like socks → 正确 He doesn't like socks。原理：don't/doesn't 与 do/does 完全镜像——主语决定。

易错 4 · some/any 错位：错误示例 Can I have any water? → 正确 Can I have some water?。原理：礼貌请求固定 some；否定/一般疑问用 any。

易错 5 · 可数/不可数混用：错误示例 Some waters → 正确 Some water。原理：water 不可数，永远单数；想表达「一杯水」用 a glass of water。

易错 6 · 指代还原失误：错误示例 把 "Tom and Lily plan a picnic. They pack sandwiches…" 的 they 还原成 the birds。原理：they 必须向前找最近同集合名词短语，而不是「就近」或「字面」。

📌 综合举例：一个学生常错的填空 Cameron ___ (like) bread. → 不假思索填 like ❌，应为 likes——这就是易错 1 的典型踩坑。

原理层面突破策略（理解「为什么」）：

  1. 主谓一致源于英语「主语突出」语言学特征——动词随主语变化以避免歧义。
  2. don't/doesn't 源于英语「操作链语法」——必须有助动词来「扛住」not。
  3. some/any 源于「礼貌语用原则」——some 给受话人「即将得到」的积极预设。
  4. 指代还原源于英语「避免重复」的文体偏好——代词密度比中文高。

十七、学习小贴士 + 归属权声明

📚 5 条原理学习建议

  1. 「为什么」比「是什么」更重要：每个语法规则不仅要会背，更要理解其语用逻辑——为什么英语要加 -s？因为主语突出；为什么用 some 因为礼貌预设。理解底层逻辑的孩子不会忘。
  2. 生活场景 = 练习场：餐桌、超市、厨房都是「真实英语场」。每天三餐时用本单元 5 句核心句模板练 1 次（如妈妈：Would you like some rice? → 孩子：Yes, please.），比纯刷题有效 3 倍。
  3. 口诀要「声形并茂」：背口诀时配上手势——「独立个体（他她它）加 s」用手指比 1；「don't 换 does」时左右手互拍。这样口诀上口不易忘。
  4. 错题本 = 进步阶梯：每次错题归到 6 类之一，月底复盘哪类错最多 → 重点突击。错题本不是负担，是「量身定制的复习指南」。
  5. 康奈尔笔记 = 主动回忆：复习时必须「先遮住主栏、看线索栏回忆」——这叫主动回忆（检索练习），效果是被动阅读的 3 倍。每周末 5 分钟做 1 次。
