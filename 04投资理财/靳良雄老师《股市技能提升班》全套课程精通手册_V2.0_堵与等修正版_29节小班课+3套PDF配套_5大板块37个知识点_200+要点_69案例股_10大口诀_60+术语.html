第一板块：9式技术体系

靳良雄老师独创的9式操盘技术体系，涵盖龙头优选、演化路径研判、波次确认、买卖标准、禁忌买入等核心内容

1.2 9式的性质判断——建仓还是启动

两个运行最高级的概念：

1. 趋势的最高级形态 = 5日线推升可以不涨停，慢慢沿5日线推，突破新高

2. 9式（连板）= 趋势的最高级形态它必然在5日线以上，但它以连板的形式出现，是趋势的最高级

9式在运行周期中的两种位置同一个9式（如两板或三板），在不同的位置有不同的含义：

  • 行情的起点（起于9式）：底部区域的9式——要么是建仓，要么是强势启动
  • 行情的终点（终于9式/死于首板）：高位末端的9式——拉高变现的结构

判断9式性质的核心问题：面对任何进9式的股票，首先要问：这两个涨停是什么性质？是主力拉高变现的位置，还是建仓的位置？

判断方法：看位置和前面的结构。如果9式出现在长期下跌后的底部（坑里面），位置不高 → 可能是建仓或启动；如果9式出现在连续上涨后的高位 → 可能是末端变现。

"9式是趋势的最高级，趋势里面5日线是最高级。我们首先就要了解...9式是趋势的最高级，这是两个演化形态"

1.3 核心概念"未变现"——选股的根本逻辑

"未变现"的定义"未变现"是指主力还没有在高位出货兑现利润，股价还没有经过主升浪的大幅拉升。这是整个9式和波段选股的最核心逻辑。

"变现"的衡量标准：主力赚了多少。主力如果只赚了十几个点，就不是变现。因为"如果主力有建仓的话，你说主力是不是只赚十几个点？肯定不是。"

未变现的两种分析路径（不论哪一种，结论一致）：

路径一假设前端有主力锁仓 → 两板是主力拉高（但仍然处于底部坑内，位置不高）→ 没赚多少钱 → 未变现

路径二假设前端没有主力锁仓 → 两板是主力在底部突击建仓 → 建仓就是买进去，成本就在附近 → 未变现

"未变现 + 三条路 = 必须跟踪"一旦确定"未变现"，无论主力选择哪种后续路径（99拉高、969洗盘再拉、96三天再拉），最终目标都是一样的——"变现必须拉高"。

至于怎么有，主力说了算，用K线的开盘价像摇骰子一样，怎么开？反正最终要实现变现，变现必须拉高。至于是99拉、969以后再拉，还是96以后再拉，那是它的选择方式，我们只需要跟就可以了。

"未变现 = 必须重点跟踪" · "9式强起必有二波" · "变现必须拉高"

1.4 9式强势启动（9式强启）的完整识别

9式强启的完整定义9式强势启动（9式强启）是指：股票前端有明确的主力建仓轨迹，经过洗盘后，用两板或三板的9式形态强势突破，直接进入主升浪拉升阶段。

前端建仓暴力洗盘以后再暴力突破进9式，这就是9式强势启动，趋势掩护的最高级，9式强势启动。起行情，起主升浪，我们可以叫9式强启。(出自第104-105段)

9式强启的四个识别要素：

  1. 前端有建仓（必须有"根"）：前面可以看到主力建仓的轨迹——双K筑底、涨停板建仓、单边推升等
  2. 洗盘：建仓后经过明显的洗盘——暴跌、横盘震荡、单阴洗盘等
  3. 进9式的位置不高：两板/三板刚刚突破底部平台或脱离成本区，不是高位
  4. 未变现：主力还没有赚到足够的钱，不具备出货条件

案例：浙江世宝 —— 前端有建仓（双K做建仓、涨停板建仓）→ 洗盘（跌下来量都没有）→ 一字板突破平台 → 高开一板脱离成本区 → 两板进9式。这里"不是建仓了，而是在前端建仓，后端洗盘，就是强势启动主升浪。"

9式强启与龙头的关系如果9式强启的股所处的板块同时启动，那么这个股就可能成为板块的龙头。"特别是在新龙头和旧龙头交替的时候出来的。"

核心结论："所有9式强势启动的股，统统是主力资金建仓，统统是主力建仓，主力运作的。全部是主力运作的。这样的股才大有可为，它就是进9式的趋势的最高级形态。它就容易连板，要不然连板不了。"

1.5 9式建仓与9式强启的本质区别

9式建仓的定义与特征：

9式建仓是指：前端没有明显的主力建仓轨迹，直接在底部出现两板/三板进9式——"前面一路下跌，底部区域你没有看见前面有建仓。这就是9式建仓。"

"用9式建仓，有的是首板一个涨停建仓，叫单K激活盘面。K一手板建仓，这个就是用三板建仓，两板建仓，进9式建仓。"

9式建仓 = 强力吃货，"9式建仓就是强力吃货"。后面还需要横盘震荡洗盘（如969形态），再用一波拉升来实现变现。

9式强启的定义与特征：

9式强启（强势启动）是指：前端有明确的建仓，已经完成了建仓和洗盘两个阶段，用9式形态直接启动主升浪。

"9式强启前面必须有根。什么叫根？必须有主力运作，有前面建仓。"

两者的核心区别：

维度9式建仓9式强启
前端建仓无——看不到建仓轨迹有——可以看到明确建仓轨迹
9式的性质建仓行为（吃货）启动行为（拉升）
后续走势需横盘震荡/洗盘后才拉升直接进主升浪/连续拉升
走势特征969横盘后再拉直接99或强势推升
识别方法在底部坑里突然连板前端有建仓+洗盘+突破

共同的结论：都要重点跟踪。不论9式建仓还是9式强启，只要在底部区域且没有变现——都是要重点跟踪的股。唯一的区别是：强启可以直接做，建仓需要等待结构演化（双K、969等）。

1.6 换手日先手操作——条件与原则

先手的定义"先手"是指在9式连板后的换手日（第三板或第四板）提前介入一部分仓位，获取先发优势。在传统课程中，换手日是"只能卖不能买"的——但本节课揭示了例外情况。

先手的两个必要条件（缺一不可）：

  1. 未变现9式：必须在底部低位的未变现区域，"最好是主力建仓、前端建仓。你要确定这两板前面是建仓，后面是想强势突破想做上去的。"主力还没赚钱，换手日进去风险可控
  2. 开盘条件：低开或平开，开盘不多，"然后顺势走强可以做先手"。如果高开五六个点以上，"就要注意了，不要随便去做"

绝对不能做先手的情况：高位换手绝对不能做先手。"只要是在高位换手，不要轻易做，因为在高位随时可以变现。高位最高级的9式是慢慢推上去以后进9式，那换手日不要随便去搞，人家可以随时砸下来的，因为可以变现，所以有不确定性。"

先手的操作原则：仓位要轻，"不要重仓位，要轻一点"；真正的重仓买点是换手之后的确认点（高开或强势分时）；先手只是"提前拿一点"，目的是不踏空；分时要观察弹性和强势特征。

换手板的概念"换手板就是在换手日那天涨停"的K线。在做先手的换手日中，如果当天最终涨停，就是换手板——这是最强的情况。

分时弹性的判断：在换手日做先手时，关键要看分时的"弹性"——弱的分时特征："死气沉沉的弱势分时，没有量，被打死了，没人来了"——不能做；强的分时特征："有弹性非常好，就有资金在底部拿筹码，打下来以后快速拉，再下来又又来。弹性好，就是有资金接盘踊跃"——可以考虑做先手。"没有弹性分时先不做，没有强势分时也可以不做换手日。"

1.7 9式的前世今生——从"根"看未来

"根"的概念"9式强启前面必须有根。什么叫根？必须有主力运作，有前面建仓。"

"根"就是9式出现之前的主力建仓轨迹——这是9式之"因"，9式是"果"。没有"因"的9式（前端没有建仓），那是"9式建仓"而非"9式强启"。

"挖前世今生"——分析主力轨迹的方法：面对任何一只进9式的股票，要像侦探一样追溯它的历史K线：

  1. 找到前端是否有主力建仓——看是否有双K筑底、涨停板建仓、单边推升、连续阳线等
  2. 确定建仓后是否有洗盘——看是否暴跌、横盘缩量、单阴洗盘
  3. 判断洗盘后在什么位置进9式——是低位突破还是高位末端
  4. 用一根线画高点——判断主力盈利了多少、有没有变现

"找这个主力的前世今生，挖它的祖宗十八代，你要把这个一字板和这个涨停高开放在这个位置。"

"一线定高点"方法简单划线法：在前端建仓的最高点画一条水平线。如果9式出现的位置在这条线附近（没有大幅高于它），说明主力没有多少盈利空间——未变现。

各种走势的贯通理解：老师强调：不管形态怎么变，原理不变。连续的阳线可以看成一个"大阳线"=建仓行为。阴线后面的高开可以看成是双K=止跌确认。一切变形都可以归结到"有因有果"的逻辑中去。

"连续的阳线底部跌下来的，我们说如果是涨停板阴线后面高开是不是双K？这一串阳线其实也是主力在建仓，也是一个K1的样子。那么后面阴线是不是K2？高开直接买。所以我们的双K妙在什么地方？标准没有什么的，全是有因有果。"

"双K实际上它是有因有果的，一个关系，而且最重要它是一个强势特征" · "掌握因果逻辑比记住形态更重要"

1.8 9式末端——终结于9式与性价比判断

终于9式的定义"终于9式"是指在行情的高位末端，经过多轮上涨后，最后一次进9式——这次进9式就是终结行情，准备出货变现。

终于9式的识别要点：

  1. 位置高：经过前面多轮拉升后
  2. 前端有变现过的痕迹：主力已经赚了足够多的钱
  3. 突破前高后在远端进9式：不是第一次出现9式

案例：西部材料 —— "这个9式在什么地方？这是末端进9式。这是起点，这是9式的末端进末端了？变现注意了，这种地方就是进入9式的变现结构，就是终于9式。要注意了，再搞符合标准你都要清仓了。"

性价比的根本差异："要注意一点，加速末端进9式，要注意性价比的问题。前面低位的时候和高位的时候，这两个点的性价比是不一样的，风险收益比是完全不同的。"在底部9式做多，收益远大于风险；在高位末端9式做多，风险远大于收益。即使技术形态都符合标准，在高位末端"你都要清仓了"

1. 趋势是最高级运行结构："趋势是一个个股运行的最高级形式。这句话的含金量在于：它已经告别了波段震荡，告别了震荡，已经进入最高级的运行结构。"

1.11 底部量能识别——新资金 vs 老资金（原教材漏掉，关键知识点）

核心问题：进9式后底部区域的涨停板，背后资金的属性决定操作策略。判断标准不是看成交量，而是看换手率。

两大量能模型对比：

量能特征资金属性操作策略风险评估
底部高换手率（如20%）新资金抄底重仓、满仓做双K，闭着眼睛买老资金可能继续砸盘
底部低换手率（2-3%）+有涨停板老主力拉升闭着眼睛打二板，最优选择老主力不会自己砸自己
底部低换手率+无涨停老资金未启动不埋伏效率低，不知何时涨

优选策略：尽量选老资金做盘的股。逻辑：老资金自己不会砸自己，新资金做盘的搞不好老资金继续砸。

效率原则：

4.1 分时总分类与强势/弱势定义

分时总分类强势分时（承接/锁仓）+ 弱势分时（贯穿/拦截/弹性/可抄底）

强势分时：3根以上连续放量的分钟柱 = 有资金在主动进攻

弱势分时：连续放量下杀/单根绿柱 = 有资金在主动出货

分时三原理（总纲）：分时必须服从于结构 / 配双K / 值得买的股才用

分时和双K绝对不能用的三类情况：下跌途中 / 高位横盘区间 / 没有K1涨停的波段

分时使用边界：

  • 分时定位：基础功力，服从结构大局
  • 分时的两个核心用途：买时看分时 / 卖时看分时
  • 分时与双K配的下一步：配上结构大局 = 三合一打击

4.2 八种分时形态详解

1. 强势分时（扫射状）：连续多根量线，资金源源不断 = 攻击性最强。"机关枪一样连续发子弹"

2. 强势分时（点射状）：单根爆发，后继无量 = 上行封闭（涨不动）

3. 锁仓分时：开盘量很小+温和放量+股价慢慢推 = 抛压极轻。底层逻辑：109亿资金抛压 vs 5000万推动 = 锁仓

4. 贯穿分时：陡峭快拉，贯穿期间不能追只能抄底。连续做多动能 = 引路 = 为未来行情指引方向

5. 拦截分时：高开+单根绿柱弱势特征+股价不跌 = 高空拦截 = 大资金以相同价位瞬间接住

6. 承接分时：每次下跌都有买单接住。公式：最大恐慌筹码 = 前一天成交金额×10%~15%承接判断标准：看开盘前三笔

7. 弹性分时：V型反转，速度+高度。挨了一拳反弹速度和力度

8. 可抄底分时：强势分时扫射+回落 = 可抄底

"双K找位置，分时找时机" · "强势分时扫射型去干" · "分时必须服从于结构"

4.3 恐慌盘公式与承接/拦截/锁仓

恐慌盘计算公式最大恐慌盘 = 前一天成交量 × 10-15%

这是判断承接/拦截是否成立的核心量化工具。

承接分时案例：前日7.6亿 → 最大恐慌盘8000万-1.2亿 → 开盘两笔2.1亿承接 = 恐慌盘被消化 = 一致性形成

拦截分时案例：前日21亿 → 2亿 → 两笔4亿承接

锁仓分时判定：354亿区间筹码 → 35亿恐慌盘 → 4根线2亿就拉上去 = 锁仓明显

承接与拦截的区别：承接看接住（被动），拦截看主动拦阻力

锁仓分时的加仓信号：低开5日线 + 锁仓分时 = K3买点

4.4 上行封闭与下行封闭

上行封闭高开+点射+后续无量+绿柱 = 涨不动（今天高点）

拉伸缩量+放量下跌+反抽无量 = 高点已出现 = 做T卖出

下行封闭弱势+点射+无续量 = 跌不动（今天低点）

弱势分时连续放量下杀 → 最后一笔单释放后不跟量 = 跌不动 → 即将震荡止跌或反弹

量能预判：昨天量-今天已放量 = 还要放出来的量 = 涨的量

振幅预判：前三天平均振幅10% → 涨5个点就封闭 = 下面还有5个点

"点射状分时与上行封闭"强势分时+点射=上行封闭；弱势分时+点射=下行封闭
