模块 1

📖 宏观大势与四季轮动（小白第一课）

📚 对应原课程：第1节 春夏秋冬 · 第3节 时代机遇 · 第4节 黑马基因 · 第5节 大盘研判

🎯 学习目标：建立股市底层世界观——理解A股不是全面大牛市，而是结构性行情；学会从时代、行业、政策三个维度锁定大方向。

一、先因后果定律（股市永恒定律）

建仓 → 拉高 → 获利兑现 → 下跌，循环不变；无因无果（无涨停基因=无强势行情）。
  • 个股 24 小时都在轮动——任何一只股票都遵循这个周期，没有例外
  • 无涨停基因无强势行情——没有涨停板的股票不值得参与
  • 三大轮动：①经济大周期（2007/5178全面大牛→当前结构性调整）；②主流行业大周期（地产→新能源→AI）；③行业内个股小周期

二、当前A股定性：结构性行情

💡 关键认知转变：当前不是全面大牛市，是结构性行情。指数可能横盘甚至下跌，但行业/个股可能涨10倍（如19年新能源、23年AI）。抛弃"看大盘点位炒个股"的传统思维！
  • 结构性行情定义：经济结构性调整阶段=行业内外大轮动
  • 传统vs科技板块：传统板块（酒/医药/资源/银行/地产/家电）=中长线价值；科技板块（芯片/AI/新能源/汽车/军工/通讯/AR）=中线活跃+弹性大+政策多
  • 当前行情性质：360年线=牛熊分界线（一年等一回）；结构性弱势震荡行情（无系统性风险/无大行情）

三、黑马土壤基因（找黑马先找土壤）

黑马基因 = 时代大背景 + 行业属性 + 战略政策（三要素缺一不可）
  • 科技行业6大特点（孕育黑马的土壤）：①历史性科技大变革 ②全球竞争 ③支柱产业 ④广泛大市场 ⑤产业资本大量进入 ⑥能容纳大量资金
  • 未来方向清单：无人驾驶/核聚变/元宇宙/AI/脑机接口/万物互联/生物工程
  • 聪明资金先知先觉：看到PDF-B的智能机器人/智能自动化等行业提示

四、大盘研判：360年线定牛熊

  • 360年线（年线）=牛熊分界（上方=多头，下方=空头），一年等一回
  • 5/10/30/60/120/360多头盘列顺序一根都不能错
  • 战略资金分散与集中度决定中长期：全行业集中=全面大牛市，行业内集中=板块牛市
    • ⚠️ 小白核心认知：进入股市前，先问自己三个问题——是不是结构性行情？我选的行业是否符合时代？是不是有政策支持？想清楚再下手。
    模块 2

    📖 板块研究方法论（如何选对方向）

    📚 对应原课程：第6节 主流板块行业属性 · 第7节 6大核心维度 · 第26节 战略性大级别行情

    🎯 学习目标：掌握板块研究的核心方法——会看板块所处阶段、判断板块行情级别、把握板块切换时机。

    一、主流板块三种状态

    状态特征对应行情
    一致性集体建仓板块内多只龙头同步建仓，资金统一部署大级别长周期（19年新能源/23年AI涨10倍）
    分化与内部一致性板块内部分龙头独立上涨（如AI中际旭创/新易盛 vs 昆仑万维）行业性行情（中等级别）
    非主流板块无集体建仓，仅个别游资炒作交易性行情（不考虑）

    二、6大核心维度（板块轮动研判）

    一致性 + 分化 + 非主流 + 资金性质 + 新旧结构级别 + 政策与重大事件 = 共振
    1. 一致性维度：板块多只个股同步启动=大级别；分化=行业性；非主流=不考虑
    2. 资金性质维度：传统=中长线价值；科技=中线活跃
    3. 新旧结构级别维度：新旧板块核心个股结构级别=切换信号
    4. 政策催化维度：战略政策（央企36领域/40家央企/52个原创技术策源地）是孕育黑马的关键；行业顶部政策利空=真正见顶；行业底部政策利好=真正见底
    5. 估值水平维度：不符合时代=估值再低也贵；符合时代=估值再贵也合理中段
    6. 消息面维度：政策接力+板块接力=切换时点

    三、新旧板块轮动4要素

    ⚠️ 4要素必须同步，缺一不可：①准确研判顶底性质 + ②分析个股演化阶段 + ③行业政策催化 + ④准确研判时间
    ⚠️ 小白易错：板块指数失真，必须看核心个股（PDF-A P4-5）。传统板块耐心持股做底仓，科技板块快进快出结合热点。
    模块 3

    📖 三大资金性质识别（看盘的灵魂）

    📚 对应原课程：第9节 三大资金性质 · 第10节 主力强弱与做盘紧迫性

    🎯 学习目标：资金是看盘的灵魂——3大资金性质决定可执行盈利模式。学会用"换手率+市值+涨停板数量"三要素公式识别资金性质。

    一、三要素识别公式

    换手率 + 市值 + 涨停板数量 = 锁定资金性质
    资金性质换手率市值涨停板口诀
    游资 > 20% < 50亿 ≥ 3板 严守5日线 · 9式涨停阵
    主力 < 10% 50-100亿 ≤ 3板 完整轨迹 · 2-8月建仓
    战略 ≤ 5% ≥ 500亿 少涨停 1年+建仓 · 5倍涨幅

    二、游资（紫）— 短平快

    • 资金量级：几千万到几亿
    • 操作风格：时间短、行情快、暴涨暴跌、不涨停非龙头
    • K线特征：高开迅速拉涨停+大振幅阴线+一字板/十字星
    • 操盘周期：几天-几周；顶部形成1-2天（最快）
    • 均线看什么：只看5日线，其他均线无效
    游资看5日线；不涨停就不是龙头；9式连续涨停

    三、主力资金（蓝）— 中长线代表

    • 资金量级：10亿-100亿
    • 操作风格：隐蔽建仓/突击涨停建仓+最完整轨迹（建仓→震荡→洗盘→突破→拉升）
    • K线特征：少涨停+沿5日/10日线推升+缩量止跌+大振幅止跌
    • 操盘周期：建仓2-8个月；上涨15天-3个月；涨幅≥1倍
    • 涨停基因上限3板：主力吃货超过3板就归游资
    强势主力三维度 = 建仓强度 + 控盘强度 + 紧迫性（3天之内必须涨）

    四、战略资金（绿）— 顶级玩家

    • 资金量级：百亿-千亿+（机构、社保、公募）
    • 操作风格：建仓形式=单日涨停（最强）或连续大阳线（次强）；少涨停+持续性长+每天都有覆盖但沿5/10日线推升+小波段调整
    • 操盘周期：建仓6-12月甚至8月-1年；上涨9-15个月甚至1年+；涨幅≥2倍（全行业布局≥5倍）
    • 重要认知：战略资金可以跌破成本≠拉高出货（建仓期洗盘）
    战略资金 = 先知先觉；运作越成熟，成长空间越大

    五、不同资金的买卖逻辑

    资金买点卖点
    游资 5日线 + 分时强势吃货 + 一次性重仓 破5日线 + 顶部1-2天
    主力 缩量止跌 + 大振幅 + 涨停建仓 + 大阳 放量滞涨 + 缩量上涨 + 低开低走
    战略 60/120/360日线支撑 + 大阳止跌 + 战略资金布局确认 加速大阳 + K线覆盖 + 缩量 = 顶部预警
    💡 小白核心认知：看一只股票，先看三要素判断是什么资金，再决定用什么策略。游资快进快出，主力波段持有，战略资金长线锁仓。
    模块 4

    📖 均线与K线核心技术（基础工具）

    📚 对应原课程：第8节 级别与结构 · 第11节 均线 · 第12节 K线振幅 · 第13节 顶底确认

    🎯 学习目标：掌握均线+K线的核心应用口诀，学会用"9宫格定位"判断个股所处阶段。

    一、均线核心口诀（资金决定均线）

    ⚠️ 核心认知：均线有效性取决于资金性质！游资看5日线（其他均线无效）；主力/战略看360年线+日+周+月（最有效）。
    均线粘 = 变盘；均线散 = 主升；均线多头 = 大牛必经之路
    均线意义口诀
    360年线牛熊分界一年等一回
    60日线多头调整极限半年等一回
    30日线中长线主力下限中长线生命线
    20日线推升线波段操作参考
    10日线波段买点强势回调买点
    5日线高速跑道加速单边+游资唯一均线
    💡 5/10/30/60/120/360多头盘列顺序一根都不能错；完全发散 = 主升浪正式启动。

    二、级别与结构 9宫格定位

    3种结构 × 3种级别 = 9宫格定位个股阶段

    结构\级别初级（种子）中级（开花）高阶（结果）
    牛市年线下方震荡突破年线试盘沿5日线加速
    熊市破年线下行中级反弹末期诱多
    结构市底部区域震荡向上主升加速

    三、K线核心：振幅封闭锁定

    • 5类基础K线：涨停板、大阳线、十字星、上下影线、一字板
    • 涨停K两种分时：①开盘后高开迅速拉升（最强）；②放量一波再放量一波直到涨停（吃货分时）
    • 跌停K两种情形：①上行空间封闭=顶部风险；②下行空间封闭=跌停板附近抄底（1-2%风险博反弹）
    • K线覆盖：相邻K线重叠 = 力量转变信号
    • -8%阴线次日：高开跟进 / 低开警惕
    K线越长，振幅越大，攻击性越强；高开=强势；低开=弱势（除吃货分时例外）

    四、顶底高效确认

    主力3顶3底

    主力顶主力底
    放量滞涨顶缩量止跌底
    缩量上涨顶单阳止跌（金针探底）
    低开低走顶双线止跌（双阳探底）

    战略3顶2底

    战略顶战略底
    高位缩量顶缩量底
    单阳后下跌顶连阳底
    M顶—
    游资看5日线；缩量上涨是诱多；放量滞涨是出货；金针探底是买点；历史大顶要清仓；历史大底敢加仓；第三波是顶部；结构性顶后还新高
    模块 5

    📖 成交量+分时技术（验证主力意图）

    📚 对应原课程：第14节 主力意图验证 · 第15节 量价换手率 · 第16节 分时技术

    🎯 学习目标：学会用"4维验证"判断主力真实意图，避免被诱多诱空欺骗。

    一、主力意图验证 4维同步（最重要！）

    4维同步才执行：①连续2日K线+振幅 ②运行结构和级别 ③成交量和换手率 ④分时走势
    💡 这是整个课程最核心的操作纪律。三大资金的确认时间差异：游资1-2天 + 主力稍慢 + 战略最长（按资金性质留出观察期）。第一买点=重仓买点=4维验证通过+底部区域+互相验证。

    二、量价核心口诀

    上涨带量 + 调整缩量 = 主力无出货迹象 = 健康
    形态含义对策
    缩量上涨 + 放量滞涨诱多（骗进来）不追高
    放量上涨 + 缩量下跌诱空（洗出去）坚定持有
    放量突破高点健康跟进
    缩量上涨不健康警惕
    ⚠️ 主力出货换手 = 建仓期3倍以上；战略出货成交量 = 建仓期5倍以上（核心识别标准）

    三、换手率三档应用

    • 游资建仓双场景：①低位小换手吃货（最健康）；②高位大换手持货（警惕）
    • T字板/一字板：低位突击建仓 = 最健康吃货
    • 换手点不做买入；等缩量+高开带量涨停 = 第二波分水岭

    四、分时3大作用

    1. 判定主力计划性
    2. 买卖点位（如何做T）
    3. 分时强弱互转（吃货还是出货）

    五、4维分时分析

    维度要点
    量的大小和持续性持续放量 = 真攻；脉冲式 = 诱多
    量价时间10点前涨停最强；尾盘涨停=做盘建仓；下午秒板=突击热点刺激
    价的斜率陡峭拉升=主力；缓慢爬升=跟风
    量价配比价涨量增=健康；价涨量缩=虚涨

    六、分时典型形态

    • 高开放量下打 = 出货分时
    • 跌停板开盘迅速放量拉高 = 强势吃货
    • 上午涨停 = 主力
    • 下午涨停 = 战略/游资偏弱
    分时线必须看——低打就买，拉高就卖；向上冲击取利润，向下封闭堵风险
    ⚠️ 小白禁区：涨5%追高后跌2%当日浮亏7% = 禁止追高！必须等分时回踩+4维同步验证后再介入。
    模块 6 ⭐

    📖 三大盈利模式（操作技术核心）

    📚 对应原课程：第17-23节（7节连讲）

    🎯 学习目标：掌握"出手见红/卧薪尝胆/一骑绝尘"三大盈利模式，匹配对应资金性质，形成完整的操作技术。

    ① 出手见红·超短线（游资专属）

    超短线只买阴，不到振幅不撒鹰（准确率目标 ≥ 75%）
    • 严守5日线：破5日线即清仓
    • 5种模式：底部横盘放量 / 次高位横盘 / 突发异动攻击 / 大波段背景超短线 / 单边行情超短线
    • 阴线买入+ 分时均线加仓 + 振幅≥5%
    • 操作要点：分批半仓 + 滚动T+0 + 短线卖出三条件（振幅/盈利/时间三选一）
    • 典型案例：A陕国投 / B罗平锌电 / C嘉麟杰 / D浙江世宝 / E天赐材料

    ② 卧薪尝胆·大波段（主力专属）

    大波段善蹲坑，不到跌幅不进坑（准确率目标 ≥ 70%）
    • 底部做大顶部做小——核心仓位管理原则
    • 跌幅20-30%相对底部= 极限位买入
    • 5步仓位：首次六成以上 + 滞涨卖1/4 + 止跌买半仓 + 趋势确立满仓 + 压力位半仓 + 高位全清
    • 3类成功模式：①主力突击暴力介入（突破360年线）；②大波段运作主力（摩登大道涨87%跌38%）；③主力介入+大波动结合（中南建设）
    • 5类买点：连续阳线止跌 / 大振幅止跌 / 大阳线止跌 / 涨停板分时上拉 / 高开分时往上打
    • 大波段卖出两点：动态验证 + 技术压力位

    ③ 一骑绝尘·主升浪（战略专属）

    主升浪等起暴，不到突破不能跳（准确率目标 ≥ 60%）
    • 5字诀仓位管理：底部重仓 + 右侧加仓 + 启动满仓 + 拉高调仓 + 顶部清仓
    • 4类形态：空头市场主升浪（中国软件）/ 60日均线主升浪（山东黄金）/ 360年线主升浪（浦东金桥）/ 单边形态主升浪（科恒股份）
    • 主升浪8大维度：①主力布局 ②完整轨迹 ③结构级别 ④均线完全多头 ⑤运作时间 ⑥异动 ⑦事件政策 ⑧板块轮动共振
    • 主升浪时间空间规律：突击建仓2个月+控盘区1倍；单日涨停/推升6个月以上+控盘区2倍以上

    一、战略资金双启动点（最重要）

    启动点位置信号意义
    起点（左侧） 年线下方 底部涨停板 + 连续大阳线 底部建仓信号，超前预判半年到一年
    起涨点（右侧） 年线上方 平台突破 + 均线完全多头 + 放大量 主升浪正式启动，重仓信号
    凡有大级别行情均有长达一年时间左右的运作周期；盘面一般形成三次拉升结构，涨幅在建仓成本5倍以上

    二、战略资金识别标准

    • 三要素：换手率 ≤ 5% + 市值 ≥ 500亿 + 少涨停
    • 时代特征行业：先知先觉 + 布局完成 + 1年+ 上涨
    • 建仓分散与集中度：
      • 分散 = 板块性牛市（行业内集中）
      • 集中（全局） = 全面大牛市
    • 历史案例：2015地产/资源、2021锂电池/光伏、2023芯片/通讯

    三、三轮拉升结构（战略资金典型形态）

    1. 第一轮：初级阶段 → 中级突破（沿60/120日线推升）
    2. 第二轮：中级 → 高级别（沿5日/10日线加速，最大最快）
    3. 第三轮：高级别 → 大顶进入熊市（涨幅小风险大，顶部清仓）
    💡 5日线在战略资金运作中是减仓线——破5日线意味着加速段结束。

    四、战略资金顶部性质

    ⚠️ 结构顶 vs 历史大顶 区别对待：
    • 结构性顶：中级行情波段盘整后回调，单次跌幅 ≤ 30% → 可波段操作
    • 历史大顶：最高阶后大顶，5年一遇，80%股民亏损 → 必须清仓远离，不能抄底

    五、战略性大级别行情结构级别

    结构性风险 中级行情波段盘整回调，单次≤30% 常见 波段操作，20-30%跌幅底部再加仓

    三、5成仓位风控基准

    • 5字诀仓位：底部重仓 + 右侧加仓 + 启动满仓 + 拉高调仓 + 顶部清仓
    • 风控原则：账户有空仓，心中不发慌；大顶空仓 / 底部重仓 / 拉高调仓 / 高位轻仓
    • 硬性纪律：普通投资者不超过3支股票；除大牛市外不要举债操作

    四、8类操作风险（必避）

    1. 追高抄底——5%追高后跌2%当日浮亏7%
    2. 错误止损——破位不止损/未破位乱止损
    3. 高位长期被套——大顶不清仓
    4. 止盈错误——小盈就卖大盈死守
    5. 由盈转亏——赚钱后麻痹大意
    6. 短线中线长线错位——用短线心态做长线/用长线心态做短线
    7. 主力突击拉升追高——异动时冲动
    8. 主力运作周期误判——把游资当主力/把主力当战略

    五、3类操作纪律

    买入前先考虑会亏多少而不是赚多少；卖出时考虑已经赚了多少而不是还能赚多少
    • 止损不看账户看标准——按技术标准止损，不按盈亏
    • 不以盈亏定买卖——盈了不止盈，亏了不止损 = 错
    • 机会只有在风险释放过程中产生——大跌后才有大机会

    三、量价口诀速查

    形态含义对策
    上涨带量 + 调整缩量主力无出货迹象 = 健康坚定持有
    缩量上涨 + 放量滞涨诱多不追高

    放量突破高点健康突破跟进
    缩量上涨不健康警惕
    主力出货换手= 建仓期3倍以上出货信号
    战略出货成交量= 建仓期5倍以上出货信号

    四、K线 + 分时口诀速查

    形态含义
    K线越长，振幅越大攻击性越强
    高开 = 强势低开 = 弱势（吃货分时例外）
    上行空间封闭= 顶部风险（卖）
    下行空间封闭= 1-2%风险博反弹（买）
    K线覆盖= 相邻K线重叠 = 力量转变信号
    -8%阴线次日高开跟进
    -8%阴线次日低开警惕
    高开放量下打= 出货分时
    跌停板开盘迅速放量拉高= 强势吃货
    10点前涨停最强（主力真攻）
    尾盘涨停= 做盘建仓（偏弱）
    下午秒板= 突击热点（游资偏弱）
