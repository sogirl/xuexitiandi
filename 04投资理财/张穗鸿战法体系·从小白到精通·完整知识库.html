01K线基础：技术分析的"细胞"

地基必学不懂 K 线，就不要碰技术分析。单根K线是所有形态、所有指标的最小单位——价格行为本身。先吃透单根K线，再学两根组合，最后看多根形成形态。

1.1 K 线的四元素：开高低收

无论阳线（红）还是阴线（绿），每根 K 线都包含 4 个价格：

开 (Open)
当天第一笔成交价
收 (Close)
当天最后一笔成交价
高 (High)
当天盘中最高成交价
低 (Low)
当天盘中最低成交价
阳线 = 收 > 开（多头占优）   |   阴线 = 收 < 开（空头占优）

中间的"实心矩形"叫实体，表示开收价区间；细线叫影线，表示最高最低价。上下影线是当日多空激烈博弈的"脚印"。

1.2 七阳七阴：14 种基本 K 线

张穗鸿老师把单根 K 线按形态分成 7 种阳线 + 7 种阴线（阴线是阳线的镜像对称）：

名称特征实战含义
光头阳线无上影线，多头一路推升强势，多方完全控盘
光脚阳线无下影线，开盘最低全天上行强势，但尾盘若缩量需警惕
光头光脚大阳无上下影，实体饱满极强势，主升浪信号
大阳线实体涨幅 > 3%主力拉升，趋势确立
中阳线实体涨幅 1%-3%正常上涨
小阳线实体涨幅 < 1%多空僵持，方向不明
穿头破脚阳实体吞没前一根阴线低位 = 强烈买入；高位 = 见顶
十字星开收几乎重合，影线上下都长多空平衡，警惕反转

阴线对偶：大阴、中阴、小阴、穿头破脚阴、光头阴、光脚阴、光头光脚大阴。把上表"涨"换成"跌"即可。

实体 > 7% 叫超大阳线/超大阴线。在黄金市场（一标准手 100 盎司），单日波动 > 30 美金（约 3%）就要高度关注，> 50 美金往往意味着主力行为或重要数据。

这几根 K 线是"反转信号"家族的明星，位置决定性质——同样形态在低位是见底信号，在高位是见顶信号。

1.6 趋势线三剑客：压力、支撑、通道

压力线
多个高点的连线
★ 突破 = 上涨空间打开
支撑线
多个低点的连线
★ 跌破 = 下行空间打开
上升通道
上升趋势线 + 平行压力线
下降通道
下降趋势线 + 平行支撑线
趋势线必须经过 第三个点验证 才有效！随便拉两个点不叫趋势线，叫"自欺欺人"。第三点是市场共识，所有人都认这个位置。
主力反做 (Trap)：散户在支撑位挂买入 + 在下方 3 个点挂止损；主力扫止损 → 抛压释放 → 反手拉升。这是张穗鸿老师反复强调的主力思维模型。不要在支撑位"接飞刀"，要等主力确认拉升后"追涨"。
突破压力线时不要追涨，等回踩（前压力变支撑）确认后再进。老师多轮验证：突破后回踩的 75% 二次进场成功率。

小白常问：K线为什么叫"K"线？ 源于日本江户时代的米市，日语"罫（けい）"意为"区隔划分"，英文写作 K Line。早期香港引入时也称"阴阳线"，台湾叫"蜡烛线"。本质都一样：把一天的开高低收画成一根带尾巴的矩形，让我们一眼看穿多空博弈。
小白常问：黄金 1 标准手 1 个点 = 多少钱？ 黄金 1 盎司变动 1 美元 = 1 个点；1 标准手 = 100 盎司；所以 1 个点 = 100 美金。黄金 952 → 984 = 涨 32 个点 = 1 标准手赚 3200 美金。单日波动 30 美金（约 3%）就要高度关注。

2.2 三重顶 / 三重底：最经典的顶部反转

是什么：3 个大致相同高度的高点 + 2 个大致相同深度的低点组成。形似"M"的升级版，多了一次冲高失败。

为什么有效：3 次冲高都过不去同一价位 → 多头力竭 → 颈线跌破 = 趋势反转。

怎么用：

  1. 3% 容差规则：3 个高点之间误差 ≤ 3%
  2. 颈线 = 2 个低点连线（跌破 = 第一卖出点）
  3. 量度跌幅 = 头部到颈线的垂直距离
  4. 跌破后反抽颈线 = 第二卖出点（绝佳加空机会）
量度跌幅公式：目标价 = 颈线位 − (头部最高 − 颈线位)
2008-3 黄金 1032 → 680 经典三重顶
1032 顶部三个高点 1032 / 1010 / 1030（误差 < 3%）→ 跌破颈线 980 → 量度跌幅 ≈ 350 美金 → 实际跌至 680。这是张穗鸿老师讲三重顶的标准案例：三重顶通常对应基本面的重大转折。

2.3 M 头 / W 底：双重顶底

M 头 (Double Top)
两个等高的高点
★ 跌破颈线 = 下跌开始
★ 量度跌幅 = M 高度
W 底 (Double Bottom)
两个等低的低点
★ 突破颈线 = 上涨开始
★ 量度涨幅 = W 高度
1997-7 黄金 418 → 282：M 头经典案例。
两次冲到 418 都失败 → 跌破颈线 350 → 量度跌幅 136 美金 → 跌至 282。2001-7-10 沪指 2180 也是 M 头，反抽颈线 1840 后跌至 1500。

2.4 喇叭形 (5 点反转)：最难操作的形态

高低点不断扩张，形似喇叭口。看涨情绪越来越疯狂，但已经强弩之末。

  • 喇叭形上轨被跌破 = 见顶信号
  • 喇叭形下轨被突破 = 见底信号
  • 量度跌幅 = 喇叭形高度
喇叭形是最难操作的反转形态。实战必须严格止损，因为扩张形态的"假突破"特别多。

2.5 菱形：喇叭 + 三角的复合体

左侧喇叭形（扩张） + 右侧三角形（收敛）= 菱形。是最复杂的顶部反转形态，通常出现在长期趋势顶部。

  • 量度跌幅 = 头部到颈线距离
  • 跌破颈线 = 卖出；跌破后反抽颈线 = 加空

2.6 旗形：升国旗的哲学

升国旗类比：国旗向上飘扬时因风的力量产生向下压力——任何向上运行的物体（国旗/股价）都会在上升途中遭反向阻力。旗杆 = 急涨段；旗面 = 整理段（向下倾斜）。
类型位置形态突破
上升旗形上升趋势中向下倾斜的矩形突破上沿 = 绝佳买入点
下降旗形下降趋势中向上倾斜的矩形跌破下沿 = 绝佳做空点
量度幅度：突破后涨幅 = 旗杆高度
旗杆必须足够长（比旗面长）；旗面低点不能跌回旗杆起点，否则旗形失效。成交量必须萎缩后再放大（突破时）。
颈线假突破陷阱：主力常在旗形高点"假跌破又迅速拉回"，教条者放空被套——主力套住空头是为了让空头在高位回补，给主力"抬轿子"。应对纪律：形态未完成前不抢跑。

2.7 楔形：反直觉的"上升楔形"

上升楔形
两条边都向上 + 收敛
★ 虽叫"上升"但大部分向下跌（反直觉！）
★ 3分之2 原则
下降楔形
两条边都向下 + 收敛
★ 突破后必创新高（确定性最高）
★ 拉升-盘整-陡峭大阳线
3分之2 原则：楔形突破必须在 3分之2 时间窗口内完成，3分之2 之后突破不可信。止损 = 关键点位外 2 个点。
黄金 5/18 上升楔形：2987 → 2917（3 小时跌 70 美金）。
止损参数：关键点位 2 个点；日线 14 根 K 线 = 2 周最低时间窗口。实战心法：下跌楔形"必创新高"的确定性是所有中继形态最高的。

2.8 单日反转：主力洗盘结束的信号

两日结构：巨阴 + 吞没大阳线（次日完全吞没前一日跌幅）。

  • 目标位 = 0.382 / 0.5 / 0.618 黄金分割
  • 加仓点 = 0.382 突破 + 0.5 二次突破
  • 日线图 30-50 美金空间
黄金分割加仓：第一加仓位 = 起点 + (起点−终点) × 0.382
第二加仓位 = 起点 + (起点−终点) × 0.5

2.9 矩形 + 头肩形：巩固形态双雄

▎矩形 (Rectangle)

  • 上下边水平的中继形态
  • 矩形 = 主力吸筹/出货区间
  • 突破方向决定后续趋势

▎头肩顶 / 头肩底 (Head & Shoulders)

头肩形 75% 成功率——所有反转形态中最可靠的一种。
项目头肩顶头肩底
结构左肩—头—右肩左肩—头—右肩（方向反）
头部高度高出左肩 3% 以上低于左肩 3% 以上
时间要求3 个月以上同向运行3 个月以上
卖出/买入跌破颈线 = 卖出突破颈线 = 买入
二次机会反抽颈线不破 = 加空回抽颈线不破 = 二次买入
量度头部到颈线距离头部到颈线距离
黄金 680 大底 (2008-10-24) 的头肩底
左肩 720 → 头部 680 → 右肩 705 → 颈线突破 730 → 量度涨幅 = 头部到颈线 = 50 美金
目标价 780 → 实际涨至 1000（量度涨幅 240 美金）
★ 实战：突破颈线 + 回抽颈线不破 = 2 个买点。

2.10 缺口理论：跳空是市场的"惊叹号"

缺口 = 开盘价与前一日收盘价之间的"无人区"。4 类缺口：

类型特征含义
普通缺口整理中短期回补无趋势意义，几天内必补
突破缺口3 天内不回补★ 主升浪启动，最强信号
持续缺口出现在趋势中段★ 可度量未来幅度
消耗缺口出现在趋势末端★ 见顶信号，最后一击
持续缺口量度公式：目标价 = 突破起点 + (持续缺口当日股价 − 最低价)
缺口实战三案例：
  • 突破缺口：股价 2 → 2.44（跳空 4%）→ 7 个涨停板拉升 50%
  • 持续缺口：股价 4 元，持续缺口当日 5.2，最低 4，预测 4+(5.2-4) = 6.8 元，实 7 元，涨幅 70%+
  • 消耗缺口：2007-9-3 见顶 20.33 后未延续前期角度 = 见顶
  • 历史特例：1929-1930 年缺口 18 年未回补

2.11 直角三角形：最容易上手的中继形态

上升直角三角形
水平阻力 + 上升支撑
★ 多头格局，向上突破
下降直角三角形
水平支撑 + 下降阻力
★ 空头格局，向下跌破
量度幅度：上升三角形涨幅 ≥ 15%，下降三角形跌幅 ≥ 15%
黄金上升三角形 180 → 760 → 1000：历史大级别三角形突破，幅度远超 15%。
黄金下降三角形 943 → 953 → 936：跌 17 美金即触发 15% 跌幅预期。

💡 提示：思维导图为横向树状静态 SVG；右侧黄色框为各形态的核心量化规则。

位置决定性质，量度决定空间，3%容差决定真假，3分之2决定时机。
★ 反形态教条陷阱：教条者画完形态就"等突破"，主力偏要"假突破"扫止损。实战必须等有效突破 + 回踩，单点突破不抢跑。
小白常问：颈线到底是什么？ 连接形态中两个关键转折点的直线。三重顶的颈线 = 2 个低点的连线；头肩顶的颈线 = 左肩低点和右肩低点的连线。颈线 = 多空分水岭，跌破颈线意味着空头接管，突破颈线意味着多头接管。
小白常问：为什么上升楔形大部分向下跌？ 上升楔形虽然两条边都向上，但每一次反弹的高点和低点都在降低（收敛），说明买盘力道越来越弱。所以即使形态向上倾斜，本质是空头积蓄能量的过程，向下突破概率远大于向上突破。这是技术分析反直觉的代表案例。
小白常问：缺口的 4 种怎么快速区分？
  • 普通缺口：几天内必补，发生在盘整中
  • 突破缺口：3 天内不回补 = 主升浪
  • 持续缺口：出现在趋势中段，可量度幅度
  • 消耗缺口：出现在趋势末端，最后一击必见顶/底
口诀："普不成势、突立方向、持续度量、耗见顶底"

03技术指标：把模糊感觉量化成数字

高阶19讲第14-19节精华形态告诉你"主力想干什么"，指标告诉你"市场情绪有多极端"。指标必带 K 线——单一信号不可信，必须多重验证。

3.1 五大类指标划分（先建坐标系）

大势型指标
判断多空大方向
例：MACD、DMI
趋势型指标
跟随趋势
例：布林线、SAR
震动型指标
捕捉超买超卖
例：KDJ、RSI、BIAS
图形化指标
直接画在价格图上
例：SAR、布林线
数值型指标
绝对取值判断
例：BR、AR、CDP

3.2 KDJ（随机指标）：五维框架

是什么：起源于期货市场的震荡型指标，由 K、D、J 三条线组成（取值 0-100）。

为什么有效：KDJ 反映"过去 9 天价格所处的相对位置"，本质是动量震荡。

五维用法（张穗鸿老师最强调的）：

  1. K 值绝对取值：K<20 超卖做多；K>80 超买做空
  2. KD 曲线形态：头肩顶/底、多重顶/底、M头/W底
  3. 金叉死叉：50% 可信度（傻瓜用法）
  4. J 值绝对取值：J>100 / J<0 极端情绪反向操作
  5. 背离：顶背离/底背离 = 可信度最大
时间周期越大越稳定：周线 > 日线 > 分钟线。1 分钟/5 分钟金叉死叉忽略。
KDJ 实战三案例：
  • 2008-08-15 K=17.15：超卖做多，3 天反弹 60 美元
  • 2009-02-20 K=80：超买做空，1 周跌 100 美元
  • 2006-07-12 J=117：极端情绪反向，黄金 655 → 560 跌 90 美元
  • 2009-03-11 ~ 04-07 底背离：880 做多 → 980，100 美元

3.3 BR（情绪指标）+ AR（人气指标）

是什么：ARBR 起源日本，太极哲学根基——开盘价是冷静价格共识，收盘价是情绪化结果，两者之差 = 群体情绪。

BR
= 情绪指标
= 昨日收盘到今日最高的累计能量
区间 50-250
AR
= 潜在动能
= 今日开盘到今日最高
反映"潜在"涨/跌意愿
BR ≈ 250 = 顶部（情绪极端）
BR ≈ 50 = 底部（情绪极端低迷）
AR/BR 协同：粘合无价值，分开即变盘
2005-12-08 BR ≈ 250：黄金 540 → 480，3 天跌 15%——历史峰值后必跌。
2008-12-08 BR ≈ 250：与 2005 类似，再次验证顶部信号。

3.4 MACD（指数平滑异同）：背离之王

是什么：由快线 DIF（白）+ 慢线 DEA（黄）+ 红绿柱组成。MACD = 大势型指标的背离之王。

金叉：DIF 上穿 DEA = 看涨
死叉：DIF 下穿 DEA = 看跌
顶背离：价格新高 + MACD 未新高 = 见顶
底背离：价格新低 + MACD 未新低 = 见底
⚠️ MACD 金叉别立即买！金叉时已经涨了一段。正确做法：金叉后等回调，等 DIF 靠拢 DEA（要死不死） + K 线反转 = 绝佳买点。
MACD 错误案例 vs 正确做法：
错误：2008-11-7 MACD 金叉 742 → 立即买入 → 跌至 700，被套 40 美金
正确：金叉后等回调 → 要死不死 + 吞没形态 = 绝佳买点
顶背离经典：2008 年初黄金顶背离 1032 → 680，跌幅 200-300 点
底背离经典：黄金 680 大底底背离 → 涨至 1000（涨 320 美金）

3.5 DMI（动向指标）：ADX 50 拐头 = 趋势结束

是什么：DMI = 纵向指标（分析方向），由 4 条线组成：

+DI（黄）
上升方向线
-DI（紫）
下降方向线
ADX（绿）
平均趋向指数 = 方向线
ADXR（蓝）
ADX 评级 = 评估线
ADX 50 以上向下转折 = 一轮行情结束（最经典信号）
ADXR 20-25 = 牛皮市，金叉死叉无效
ADXR ≥ 25 = 活跃市，用 DMI
ADX < +DI 且 < 20 = DMI 无效信号，暂停使用
ADX 50 拐头黄金案例：
2008-7-9 黄金 988 → 738：ADX 8/27 上穿 50（接近结束）→ 9/15 下穿 50（正式结束）
2009-1-14 黄金 800 → 1000：ADX 上穿 50 后拐头 → 上升趋势
2008-10-27 ADX 上穿 +DI，黄金 680 筑底 → 大级别做多信号

▎CDP 五线（盘整期最佳搭档）

AH（外轨阻力）> NH（重要阻力）> CDP（多空分水岭）> NL（重要支撑）> AL（外轨支撑）
涨到 NH 卖出，跌到 NL 买入，突破 AH 多单持有，跌破 AL 空单持有

3.6 BIAS（乖离率）：价格 vs 价值

是什么：衡量价格偏离长期均线（价值）的程度。

BIAS = (股价 − 均线) / 均线 × 100%
三条线：6 日（短期）/ 12 日（中期）/ 24 日（长期）
正 5% 卖，负 5% 买（中短期标准）
±6 是黄金正常运行区间，超出即非理性
极值状态 = 暴利 + 暴亏（2008-08 黄金 BIAS=-12，680 vs 838 价值曲线，严重低估）
BIAS 接近 0 + 均线向上 = 价值投资黄金点
BIAS 黄金案例：
  • 2008-08 黄金 BIAS=-12：680 vs 838 价值曲线，12% 低估 = 严重低估
  • 2008-10-22 黄金 BIAS=-14：730 → 次日 680，跌 40 美金（反面案例：极值继续走）
  • 2006-05-05 黄金 BIAS=+11：718 vs 643，严重高估
  • 2009-04-06 黄金 BIAS=+0.43：价值投资最佳买点
  • 2009-05-29 黄金 BIAS=5.7：5% 回调卖出信号

3.7 RSI（相对强弱指标）：50 分水岭 + 背离

是什么：0-100 取值的震动型指标。50 = 多空分水岭。

多头市场三道防线
50 / 40 / 30
RSI 不破 50 = 强势
空头市场三道压力
50 / 60 / 70
RSI 不破 50 = 弱势
极值
>80 超买
<20 超卖
最佳周期
4 小时 / 30 分钟
箱体震荡最好用
RSI 黄金实战：
2008-3 RSI=87：顶背离 → 较大调整（1032 → 680）
黄金 680 RSI 三次底背离：大级别上涨 → 1000
★ 实战结论：RSI 背离的可靠性 > RSI 极值

3.8 布林线 BOLL：开口 + 闭口 = 突破 + 盘整

是什么：趋势型 + 图形化指标。由中轨（20 日均线）+ 上轨 + 下轨（±1.7σ 标准差）组成。

中轨 = 20 日 SMA
上轨 = 中轨 + 1.7σ
下轨 = 中轨 − 1.7σ
开口（上下轨扩大）= 突破 / 强趋势
闭口（上下轨收窄）= 盘整 / 蓄势
跌破下轨必止盈（月线 > 周线 > 日线 稳定度）

3.9 SAR（抛物线转向）：移动止损神器

是什么：画在价格图上的图形化指标，核心用途 = 移动止损。

多头市场
SAR 在价格下方
SAR 上移 = 多头保护
空头市场
SAR 在价格上方
SAR 下移 = 空头保护
位置转换
由支撑 → 压力
= 多空转换
日线图最稳定
SAR 心法：上做空，下做多，移动止损让它跟，价格破位先离场。
SAR 黄金实战：
  • 2009-5-22 SAR=911：做多 910 买入 → SAR 上移到 911 = 移动止损保护
  • 2009-6-3 SAR=961：SAR 由支撑转压力 → 多空转换信号
  • 2009-6-5 SAR 由支撑转压力：979 做空 → 跌至 952，49 美金利润

3.10 多指标联合应用：终极心法

单一指标有局限性，必须联合应用。3 类指标共振 = 最强信号：

趋势型
MACD · 布林线 · SAR
判断方向
震荡型
KDJ · RSI · BIAS
判断极端情绪
数值型
BR · AR · CDP
判断绝对数值
不同类型指标互相印证，单一信号不可信；多周期共振（大周期定方向，小周期找入场）；信号不一致 = 减仓或等待。
★ 终极心法：用得好 > 指标本身好坏。个性化选择最适合自己的指标；三指标共振才是最强信号；信号不一致 = 减仓或等待。

💡 提示：思维导图为横向树状静态 SVG；右侧黄色 = 关键概念，深色 = 终极铁律。

★ 跨案例验证 (黄金 680 大底 6 重共振)：
  • K线/形态：锤子线 + 吞没 + 头肩底颈线突破 (第03/11/12节)
  • MACD：底背离，价格新低但 MACD 未新低 (第15节)
  • DMI：ADX 上穿 +DI = 方向转多 (第16节)
  • BIAS：-12 严重低估 = 价值回归 (第18节)
  • RSI：680 三次底背离 = 大级别上涨 (第19节)

一、最小砖头：顶分型与底分型（小白通俗）

什么是分型？为什么叫"顶底分型"？

把走势图缩小到最小尺度，只看三根相邻的K线：

  • 如果中间K线的高点和低点都是三根里最高的——这就是顶分型，代表阶段性顶部。
  • 如果中间K线的高点和低点都是三根里最低的——这就是底分型，代表阶段性底部。

老师有个形象比喻：底分型就像一个"小美女"——左右两根K线是"双手叉腰"，中间那根K线是"弯腰屈膝"。而顶分型反过来，中间K线"踮起脚尖"高高在上。

在分时图里，把"小美女"放大来看，它就是一个头肩底形态（底分型）；反过来，顶分型就是头肩顶。

📐 顶底分型判定公式（铁律）
顶分型成立条件（三根K线，不含包含关系）：
K线₂.高 = max(K线₁.高, K线₂.高, K线₃.高)
K线₂.低 = max(K线₁.低, K线₂.低, K线₃.低)
且  K线₂.高 > K线₁.高  且  K线₂.高 > K线₃.高
且  K线₂.低 > K线₁.低  且  K线₂.低 > K线₃.低
底分型成立条件（三根K线，不含包含关系）：
K线₂.高 = min(K线₁.高, K线₂.高, K线₃.高)
K线₂.低 = min(K线₁.低, K线₂.低, K线₃.低)
且  K线₂.高 < K线₁.高  且  K线₂.高 < K线₃.高
且  K线₂.低 < K线₁.低  且  K线₂.低 < K线₃.低
禅师金句：分型定理（100%正确）
"不见顶分型就不见顶，不见底分型就不见底。" —— 缠中说禅

这是缠论最基础、也是最核心的定理。它意味着：

  • 任何阶段性顶部，100%由一根分型构成（已经验证）。
  • 任何阶段性底部，100%由一根分型构成。
  • 反过来推：没有分型，就没有顶/底——这就是"不见不散"的实战铁律。

对应操作：

  • 持股端：只要没出现顶分型，安心睡觉，一直持有。
  • 买入端：不见底分型不买，见到底分型才买。

某只股票跌到43.66元后，三根K线（无包含关系）形成标准底分型：

  • K线₁：最高 6 点、最低 5 点

二、判别前的"数据清洗"：K线包含关系处理

为什么必须先处理包含？

实际行情中，三根K线常常不干净——经常有一根K线被另一根K线完全"包住"的情况。如果不做处理就直接判分型，90%会判错。老师用"孕线"打比方：

"一根K线完全在另一根K线的肚子里，就像母亲怀了一个孩子。孩子的脚和手都不能突破母亲的肚皮；如果突破了，这个'母亲'就死掉了——也就是包含关系解除。"

所以，判分型前必须先做"包含处理"，把多根K线合并成"无包含"的标准状态。

📐 包含处理口诀（机械执行）
上涨过程中（向上走）→ 取"高高"：
新高 = max(K线A.高, K线B.高)
新低 = max(K线A.低, K线B.低)   ← 低点取较高者
→ 即"高更高、低也高"
下跌过程中（向下走）→ 取"低低"：
新高 = min(K线A.高, K线B.高)  ← 高点取较低者
新低 = min(K线A.低, K线B.低)
→ 即"高更低、低也低"
处理顺序原则：
① 从左到右逐根合并（不可"上帝视角"从右往左）
② 反复处理直到"没有包含关系"
③ 然后再判断顶底分型
口诀：涨高高、跌低低、从左到右
  • 涨高高 → 上涨时：高点取高、低点取较高
  • 跌低低 → 下跌时：高点取低、低点取低
  • 从左到右 → 走势图不可逆，必须从左往右处理

三、真假分型识别：中继分型 vs 真顶底分型

核心问题：你看到的顶分型，90%是假的！

老师在第31节反复强调："形态上成立的顶分型，未必引发趋势转折"。很多看似顶分型的东西，其实只是中继分型——在上涨中段出现的"假顶"。

举例：

  • 上证指数某段走势中，符合顶分型定义的三根K线出现。
  • 但走出第四根K线时，没有有效跌破第一根的最低价。
  • 结果：后续继续上涨 → 这是中继分型，不是真顶。

那么，怎么判别真假？

第一性原理：连接两笔原则
"真正的顶分型，是连接两笔的转折点。" —— 张穗鸿老师
  • 真顶分型：顶分型出现后，能成功向下走出一笔（下跌→底分型→再上涨）。
  • 真底分型：底分型出现后，能成功向上走出一笔（上涨→顶分型→再下跌）。
  • 中继分型：形态成立，但无法延续出反向笔，趋势继续原方向运行。

问题：能否"延续出反向笔"是事后才能确认的。所以我们需要其他辅助方法做预判——这就是下面讲的5日线和主动降级别。

辅助判别方法：5日线确认（最简单、最落地）

分型只是"形态信号"，必须配合5日线做"动量确认"，避免单纯依赖形态的误判：

  • 顶分型 + 跌破5日线 = 顶分型成立，至少调整7天 → 减仓信号。
  • 底分型 + 突破5日线（回踩确认） = 调整结束，至少上涨7天 → 入场信号。
  • 底分型跳空突破5日线 = 极强信号，多头力量强劲。

5日线在这里扮演"体温计"的角色：跌破5日线 = "生病需要吃药"；突破5日线 = "康复可以继续干活"。

日线级别：  至少 7 天  =  7 根 K 线

原理：级别越大，惯性越大，调整时间越长。这是不同级别的同一规律，不是巧合。

把走势图缩小一点，会发现股价大部分时间在一个区间内来回震荡。这个震荡区间就是中枢。

用更形象的话：

七、笔与线段：分型升级的递归结构

什么是"笔"？

笔是缠论里的最小单向走势单位，比"分型"高一级别。它的定义非常严格：

  • 由顶分型三根K线 + 中间至少一根不被顶底分型包含的K线 + 底分型三根K线组成。
  • 最短的笔至少由7根K线构成（3 + 1 + 3）。
  • 上涨后下跌 → 向下笔；下跌后上涨 → 向上笔。

通俗理解：笔 = "上升→下降"或"下降→上升"的一小段。它代表了最小尺度的趋势变化。

什么是"线段"？

线段是比笔高一级的结构，由至少3笔构成。它的特点是：

  • 必须被线段所破坏才算被破坏（不是被一笔破坏）。
  • 一笔下跌不能破坏线段——这非常重要！
  • 实战意义：在次级别上看到"只是一笔下跌"时，可以判断本级别的中继分型大概率成立。

举个例子：15分钟级别上的下跌如果只是一笔下跌，没有走出线段下跌，那么原方向会继续延续。

五、3% 有效突破原则：真假美女的分水岭

"有效突破"是大美女战法里最高频的过滤规则。它解决一个问题：怎么区分主力真突破 vs 假突破？

🎯 3% 有效突破的完整定义
  • 有效突破 = 突破幅度 ≥ 3%：股价收盘价相对颈线位的涨幅必须达到或超过 3%。例如厚普股份颈线 14.89 元，3% 突破价 ≈ 14.89 × 1.03 = 15.34 元。
  • 3% 的设计理由：避免突发利空下创业板股票（300 开头）当日可达 20% 跌幅的极端亏损；避免盘中洗盘的下影线被误判。
  • 3 天站稳：突破后必须连续 3 天收盘站在颈线位上方，才算"有效站稳"。
  • 假突破的典型特征：盘中冲高 3% 后快速回落 → 收盘价仍低于颈线位 3% → 这就是"假突破"，必须放弃。
  • 利达信案例：颈线 18.46 元，3% ≈ 19 元；第二天最高价已突破 19 元 → 满足有效突破 → 但 15 倍报酬比不够 → 等回落 18.6 元附近再介入。
【有效跌破】 = 盘中跌幅 ≥ 3% 或 收盘价跌破颈线位 → 立刻走人，不抱幻想。

六、小财神计算器：15 倍投资报酬比的硬公式

"小财神计算器"是老师发明的买入价 + 止损价 + 目标价的三合一工具，专门解决"该不该买、买多少、跌到哪止损"三大问题。

【小财神核心公式】 目标价 = 颈线位 + 头肩底高度（颈线 - 头部最低价） 买入价 = 颈线 × 1.03（3% 有效突破价），但要满足 报酬比 ≥ 15 倍 止损价 = 颈线位（跌破即走） 报酬比 = (目标价 - 买入价) ÷ (买入价 - 止损价) ≥ 15
🎯 案例复盘 · 蓝起科技（头肩底 + 九五线共振）共振型

已知条件：颈线位 = 72.55 元，头部价格 = 41.8 元，当前价 = 75.5 元。

① 目标价：72.55 + (72.55 - 41.8) = 103.3 元（涨幅 ≈ 42%）。

② 3% 突破价：72.55 × 1.03 ≈ 74.7 元（当天已突破 77 元 → 完成 3% 有效突破）。

③ 当前报酬比：(103.3 - 75.5) ÷ (75.5 - 72.55) ≈ 9.5 倍（不够 15 倍 → 不能买）。

④ 计算合理买入价：要让报酬比 ≥ 15，反推买入价 ≈ 74.47 元。

⑤ 实战验证：后来确实跌回 74 元附近 → 在 74.47 元买入 → 止损 72.55 元 → 目标 103.3 元。

⑥ 九五线配合：必须等收盘看是否站上九五线，而非盘中突破即介入。

📌 15 倍报酬比的本质：这不是"贪心"，而是统计学意义上的期望值管理。即使胜率只有 50%，15 倍的盈亏比仍能让期望收益为正：0.5 × 15 - 0.5 × 1 = 7 倍期望收益。这就是为什么"小财神"不是工具，而是大美女战法的风险收益比生命线。

十一、关键答疑精选（小白必看 FAQ）

❓ Q1：反转 K 线不标准，能否看作信号？
不能。老师的硬性标准：成功率必须 ≥ 75%。30% 也能涨，但 70% 失败——很多"看图派"老师拿这 30% 的成功案例做宣传，但 70% 失败案例不会告诉你。真正的反转 K 线标准：下影线 ≥ 实体的 3-4 倍，阴阳不拘。
❓ Q2：带量涨停是底部反转信号吗？
不是。带量涨停是"两日反转"（阴线 + 涨停反包），成功率仅 53%，属于"形态"而非"信号"。头部阶段量能反包可能"包不住"前量，但一般下跌/横盘阶段，涨停板的成交量一定比前面阴线大。
❓ Q3：顶底分型如何应用？
顶分型 + 跌破 5 日线 = 卖出信号；底分型 + 升破 5 日线 = 买入信号。"没有顶分型就没有顶，没有底分型就没有底"——这是核心原则。100 元跌到 1 毛也不买，要等足数完 + 突破 5 日线才进场。
❓ Q4：为什么头肩底不讲成交量？
因为 95% 突破时颈线位必定放量——这是常识。而 95 至尊（筹码算法）已经把成交量算法包含进去了，看量是冗余。99.999% 情况下，价涨必放量；上涨必然放量（79% 以上的样本统计）。唯一例外：单日换手率 > 40% 的异常量需要特别关注。老师原话："成交量这些东西都是做给散户看的"。
❓ Q5：头肩底第二目标怎么算？
第一目标 = 颈线 + (颈线 - 头部最低价)。第二目标通常依据波浪理论第三浪最长原则：从形态最深处（头部）到颈线的距离 H，第三浪（主升）的目标位往往是 H 的 2-3 倍。即：第二目标 = 颈线 + H × 2 或 H × 3。例：颈线 14.89，头部 11.5，H = 3.39；第一目标 = 18.28 元，第二目标 = 21.67 元（≈ 2H）或 25.06 元（≈ 3H）。
❓ Q6：双底（W 底）和头肩底有何区别？
双底：两个低点几乎同一价位，底部没有"鼻子"下探，力度较弱，成功率 约 60-65%。头肩底：第二个低点（头部）明显低于两侧（左肩、右肩），主力刻意下探制造恐慌吸筹，成功率 约 75-80%。头肩底 = 加强版双底，更具爆发力。
❓ Q7：斜头肩底真的完全无效吗？
在老师体系下直接打叉。理由：斜颈线是市场自然走势形成的图形，没有"红线条贯入"——而红色线条的内用是"主力画线介入"的标志，是大美女战法的"基因"。没经过主力"红线操作"的颈线位失去 75% 成功率的统计意义。但注意：实战中极少数斜头肩底也能涨——只是概率远低于 50%，不值得作为信号使用。
❓ Q8：横盘多久算"长期横盘美女"？
长期横盘异型美女的时间跨度通常 ≥ 1 年（约 250 个交易日）。剑桥科技案例：底部横盘 89 天后拉起；2009 年安纳达 7 个月横盘突破 100%；新潮能源底部 130 天横盘，理论目标位 2.64 元。横盘期间成交量应逐步萎缩至地量水平，筹码高度锁定，筹码峰密集。一旦放量突破 → 进入主升浪。
❓ Q9：怎样把大美女升级成"九五至尊美女"？
当头肩底形态形成后，在突破颈线那一刻同步观察九五至尊数值——如果突破日九五至尊从 90-95 区间迅速突破到 97 以上，说明主力筹码集中度大幅提升，"做皇帝"意图落地。这种"大美女 + 九五至尊"共振的标的，是老师体系下胜率最高的标的，远胜单一指标。蓝起科技、新业盛、中际旭创都是典型。

🤔 小白问答：什么是博弈K线（CYQKL）？
  • 博弈K线：来自指南针的技术指标，显示在股价K线下方，反映"该K线穿越了多少比例的筹码"。

  • 数值范围：0-100%。一般运行在 0-60 区间。
  • 关键阈值：≥ 80% 称为博弈K线长阳，是主力高控盘信号。
  • 类比：筹码峰像一座山，主力从下往上"轻松穿越"80%的山头 = 这座山本来就是主力的。

  4. K线整齐规整——小阴小阳，实体小，上下影线短（主力刻意控盘痕迹）
  5. 分时"织布"——日内波动极小，紧贴均价线（分时图走得"像织布机"）
🤔 筹码集中度怎么看？

09一统天下战法·中长线周线操盘体系

🏯 周线一笔上·极品底·平台突破·多级别联立——拉长时间维度，让利润奔跑

9.0 一句话读懂"一统天下"

一统天下是张穗鸿老师中长线战法的总称，核心是站在周线角度寻找具有翻倍乃至数倍潜力的大级别机会。它不是短线抓涨停，而是"用做生意的眼光做股票"——找极品底、找周线一笔上、找平台突破，然后多级别联立持仓，让利润从周线级别上"一统"市场。
战法定位：与"九五战法"（日线主升）形成时间维度互补——
• 九五：日线级别主升，吃 30%~80% 主升段
• 一统天下：周线级别翻倍，吃 100%~500% 长牛段
• 潜龙：极端超跌反弹，吃 20%~40% 反弹段
三者构成完整的短线 + 中线 + 长线战法矩阵。

9.1 战法根基：为什么必须看周线？

📊 三个真相
  • 真相一：日线会骗人，周线骗不了
    日线可以一根大阳线拉起再回落，但周线要收阳需要整周多头主导，假突破概率极低。
  • 真相二：财富需要时间放大
    短线抓涨停年化难超 30%；周线持仓遇到主升浪，年化 100%+ 并不稀奇——因为时间是你的朋友。
  • 真相三：大资金只看周线
    公募基金、私募、险资调仓周期都是周/月级，跟随大资金步伐必须升级看图周期。
🤔 小白问答：日线和周线有什么区别？
  • 日线：1 根 K 线 = 1 个交易日，反映短线多空博弈
  • 周线：1 根 K 线 = 5 个交易日，反映中线趋势方向
  • 月线：1 根 K 线 = 20 个交易日，反映长线牛熊
  • 类比：日线是天气，周线是季节，月线是气候——做中长线必须看季节和气候。

9.3 周线一笔上：周线战法的灵魂

📐 "周线一笔上"定义
在周线图上，从一个明显的中枢底分型开始，经历连续的阳线或小阴小阳，价格显著脱离中枢上沿，MACD 同步金叉，构成周线级别的上攻一笔。
本质：相当于把日线的"一笔"放到周线尺度上观察，是大级别趋势的主升段信号。
💡 周线一笔上的实战买点
• 潜伏买点：周线底分型出现 + MACD 绿柱缩短 → 建 30% 底仓
• 加仓买点：周线收盘突破中枢上沿 + MACD 金叉 → 加至 60%
• 满仓买点：日线小三买确认 + 30F 同向 → 加至 80%~100%

9.4 极品底：周线抄底的艺术

💎 极品底的四个特征
  1. 跌幅够深：从高点回落 ≥ 30%，最好 50% 以上
  2. 时间够长：底部横盘 ≥ 3 个月，形成筹码沉淀
  3. 形态够标准：周线头肩底、双底、圆弧底形态完整
  4. 量能异动：底部出现放量阳线或底部堆量
极品底 ≠ 便宜底，而是极端+标准+异动三位一体的高胜率反转结构。
🤔 极品底和潜龙在渊有什么区别？
  • 潜龙在渊：依赖 95 至尊指标的极端信号（潜龙线 < -100%），是量化触发的反弹
  • 极品底：依赖形态+时间+量能的结构共振，是视觉识别的转折
  • 两者可以叠加：当一只股票潜龙线 < -100% 且 周线形成极品底形态，就是极品中的极品——一统天下的黄金买点

平台突破的定义：股价在周线图上形成3~6 个月的横盘整理区间（高点差 ≤ 15%），某一周收盘放量突破平台上沿，伴随 MACD 金叉，即为周线平台突破。

9.7 一统天下买点体系

🎯 买点一：周线回踩+日线小三买（主推买点）

触发条件：

  • 周线已形成一笔上，但股价回踩周线中枢上沿或 5 周均线
  • 回踩过程中，日线级别出现缠论小三买（次级别回踩不创新低）
  • 30 分钟级别 MACD 同步金叉

操作：底仓买入 60%，止损位设在周线回踩低点下方 3%。

逻辑：周线回踩是健康的洗盘，日线小三买确认洗盘结束，三层共振 = 高胜率买点。

🎯 买点二：周线极品底+月线多头（左侧买点）

触发条件：

  • 周线已形成极品底（头肩底/双底/圆弧底）
  • 月线 MACD 在零轴附近企稳，多头排列未被破坏
  • 底部出现周线级别放量阳线

操作：先建 30% 底仓，等周线收盘突破平台再加至 60%。

逻辑：左侧买入成本最低，但需要承受底部震荡，分批建仓是稳妥做法。

🎯 买点三：周线平台突破+日线放量（右侧买点）

触发条件：

  • 周线横盘平台 5~8 个月
  • 某一周收盘放量突破平台上沿（突破量 ≥ 5 周均量 1.5 倍）
  • 日线次日跳空高开或大阳线确认

操作：突破当日尾盘建仓 50%，回踩不破位加至 80%。

逻辑：右侧追涨胜率高、效率高，但成本较高，适合趋势确立后的加速段。

10.4 做T 三要素：底仓不动+滚动操作+降低成本

  2. 滚动操作：用机动仓反复做 T，同一笔仓位在日内/数日反复进出

⚠️ 做T 三大禁忌
  • ❌ 忌把底仓也 T 飞了：贪图做T 利润，把战略仓也卖了，结果主升浪来临空仓
  • ❌ 忌追涨杀跌做反T：低卖高买，越做成本越高

11.1 凯利公式——每次下注多少的科学

凯利公式：f* = (bp - q) / b
其中：
f* = 最优下注比例（占总资金的百分比）
b = 净赔率（平均盈利 / 平均亏损）
p = 胜率
q = 败率 = 1 - p
实战建议（半凯利）：教科书用半凯利（0.5×f*），因为教科书假设是无限次交易，但实战中交易次数有限，且情绪波动会让人偏离最优解。
例如：胜率60%、盈亏比2:1 → f*=0.4（40%仓位） → 实战用20%

📊 案例：凯利公式实战计算

📅 2025年回测🎯 模拟交易100笔📈 胜率58%

假设：胜率58%，平均盈利10%，平均亏损5%

计算：b=2, p=0.58, q=0.42

f* = (2×0.58 - 0.42) / 2 = 29%

实战使用：半凯利 = 14.5% 单笔仓位

含义：每笔交易最多动用14.5%本金，100笔下来复利最大化且回撤可控。

境界名称:无情(第16节 [04:01])

逻辑前提:既然情绪总是干扰我们,那我们就让自己变得无情——在做决策的时候,尽量不让情绪参与进来。

典型训练:在止损的时候,练习"手起刀落那一刹那的无情"。

金刚经的"散户炼":"应无所住而生其心",对应到交易中就是聚焦于当下。不被过去的成功困扰,也不被过去的失败困扰。

境界意义:"这个阶段通常也是走向盈利的开始"。能执行你的计划,"交易你的计划,计划你的交易"。

无情境界的局限:无情阶段说明其实还是有情绪的,只不过是努力的强行把情绪堵在了门外。这是从"失控"到"压抑"的进步,但还不是与情绪和解、彻底内化的状态。

突破方向:把压抑的纪律变成自然的习惯——进入第四重"三好学生"。

📚 第四重 三好学生——"铁的纪律,过程远比结果重要"

境界名称:三好学生(第16节 [04:57])

核心特征:遵守纪律。无情阶段是把情绪强挡在门外,三好学生则是用纪律把执行变得简单。

典型习惯:收盘后做第二天的交易计划,次日无条件执行。

经典案例:3.58元止损 vs 5.8元反弹

  • 交易计划:某只股票跌到3.58块就止损。
  • 实际发生:盘中最低价下探到3.58块,按计划止损了。
  • 结果:股价又一路上涨涨到了5.8块。
  • 评价:"从交易者的结果来说,今天的操作很糟糕,但从交易的过程来说,你的交易计划执行的非常完美"。

本境界最核心的认知飞跃:把交易结果和交易过程分开来对待——"正确的交易过程远比某一次正确的交易结果重要100倍"。

本境界最危险的陷阱——错误过程赢得正确结果:

  • 反面案例:交易计划写明3.58块止损(比如头肩底/大美女形态破了颈线位),价格到了没止损,收盘又涨回去。
  • 表面上盈利了,但这"才是最危险的地方"。你靠违背交易计划赢得了奖赏,于是下一次你会进一步违背。
  • 雷池不能逾越!最终整个交易系统都会坍塌。
  • 典型命运:很多有过赚钱经验的人,他们基本上就停留在了第四重境界里面,然后被市场消灭掉了。
💎 第五重 内化——"赚钱的基因刻在骨子里"

境界名称:内化(第16节 [07:56])

核心心法:"把赚钱的基因刻在骨子里"。张老师反复说过:"头肩底你要作为基因刻在骨子里,底分型你要作为基因刻在你的骨子里"。

典型表现:

  • 不再需要每天写交易计划:所有纪律、铁的执行都已经内化了。
  • 类比驾驶:好比一个熟练的驾驶员,"什么时候踩油门,什么时候踩刹车,已经内化了"。
  • 下意识系统化:内心已经形成了一个交易系统,下意识地按这个系统执行。

境界身份:你已经是量化交易者,或半量化交易者。"很多主观的高手其实就是在这个境界中"。

课程承诺:"如果大家能够把龙虎跃的证券精修课能够完全掌握,其实你就已经在了第五重境界"。张老师定位:"大家这么短的时间能够把这个学会,相当于我们把内功传授给大家,大家可以少走基本上少走十年以上的弯路"。

突破方向:当系统已经成熟到不需要主观干预时——进入第六重"无为胜有为"。

🤖 第六重 无为胜有为——"做得越少,赚得越多"

境界名称:无为胜有为(第16节 [08:52])

核心现象:

  • 系统已形成:当系统已经形成后,你甚至可以不看盘了。
  • 代码化执行:把交易策略写成计算机代码,让计算机帮你看盘执行下单。
  • 监控者角色:你作为监控者,偶尔看一眼就行。

本境界的核心悖论:

  • "你做的越少,赚的越多"。
  • 不作为正是保证系统发挥威力的前提条件。
  • 一旦你做的太多、对系统干预太多,反而会产生负面作用。
  • 核心修炼:控制好主观干预系统的欲望。

境界身份:"这个就是我们所说的程序化交易者"。"现在主要用于期货市场"。"大家看到很多期货的团队,他们的成功率70%左右,他们基本上就已经可以在市场中赚到钱了"——70%成功率即可稳定盈利。

突破方向:当你想理解系统为什么赚钱、想用数学方式优化时——进入第七重"数学家"。

📊 第七重 数学家——"参数越多,未来越差"

境界名称:数学家(第16节 [09:46])

张老师亲历:是2000年到2003年张老师干的事情。

工作流——四步循环:

  1. 策略思想→代码化:有了策略思想,需要把它写成计算机代码。
  2. 真金白银vs计算机回测的对比:2000年的做法:把市场中所有赚钱的策略,直接让计算机去帮我们跑(不需真金白银测试)。
  3. 跑数据看效果:策略案例:5日线上穿10日线买入,5日线下穿20日线卖出。1990年到2003年33年的数据回测。残酷现实:效果并没有想象的那么好。
  4. 参数优化:5日线和20日线的效果没那么好,换成10日线和30日线会不会更稳定?

核心环节——修轨/拟合:当时的鬼域版(指南针软件)可以把市场上所有指标全部参加运算。优选一个指标,它的哪个值可以在全市场中是最高的,就可以加进去——这个过程叫修轨。"在大量的参数中去找最优解,这个过程在数学上叫做拟合"。

张老师的实战成果——龙虎榜:2003年发明龙虎榜。当时指标:成功率99%,每次出击赚6%。"基本上已经是当时整个指南针里面最顶尖的一个交易系统了"。20年后:经过资金回测、加入缠论,优化到赚10%、成功率100%。

突破方向:当你发现拟合越好、未来越差时——进入第八重"不做优秀裁缝"。

✂️ 第八重 不做优秀裁缝——"主动做减法"

境界名称:努力不做一个优秀的裁缝(第16节 [13:26])

张老师亲历:"这个阶段其实我们就早就已经越过去了",但仍详细讲解,因为这是很多民间高手没有越过去的坎。

本境界的发现——过拟合问题:"前面一个交易阶段的拟合过程中你可能用到大量的过滤器、大量的条件,让策略在历史中表现得足够好"。忽然有一天你会发现一个问题:策略的参数越多,这个策略对未来行情的适应性就越差。

裁缝做衣服的比喻:当下这个时刻越适合的衣服,意味着适应你未来身材变化的可能性越来越小。

真实案例——注册制下的板学选手:"在注册制之前,大家看到龙头选手、他们打板选手都做的特别好。可是这几天注册制开始了,连板基本上就没有了。那么这些板学选手,他们现在基本上他们的策略在未来的市场中可能就发挥不了作用"。

真实案例——出水芙蓉的衰落:张老师在前期测过的"出水芙蓉"形态——1996年:成功率100%。1990年后:跌落到45%的成功率。"就是这个原因,这个衣服已经没法穿了"。

张老师2002-2003年的亲身取舍:

  • 当时追求的目标:成功率10%、收益率10%。
  • 代价:"那么我的成功率当时就降到了89%"。
  • 减法实验:收益率降到9%→成功率92%。收益率降到8%→成功率95%。收益率降到7%→成功率98%。收益率6%→咨询普通散户意见,"能够赚6%他们就可以接受"。
  • 最终:"我的成功率,当时提升到了99%,每次操作都可以赚六个点,其实这就是可以的"。"这个叫做努力不做一个优秀的裁缝"。
🌟 第九重 大道至简——"只有简单才能长期有效"

境界名称:大道至简(第16节 [17:27])

张老师告白:"我非常喜欢这句话"。

境界内涵:"当你试过了万千的法门,用过无数诺贝尔方程式之后,最后你会发现世界其实是简单的"。"只有简单的东西才能在实在长河中保持长期有效的长期能够保持长期有效的,他们都是朴素而简单的"。

  • "第一节课大家刚刚接触我的时候,我给大家的大美女形态"。

14.5 控仓高手心法——世界十大投资大师方法论提炼

💰 控仓心法的核心:不要让"懂得事情"与"做到事情"之间存在鸿沟。张穗鸿老师通过对比十位世界级投资大师的方法论,提炼出控仓心法的十个维度。

14.5.1 索罗斯六大核心要素

  1. 小部分资金测试市场——试探水温。
  2. 正确则继续投入——顺势加码。
  3. 善于运用杠杆——但融资必须小心,大盘高位震荡期不可融资。
  4. 保住本钱(极重要)——进入股市的首要原则:活下去。
  5. 敢于认错——错了需要及时的撤退。
  6. 设立亏损底线——张老师策略中,亏损底线基本都不会达到3%以上。

14.5.2 利弗摩尔的分批进场与10%机动资金

  • 分仓分批进场原则——不是一次性满仓。
  • 试探性操作——与索罗斯"小资金测试"一致。
  • 保留一份存储金(10%机动资金)——关键原则:10%机动资金必须每天收市时回到账户。这笔钱不存在于任何一只股票中。100万仓位→至少有10万资金在账户里。
  • 绝不能平摊亏损——亏损不补仓,不在亏损上加码。
  • 割掉亏损,让利润奔跑——及时止损,让盈利单继续持有。
  • 损失不到10%就必须止损——单笔10%止损线。

⚠️ 利弗摩尔的悲剧:方法论总结得非常好,但他本人没有做到。老年赚了很多钱,死的时候依然凄惨——知行不一的典型反例。

15.3 案例二:特发信息(000070)——1:15报酬比的控仓全程

股票名称:特发信息(000070)

战法定位:控仓高手心法·1:15投资报酬比——《鸿雁进阶专修课》第23节控仓高手心法重点案例。

头肩底关键价位:

  • 头部价格:4.13元。
  • 颈线位:7.52元。
  • 测量目标:10.91元(1:4.5报酬比)。
  • 实际最高价:11.42元(1:5.2报酬比,接近15倍)。

控仓全程解析:

步骤操作价位仓位
① 头肩底成型左肩、头部、右肩确认——
② 颈线位确认买入点确认7.52—
③ 第一仓颈线突破当日买入7.52333法则·1/3仓位
④ 上涨途中缠论三买加仓8.x-9.x333法则·1/3仓位
⑤ 主升段九五至尊确认后加仓9.x-10.x333法则·1/3仓位
⑥ 卖出顶分型出现时分批止盈10.91(目标)→11.42(实际)分批止盈

投资报酬比计算:

  • 目标报酬:颈线位7.52→目标位10.91=4.39/7.52≈58%。

  5. 单股30%仓位上限:总资金的30%投在这只股票。
  6. 5%斩仓线:30%资金亏损5%直接斩掉。
