②学习路径（六阶段）

从工具到哲学，循序渐进，小白按此路径 6 阶段即可进阶。

1
基础建设（1-2周） · 01 看盘界面 + 06 界面答疑
按三层架构实际搭建自己的看盘界面，熟练方向键 / 动态显示牌 / 图形叠加，设置自选股分类。
2
信息处理（2-3周） · 02 一表复盘 + 03 交易计划
每天填写复盘表格（时间轴 + 周期 + 高度），按四维框架制定次日计划，坚持 1-2 周形成习惯。
3
标准建立（3-4周） · 04 涨停板分类 + 10 封板性质 + 11 避免炸板
每天复盘涨停板按形态/时间/量能三维分类，重点放量板（一进二进三），学会识别强板与弱板。
4
标的选择（持续） · 05 F10补涨 + 12 分歧与一致
龙头已成势后用三维体系（股东/主营/暗线）挖补涨，严守市场认可原则，体会"打板抓拐点"。
5
环境与策略（持续） · 07 黄金时间 + 08 普通人方法 + 09 反弹量能
每日判断市场环境（牛市/震荡/下跌），识别黄金时间点，严格执行 5 万以内试水，用量价配合验证反弹。
6
综合实战（长期） · 反复练习
严格执行交易计划，重视合理买点，避免贪心与知行不合一，反复练习找到"分歧到一致拐点"的盘感。
✅ 关键成功要素 ① 从工具到哲学的递进 · ② 主线与答疑结合 · ③ 量变到质变（多练习多复盘多实战） · ④ 核心哲学回归「分歧与一致」 · ⑤ 风险控制贯穿始终。

③第一式 · 定制看盘界面 工具层

回答：短线交易者如何在开盘时间内用最少的视觉切换获取最多的决策信息？

核心理念 工欲善其事，必先利其器。看盘界面服务于短线节奏——「看的是中线，做的是短线」。一切以个人看盘习惯与需求为主导，内容决定形式，绝不盲从他人。

3.1 操作系统选择

方向侧重内容推荐软件
中长线 / 价值投资F10、基本面、业绩、行业研报万得数据库
短线动态数据 + 实时数据 + 跨市场信息（美股、期货联动）通达信、大智慧、同花顺

3.2 三层界面架构（核心框架）

宏观（大盘）→ 中观（自选/关联/涨速）→ 微观（个股） 趋势方向 · 资金流向 · 个股强弱 风格切换 · 板块轮动 · 突变信号 转势节点 · 龙头带动 · 第一档挂单

信息流方向：宏观判断市场环境 → 中观锁定热点板块/龙头 → 微观决定介入时机。

📐 三层看盘界面架构

3.3 微观层面（个股主界面 · 占屏幕最大区域）

  • 分时图：看白线（个股）vs 黄线（板块/大盘）的对比，判断个股相对强弱；图形不能过于扁平（避免压缩导致波动看不清）。
  • 看两天分时：多数软件按方向键下键即可，对比「今日 vs 昨日」。
  • 第一档挂单区宽度要够：括号内撤单数要能显示，用于识别撤单、藏单、集中买卖。
  • K线：要够长，能体现日线级别趋势变化、主力点位置、筹码分布；成交量比例要到位（能看清爆量/缩量）。
  • K线要简洁：作者只用「价格 + 成交量」，连 MACD 都不用；个人习惯把涨停K线变黄色提醒。

3.4 中观层面（自选股 + 关联个股 + 涨速榜）

  • 自选股分类（关键在分类，而非堆砌）三种维度：① 按出现时间点 ② 按股票高度（两连板/三连板/四连板）③ 按市场地位（龙头/跟风/主线题材/竞技题材）。建议按市场地位 + 按高度分类最合理。
  • 关联个股：单独窗口盯总龙头 + 题材龙头 + 支线龙头，通过分时叠加同窗口显示，看竞争/替代关系。即使不操作龙头，也影响交易节奏，必须观察。
  • 涨速榜：看前3-5名（时段风向标）+ 前15-20只（识别共性）。若某类股票持续出现在涨速榜，意味着该类股票正在异动。

3.5 宏观层面（大盘对比）

  • 大盘窗口与个股分时图时间轴对位（如都在10:00），便于个股-大盘对比。
  • 大盘下跌波段中，K线不跌反涨的板块/个股 = 下一阶段主线/热门题材候选。
  • 下午两点跳水后常出现转势板，抓第一个转势龙头。
  • 龙头股/中位股到四板后犹豫，等待大盘翻红（10:00或11:00转折），需多界面同步观察。

3.6 大智慧软件实操（答疑06补充）

功能操作步骤
新建大盘窗口任意股票 → 右键 → 打开新窗口 → 调位置大小；分时界面拐角箭头切换全屏趋势图。
多日行情默认显示 2 天，向下键每按一次 +1 天（最多 5 天），向上键反向操作。
多窗口同时操作菜单 → 系统管理 → 新建窗口 → 图形分析窗口；右键标题可选显示内容（基本行情/暴力/涨幅/涨速），推荐组合「涨幅+涨速+最新」（小窗口可仅看2项）。
动态显示牌/涨速榜菜单 → 系统管理 → 新建窗口 → 动态显示牌 → 右侧品种 → 股票 → 加入上证、深圳 → 点「涨速」排名；显示范围可调长/短周期。

3.7 个性化原则

风格类型盯盘界面侧重
中长线/价值投资F10 + 基本面 + 财报
短线一进二操作者早盘涨速榜 + 自选分类
半路介入者大盘窗口 + 分时叠加
尾盘T+0操作者尾盘异动监控 + 分时突变
核心忠告：他人的界面设置自有其道理，不要照搬。没有最好的界面，只有最适合自己的界面。
📌 五大设计原则 ① 形式服从内容 ② 主次分明（微观占最大区域） ③ 简洁优于复杂（K线指标越少越好） ④ 时间轴对齐 ⑤ 个性化（拒绝盲从）。

④第二式 · 一张表的复盘 信息层

回答：如何用一张表看懂整个市场？

核心理念 用一张表看懂整个市场——剔除无效信号、信息提炼、全景回顾、市场倒影。三大目的：清晰判断 + 正确时机 + 高手共识（个性化表格）。
📐 复盘表三大支柱

4.1 时间轴：表格的灵魂

  • 当前市场周期：龙头股周期（处于哪个龙头周期）+ 市场情绪周期（上升期/下降期/回暖期/退潮期）。
  • 时间点上的事件：标记特定时间点通常出现的事件。
  • 当天市场的高度：每日空间高度量化（三板/四板/六板/七板），用颜色区分高度差异。
  • 周期变化点：退潮→回暖等关键节点用突出颜色标记（如宝鼎科技四板回暖日），是最重要的开仓/减仓时间点。
  • 断板日：龙头股未能进阶（如宝鼎科技五板失败）→ 标记为退潮信号，可能产生新机遇或对存量题材构成伤害。
  • 空间高度预判：前龙头三板四板挂掉，新龙头走到三板四板时，市场可能分歧。

4.2 主龙头股的周期

  • 总龙头：市场带节奏的龙头，定义周期。经典：泰永长征周期、宝鼎科技周期、风范股份周期。
  • 颜色差异化：主龙头宽度更宽、颜色更醒目；跟风股/一进二用灰色。
  • 每日涨停板标记：板数（第几板）+ 量能变化（缩量/放量）+ 爆量（特别醒目标示，代表市场重大分歧）。
  • 资金流向：一部分做补涨（新支线逻辑），另一部分做新题材。
  • 龙头末期首阴标记：结束方式（闷杀/盖杀/出货/平稳过渡）。交棒日=首阴日，用蓝色框框显示，是一进二选手重点研究日。

4.3 经典案例：2018年12月—2019年1月

日期关键事件周期定位操作意义
12月17日汉嘉设计四板（前龙头三板）回暖信号关注新主线
12月24日泰永长征五板（高于汉嘉四板）一阶段可开仓/加仓
12月26日泰永长征六板结束，新题材新基建交棒日风范股份走出九板十板
1月2日风范股份周期内，鹏启科技出现叠加逻辑5G+军工+特高压 → 特发信息五板
📌 四大关键方法论 ① 周期定位（每日先判断周期阶段） ② 交棒日识别（首阴日=新题材活跃日） ③ 断板预警（龙头未进阶=退潮信号） ④ 量价异动（爆量=市场重大分歧）。
📎 补充要点 表头设计：时间轴通常放在表头（横轴），空间高度每日必须清晰标记。长期价值：通过切身制作表格加深理解、积累回顾，高手通过回顾过去总结避免被市场淘汰（市场进化）；建议每月回顾半年内的表格，发现规律。

⑤第三式 · 制定交易计划 决策层

回答：如何避免被市场情绪支配，建立科学判断？

核心理念 计划你的交易，交易你的计划。散户常见问题：「开盘两条线（白线/黄线），收盘光软件」——每天盯盘却毫无章法。

5.1 三大核心功能

  • 信息提炼：盘前/盘中/盘后纷繁信息筛选。
  • 盘感量化：将强弱、赚钱效应等主观感受大致量化，形成连贯记忆。
  • 预期更新：对大盘、个股判断动态修正，形成系统计划。

最终目标：缩短看盘及交易过程中的反应时间。

📐 交易计划四维框架

5.2 复盘维度

  • 指数趋势：不追求精确预测，但需判断一段时间内是否有系统性风险或突破/加速趋势。
  • 分时叠加题材贡献：明确上涨/下跌时点是哪个题材在表现，理解题材分布、人气走向与资金进攻方向。
  • 顺势 vs 逆势题材：顺势题材（如科技）指数上涨时表现；逆势题材（如军工）指数下跌时可能反复表现，构成机会。

5.3 涨停分析维度

  • 归类与原因解析（重中之重）：可参考他人分析，但必须有自己的理解；注意个股叠加概念，避免漏票（漏掉逻辑可能错失龙头）。
  • 题材主次与强弱：理清主线/支线、强/弱题材，判断主线是发酵放大还是压缩缩小；梯队梳理（四板/三板/二板了然于胸）。
  • 新题材特别关注：新题材出现时市场资金高度重视，判断大级别 vs 小级别，影响后续补涨股及一进二进三的优先选择。
实战案例：澳交所活跃时压制 VPN 与瑞达期货；澳交所退潮时，另两个题材反包。

5.4 核心票分析

  • 范围：龙头股 + 对市场人气影响大的票，影响市场整体节奏。
  • 龙头打出新高度 → 市场周期可能进入新阶段。
  • 前期龙头反抽涨停 → 退潮期可能结束，市场进入回暖期。
  • 龙头自身周期：缩量连板后爆量开板 → 周期可能结束，资金分流寻找新方向。
实战案例（宝鼎科技）：10月17日十天线附近反抽涨停 → 退潮期尾声；反抽四连板缩量 → 一旦开板爆量周期结束；爆量封不住时新题材（澳交所）出现。

5.5 统计数据

  • 连板指数走势：判断是否连续偏离，预示风险。
  • 涨停溢价率：昨日涨停股今日高开比例。
  • 封板成功率/炸板率：对打板型选手的出手参考。
  • 龙头股首阴走势：尖顶还是平稳过渡。
  • 盘后新闻与个股公告：如宝鼎科技10月11日被交易所关注，次日结束。
📌 四大关键方法论 ① 避免情绪化（用计划约束行为） ② 顺势+逆势双线判断 ③ 新题材优先级最高 ④ 核心票分析（龙头决定市场节奏）。
凡事预则立，不预则废——充分复盘后，有准备、有底气地进入下一交易日博弈。

⑥第四式 · 涨停板的分类 标准层

回答：看懂涨停板——短线交易的核心基本功。

核心理念 涨停板是短线交易的核心。分析维度是分歧与一致——判断涨停板背后原因（技术成因，非逻辑成因），为预期判断提供技术依据，大幅提高胜率。
📐 涨停板三维分类体系

6.1 维度一：形态分类

类型形态特征次日预期
一字板买方抢筹，卖方惜售，看法高度一致高溢价预期；若次日平开或略低开 = 机会
T字板与一字板相似，存在小分歧，承接更强高位小心，低位是机会
中高开秒板缩量开盘5-6个点，秒板缩量可对标T字板
一根长阳量价齐升，资金主动做多拉出7-8个点最具攻击力，后续会有新高
地天板跌停到涨停（20点阳线）溢价不高，走不远，不建议接力（更适合当天水下低吸）

6.2 维度二：时间分类（更重要）

类型时间案例操作策略
加速板10:30前封板华谊嘉信3、4板溢价高，一封可打；低位好题材次日可能进一步加速（进入一字/T字）；迷茫期可能再次换手（分歧加大）

⑧答疑系列 · 实战细节 答疑层

8.1 答疑二 · 市场环境与黄金时间点

核心问题何种市场环境适合做短线？——市场环境决定短线操作可行性。
📐 市场环境三分法
  • 牛市：系统性上涨，所有模式均表现良好。
  • 震荡市（风格切换）：蓝筹单边 → 资金流向小票题材股，是黄金时间，题材热点爆发（如电力物联网、OLED 单日百股涨停），龙头战法单票翻倍（7个涨停板）。典型：3288点。案例：风华股份、银星能源、龙津药业、东方网络、复旦复华。
  • 下跌市（止跌企稳）：连续下跌后确认止跌，是黄金时间。第一阶段探路龙头（涨幅有限4-5板）→ 第二阶段主升龙头（新大龙头诞生）。典型：2733点、11月低点。案例：九鼎新材（2733点后）、宝鼎科技（11月低点后）、2015股灾后梅雁吉祥/中航光电。
📌 抛砖引玉 + 杠杆策略 用「推背图工具」：白字标记「砖」（探路龙头），黄字标记「玉」（主升龙头），黄色机会（玉）确定性大于白色机会（砖）。杠杆仅在确定性极高的黄金时间点考虑。

8.2 答疑三 · 普通人炒股方法

核心问题普通小韭菜如何快速学会炒股？（案例：3个月40万亏至20万，亏损50%）
⚠️ 入场时机判断（被忽视的前提） 入场时机错误是亏损的首要原因：市场不景气、短线生存环境近年最差，震荡下跌（最磨人行情）最易「闪婚把裤子赔掉」。对比数据：2018年90%资产负收益；2019上半年有行情、下半年持续震荡。炒股门槛虽低，但成功概率仅10%，务必先小资金试错。

资金控制

  • 5万以内试半年到一年，目标「稳定亏损」（非大起大伏），找到感觉后再加资金。
  • 风险警示：一赚二平七亏是常态；激流勇退极难（染上赌性难退出）；初始盈利更危险（易无法自拔）。

方案一：有行情做，没行情不做（稳健）

  • 空仓是交易的重要组成部分：不操作也是一种操作，大部分时间空仓。
  • 关键信号：爆量大阳线（成交量突然放大，增量资金入场）——个股易造假，大盘不易造假，至少3天内安全。
  • 操作标的：最傻做法买ETF（如50ETF）；稳健做法买上证50十大权重股；白马股大盘上涨时收益不会太差。
  • 收益预期：指数涨20%，收益应接近20%。

方案二：做题材股（激进）

  • 只做重大题材（化工厂爆炸、重大政策规划），通常一个月一次。
  • 看着龙头做跟风：浙江龙盛（丽水化工厂爆炸）→ 鲁西化工，最高50%收益取20%即可。区块链消息首日130个涨停、次日60多个。
  • 不贪心，只求10%，一年做3-5个题材，收益可达50%。
  • 避免两大错误：贪心 + 知行不合一。

8.3 答疑四 · 反弹有效量判断

核心逻辑反弹有效性判断非单一指标，基于K线重心 + 盘感；核心原则：量在价先，成交量先行确认。
实战案例（11月25日）22日冲高回落，25日翘尾收阳线且成交量大于前一日→ 放量吃掉前一日阴线，短期看多。补充：顶部爆量在强趋势中（如2014-2015年）可能反复，先兆信号后或再创新高，最终撑不住下跌。
信号特征含义
有效放量吃掉前一日阴线短期看多，反弹有效
无效缩量、阳线小反弹存疑，连续性不确定
底部爆量下跌尾声最后见底日爆量（恐慌盘+抄底资金集中交换）形成尖底（单底），如2733点、8月6日
顶部爆量高点异于常态的爆量（阳线/十字星/长下影线/阴十字星）重大分歧，如5178点、3478点、3288点

8.4 答疑五 · 10点封板性质判断

核心问题10点上板后打开，14:30再次封板，属偷板还是弱转强？需区分强板与弱板。
类型量能含义
放量板放大= 分歧板，多空分歧大，换手充分
缩量板缩小= 加速板，市场一致看多，抛压轻
  • 10点关键时间点：势强（主动上板或冲至8个点横盘，表明态度留筹码）；势弱（10点不试强会引发集中抛压，10点、10:30为砸盘高峰）。
  • 10点封板两种类型：① 一进二抢板（卡位）② 弱转强加速板（如海联讯，昨日分歧今日高开10:14封板）。
  • 勉强板 vs 主动板：勉强板（被动跟随，二封成交量极小、上板不坚决）→ 谨慎参与；主动板（主力主动引导，封板坚决、量配合、分时流畅）→ 可参与，次日溢价概率高。
  • 弱转强：弱板需观察次日集合竞价（高开带量则可能转强）。
⚠️ 核心风险混淆强板与弱板，会导致次日操作方向完全相反（如弱板次日跌停）。

8.5 答疑六 · 避免打板炸板

核心问题如何避免打板炸板？从逻辑角度切入，非单纯技术讨论。炸板概率：一半炸一半不炸（封板率60%）。
  • 对标的预期：判断次日是否有强上板预期，用于过滤无效板。
  • 分歧板 vs 加速板：分歧板次日通常加速；加速板可能迎来新分歧，或极限「两板缝一致」（更强）。关键：明确票的周期定位与定性（上一板是什么板）。
  • 强到更强的高风险：若无法封住，获利盘倾泻而出（已有20%利润）；关键阈值 20%。
  • 合理买点：决定炸板后是否会被自救。合理买点 → 理论上会自救；非合理买点 → 可能无修复。
案例定位次日表现后续修复
银禧科技三版换手板+周期+新能源叠加（绝对高度安源煤业；当日周期股涨停时7个新能源涨停）不被认可（韶钢、安阳煤业大阴线，周期走弱）救回新高（因合理买点）
国风塑业折叠屏龙头大幅杀跌（盘中跌停）被救回（因合理买点）
📌 核心结论打板不炸的根本因素是逻辑（对市场的理解），非技术；合理买点是打板前提，决定是否会被自救。

8.6 答疑七 · 分歧与一致的本质（哲学层）

核心观点抓住分歧与一致的本质，比单纯看指标更重要。
📐 分歧与一致二维体系
  • 概念区分：分析（个体偏好差异）vs 分歧（群体意见不统一）。
  • 分歧的市场结果（两种形态）：① 强——下午拉升强势但未封涨停（大阳线）；② 板——涨停板。分歧既可能走向「强」也可能走向「板」。
  • 简化模型：涨停 = 一致（过滤强势因素）；未涨停 = 分歧（含分歧板）；放量 = 分歧；缩量 = 加速（一致，惜售不卖）。
  • 分歧到一致的瞬间（打板最具艺术性的环节）：类比辩论赛——初始正反各半 → 真理越辩越明 → 有人带头点明逻辑（点火的人） → 跟风资金一上形成一致。
  • T+1市场加速效应：分歧到一致后，第二天通常加速一致；场外观望者当日无法买入，次日会毫不犹豫冲进来。
  • 涨停板中的分歧：已封涨停仍有大量抛单（1000手反复加撤、开板回封），本质是涨停板内资金仍有分歧。
  • 判断标准：量化指标中没有明确的分歧与一致判断标准，解决路径是谈感觉、多练习。
哲学总结：短线不是纯技术，而是对人性的理解。「打板即打分歧到一致的那个拐点」是整个系列的核心方法论。经验的积累比任何指标都重要。
