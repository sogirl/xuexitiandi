第2讲 · 课程学习指导（洪攻略体系）

定位：龙虎榜战法理论总览课，从洪攻略体系框架出发，梳理投资体系基本要求，查漏补缺与深入提升。

1. 龙虎榜定义与作用

  • 本质：交易所公开的成交回报（每日披露）
  • 定位：基础且专业的工具，投资不局限于龙虎榜
  • 最大作用：了解自己与谁站在同一队伍（游资 / 机构 / 量化 / 散户）

2. 洪攻略体系框架（道）

  • 三要素：思维、投资时空观、操盘策略（H333/H000/H110）
  • 实战应用：看消息 → 选股 → 择时 → 操盘
  • 龙虎榜战法落地：看龙虎榜 → 盯盘 → 复盘 → 选股 → 择时 → 风控

3. 洪攻略思维三大要点

  • 聪明的钱：机构资金（禁止日内反向交易）vs 游资资金（多数隔日交易）；最佳品种是机构锁仓 + 游资拉抬
  • 主要矛盾：抓住市场主线，关注龙头板块（城门立木所在板块）
  • 预期可控：用情绪温度计判断春夏秋冬

4. 复盘方法（五维度）

  • 五维度：涨停股、涨停时间、连续涨停天数、涨停原因、板块
  • 梳理顺序：按板块分类 → 按涨停天数（高标四/三/二板）→ 按涨停时间
  • 核心要求：如数家珍，盘中/盘后清晰掌握
  • 标杆案例：渤海彰武路大佬每日逐股翻看（5000+ 品种，约 3 小时）

5. 挖掘城门立木（龙头）

  • 核心标准：以高度区分，辅以带动性、涨停顺序
  • 类型：游资票龙头（连板高度）vs 机构票龙头（如长安汽车）
  • 龙头特征：最受资金关注、涨时涨幅最大、跌时最抗跌
  • 复盘规律：龙头死得最晚、涨得最多，贯穿板块始末

第4讲 · 龙虎榜实战运用（成本计算）

定位：龙虎榜战法第三讲——实战应用（案例教学：长安汽车 + 爱康科技），核心能力是成本计算。

1. 核心能力：成本计算

  • 目的：知己知彼，百战不殆
  • 估算大资金底仓数量与成本位置，避免被震荡洗盘出局
  • 方法：基于龙虎榜数据（每日进出资金量）进行推算
  • 意义：盘中变化需临盘应对，计算经验提升盘感

2. 炒股养家对龙虎榜的观点

  • 观点一：知己知彼——了解对手心理与动作，操作更主动
  • 观点二：龙虎榜有用，但需全面了解——存在对倒行为，主力意图可变
  • 案例：浙江世宝护盘信号（9:24分出现多笔大单）

3. 长安汽车案例（深股通）

  • 时间区间：2022年4月26日—6月28日
  • 股价区间：-27低点-55元 → 涨停启动 → 高点-88元
  • 主导资金：深股通
  • 数据陷阱：6月24日除权日，系统直接计入送股，持股数从约-32亿跳变为-7亿（需手动调整）
  • 计算假设：以每日收盘价作为交易价格，忽略税费

4. 成本计算的两大方法

  • 解法一（每日计算法）：以每日收盘价为基准，分日计算盈亏
  • 解法二（总市值差额法）：总市值变动 - 累计净买入金额
  • 两种解法差异约 53 万（因未扣税）
  • 核心结论：深股通净买入仅 -3.9亿，市值从 10 多亿拉抬至 -35亿，杠杆效应显著

5. 除权处理的关键

  • 数据陷阱：除权日系统直接计入送股，持股数跳变
  • 修正方法：获取除权价格（下一日昨日收盘价），手动调整持股数
  • 长安汽车：10送3，原持股-3.1亿 → 送股约3900万；现金分红约3053万元

6. 爱康科技案例（私募运作）

  • 背景：光伏板块行情期

1. 龙虎榜规则重要性

  • 上榜条件：必须清晰了解游戏规则
  • 三日榜 vs 单日榜区别：三日榜买入卖出可能非当日操作（前日买入、当日卖出）
  • 成本估算：难以精确，通常以收盘价或均价为参考
  • 核心洞察：判断主力方向（撤退 或 志存高远）

2. 五大制度要点（注册制新规）

  1. 精简优化发行上市条件：以信息披露为主
  2. 完善审核注册程序：交易所审核 + 证监会督导
  3. 优化发行承销制度：市场化定价（新股可能破发）
  4. 完善上市公司重大重组制度
  5. 强化监督执行与投资者保护

11. 交易原则精华

  1. 市场主线优先：每次参与均在市场主线板块，相当于小牛市

  3. 极端交易：只选极端品种（强者恒强）
  4. 做鱼身策略：右侧交易，不做左侧抄底或逃顶（让渡鱼头与鱼尾）
  5. 仓位管理：好机会重仓，普通机会轻仓
  6. 做T前提：必须基于趋势
  7. 首板纪律：以涨停为买卖点

复盘的本质

  • 对高手是基础工作，对新手是必修课；关键是认知水平达到一定高度后的简化

卖点盈亏同源
