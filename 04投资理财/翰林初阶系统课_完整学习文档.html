阶段一：理论基础

第1课：极点战法情绪周期

万物皆周期

理论基础

翰林老师提出"万物皆周期"的核心理念——日出日落、潮起潮落、花开花谢、生老病死，无一不是周期现象。映射到股市，任何股票也无法逃离情绪周期。因为股票操作的本质是人，人必然有情绪周期。

情绪周期的根源是人性中两个根本驱动力：贪婪与恐惧。贪婪导致追高买入，恐惧导致恐慌割肉。这两种情绪使90%以上的交易者追涨杀跌，且不受控——这是人类上万年前原始社会形成的群体本能。

五大情绪周期

核心框架

整个股价运行被划分为五个阶段，周而复始、永恒循环：

高潮期→退潮期→冰点期→启动期→加速期→高潮期
  1. 高潮期：成交量最大，买的人疯狂，怕追不到。高潮是短暂的，往往是见顶信号。
  2. 退潮期：高潮之后必然退潮，股价开始下跌调整。
  3. 冰点期：成交量极其稀少，市场停滞，"极价+极量"——十字星配合低量柱。
  4. 启动期：冰点之后慢慢恢复，关键介入时机。
  5. 加速期：启动后加速上涨，往往以涨停方式加速，最终再次进入高潮。

散户常见误区

认知纠正

大部分人在高潮期追进去——高潮时成交量最大，买的人最疯狂，怕追不到。结果恰恰追在最高点，此后一路下跌进入退潮。

正确的做法：在冰点之后的启动期买入。在高潮之后调整到位，于启动期重新买入，才能"一买就涨"。

极点战法的定义与三大核心要素

核心定义

极点战法是一套极致低吸战法。定义：主力取得绝对优势的前提下，刻意洗盘出现的极致低点。

三个关键词（缺一不可）：

  1. 绝对优势：主力已取得优势地位。
  2. 刻意洗盘：主力主动打压清洗不坚定筹码。
  3. 极致低点：调整到最极限的位置。
操作口诀

买在启动而非冰点。冰点虽是最低点，但"没有确认的时候它可能还会跌"。真正的买点在冰点之后的确认——必须有启动信号（涨停或中阳线确认），才能"一买就涨"。 巴菲特："当别人恐惧的时候我贪婪，当别人贪婪的时候我恐惧。"

经典案例
金科股份情绪周期分析
金科股份

高潮期（A、F）：最高的两根量柱。

退潮期：紧跟着最高量柱开始的下跌调整。

冰点期（C）：退潮之后的最低量柱，极价+极量，十字星+低量。出现连续三天可视为冰点期。

启动期（D、I）：以涨停的方式启动，I本身既是启动又是加速。

加速期（E）：涨停板加速。

阶段二：识别工具——量柱结构、形态分类、时间结构

第2课：极点战法量柱结构

六大支柱体系总览

识别工具

翰林老师将五大周期对应到具体的量柱结构，形成ABCDEF六大支柱体系：

情绪周期对应量柱简写核心判定标准 / 特征
高潮期高潮柱A柱最高量 + 最高价（不分阴阳线）
退潮期恐吓柱B柱缩量阴线，1-6根（常见3根），假跌洗盘
(支撑)支撑柱C柱高倍量大阳线，提供顶底腰缺支撑，独立于五大周期
冰点期停止柱D柱极量（缩量1/2）+ 极价（十字星），需确认才正式成立
启动期确认柱E柱涨3%+ 概括阴线，量平或量增，涨停确认最佳
加速期反攻柱F柱三"为强"：倍量为强 / 跳空为强 / 涨停为强

ABCDEF各柱详解

识别工具

A 高潮柱：最高量 + 最高价 = 高潮柱。不分阴阳线。识别高潮柱是避免"追高买入"的前提。

B 恐吓柱：主力刻意洗盘的"假跌"。缩量阴线，1-6根（常见3根）。最佳形态是"量价连缩"——量与价同时连续缩小。

C 支撑柱：高倍量大阳线，最好涨停板。支撑位置"顶底腰缺"——顶（阳线顶部）、底（阳线底部）、腰（实体中间）、缺（跳空缺口）。有时与高潮柱合二为一，"又当爹又当妈"。

D 停止柱：低量窄幅十字星（极量+极价），涨跌幅约1%。需被确认才能算正式极点。未被确认只能视为"潜在节点"。

E 确认柱：涨3%以上（最低门槛），概括/吃掉停止柱左侧最近阴线。涨停板确认最佳（此时E与F合二为一）。

F 反攻柱：三"为强"标准——倍量为强、跳空为强、涨停为强，涨幅大于5%为强。

双重极点（"俄罗斯套娃"）：调整结构内部嵌套小极点结构，往往是牛股启动点，爆发力极强。

核心密码：3121法则

核心公式

3121是极点战法的量比关键参数：

停止柱的量 ÷ 高潮柱的量

  • 1/2（二分之一）：缩至高潮柱量1/2以下，基本调整到位（大多数情况）
  • 1/3（三分之一）：缩至高潮柱量1/3，调整更充分（少数情况）

达到1/2 + 十字星（极量+极价）= 调整到位，等待确认柱。

五大买入时机

操作指南

所有买点集中在D-E-F三根柱子上：

序号买入时机位置适合人群说明
1停止柱尾盘买入D柱当天尾盘仅老手提前潜伏，风险较高
2确认柱开盘买入E柱当天开盘通用 ★跳空高开开盘买最佳
3确认柱盘中买入E柱当天盘中通用盘中确认后介入
4确认柱尾盘买入E柱当天尾盘通用非涨停中阳线时尾盘来得及
5反攻柱买入F柱（次日）通用错过确认时用
操作口诀

新手不建议在D柱尾盘潜伏——未经确认存在继续下跌风险。 优先使用确认柱(E柱)和反攻柱(F柱)的买入时机。 确认柱三大买点（开盘/盘中/尾盘）是实战核心窗口。 涨停板确认时E+F合二为一，是最强信号！

第3课：极点战法形态分类

五维分类逻辑框架

识别工具

形态分类依据量柱结构中不同柱子的特征变化，共有五个维度。同一个节点可以同时属于多个分类（多标签共存），分类目的是一眼识别每个节点属于哪个分类，快速判断主力行为模式。

五大分类维度：

  1. 按恐吓柱分类：一日极点 / 双阴极点 / 连阴极点
  2. 按停止柱分类：标准极点 / 完美极点 / 变异极点
  3. 按支撑柱分类：涨停极点 / 大阳极点 / 连阳极点
  4. 按确认柱分类：飞天极点 / 空点极点
  5. 按反攻柱分类：（进阶内容）
分类维度类型占比/频率核心特征
按恐吓柱(B)一日极点极低·最强调整1天，恐吓柱=停止柱，爆发力最强
按恐吓柱(B)双阴极点最常见连续2根缩量阴线，最常见形态
按恐吓柱(B)连阴极点稳健3-5根阴线，调整更充分，确认后爆发力强
按停止柱(D)完美极点≈10%最标准，四大铁律，送分题·起爆点
按停止柱(D)标准极点≈20%首尾框架：首阴缩量+尾十字星缩1/2
按停止柱(D)变异极点≈70%三变异：高潮柱/恐吓柱/停止柱变异
按支撑柱(C)涨停极点以涨停板为支撑柱，支撑最强
按支撑柱(C)大阳/连阳极点大阳线或2-3根小阳合并支撑
按确认柱(E)飞天极点跳空高开过阴顶，主力迫不及待拉升
按确认柱(E)空点极点二阶课程详讲
分类总纲

万变不离其宗：高潮柱 + 支撑柱 + 停止柱 = 极点本质。 分类的目的是让交易者在不同"马甲"下识别出同一个本质结构。 多标签共存：一个极点可同时是"左峰+完美+单枪+一日"。

第4课：极点战法时间结构

"三八十"时间约束

识别工具

时间结构是支撑柱、高潮柱、停止柱之间相隔的天数，是决定极点爆发力的第三维度：

时间区间约束说明
支撑柱 → 高潮柱最多3天三种模式：合二为一（最理想）> 相邻紧挨 > 相隔一天（上限）
高潮柱 → 停止柱最多8天以2、3、5天为最佳（235最佳），8天为上限，"调整不过八，过了主力差"
支撑柱 → 停止柱总计不超过10天"十天是红线，超过就失效"，能量散了，可能演变成另一周期的节点
时间与爆发力越短爆发越强1天=一日极点（最强）> 2天=双阴极点 > 3天+=连阴极点
时间口诀

高潮支撑合二为一最理想，相邻一天也可以，隔了一天是上限。 调整不过八，过了主力差。 十天是红线，超过就失效。 时间越短爆发越强（黄金公式）。

阶段三：战略选股——城堡战法

第5课：城堡战法

城堡的来源与核心比喻

战略选股

翰林老师以欧洲中世纪（1066-1400年）城堡为引子：城堡作为军事基地修建，既用来发动攻击，也用来防守。股票中主力同样通过构建"城堡"作为进攻和防守的基地。

核心口诀：城堡选股，极点择时。

城堡战法用于选股和判断主力动向，极点战法用于确定精准买卖时机。

城堡的定义与分类

战略选股

城堡 = 高倍量中大阳线，根据涨幅分为四等：

类型涨幅范围说明
小城堡3%-5%以内中小级别城堡
大城堡5%-10%加速阶段主力阵地
超大城堡10%以上（含20cm/30cm）最强级别城堡

城堡的两大要素

战略选股

要素一：高倍中大型阳线——量柱为高量或倍量（放量明显），K线为中大阳线（涨幅至少3%以上）。

要素二：3日内不破顶或不破底——守住顶线=进攻状态（强势）；守住底线=防守状态（蓄力）。

进攻型 vs 防守型城堡

核心分类

防守型城堡：高倍中大阳后股价连续回调，但始终不破底线。主力洗盘整理，城堡底部支撑有效。

进攻型城堡：高倍中大阳后股价连续上涨，始终不破顶线。主力强势上攻，持续上涨。

失效城堡：股价跌破底线——该城堡失效，不破底是城堡存在的底线条件。

攻防三区

操作体系

以城堡的顶线（收盘价）和底线（开盘价）为界，划分三个区域：

区域位置操作策略信号
进攻区顶线之上可以持有，安心拿住多头强势
防守区顶线与底线之间观察等待，看能否站上顶线蓄力阶段
撤退区底线之下跌破底线就止损！弃城而逃主力出逃

大小城堡支撑位置差异

补充要点
  • 大城堡（5%以上）：支撑在顶、底、腰、缺（四个位置都可能成为支撑点）。
  • 小城堡（3%-5%）：支撑主要在顶（也可在底）。

大城堡阳线实体足够大，内部有足够支撑空间；小城堡实体较小，支撑位置相对集中。

城堡战法口诀

高倍中大阳，三日不破底，城堡成立。 顶之上进攻可拿住，顶底间防守需观望，底之下撤退快止损。 城堡选股，极点择时。 跌破城堡，弃城而逃。 没有城堡的股票不能碰——下跌中无城堡=无主力护盘。

⚠
前置知识：城堡战法需要先掌握1.情绪周期和2.量柱结构（ABC柱识别），尤其是支撑柱（C柱）的顶底腰缺概念。

阶段四：具体战法——十大极点类型 + 涨停战法 + 分时战法

子板块A：按调整天数分类（第6-8课）

第6课：一日极点

一日极点的两种类型

调整1天·最强

调整时间仅一天的特殊极点形态。阳线次日缩量1/2十字星/小阴线，第三天即上涨。极其稀缺，是最佳介入时机之一。

防守型：恐吓柱与停止柱合二为一——前一天阳线，次日跳空低开收十字星（缩量1/2），第三天上涨。极量+极价=调整到位。

进攻型：高倍量次日价涨量缩——前一天高量/倍量阳线，次日价涨量缩十字星（缩至1/2）。"非常神奇，价格涨了量居然是缩的"——往往是牛股爆发点。

缩量涨停过前高：说明"主力可以用很少的力量创造新高"，意味着主力已牢牢控制局面。

经典案例
新五丰（防守型一日极点）
新五丰·2023年4月4日

涨停板后出现放量中阳十字星（A柱），次日缩量1/2小阴线，次日以缩量涨停突破前高，随后连续大涨。

经典案例
九安医疗（进攻型一日极点）
九安医疗·2021年

D柱为倍量柱大阳线，次日跳空高开收十字星，成交量缩1/2——经典的极量+极价到位。之后连续5个涨停板，从起涨点（3元多）最终涨到90多元，涨幅近30倍。

经典案例
汇成科技（过渡案例）
汇成科技·2020年

放量大阳线后第三天缩量1/2+十字星（极量+极价），第四天缩量突破前高，随后连续5个涨停板。翰林老师比喻为"起飞之前的下蹲动作——起跳之前先下蹲，然后弹跳起来"。

第7课：双阴极点

双阴极点五个核心条件

调整2天·最常见

全称"双阴极点涨停"。高潮柱后连续两根缩量阴线（恐吓柱），停止柱缩量1/2十字星确认调整到位，确认柱开启新一轮上涨。

  1. 高潮柱与支撑柱一体：同一根K线，"又当爹又当妈"。允许相邻的变异形态。
  2. 恐吓柱两根：连续两阴。如停止柱是十字星可不包含在阴线内，最标准形态："一根阴线 + 一根小阴线"。
  3. 连续缩量：第二根量比第一根更小——假跌判断依据，主力出货不会缩量。
  4. 停止柱缩量1/2：极量+极价的统一标准。
  5. 停止柱以十字星为佳：标准十字星为最优。

三种买入时机

操作指南
  • 时机一：跳空高开竞价买入——9:25集合竞价确认后直接买入，结合大盘热点板块。
  • 时机二：盘中过尾阴买入——价格突破两根阴线最后一根的最高点（阴顶）时买入。
  • 时机三：确认柱收盘前买入——确认柱为中阳线（3-6个点）时尾盘买入，期待次日溢价。

第8课：连阴极点

连阴极点核心要点

调整3-5天·最稳健

调整时间超过两根阴线，3至5根阴线的极点形态。恐吓柱数量：通常3-5根，过多则形态走弱，过少则归为双阴极点。

完美缩量连阴：价与量同时缩——阴线跌幅逐日减小+成交量逐日递减。"量也缩，价也缩，这种是完美的"。

统一标准：停止柱仍须满足极量+极价（缩量1/2+十字星）。

重要：潜伏风险更高——连阴情况下即使出现极量+极价，还可能继续跌。最佳买点一定是确认柱，以牺牲少量利润换取更高确定性。

经典案例

连续四天调整（四阴），量价连缩。C柱十字星+缩量1/2到位，D柱确认后连续大涨。关键教训：C柱前一日量未到位，"量没到位就是量价不到位，所以继续跌，直到量到位才出现真正的极阴"。

子板块B：按标准程度分类（第9-11课）

第9课：标准极点

标准极点——基准坐标

约20%

标准极点是所有极点的基准坐标系。核心方法："首尾框架法"。

  • 首阴缩量：高潮柱后第一根阴线应缩量1/3以上——"首跌缩越多，假跌概率越高"。
  • 尾十字星缩量1/2：停止柱须是缩量1/2的十字星。

只要首尾两个端点满足，中间的变化（三阴、双阴、变异等）都可归入标准极点范畴。

量价线位四维分析法：量（缩1/2）、价（十字星）、线（顶/底/腰/缺四种支撑线）、位（停止柱在关键线上的精确位置）。精准回踩（一分不差或差一两分钱）是最强信号。

总纲领

万变不离其宗：高潮柱 + 支撑柱 + 停止柱 = 极点本质。 分类意义：让交易者在一眼就能看清楚——"他只是换了个马甲而已"。 离标准越近，确定性越强。

第10课：完美极点

完美极点——送分题与起爆点

约10%·最重要

极点体系中确定性最高的形态，翰林老师多次用"送分题"、"主力送钱的"来形容。四大铁律：

  1. 高潮柱与支撑柱必须一体（一极）：同一根K线，"这是核心，这是重点"。
  2. 恐吓柱最多1至2根：只能是一根阴线或两根阴线，超过即不符。
  3. 支撑柱与确认柱相隔2天或3天：两日完美极点=一阴+十字星；三日完美极点=两阴+十字星。"完美极点只有两种情况，没有其他的"。
  4. 停止柱必须是标准十字星 + 缩量1/2：不允许任何形态变异。

五次买入机会

多重窗口

翰林老师明确列举完美极点提供的五次买入机会：

  1. 停止柱尾盘潜伏——完美极点是少数明确允许潜伏的类型
  2. 确认柱跳空高开竞价买入——9:25后直接买
  3. 确认柱盘中追买
  4. 确认柱尾盘买入——非涨停板时的选择
  5. 确认柱次日买入——以上全错过仍可入场
翰林老师的心智训练要求

把这个完美节点刻画在你的脑海里面。 做梦都能够出现完美节点的形态。 闭上眼睛能够立刻跳出完美极点形态出来。 在梦中能够梦见出来——就代表你已经进入家境了。 给了你五次机会，如果你都没买，一定要检讨！

第11课：变异极点

变异极点——实战主体

约70%·最重要

变异极点占市场所有极点的约70%。形态可伪装，量价关系不骗人。

三种变异类型：

  • 高潮柱变异：放量阴线作为高潮柱——K线同时具备高潮柱（放量）和恐吓柱（阴线）双重属性。
  • 恐吓柱变异：下跌中夹杂阳线——不是连续阴线，而是阴阳交替。
  • 停止柱变异：中小阴线代替十字星——跌幅比前一天大，但量没放大。

核心原则：极量+极价才是根本，任何变异后必须出现标准停止柱。

子板块C：按支撑/确认方式分类（第12-14课）

第12课：涨停极点

涨停极点的投资逻辑

涨停板支撑

以涨停板作为支撑柱的极点形态。核心选股思路："在涨停板里面抓涨停"——"在有鱼的地方去钓鱼，而且是有大鱼的地方去钓鱼"。

连环涨停极点效应：同一个涨停板可以为多个后续涨停提供支撑——一个涨停确认柱可同时成为下一个极点的支撑柱，形成连续涨停机会链。

跌时缩量 = 主力没逃：调整期间缩量是关键信号，说明主力没有出逃。

经典案例
天房股份（连环涨停）
天房股份

展示多层次涨停极点逻辑：第一个极点缩量1/3次日涨停；第二个极点十字星量价到位+C柱跳空高开涨停。C柱涨停板既是前一极点确认柱，又是后续极点支撑柱——连环效应。

经典案例

涨停极点口诀

在涨停板里找涨停板——先去有大鱼的池塘再下网。 涨停板是"大鱼"信号，有涨停=有强主力资金。 跌时缩量不惧——缩量说明主力没逃。

第13课：飞天极点

飞天极点——最强确认形态

跳空确认

前一天标准极点（停止柱中小阴/十字星+缩量到位），次日跳空高开过最后阴线顶部。命名含义——股价像"直接升天"一样跳空飞出。高开是主力行为，散户做不到——主力迫不及待拉升的强烈做多信号。

标准飞天：跳空直接过阴顶，可直接买入。

变异飞天：跳空但未过阴顶——等盘中过顶再买。

精准度要求：越精准越好，精确到一分钱的跳空最说明主力刻意行为。

纯净精工

第14课：双域极点

合力双域极点

有重叠·更强

连续两座城堡加极点，且两座城堡有价格重叠区域。

关键信号：第二个极点的成交量比第一个极点更低（缩量）——上涨确定性更强，可直接潜伏。

标志特征：确认柱身兼两职——既是前极点确认柱，又是后极点支撑柱。

水平双极点：合力极致形态——两城堡几乎完全重合，两极点在统一水平线上。

接力双域极点

无重叠·较强

连续两座城堡加极点，但两座城堡之间没有价格重叠——阶梯式上行。

第一极点启动，第二极点加速。第一波是前奏，第二波往往是主升浪。

合力与接力在同一图中是相对关系——有重叠=合力，无重叠=接力。

双域极点口诀

错过第一个不要紧，第二个千万别错过——它可能是主升浪的开始。 第二极量比第一更低 = 上涨确定性更高。 第二波涨幅往往大于第一波。

子板块D：按位置/筹码/节奏分类（第15-21课）

第15课：单枪极点

单枪极点的定义与本质

长上影试探

单枪：上涨途中的长上影线阳线，上影线幅度>3%。

本质：主力主动试探左侧压力位，消耗套牢盘供应，为后续拉升扫清障碍。形成过程：主动拉升到压力位后冲高回落，让解套者和微利者卖出，洗掉不坚定筹码。

两大子类：单枪一日极点（次日缩量十字星即止跌）和单枪标准极点（调整2-3天后出现极点）。

第16课：左峰极点

左峰极点的命名与特征

前期高点处

以位置命名——股价经过前期大涨调整后重新涨回左侧前期高点（左峰）附近，受压回调，在回调中产生极点。

调整周期：通常1到3个月最理想。调整时间越长，主力准备越充分，后续上涨潜力越大。

与单枪极点可叠加——"左峰单枪极点" = 万般宠爱集一身。

经典案例
左峰单枪极点

A柱左侧重大压力位，中间调整近两个月。B柱触达左峰形成单枪，后面出现完美极点。当多种极点集于一身（左峰+单枪+完美）时，称为"万般宠爱集一身"，股票开始爆炸性生长。

左峰极点口诀

所有牛股必然都会经过左峰——这是必经之路。 调整时间越长，主力准备越充分。 每节课至少找50个案例验证，找到越多信心越强。

第17课：巅峰极点

巅峰极点的循环特征

创新高回调

上升趋势中每次创新高之后回调形成的极点，呈现"高点更高、低点更高"的特征。

vs 左峰极点：调整时间偏短（数天到两周），左峰极点调整长（1-3个月）。

交易价值：主升浪中不断重复"上去-下来-上去-下来"，每次新高后出现极点就是买点。

极点与空点：极点=阴属性（低吸），空点=阳属性（追涨）。有低吸机会一定首先低吸——安全、成本低、风险小、利润大。

经典案例
姚记科技（多买点实例）
姚记科技·从17元涨至36元翻倍

整个上涨过程中出现五次入场机会：B柱极点、D柱极点、非标准极点、F柱极点、H柱极点。每次买点都买在洗盘的极致地点，可潜伏可次日确认买入，确认后每次都是"一买就涨"。

第18课：命门极点

命门极点的底层逻辑

主力成本·核心

命门 = 主力成本价。与主力成本一致甚至更低=立于不败之地。

核心预备知识——筹码集中度：

  • 黄金筹码：90%和70%成本集中度同时在5%-10%之间。
  • 钻石筹码：两个集中度都同时≤5%。
  • 两者合称"金钻筹码"，钻石比黄金更具价值。

命门极点三大条件

判定标准
  1. 股价区间震荡20%以内，同时回到震荡区间下沿。
  2. 供应耗尽：出现极点信号（缩量十字星等），卖盘枯竭。
  3. 筹码为金钻筹码，且套牢比例在50%以上。

三个条件同时满足 = 命门极点成立。往往是主升浪的起点！

天龙股份·2023年

黄金筹码（90%=9.6%, 70%=7.6%）+ 套牢超50% + 涨停极点。精准达到涨停板底线，低量+十字星。确认后连续涨停九天（1-9连板），底部起涨近三倍。

真视通

经典案例
经典命门极点

钻石筹码（90%=4.3%, 70%=2.8%·超级集中）+ 套牢65% + 连阳回调极点。确认后股价涨30%。

第19课：金钻涨停

金钻涨停——牛股起爆点

筹码+涨停

命门极点课程的延伸应用，将筹码集中度与涨停板结合：

  • 黄金涨停（金条）：突破平台的涨停板 + 黄金筹码（集中度5%-10%）。
  • 钻石涨停：突破平台的涨停板 + 钻石筹码（集中度≤5%）。价值大于金条。
  • 合称"金钻涨停"：主力集中集结发起冲锋号的信号，往往是牛股的起爆点。叠加热点题材时起爆概率更高。
经典案例
凯华材料（史上涨幅纪录）
凯华材料·2023年11月27日

钻石筹码（90%=5.3%, 70%=3.7%）涨停板过前高。因为是30cm品种，七个交易日涨了八倍——创造了有史以来七个交易日内涨幅最大的个股纪录。

经典案例
大众交通（翻三倍）

第20课：合力涨停

合力涨停的形态与条件

有重叠·2-8天

首板/二板/三板 -> 调整2-8天（不破底线）-> 再次缩量涨停。两个涨停板之间有重叠区域。

最核心条件：第二个涨停板必须缩量。缩量打板入场，次日通常至少五个点溢价，甚至连板。

本质：主力涨停后洗盘再蓄势进攻。涨停板是主力给自己的"加油"信号。

经典案例
剑桥科技（经典合力接力交替）
剑桥科技

展示主力如何反复用合力和接力交替推高股价：连续涨停板休息一天是接力，接力完合力，合力完再合力——连续不断。核心启示：在涨停板里面去找涨停。

合力涨停操作口诀

最佳买入：涨停板当天打板。 次选：第二天竞价择机买入（需结合竞价、大盘、板块、题材）。 涨停=主力进攻信号，不是风险。 要在涨停板里面找涨停——在有鱼的地方钓鱼。

第21课：接力涨停

合力 vs 接力核心区别

无重叠·1-3天

涨停板 -> 1-3天缩量调整（不破前涨停板收盘价）-> 再次缩量涨停。两个涨停板之间没有重叠。

对比维度接力涨停合力涨停
两个涨停板之间没有重叠有重叠部分
调整方式短暂暂停·快速洗盘1-3天阴线回调·回撤稍深
调整天数1-3天2-8天
走势强度更强（主力基本没休息）较强（主力有回调休息）
本质主力不停歇继续推进主力休整后再进攻
经典案例
铭普光磁
铭普光磁·2023年6月7日

涨停板后出现放量十字星（多空分歧），次日竞价高开即接力形态确认信号，可在集合竞价直接买入。随后连续大涨。

经典案例
首创证券（合力转接力）
首创证券·2023年8月7日

A-B之间是合力（有重叠），B-C之间是接力（调整三天不破收盘价）。主力交替使用合力与接力将股价推向高位。连续三个板。

接力涨停口诀

接力与买法一模一样：要么当天买，要么第二天买。 涨停板后放量十字星+次日竞价跳空高开=接力确认·集合竞价直接买。 主力交替使用接力与合力是常规操盘手法。

第22课：分时极点擒涨停

完美涨停分时的核心结构

分时层面

在分钟级分时走势图中寻找极点信号来捕捉涨停板。完美涨停分时三条件：

  1. 第一笔拉升幅度超过3%
  2. 回落不破1/2或1/3（3121法则的分时版本）
  3. 呈现N字型结构（上下上）

三段式：3段完成即涨停（一个N字）。五段式：5段完成（更复杂N字）。一段式（秒板）：直接开盘秒拉涨停，最难买到。

关键：分时回落段缩量1/3或1/2（3121法则分时版）——缩量达标才是极点。

叠加共振效应

最强信号

日线出现极点 + 分时出现极点 = "叠加共振效应"——这是"必打信号"，溢价率非常高，成功率极高。

尤其是合力涨停极点或标准极点在首板中出现三段式完美极点时——威力最大。

第23课：冲天分时擒涨停

冲天分时五大要素

分时层面

盘中快速放量冲击涨停后回落，缩量调整后再次涨停：

  1. 快速冲涨停：盘中突然放量冲击涨停板
  2. 回调缩量：冲高后回调缩量
  3. 回调时间：15-60分钟（最少15分钟，最长可达2小时）
  4. 在分时均线之上：全回调过程不破均线
  5. 再次涨停：调整后重新封板

冲天分时四大优点

独特优势
  1. 看得到：快速冲涨停+回落15-60分钟，有充足时间分析
  2. 买得着：等待和决策时间充分
  3. 溢价高：第二天连板概率高，"搞不好连板，最差也有三个点溢价"
  4. 频率高：同一主力反复使用，同一标的多次出现买卖机会
经典案例
上海电影（三次冲天分时）
上海电影·2023年3月

一个月内三次标准冲天分时——3月8日（后两天连板）、3月20日（涨超30%）、3月31日（涨近50%）。"很多主力反复用冲天分时"——这是主力经典动作。

经典案例
多伦科技（两次冲天分时+接力）
多伦科技·2023年11月

两次教科书级冲天分时相隔10天。日线对照：冲天分时后无卖点反而是加仓/潜伏机会，中间形成接力涨停，总共涨了五个板。

冲天分时四前提

1. 板位限制：最好三连板以内（四板五板以上风险大） 2. 板块要求：最好是当下热点板块 3. 主力蓄势：极点之后的冲天分时效果更好 4. 行情环境：强势上午打、弱势下午打

阶段五：风险控制与实操

第24课：极点战法过滤法则

四大核心过滤法则

风险控制

过滤法则直接关系交易成败：

法则核心内容关键逻辑
法则一没有确认无极点除完美极点外，所有极点都须确认柱确认。未确认=只是"潜在极点"，不能买。
法则二跌破前低无极点两个极点只能抬高或水平，不能一高一低。跌破前低=下降趋势，不存在极点。
法则三下降趋势无极点所有反弹都不能做，"下降趋势中的低量柱是多方衰竭信号"。只做主升浪。
法则四主升浪之后无极点大涨翻倍后的回调不能当极点。"这种的不是极点"——充分调整后才安全。

四大易犯错误

风险意识
  1. 只看极点，忽视大盘环境：大盘不好时个股极点很容易失败，尽可能休息。
  2. 只看极点，忽视题材效应：没有题材就没资金追捧，很难产生确认柱。
  3. 忽视城堡建构：至少需要3-5个城堡，第一次阳线城堡要放弃——"第一次可能是下跌中继"。城堡应依次抬高。
  4. 只看极点，忽视左侧压力：左侧巨大阴线压制时空间太小，就算出现极点也不买。

六层滤网审核

买入前必审

只有当六个滤网全部通过，才构成有效极点，才可以考虑买入：

  1. 趋势滤网
    是否在上升趋势中？下降趋势中不存在极点，直接排除。
  2. 位置滤网
    是否在主升浪之前而非之后？大涨翻倍后的回调不能当极点。
  3. 前低滤网
    当前低点是否高于前低？跌破前低的反弹处不存在极点。
  4. 城堡滤网
    是否为第二次以上阳线形成的城堡？第一次城堡要放弃，需要3-5个城堡。
  5. 确认滤网
    是否有确认柱？没有确认的十字星只是"潜在极点"，不能买。
  6. 环境滤网
    大盘、题材、左侧压力是否配合？孤立极点不能买。

第25课：极点战法选股攻略

两种选股方式

实战操作

方式一：守株待兔式（被动等待）——平时收藏看好的股票，跟踪高潮柱/恐吓柱/停止柱，等确认柱出现再买入。优点：主动提前布局；缺点：等待周期长（三五天甚至七八天）。

方式二：积极主动型（当天找机会）——两个途径：

  • 找停止柱：下午2:30开始，在涨幅±1%中找十字星+有支撑柱的个股，等明天确认。
  • 找确认柱：当天尾盘在涨幅3%-5%中找确认柱（大阳线），回溯前一天十字星+城堡，尾盘买入抢次日溢价。

大盘环境配合法则

操作技巧

大盘涨1%以上：主要找确认柱（好股票已涨上去了）。

大盘跌或十字星：主要找停止柱（"大盘跌时提前出现停止柱的股票强于大盘"）。

C128涨停板选股法（最高效）

核心方法

核心理念："在涨停板里找涨停板"——在有大鱼的池塘里钓鱼。

步骤：

  1. Ctrl+T 打开条件选股
  2. 选择公式 C128（N天内以涨停收盘）
  3. 设置统计周期为 5天
  4. 保存方案（如"五天涨停选股"），以后直接引入
  5. 选股结果入自定义板块

每天40个涨停板 x 5天 = 约200只标的。逐只翻一遍即可覆盖所有涨停相关战法（极点/合力/接力/冲天分时）。

预警设置：Ctrl+Y设置上破/下破价格预警。

选股攻略口诀

每天收盘后第一件事：Ctrl+T C128 五天涨停选股。 在200只股票中逐只翻阅——识别所有潜在模式。 配合预警系统："一网打尽"——你只需要这一个动作。 选买持卖四步闭环：选股是第一步，选不到好股票后面全白费。

阶段六：卖出体系——头顶三绝

第26课：乌云盖顶

卖点的重要性

核心理念

"会买的是徒弟，会卖的是师傅，会空仓的才是祖师爷。"——交易老话

核心公式：捕捉机会靠买点，锁定利润靠卖点。不会卖出=小亏变大亏、大赚变小赚，所有盈利只是"纸上富贵"。

乌云盖顶——本质与分类

第一信号·量信号

本质定义：高量阴盖阳——连续大涨后大阳线（高量）-> 次日更大阴线（量比前日更大）。

单盖（量盖价不盖）：量盖住了但阴线未完全破阳底。

双盖（量价双盖）：量盖住 + 价格跌破昨日最低价。

核心判据：量必须盖住！只要高位放量阴线出现，无论单盖双盖，"先卖了再说"。八九不离十就是顶部。

底层逻辑：供应远大于需求，主力清仓大甩卖——不计成本往下砸盘。

经典案例
天元智能（6连板后乌云盖顶）
天元智能·2024年4月16日

连续6个涨停板后冲击第7板高开低走，形成巨大阴线+近期最高量——经典乌云盖顶（单盖）。当天收盘前必须跑，后面一路暴跌，再也不给机会。

经典案例
三柏硕（10连板双盖）
三柏硕·2024年1月2日

从11元涨到30多元翻三倍（近10个板），结束点在那根巨大阴线上——量价双盖（量比昨日高+价格破昨日底）。标准双盖见顶，此后连续大跌。

经典案例
我乐家居（8连板双盖）
我乐家居

8个涨停板翻倍后出现巨量阴线+破最后一根涨停板底——经典双盖。持仓策略：没有出现大阴之前一直持有，直到最后城堡底被破就卖。

第27课：弃城而逃

弃城而逃的本质

第二信号·价信号

军事命名：主力连城池都放弃了——溃不成军。散户更应马上跟着逃。

本质定义：城堡底破位——主力用大阳线搭建城堡往上推，某天大阴线跌破最后城堡底线=到头了。

底层逻辑：主力自己亲手打造的城堡底线都放弃了、跌破了——空军力量太强大，主力自己都撑不住了。"主力自己都不要城了，散户更不能留下来守城"。

复合型卖点

信号叠加

头顶三绝往往不是孤立出现的，同一根K线上出现两种信号叠加=复合型卖点=见顶确定性最高：

  • 弃城而逃 + 巅峰跳崖：同一K线破底+跳空阴（最常叠加）
  • 乌云盖顶 + 弃城而逃：量价双盖同时破城堡底
  • 乌云盖顶双盖=同时满足两个卖点
经典案例
开开实业
开开实业·2023年9月

经典案例

连续5根大阳线后A柱历史级别巨量，B柱跳空低开+破A柱底=弃城而逃。也同时满足巅峰跳崖条件。不卖=一路跌跌不休无翻身之日。

第28课：巅峰跳崖

巅峰跳崖的命名与本质

第三信号·跳空信号

命名喻义：深圳梧桐山顶巨石——最高处风光无限，跳下去粉身碎骨。

本质定义：高量跳空阴——巨量阳线（巅峰）+ 次日跳空低开收阴（跳崖）。两个条件缺一不可。

底层逻辑：前一天巨量阳线=主力边拉边出（将筹码转移给接盘散户）；次日跳空阴=主力不再维护股价，直接清仓大甩卖，跳空锁死追高者。

重要误区：缩量安全假象

关键提醒

巅峰跳崖次日阴线往往缩量——初学者可能误判"缩量=安全"。

真相恰恰相反：不是没人跑，而是根本跑不出来！前一天主力已完成出货，跳空直接锁死所有追高资金。

操作要求（最猛烈）：集合竞价阶段就要开始跑！不要等跌停板！第二天可能继续低开——损失进一步扩大。

经典案例

长传媒

连续4个涨停板（含一字板）后A柱历史最高量，次日跳空低开+破最后涨停板底。同一天既有巅峰跳崖又有弃城而逃——复合型卖点。不跑"可能连爹妈都不认识了"。

经典案例

丽影光电·2024年2月
