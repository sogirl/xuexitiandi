第一招破位首阳，精准锁定双头起点信号

📍 核心思想：龙头股首次破位后的反抽博弈——「首次破位 + 首阳」的组合信号是双头套利的核心模型。

一、首阴博弈（破位首阳的前置知识）

首阴定义：连板股首次不涨停日。注意：首阴未必收阴线，不涨停即视为收阴（K线首次分歧）。典型案例：东方通信。

买入前置三种首阴模式

  • 模式一：缩量闷杀——成交量明显萎缩、价格被压制。案例：惠而浦（C2M龙头）。
  • 模式二：放量盖杀——首阴当天分时先冲击涨停封板，后打开涨停（比喻"投篮被盖帽"）。分类：
    • 当天杀：国际石油
    • 隔天杀：华资实业
    • 关键：九鼎新材第一波为一天完成
  • 模式三：双阴盖杀再反包——首阴 → 次日高开弱转强失败 → 再杀阴线（连续两天闷杀）→ 第三天高开/低开反包。案例：江南高纤。
  • 模式四：腰鼓双头——位置通常在10天线附近（可能在10天线上方、下方或正好在10天线位）。它是衍生出破位首阳模型的母体。

二、破位首阳（核心模型）

核心要素：「首次破位」+「首阳」。
  • 必须是首次破位（多次破位无意义）；首次破位后的反抽预期最确定。
  • 趋势理解：单头抛压衰竭，通常伴随明显缩量。
  • 次日表现预期：通常高开，快速拉涨停，或半/满换手拉涨停。

适用位置

  • ✅ 适用：破5天线反抽首阳；破10天线首阳反抽。
  • ❌ 不适用：破20天线（意义不大，成功概率小）。

买点卖点核心操作（"两买一卖"）

  • 买点1：首阳当日介入（判断为趋势转点）。
  • 买点2（加仓点）：次日高开时加仓。
  • 卖点：基于前单头高点水平位附近，接近或新高即为合理卖点。
  • 关键纪律：切忌贪多，否则易导致明显利润回撤。

三、注意事项（风险控制与优化）

失败案例破位首阳非必然反抽

失败案例：九鼎新材——破10天线首阳无反抽；破5天线首阳仅高开。失败原因：

  1. 破位必须明显（差之毫厘则信号不足）；
  2. 前首阴盖杀已完成自救（自救后无预期）；
  3. 越连阴越突然（如东方通信炸尾盘），自救预期越明确、高度越高。

买点优化

  • 首阳尾盘翘尾 = 资金抢先手的信号。
  • 次日操作：高开→加仓；低开→放弃加仓，观望。
  • 优势：若失败（如冲击涨停后打开），前日先手可锁定利润。

卖点纪律

  • 未达预期（未涨停或涨停失败）：果断离场；次日集合竞价为合理卖点。
  • 案例：保变电气（低开冲击涨停未封住，前日尾盘筹码可离场）；以岭药业（高开5个多点后收大阴线，不及预期果断离场）。
适用范围（重要前提）：仅限阶段人气牛股或妖股，非所有图形符合者都适用。核心思想：研究龙头战法，一切基于龙头。
重点 ⭐⭐⭐
  1. 破位首阳核心三要素：首次破位 + 缩量 + 首阳。
  2. 买点优化：尾盘翘尾 = 资金抢先手；次日高开 = 加仓信号。
  3. 适用范围：仅限阶段人气牛股或妖股（前提）。
难点 ⭐⭐⭐
  1. 破位幅度的判定：破5/10/20天线的差异；破位必须"明显"的程度判断。
  2. 自救预期的判断：首阴盖杀已完成自救后，无预期可博弈（九鼎新材教训）。
  3. 强势信号识别："越连阴越突然"则自救预期越明确、高度越高（东方通信炸尾盘逻辑）。

案例库

东方通信惠而浦国际石油华资实业九鼎新材江南高纤保变电气以岭药业

第二招N+1 很完美，你要如何参与

📍 核心思想：用「连板 → 分歧 → 再连板」的节奏切换（弱转强+反包），绕开情绪天花板（三四板瓶颈）与高压监管，实现高度突破。

一、N+1 形态概述

  • N+1 形态自 2020 年起日益常见，形成独立选股偏好与市场风格；是全新的龙头接力模式。
  • 典型个股（2020"星期系列"牛股）：魔塑科技、航天长峰、金健米业——最终顶部形态均以 N+1 形式呈现。
  • 本质：市场资金面对监管高压与情绪瓶颈时，自发演化出的"曲线救国"路径。
N+1 模式的两大根基
  • 题材热度——必须有足够强的题材作为"反包基础"，无题材不反包。
  • 节奏切换——利用弱转强制造买点，用反包完成高度突破。

二、N+1 判断标准

  • 最终形态举例：航天长峰 2+2+1+4；金健米业 1+2+6。数字串 = "连板数 + 分歧天数 + 再连板"的节奏结构。
  • 启动判断要点：板块首次发酵、新热点刚出炉时，个股已经呈现 N+1 形态——这是后续成为龙头的关键前提。案例：航天长峰在"呼吸机"概念首次发酵时已是 2+2（具备身位优势）。

三、N+1 与趋势股的区别

维度N+1 模式趋势股（例：新诺威）
形态要求严谨，必须严格符合 N+1 结构灵活，可为 N+2、N+3，间隔天数不限
核心关注点弱转强与反包节奏量价关系与五天线支撑
考验周期相对较短更长（"3000步新高，跑车也要跑"——耐心持有）
分歧的定义与判定
  • 典型分歧形态：断板日 K 线实体较小的十字星（案例：2020年5月11日华盛昌）。
  • 非分歧形态（警惕）：阴包阳、长阴线——这是趋势转弱信号，不是分歧。
  • 关键判定原则：分歧后若不能实现反包，趋势直接结束——这是判断 N+1 个股是否还有延续动力的核心标尺。

四、合理买点（两个时间窗口）

  • 买点1：分歧后高开弱转强——时间窗口：分歧次日；大幅高开、市场抢筹明显。案例：航天长峰4月1日前。逻辑：高开代表多头资金不惧分歧、主动承接。
  • 买点2：盘中分时弱转强（加速板）——时间窗口：分歧当日；低开后盘中拉升打板，且成交量小于前一日分歧量（加速板特征）。案例：航天长峰4月1日打板。逻辑：分歧日直接反包+缩量封板，抛压衰竭、上涨阻力最小，相对安全。

五、合理卖点（三层卖点体系）

  1. 简单卖点：个股不能再 N+1（无法完成反包）时坚决卖出。
  2. 进阶卖点：
    • 卖点A：分歧不能反包——出现阴线后无法反包。
    • 卖点B：反包不能连板——反包后次日无法连板（此信号通常比卖点A提前出现），原则上开始减仓或离场。
  3. 双分歧卖点：出现 1+1 的双分歧结构（反包一次后又再次分歧）——趋势已尽的明确信号。
  4. （叠加）加速后再分歧 / 长阴线——加速后再出现分歧，是顶部信号。

六、身位龙（N+1 高阶应用）

身位龙定义：新热点出现第一天（首日），个别提前涨停的个股即已构成两板或更多板。案例：2020年2月28日，保变电气之于特高压热点，首日已两板。
  • 穿越分歧核心操作：板块整体分歧后，率先加速反包的品种（同时满足买点）——必打。这是"穿越分歧的龙头"，龙头接力中的最强标的。
  • 加速规律：二次分歧再连板后，通常走一段明显加速（如 1+2 后接 6+7）。
  • 见顶信号：再加速之后再分歧——通常是顶部信号（市场对加速已有充分预期，再分歧易引发集中抛压）。
红线纪律（终极）：任何过程中出现明显长阴线、特别是爆量长阴线——先看结束，先卖出，后续重新连板再回补也不迟。宁可错过，不可做错。

七、注意事项与应用场景

  • 应用场景一：低迷期的突破口——N+1 模式最常出现于市场情绪低迷期；当三板、四板（尤其四板）难以突破时，N+1 成为资金绕开瓶颈的首选突破口。
  • 应用场景二：大题材背景下的提前分歧——即便板块题材很大（如金力永磁所属的"稀土反制"题材），也会因市场整体情绪原因提前出现分歧——这是 N+1 模式在大题材中也能成立的条件。
重点：分歧判定（十字星是典型，阴包阳/长阴线是转弱非分歧）；两个买点时间窗口；三层卖点；身位龙定义。
难点：加速板成交量判断（缩量是关键）；加速规律的节奏把握（1+2接6+7）；身位龙"穿越分歧"的判断（分时强度+封板时间+成交量综合判断）。

三大纪律

  1. 纪律一：分歧必反包——分歧后能否反包是趋势存续的唯一标尺。
  2. 纪律二：长阴必先卖——出现爆量长阴线时无条件离场。
  3. 纪律三：买在弱转强——买点集中在分歧次日高开或分歧日盘中打板。

案例索引：航天长峰金健米业魔塑科技华盛昌金力永磁保变电气新诺威

第三招都说明预期差，何为预期差

📍 核心思想：预期差是短线博弈的灵魂——不及预期 = 卖，结果相反 = 买。有预期差才有博弈价值。

一、预期差的定义与核心框架

预期差 = 触发因素 + 结果表现
  • 触发因素：竞价突变或分时突变。
  • 结果表现：股价走势偏离既定趋势/预期走势，甚至走向相反结果。
典型案例容大感光：三联板后当日走分歧（按预期应结束），次日集合竞价高开、快速上板——核心手法分歧弱转强（当弱不弱反转强）。

二、加速的定义与判断

加速的五大特征：① 分时快速涨停；② K线明显缩量涨停；③ 趋势感加速上涨；④ 资金共识（多数资金判断一致，盘口分歧小）；⑤ 时间窗口（通常开盘1小时内封板）。案例：2020年4月30日金威股份。

预期差的两种类型：不及预期（加速未出现）｜预期相反（走势与预期完全背离）。

判断前提（关键方法论）：第一步先判断预期（基于事前套路）→ 第二步再判断预期差（事中应变）。顺序不可颠倒。

三、常见预期套路（四类）

套路定义后续预期案例

妖股二波关键差异（重要判断点）：阴线收盘价创新低 → 预期失败合理；阴线收盘价未创新低 → 预期成功合理。

四、常见预期差的两大类（实操核心）

不及预期 = 卖出信号

案例背景/预期实际结果操作

结果相反 = 买入信号（套利机会）

案例背景/预期实际结果操作
蓝鹰装备5板分歧转一致，预期6天加速早盘竖板后炸板，尾盘接近跌停（盖砂/闷砂）次日自救=买点
江南化纤首阴后次日高开，预期反包不仅未反包反而杀出更大阴线（盖砂双阴）次日自救=买点
保变电气4板一字板加速后，预期次日高开竞价低开（抢筹，非竞价不及预期），开盘迅速上拉封换手板（空中加油）抢筹=买点

五、妖股二波预期差套利

  • 通产立新：创投周期，停牌复牌后连续一字，后两连板；市场类比雄安周期冀东装备预期二波；实际第三日跌停阴线 → 结果相反构成套利，连续3天自救。
  • 星期六：n+1模式调整3天（未破5日线）再起首板；类比贵州燃气（8+5）预期二波；实际次日高开后长阴线 → 二波预期结果相反，形成套利买点。
预期差核心总结：动态转化机制——预期差产生新预期，新预期未实现又产生新预期差，二者相互转化，类似因果循环。综合案例华盛昌（2020年5月次新龙头）演化路径：首阴转反包 → 分歧转一致（预期加速）→ 加速失败（阴线）→ 自救（买点）→ 二次预期差。
重点 ⭐⭐⭐
  1. 预期差两面性：不及预期=卖，结果相反=买。
  2. 判断顺序：先判断预期→再判断预期差（不可颠倒）。
  3. 四大预期套路：分歧转一致、分歧弱转强、反包、妖股二波。
  4. 加速五大特征：分时涨停+缩量+1小时内+资金共识+快速封板。
  5. 妖股二波关键差异：阴线收盘价是否创新低决定预期成败。
难点 ⭐
  1. 盖砂/闷砂本质：坐板资金被套→次日自救→买点（蓝鹰装备、江南化纤）。
  2. 一字板后低开的特殊性：非"竞价不及预期"，而是"抢筹+空中加油"（保变电气）。
  3. 预期差动态循环：因果循环机制（华盛昌案例）。
  4. 反包前的"走废"判断：长阴不被看好但反包则需重点关注。
  5. 预期差与新预期的相互转化：连续套利的根本逻辑。

第四招注册制来了，不打板要怎么做？

📍 核心思想：注册制背景下连板股生存空间被压缩，趋势股成为重要替代——核心是「底势 + 硬核逻辑 + 游资主导」。

一、趋势股的概念

趋势股：相对于连板股（连续涨停或N+1）的另一种短线操作模式。形态："不涨停、不停涨、一波流"，不追求一定涨停，可接受烂板、大阳线、震荡洗盘。
两种具体表现：① 涨停加速型（前期缓慢上涨→涨停后加速）；② 涨停突破加速型（前期趋势+震荡平台→涨停附近突破平台加速）。案例：国轩高科、容大感光。

二、趋势股与庄股的区别（极易混淆）

维度趋势股庄股
形态不涨停不停涨、一波流不涨停不停涨、一波流
涨停意图调动短线资金向上加速高位找人接盘
涨停后表现加速见光死
操作价值高低（陷阱）
必须严格区分：形态相似但本质相反，误判会导致高位接盘。

三、核心逻辑：三大组成部分

核心节点是「涨停」——从量变到质变的转折点。三大组成：

  1. 底势：启动前形成的良好技术面基础。特征：量价低位震荡攀升/缓慢爬升、上升斜率<45度、无明显破位打断趋势。案例：国轩高科2020年1月17日前走势。
  2. 单票硬核逻辑：实质性利好逻辑（明确聚焦、推力大）。案例：莲花清瘟对新冠有效→以岭药业；国轩高科因大众参股传言涨停。作用：催化剂，推动量变到质变。
  3. 加速段主导力量（游资）：非庄股资金、非机构资金。案例：国轩高科涨停日席位——闵行东川路、南京太平南路、小鳄鱼、新-欢乐海等游资席位。注意：机构资金加速段较慢，属非短线范畴。

关键均线规则：5天线 = 强弱线（不破则趋势加速保持）；10天线 = 生命线（破位则趋势结束、资金抽离）。

四、合理买卖点

短买卖点数字三连（只做加速段）

节奏模型：涨停启动 → 连续涨停 → 首次分歧（第一次不涨停）

  • 买点：首次分歧时介入（高开更好，看加速）。
  • 经典节奏：首次分歧 → 加速 → 再分歧。
  • 卖点：第二次分歧时卖出。
  • 原则：只做加速段，其他不参与。变体可能为四连、五连，核心逻辑一致。

长买卖点格局买卖点（吃完整段，会算空间）

  • 空间目标：常规波段翻倍（低点到高点）；少数逻辑加持下三倍。
  • 案例：国轩高科启动价近20元——翻倍目标20元（非终点），游资需30%以上空间出货，实际目标25-30元。
  • 抢跑问题：市场预期一致时，需在目标位前（如28-30元）分批卖出，避免错过最佳卖点。
  • 均线规则：空间未到、均线未破（5/10天线未破）可继续持有。
  • 适用对象：大资金（短线资金无法出货，需要足够空间）。

五、复杂情况应变

案例一：新诺威（年报高送转第一股10送11）——涨停→首次分歧（次日未涨停低于预期）→第三天高开弱转强（缩量涨停）。应变：卖点延迟至"再分歧"。关键判断：低开则低于预期先走；高开弱转强则继续等待。

案例二：以岭药业——全程遵循5/10天线原则。第一波未翻倍（约49跌至28）：短线可走（数字三连卖点），格局则等28附近（生命线附近）。破位处理：破位后次日返包（涨停反包阴线）视为OK仍可继续。新逻辑推动三倍：使用说明加入新冠治疗范围→推至三倍（约42元）→跨级别行情。抢跑提醒：资金往往在目标位前提前卖出。

六、题材中军龙头化（新趋势）

  • 传统模式：中军品种（大票）走中军化（缓慢推升），稳定板块情绪。
  • 当前新趋势：中军品种带头向前冲，走龙头化。
  • 案例：广电运通（数字货币，在龙头汇金股份结束后仍涨实现"穿越"）；中国西电（特高压，在龙头保变电气结束后继续涨）。
  • 启示：重视资金量大、流动性充裕、趋势较好的趋势股；"穿越"可能性是中军品种的重要特征，应纳入趋势股体系。
重点
  1. 趋势股 vs 庄股本质区别（涨停后的资金意图）。
  2. 三大要素：底势、硬核逻辑、游资主导。
  3. 数字三连节奏：高开弱转强买点、再分歧卖点。
  4. 两条均线纪律：5天线强弱线、10天线生命线。
难点
  1. 首次分歧后强弱判断：高开 vs 低开的应对差异。
  2. 抢跑问题：如何在目标位前分批卖出而不踏空。
  3. 复杂案例应变：破位后返包、新逻辑加持下的三倍行情。

第五招短线找卖点，助你成为会卖的师傅

📍 核心思想：会买是徒弟，会卖是师傅——卖点比买点更难掌握。没有完美卖点，只有合理卖点（所有卖点均合理即足够）。

一、核心理念（引子案例）

  • 永泰科技（炒作瑞德西韦新冠概念）：二板三板分歧转一致买点易把握，但稍有迟疑遇大阴线分时，因吉利德最终与博腾股份合作，"差之毫厘失之千里"，甚至亏损出局。
  • 蓝英装备：五板后"盖杀"（长阴分时），尾盘未跌停撬开（先手买点）+次日竞价（加仓买点），但反包涨停成功仍可能因卖点不当不赚钱或亏钱。
  • 理念例证：轴研科技——不必等最后反包板，断板日离场即合理；中国西电——翻倍位离场即合理（后续新逻辑视为新波段）。

二、断板的基础定义

断板：K线连续涨停（连板股）中，涨停中断的这一天，也称"首阴"或"首次分歧"。案例：轴研科技2020年5月18日。断板是后续所有卖点判断（尤其双分歧）的基础概念。

三、常规卖点一：盘口强转弱（三种形式）

  1. 分时强转弱：白线（股价）在黄线（均价）上方为"强"，下方为"弱"。卖点信号：白线下穿黄线（交界处）。案例：深广集团。
  2. 封单强转弱：封单数量级差距。案例香梨股份四板（西部开发）——一封4万多手、二封5万多手（意图回封打造龙头），后炸板最终封单仅1000手，需考虑先撤。
  3. 竞价分时陡降：关键时间9:24分。危险信号：竞价顶高（8%-9%）但无脱单、成交额小，9:25突然降至2%-3%甚至平开 → 竞价强转弱，是卖点。

四、常规卖点二：不及预期（基于预期差）

  • 加速失败：未名医药（二+1结构）——高开弱转强开盘迅速上板（加速）但盘中失败，勉强回封导致成交巨量 → 加速失败即不及预期，先出。
  • 竞价被卡位：两板高度相同的票隔日竞争（一进二、二进三……），率先涨停封满者胜出，其余被淘汰。案例：麦克生物 vs 达安基因（二进三检测试剂），麦克生物被卡位即卖点。
  • 上板失败：意图引导涨停但失败 → 不及预期，是卖点。
  • 特殊情况（新买点出现）：麦克生物第三天买入被套，次日出现集合竞价弱转强（新买点）→ 可再看一天，构成新逻辑。
卖点和买点是动态转化的：被套后若出现新弱转强买点可再看一天；若仍不及预期则继续执行卖点。

五、非市场总龙头的处理原则

核心原则：非市场总龙头切勿恋战，随时可能被资金抛弃。
  • 观察点一（10:00）：必须在此时间点试强。若10:00不能试强，通常收盘有集中抛压，可先走；开盘不及预期可等到10:00看是否试强。
  • 观察点二（10:20-10:30）：市场由小周期转大周期的关键过程，非龙头可能上位成总龙头（交接棒）。案例凤凰股份（达安基因结束，凤凰上位）。10:00一封失败，10:20-10:30可能有资金修板。
  • 科学策略：10:00先走一半，留一半等到10:30。经验规律：即使10:00前转弱，通常也给"勾头（次高点）"出货机会。

六、总龙头连板卖点之续命

核心原则：市场总龙头需看到尾盘（通常两点半附近），因常有资金做续命。
  • 国电南自：四板上位总龙头，七板均被大资金续命；五板、六板极限顶在两点半附近。
  • 航天长峰：最后一天高位大阴线结束，分时两点半附近给制高点（勾头）——两点半附近才是真正见分晓的时间点。
  • 弱板特征：两点半以后出的板通常视为弱板，后续高度有限。案例宝鼎电气十板两点半后封板，次日跌停。
📌 非总龙头看10:00/10:30；总龙头看两点半附近——这是分清个股地位后选择不同观察点的核心。

七、总龙头格局卖点之双分歧

定义：格局卖点指等待双分歧，即首阴后能否反包。经典案例：丰乐种业、金力永磁、漫步者。

双分歧的两种情况（均为卖点）：

  1. 分歧不能反包——次日不能反包，即卖点。
  2. 分歧反包但不能连板——反包成功但次日不能连板（一+1结构），即卖点。

反面教材鼎汇网络：逻辑强势，但次日不能反包，第三天市场一致看空，直接跌停。

八、高阶卖点：换手（适用面最广、价值最高）

原理：涨停板加速过程中，换手率应越来越低（缩量）。一旦换手率变大（超过前一日）即为破绽，是卖点。

经典案例永泰科技：三板、四板（四板一字板换手约82%），第五天开盘一字板，9:40:21时换手率与前一日持平（约82%），随后几秒超过，大批抛单出现——掌握此卖点可在五板卖出，避免第六天被秒跌停。

操作原则：换手而不能板，先走再说；若前面走势不佳但换手未平前日，换手再次回到相同位置时会有制高点给出货机会。

九、核心操作口诀（提炼）

  1. 心态口诀：会买是徒弟，会卖是师傅；没有完美卖点，只有合理卖点。
  2. 分时口诀：白线下穿黄线，先走为敬；封单跳数量级，赶紧撤退。
  3. 竞价口诀：9:24顶高9:25跳水，竞价强转弱必卖。
  4. 非龙头口诀：10:00试强不见，先走一半；10:30不能修板，全部清仓。
  5. 总龙头口诀：两点半前见分晓，能续命则留，不能则走。
  6. 格局口诀：双分歧不反包必卖，反包不连板必卖。
  7. 换手口诀：加速本应缩量，换手一旦放大，破绽立现必走。
重点
  1. 断板的定义与判定（所有连板股卖点的起点）。
  2. 盘口强转弱三种形式（分时、封单、竞价）。
  3. 非龙头10:00/10:30双时点策略。
  4. 总龙头两点半续命判断。
  5. 换手卖点（最普适、最具操作性）。
难点
  1. 竞价分时陡降识别（9:24-9:25仅一分钟，需提前挂单）。
  2. 总龙头与补涨龙/跟风龙的区分（影响时间窗选择）。
  3. 双分歧的"格局"判断（反包失败可能直接跌停，鼎汇网络）。
  4. 换手率精确比较（一字板/T字板换手率含义不同）。

第六招老妖后浪的正确插入方式

📍 核心思想：大周期妖股结束后进入退潮期，资金交棒新龙头；若新龙头无法承接，资金回流老龙头，形成"后浪"套利机会（新老龙头跷跷板效应）。

一、何谓妖股（标的筛选）

妖股定义：大周期龙头，连板或n+1涨幅超过100%（股价一波翻倍）；波段高度大于7个板方称"妖股"。典型：保变电气（10连板）、金健米业、航天长峰、模塑科技、金力永磁。

二、避险——核心逻辑（跷跷板效应）

操作链条（海特生物 vs 顺威股份）：

  1. 海特生物（换手主龙头）结束（跌停、次日不能反包）。
  2. 资金交棒新龙头顺威股份（连板总龙头）。
  3. 顺威次日无法涨停 → 资金回流老龙头海特生物。
  4. 避险本质：资金从新龙头回流老龙头，形成后浪套利。

跷跷板效应：新老龙头股价走势明显相反。2020年3月17日海特生物与顺威股份开盘走势相反；3月18日顺威跌停封板期间海特生物迅速涨停（避险确认）。

避险失败信号：顺威午后上摆 → 海特生物炸板 → 资金重新回流新龙头。

分时验证要点：海特生物（白线）与顺威股份（紫线）呈反向拐点（顺威跌停=海特拐点）。

三、合理买卖点解析

案例：轴研科技 vs 西部创业——交棒节点：轴研科技8+1走完、跌停不能反包→西部创业拿板；避险日：西部创业断板→资金回流轴研科技。

双买点 + 科学仓位

  • 先手买点：避险日下午2:30左右（判断西部创业无法封板）→ 上一半仓位。
  • 后手买点：避险日次日集合竞价（确认西部创业断板）→ 再上一半仓位。

卖点：10%法则

  • 止盈基准：账户盈利接近或超过10%即卖出。
  • 期望值：新龙头挂掉后老龙头避险通常一个板利润；次日5%左右即合理止盈点（先手买点次日5%+当日浮盈≈10%）。

四、换手法则

案例金力永磁避险：金力永磁（反包失败）→交棒明普光磁→明普光磁结束→资金回流。避险日6月6日明普光磁跌停，金力永磁尾盘抢跑（2:30在3%附近）→ 尾盘买入当日享受7个点涨停；次日集合竞价高于3%→总利润已超10%→10%法则触发卖出。

换手法则定义：换手不板即卖点。计算基准：以避险日次日集合竞价作为买点；操作：次日换手持平不能上板→卖出。

案例1：尾盘先手买点→次日开盘确认→当天被套→次日缩量秒板→第三天涨停→炸板→回封→再炸板→第二次炸板时成交量与前日持平→卖点。

案例2：换手持平，收盘价附近卖出。

核心：对时间与幅度的精确理解。

五、格局卖点

格局卖点：市场走出退潮期、进入新周期时，老龙头资金应全部卖出。案例1（轴研科技）：5月28日市场出现7板新龙头→轴研科技跌停，出现连板以来第一根爆量单阴线→格局卖点。案例2（金力永磁）：新龙头出现，市场走出退潮期→格局卖点。

六、套利机会总结

套利机会：所有符合定义的老妖股，至少有一次后浪套利机会，可榨取接近 10% 甚至更多利润。

  3. 格局卖点的判断——以"市场走出退潮期"标志（7板新龙头出现、首根爆量单阴）为依据，避免过早离场或贪恋鱼尾。
与前几讲的核心差异：本讲"后浪"是新龙头失败后的避险回流；此前"射天线双头反抽""首阴/二波"是同一龙头自身的回调反抽——逻辑完全不同。

案例标的清单：保变电气金健米业航天长峰模塑科技金力永磁海特生物顺威股份轴研科技西部创业明普光磁

第七招暗线怎么参与

📍 核心思想：暗线是市场中隐含的共性——多个看似不相关涨停股背后隐藏的某种共同属性。核心是"共性"，「越早发现，越能获利」。

一、暗线的定义与本质

核心案例：2020年6月5日和顺石油（二板）龙虎榜显示三天内五家机构大幅净买入，结果第三天一字板、第四天涨停开、20%溢价。6月9日扩散：金丹科技、博杰股份、鲜乐健康、万泰生物；后续三人行（三板定一字）、金丹科技（高溢价）。暗线逻辑提炼：机构席位上榜 + 大幅净买入次新股 = 高溢价。

二、暗线 vs 明线的对比

对比维度明线暗线
逻辑支撑逻辑性强（如政策驱动）源自资金联想，无硬核逻辑
市场关注度被广泛研究（如国六题材）被明线掩盖，朦胧期与分歧阶段
买点与参与性高潮即结束，买点难把握买点更好，参与性更强
流动性承接明线结束后暗线优先承接流动性—
关键时点—及早发现（比买卖点更重要）

三、暗线的两大模式

模式一：直接共性

定义：当天涨停板中出现四家或更多具有相同属性、但分布在不同概念的涨停股。需自己发现，大V复盘通常不单独罗列。

  • 案例1 和康新能（2020年4月）：当日龙头分散（金健米业食品、航天长峰呼吸机、继峰股份新能源车），暗线发现当天五个股权转让涨停分布不同板块→和康新能走出五板高度。
  • 案例2 业绩预增股（2019年4月29日）：市场龙头科隆股份（八板），当天高度美丽云（四板）；暗线发现五洲交通（二板）+六个市盈率五倍以下个股涨停→暗线本质是低PE；第三天弱转强，第四天四板未封住（验证天花板），预期收益十几个点。

操作要点：涨停家数越多板块效应越强；优先做龙头；天花板四板为明显天花板（少数能过）；受明线压制。

模式二：间接共性

定义：非同日出现板块效应，需从连续龙头中寻找共性。核心方法：临近龙头找共性。

  • 贵州燃气周期：龙头贵州燃气（燃气+次新+贵州偏远地区）→华森制药（重庆偏远地区）、卫信康（三板偏远地区）→共性"偏远地区+次新"→产生永吉股份（贵州次新）。
  • 万兴科技周期：万兴科技（独角兽+西藏次新）、泰永长征（贵州开板新股）→共性"偏远地区次新"→盘龙药业（西部）走出高度。
  • 机构大幅净买入（2020年6月）：和顺石油→金丹科技→博杰股份/万泰生物→三人行（次日一字开）。涨停未必同日（区别于直接共性）。

操作逻辑：顺藤摸瓜，用补涨逻辑理解，中间穿插二板、三板机会（国芳股份、卫信康、川恒股份）。操作优势：买在分歧，市场未充分认知，买点安全、溢价有保障。

四、暗线与明线的竞争

  • 竞争关系：明线结束后，暗线通常持续1-2天即结束；少数情况暗线走成明线（成为市场主线）。
  • 案例1 星期六周期：初期炒大金融（南京证券、绿庭投资），第三天虚拟现实出现4-5个涨停（直接共性）→星期六走出，暗线变明线，后挖掘出网红MCN新逻辑。
  • 案例2 2018中兴通讯事件：强势股华锋股份（六连板+两次反包），第一根阴线时市场出现三个两板股（星光药业、永和智控、中潜股份）→共性"填权属性"。

五、填权专题

填权：高送转股票除权后，股价波段拉升回补缺口。抢权：除权日前的拉升。典型案例荣盛科技。暗线演化：老填权（上一财报季）→走成市场新主流（明线）→后续永和智控（六板+反包）→新暗线"出口占比"（中兴事件后出口占比高不受影响）。

六、实战 SOP

  1. 盘中：扫描当日涨停板，标注各股所属概念。
  2. 发现共性：≥4家分散在多概念的涨停股具同一属性 → 直接共性。
  3. 寻找龙头：从连续龙头倒推共性 → 间接共性。
  4. 确认买点：买在分歧（市场未充分认知时）。
  5. 持有逻辑：预期暗线→明线的演化溢价，或1-2天接力机会。
  6. 风控纪律：四板天花板、500万以上资金才能"造势"（如乔帮主尾盘打造永吉股份）。
重点：直接共性"四家以上同属性"标准；间接共性"临近龙头找共性"；填权+出口占比复合暗线叠加逻辑。
难点：暗线识别需盘中盯盘+复盘确认的连贯流程；"机构席位+次新"捕捉时机；偏远地区次新等隐含属性的敏锐捕捉。

核心结论：暗线做得好，不一定比明线差。间接共性更易操作，不追求绝对龙头。

第八招共振出大牛，中枢养小牛

📍 核心思想：短线不是不看大盘，而是必须看懂大盘。「大盘是土壤，牛股是花朵」——共振即大盘转势点与牛股启动点的同步现象。

一、共振定义与趋势分类

引用李彪（"禅中说禅"作者）："不看大盘做个股，实为看不懂大盘"。禅论基础：构建"趋势—中枢—次级别趋势/中枢"模型判断趋势转折点。

2018牛股共振图结论：大部分牛股在相对阶段低点出现；成交量明显异常时伴随牛股出现；单边下跌趋势极少出大牛股（智慧农业仅5板）。

趋势分类：按量能分存量行情（无量）vs 增量行情（放量）；按结构分趋势（有方向）vs 中枢（无方向，如箱体）。

核心结论：每一次趋势转折点都会出现牛股；大盘不好难出牛股；大盘强则牛股集中。

二、六大共振场景

1. 存量行情：下降趋势转中枢（见底）——先看低点（第一个低点不能确认，可能下跌中继），确认拐点：收盘价站上10天线。方向：新热点/新题材最强者。案例：2020年3月25日（2646点）抗疫概念→呼吸机→航天长峰；2019年8月15日（2733点）深圳40周年→九鼎新材（7板半）。

2. 存量行情：上升趋势转中枢（二八切换）——一波拉升后转中枢，出现"二八切换"（二=20%大市值蓝筹，八=80%中小题材；蓝筹到位转震荡，活跃资金转小票）。确认点：收盘价跌破10天线。案例：2019年3月8日科创板→复旦复华（联动张江高科）；2020年2月27日特高压→保变电气（10连板）。

3. 增量行情：中枢转上升趋势（突破）——放量突破中枢箱体（以收盘价为准）。操作：直接做大金融。案例：2020年4月1日华创阳安（卖点双分歧结束）；2019年6月20日互联网金融→科蓝软件。

4. 增量行情：趋势加速（爆量）——慢涨转快涨，突然爆量（沪市单边3500亿以上）。操作：直接做大金融。案例：2019年2月25日爆量4000亿（大金融）；2019年12月17日绿庭投资、南京证券。

5. 长假之后情绪共振（节点）——春节、十一前后，流动性及情绪积蓄，节后买入冲动强。操作：寻找最强新题材。案例：2019年2月11日业绩预增→银星能源；2020年2月3日疫情→联环药业；2019年10月8日股权转让→宝鼎科技（借势九鼎新材）。

6. 季度浪/月度浪——每月出现一只200%级别大牛股（3月保变电气、4月深广集团、5月轴研科技、6月凯撒文化）；背后资金除游资外还有私募、公募等中线资金。

三、季度浪详解（中线方法）

典型案例：青岛啤酒（2020Q2，4月1日启动→6月24日结束，公募/大私募推动）；国药股份（2020年6月，6月11日后月内涨幅超60%）。

识别关键——时间节点：月末/季末交替前后一周（如三月底至四月初），关注反复异动的板块/方向。

识别条件：

  1. 涨停启动（如青岛啤酒代表食品消费板块）。
  2. 位置：底部区域或中位调整到位（绝对/相对低点启动）。
  3. 板块联动：连续1-2天同一方向联动。
  4. 题材新颖：与前一阶段市场方向明显不同（如科技转消费）。
  5. 盘口特征：机构盘口（非游资盘口）。
  6. 高辨识度：标的知名度高（如青岛啤酒）、市值有容量。

拿货平台与买卖点：启动信号=第一次涨停；拿货平台=底部爆量大阳线/涨停后缩量整理平台（青岛啤酒3月24日-4月24日）；买点=再次放量突破拿货平台时（突破直接买或回踩5日线买）。典型结构：涨停启动 → 拿货平台（缩量整理）→ 再次放量突破 → 主升浪。

月度浪特征：更快、趋势更短（适合激进投资者）；典型结构双响炮（底部涨停+上方更高涨停→加速）；案例蓝思科技；方向数量月度浪可含多个子方向，季度浪通常单一方向。

卖点原则——波段翻倍：放量突破后股价达到波段翻倍即卖。案例：青岛啤酒75→150；国药股份27→55；海天味业、蓝思科技同理。翻倍后行情与操作者无关。

四、机构盘口 vs 游资盘口

特征游资盘口机构盘口
拉升方式果断、意图明确缓慢、小碎步推高
分时形态脉冲式拉升少见脉冲
封板目的追求高质量涨停板不以封硬板为目的
技术表现线性化特征明显技术淡化
案例新力金融（23）国药股份（29）
重点
  1. 五种共振场景识别与对应操作方向（见底/见顶/突破/加速/长假共振）。
  2. 10天线法则：趋势转折确认核心指标。
  3. 拿货平台识别：缩量整理区间是机构建仓特征。
  4. 波段翻倍卖点：中线操作铁律。
难点
  1. 真假拐点辨别：第一个低点不一定是真底，需10天线确认。
  2. 盘口识别：游资盘口 vs 机构盘口的实战区分。
  3. 资金切换判断：通富微电到青岛啤酒的风格转换提前预判。
  4. 大金融方向爆发力把握（增量行情确定性最高，需勇气和资金体量）。
三大核心方法论：① 拐点确认法（站上10天线见底/跌破10天线见顶/放量破箱体突破）；② 资金切换识别法（存量→增量、蓝筹→题材、科技→消费、游资vs机构盘口）；③ 季度/月度浪战法（涨停启动→拿货平台→放量突破→主升浪→波段翻倍）。
适用场景：300万以上资金体量；收益目标月度浪20%-30%、季度浪50%；定位"比短线更确定的投资方法"。心态：不慌不忙、不贪——翻倍即走。

第九招机构调仓，摔杯为号

📍 核心思想：识别机构（中线/大资金）调仓方向，抓住月度浪、季度浪级别的波段机会——确定性高于纯短线连板。

一、连板大牛股 vs 机构调仓

  • 连板大牛股：每月出现翻倍以上连板牛股（3月宝贝电器、4月深广集团、5月周岩科技、6月凯撒文化），核心驱动力是游资。
  • 机构调仓：私募、公募对应「季度浪」或「月度浪」行情，与连板股形成风格互补。
  • 资金类型：能推动季度/月度浪的是公募/大私募级别，普通资金无法推动。
  • 本质：中线风格资金在月度/季度方向上的选择，蕴含投资与套利机会。

二、识别季度浪的关键

核心时间窗口：月末/季末交替前后一周（青岛啤酒4月1日启动，关注3月末最后一周与4月第一周）。观察对象：反复异动的板块/方向。

三、筛选条件（涨停启动的要素）

  1. 必须出现涨停（吸引流动性，非单一主力可完成）。
  2. 启动位置：底部区域或中位调整到位（绝对或相对低点）。
  3. 板块联动：多支个股连续1-2天同向联动。
  4. 方向新颖：与前一阶段市场上涨方向明显不同（风格迥异）。
  5. 盘口特征：非游资盘口（区别于连板股）。

四、拿货平台（核心形态学概念）

拿货平台：股价底部区域爆量大阳线/涨停后出现缩量整理。构成：大阳线+整理平台=拿货区间。突破信号：再次放量突破平台，预示主升浪到来。买点：① 突破后直接买入；② 回踩5日线等点位介入。案例青岛啤酒：平台区间3月24日-4月24日，操作逻辑启动→拿货→放量突破→主升浪。

五、案例演示

合力买卖点——海天味业：与青岛啤酒同期同类型，节奏涨停→拿货整理→放量突破（买点）。

月度浪——国药股份（6月29日-7月1日）：启动月末低点涨停（非游资盘口）→震荡整理平台→突破（叠加短线利好）→双响炮形成后加速。

蓝思科技（7月1日）：涨停→震荡整理→双响炮涨停→加速。

前后联系立体判断——青岛啤酒与通富微电对比：大盘单边下跌，通富微电（芯片科技）已走完一波拉升，3月23日见底后市场思变，资金从科技切换至消费（防御逻辑）。

六、卖点原则与纪律

核心纪律：波段翻倍即走。典型幅度：青岛啤酒75→150；国药股份27→55；海天味业/蓝思科技类似。关键原则：「翻倍后行情与你无关」。

心态：不慌不忙、不贪——翻倍即走，中间过程未知。反面案例赛森药业（6月26日涨停，机构盘口，低点4元，翻倍至28元后加速仍需离场）。

节奏差异：慢节奏（青岛啤酒、蓝思科技）vs 快节奏（国药股份）。

七、选股标准与收益目标

  • 选股标准：必须涨停启动；最优标的=辨识度最高（海天味业、青岛啤酒、国药股份、蓝思科技）；并非"涨停最强"即最好，关键看机构盘口特征。
  • 适用资金：300万以上资金体量，可重仓博弈头部公司。
  • 收益目标：月度浪20%-30%；季度浪50%。
  • 方法定位：介于纯短线连板（高赔率低胜率）与中长线价值投资（低赔率高胜率）之间的中线波段方法，强调确定性。
重点
  1. 「拿货平台」形态识别（买卖点体系核心锚点）。
  2. 机构盘口与游资盘口的辨别（决定操作风格匹配）。
  3. 月末/季末时间窗口（强规律性）。
难点
  1. 前后联系立体判断（大盘+上一阶段主流方向+新方向异动综合盘感）。
  2. 节奏把握（慢节奏vs快节奏的持仓耐心）。
  3. 心态纪律（明知翻倍即走，面对加速行情容易贪婪）。

第十招君子有四时，进退有格局

📍 核心思想：本讲是整个系列的总结篇，把前九讲归并为「技术 + 逻辑 + 心法」三层格局——从"术"到"道"。

一、格局三层次（开篇总纲）

  • 技术：看得见的部分，即套路（战法、指标、经验）。
  • 逻辑：看不见的思考总结，即方向（何时做何事）。
  • 心法：更高层次，解决实操中的心态问题。

注：格局 = 技术 + 逻辑 + 心法这一整体框架。

二、技术层（保变电气十连板逐板详解）

保变电气是2020年3月特高压龙头、新基建龙头，案例串讲身位龙、筹码结构、加速、分歧、出货板等几乎所有经典短线技术。

板次要点
一板（首板）定位"骑手"
二板特高压板块唯一两板股（身位龙）；爆量，兼具"身位"与"换手"
三板一致阶段，资金判断趋同，"弱转强+加速一字板"
四板正常推进
五板挑战市场高度，首次分歧、爆量（首次天量）——龙头与妖股的分水岭
六板开盘高开即"弱转强确认"→加速
七板一致
八板分歧加大，成交量放大
九板分歧，开盘不高、深水下探→格局资金承接→新"分歧转移"
十板大幅高开（联想九板记忆、博弈11板翻三倍）→秒板后爆量→加速失败→一致转分歧，龙头见顶

关键口诀：五板是龙头与妖股的分水岭；格局资金意愿+市场情绪基础（试错阶段）是突破关键位置的核心条件。

天量分歧

定义：波段上涨趋势高位首次出现成交爆量分歧。形态多呈十字星或小阴线；量能通常为前一阶段平均成交量的两倍以上；后续信号"天量后见天价"，共同构筑趋势见顶。历史案例：2019年2月26日大盘天量分歧，3月2日天价分歧，随后调整。

出货板

定义：连板票高位爆量分歧，分时迟迟不上板，尾盘30分钟勉强封板。本质是买力衰竭，预示调整将至。典型案例：2020年3月11日保变电气。

保变电气后续走势与套利（4步）：① 次日缩量跌停（预期一致）构成闷杀；② 首阴套利：买点=闷杀日开盘价，卖点=次日集合竞价（若盘中封板失败弱于预期）；③ 后续走势：妖股后浪，破位首阴（前一日曾封板）；④ 案例价值：囊括经典龙头与近期妖股所有技术要点。

熟能生巧

突破技术障碍的核心是熟能生巧：方法 = 多操作、积累交易厚度；结果 = 自然悟道（久病成医）。技术不可速成，唯有反复实战打磨才能化为肌肉记忆。

三、逻辑层（何时做何事）

例题：通富微电与青岛啤酒走势（2019年底-2020年）讲季度浪切换与市场风格切换。

  • 标的对比：通富微电（芯片，成长）vs 青岛啤酒（消费白马，防御）。
  • 时间点：2019年11月底（月末/季末）判断下周期方向；12月方向芯片（通富微电10元启动涨至20、30元）。
  • 强势市场特征：大盘强势+流动性充裕→讲成长、讲概念（"梦率、胆率"）。
  • 3月后切换：大盘单边下跌，3月23日见底，3月24日青岛啤酒涨停；机构资金从成长向防御切换。后续验证：青岛啤酒翻倍，涪陵榨菜、海天味业、医药股同步上涨。
  • 规律：每年都会发生的季度量大型切换。

结构性行情

特征：每年或每1-2年出现的、与大盘走势分离的结构性行情。

年份分离点描述
20132013年2月8日2012年底银行股（民生银行）翻倍后指数新低（1846），创业板单边结构性行情（教育传媒）

发生节点两大规律：① 新年节点（连续三次验证，非巧合）；② 指数一波上涨结束后（如3500点之后）。核心逻辑：大盘无趋势性行情时资金判断"蓝筹搭台，题材唱戏"。

股市和楼市的关系

核心结论：国内主要投资品为房子与股票，资金在两者间负相关流动。三轮牛市验证：① 1999年后股市涨完房子猛涨；② 2005-2007后2009小牛市反弹房子大涨；③ 2014-2015股市高峰=楼市低谷，2015股灾后2016下半年楼市启动（上海一线一年翻倍，杠杆资金）。细致观察：2016年1月分离、6月加速。

强弱线、荣枯线

  • 3500点 = 强弱线（牛市屏障）：有效站上即来行情。
  • 3000点 = 中轴线：只守不攻，低于则暂停IPO。例：2019年2440点以来掉下3000即拉回，但到3000不攻。
  • 政策背景：注册制是工具，目的是实现经济转型——资金投向科技型企业，解决"卡脖子、自主可控、新旧经济切换"。核心结论：炒股需关注更高层面（政策、经济），而非仅盯K线。

四、心法层（实操心理）

心法特征：玄幻、虚，但多年交易经验 + 自有模式后能体会。知名代表：养家心法（深奥）。

知和行

核心论断：知而未行，实为未知——知道却做不到，本质是认知不足。两种"做不到"：知不会行（知道方向但缺乏方法→需亲身参与总结）；知不能行（知道方法但无法执行→需克服懒惰与自律修炼）。更高哲学：知之为不知，不知更非知。

反身性（索罗斯）

核心机制：交易者对趋势的判断→支配交易行为→微观行为汇聚→强化趋势。趋势特征：牛市任何利空仅致低开不改方向；熊市任何利好仅致高开不改方向。哲学总结：宏观即微观，微观即宏观。

通盘无妙手

核心原则：善战者无赫赫之功，善弈者通盘无妙手。取胜之道非靠奇谋，而是结硬寨、打呆仗，步步为营。投资启示：❌追求单票暴利、抄底逃顶；✅稳定盈利，通过复利实现目标。

买入分歧，卖出一致

买入时机：在分歧中看出潜在一致性时买入；卖出时机：在高潮中、众人抢筹时卖出。通俗理解：众人未发现时入场，众人皆知时退出。

人性

三毒（贪嗔痴）在交易中的体现：不以盈喜，不以亏悲。常见错误：亏损后删除自选股（嗔，被情绪支配）。克服方法：手中有股、心中有股，长期锻炼。盈亏同源：从亏损单中反复复盘，可发现盈利规律（久病成医）。总结：勤加练习、多加思考，反哺交易，最终实现交易升华。

五、关键要点回顾（按主题分类）

节奏控制

N+1=板板停……板板停；数字三连=涨停→连板→首次分歧；加速节奏1+2→6+7；双分歧1+1=趋势已尽；出货板=尾盘30分钟勉强封板

买点原则

不及预期=卖/结果相反=买；买入分歧卖出一致；首次破位最确定反抽；买在弱转强

卖点原则

没有完美卖点只有合理卖点；翻倍即走；10%法则止盈；换手不板即卖；长阴必先卖

风险控制

长阴先看结束先卖；持续破位=趋势结束；反包失败直接跌停；贪多导致利润回撤；知而未行=未知

大盘判断

站上10天线=见底；跌破10天线=见顶/二八切换；放量破箱体=中枢转上升；月末/季末窗口=季度浪；3500强弱线/3000中轴线

学习方式：先背诵各模型核心要素与买卖点；配合历史K线（保变电气、东方通信）做静态复盘；暂不实盘，先做模拟交易训练节奏感。

二、面向有经验的短线交易者

学习顺序：第3讲 → 第5讲 → 第6讲 → 第7讲 → 第10讲。

重点掌握：第3讲预期差（博弈底层哲学）；第5讲卖点全集；第6讲老妖后浪；第7讲暗线；第10讲心法。

学习方式：结合近1-3年自己参与过的实战案例对照；把模型要点写成"作战清单"每天盘前/盘中对照；重点复盘"卖错"的单子。

三、面向资深短线交易者

学习顺序：第4讲 → 第8讲 → 第9讲 → 第10讲。

重点掌握：第4讲趋势股；第8讲共振与中枢（大盘择时）；第9讲机构调仓；第10讲心法（反思知行合一）。

学习方式：不必拘泥细节，重点"视角升级"；用禅中说禅的"趋势-中枢"模型重新审视大盘判断；反思亏损单，找"盈亏同源"逻辑。

四、面向所有人（共性建议）

  1. 复盘优先：每讲学习后，先复盘近3年该模型对应的10个典型案例。
  2. 背诵口诀：每讲核心口诀必须能背诵。
  3. 小资金试错：所有模型先用1/10仓位验证1年再放大。
  4. 记录交易日志：每笔交易标注"用了哪个模型+触发条件+实际结果"，3个月后回看。
  5. 心态先行：第10讲心法应最后学、终身修——技术可速成，心态无法速成。

五、终极学习目标

从"凭感觉买股"到"按模型交易"，从"按模型交易"到"按格局应变"——这是十招寻龙诀的进阶路径。
  • 初阶：能识别5-10个核心模型（破位首阳/N+1/趋势股/预期差/换手卖点）。
  • 中阶：能根据大盘环境选择模型（低迷期做N+1，共振期做龙头，转势期做趋势股）。
  • 高阶：能根据资金风格匹配策略（游资风格用短线，机构风格用季度浪）。
  • 化境：买入分歧，卖出一致；众人未发现时入场，众人皆知时退出——技术与心法融为一体。
