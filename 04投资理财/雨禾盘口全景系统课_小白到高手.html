📌 一、什么是"盘口"

狭义盘口：指股票交易软件右侧的"盘口数据区"，包括买一到买五、卖一到卖五的委托挂单，以及最新成交价、成交量、换手率等实时数据。

广义盘口：指整个分时图所反映的所有信息——买卖盘、分时走势、量能变化、换手率、大单流向、分时均价线、量比、内外盘等所有盘中可观测数据的总称。

📍 雨禾观点：本课讲的盘口是广义盘口——单看买卖五档是远远不够的，必须看分时、看量、看挂单变化、看均价线。

📌 二、九大指标逐一拆解

1️⃣ 委比（委托买卖比）

委比 = (委买手数 - 委卖手数) / (委买手数 + 委卖手数) × 100%

判断标准：

  • 委比 > +50%：买方力量强，多方占优
  • 委比在 -50% 到 +50%：多空平衡
  • 委比 < -50%：卖方力量强，空方占优
⚠️ 注意：委比是动态指标，会随着挂单的撤单、改单瞬间变化。主力常用"挂大单诱多"——瞬间挂出巨量买单后再撤，制造委比假象。

2️⃣ 委差（委托买卖差）

委差 = 委买手数 - 委卖手数（单位：手）

委差为正表示买盘挂单多于卖盘，为负则反之。比委比更直观。雨禾观点：委差比委比更值得参考，因为它不受挂单撤单波动影响（撤单后委比变化大，委差变化小）。

3️⃣ 内盘（主动卖盘）

指以买一价主动成交的量，说明卖方以更低的价格急于卖出。在交易明细里显示为绿色"S"。

实战意义：内盘放大 + 股价不跌 = 主力可能吸筹（卖盘被主力吃掉）；内盘放大 + 股价下跌 = 真出货。

4️⃣ 外盘（主动买盘）

指以卖一价主动成交的量，说明买方以更高的价格急于买入。在交易明细里显示为红色"B"。

实战意义：外盘放大 + 股价上涨 = 健康上涨；外盘放大 + 股价不涨或下跌 = 主力可能在出货（诱多）。

5️⃣ 总量（当日累计成交）

从开盘到当前的累计成交手数。判断个股当日活跃度的基础指标。雨禾观点：早盘30分钟的总量大致能预测全天成交量的 1/3 到 1/4。

6️⃣ 量比（量能异动指标）

量比 = 现成交总手 / (过去5个交易日平均每分钟成交量 × 当日累计交易时间)

实战用法：

  • 量比 < 0.5：严重缩量，观望
  • 量比 0.5-1.0：缩量整理
  • 量比 1.0-2.0：温和放量
  • 量比 2.0-5.0：明显放量
  • 量比 > 5.0：剧烈放量，警惕异动
📍 开盘量比（9:30量比）最具实战价值，是捕捉当日异动股的第一指标。

7️⃣ 换手率（流通性指标）

换手率 = 当日成交股数 / 流通股本 × 100%
换手率区间含义主力行为
< 1%极度低迷无人问津，观望
1%-3%成交温和正常波动
3%-7%成交活跃开始有主力关注
7%-10%高度活跃主力可能拉升
10%-20%异常活跃可能是拉升或出货
> 20%极度活跃警惕主力出货

8️⃣ 大单（主力动向）

大小盘划分标准（雨禾核心心法）：

股票类型市值标准大单标准特大单标准
大盘股流通市值 > 500亿≥ 1000手≥ 5000手
中盘股100亿 ~ 500亿≥ 500手≥ 1000手
小盘股< 100亿≥ 100手≥ 500手
📍 雨禾心法：用固定金额（而非固定手数）判断大单更合理。大盘股1000手 = 1000万元左右，可能不构成大单；但小盘股100手 = 50万元就是大单。

9️⃣ 对敲（主力自买自卖）

主力左手卖给右手的虚假成交，目的通常是：

  • 制造成交量放大的假象，诱导散户跟进
  • 维持分时图的活跃度
  • 试探上下方接盘力度
⚠️ 对敲识别法：
  1. 同一价位短时间内多次大额成交
  2. 成交手数高度一致（如连续3笔都是500手）
  3. 外盘/内盘同步放大但价格不涨不跌
  4. Level-2逐笔成交显示相同营业部反复出现

⚡ 本课口诀

委比委差看多空，内外盘看主被动。总量看活跃，量比看异动。换手看流通，大单看主力，对敲看真假。

第1步：盘前看竞价（9:15-9:25）

看什么：

  1. 9:15-9:20：观察竞价挂单变化（可撤单期，主力常挂大单后撤）
  2. 9:20-9:25：观察真实挂单（不可撤单期）
  3. 9:25：看开盘价、开盘量、竞价形态

做什么：

  • 识别竞价8大形态（一字/L/阶梯/凹/拱/锥/尖角/复合）
  • 预判今日是涨是跌
  • 确定是否关注该股

第2步：早盘看方向（9:30-10:00）

看什么：

  1. 开盘30分钟的分时走势
  2. 量能变化（量比是否放大）
  3. 主力挂单（压单/托单/夹板/蜂窝）
  4. 是否突破均价线、开盘价

做什么：

  • 判断今日主方向（上涨/下跌/震荡）
  • 决定是否介入

第3步：中盘看洗盘（10:00-11:30）

看什么：

  1. 分时回调的力度（缩量/放量）
  2. 回调是否破位（均价线/开盘价/最低价）
  3. 拉升时的成交量配合

做什么：

  • 判断主力是洗盘还是出货
  • 寻找加仓点位

第4步：尾盘看决战（14:30-15:00）

看什么：

  1. 14:30后的方向选择
  2. 尾盘拉升/砸盘
  3. 最后5分钟的异动

做什么：

  • 决定是否持仓过夜
  • 捕捉尾盘机会

第5步：盘后看复盘（15:00之后）

看什么：

  1. 涨停板复盘（哪些涨停了、为什么涨停）
  2. 板块联动（哪个板块最强）
  3. 主力资金流向（北向、机构、游资）
  4. 明日计划（关注哪些个股）

📌 一、什么是"主线题材"

主线题材是指在一段时间内持续受到资金关注、反复活跃、能带动整个板块甚至大盘上涨的题材。它具备以下特征：

  • 持续性强：不是一两天的热度，而是持续数周甚至数月
  • 规模大：涉及多只个股，形成板块效应
  • 政策/事件驱动：背后有明确的政策支持或重大事件
  • 龙头明确：有清晰的领涨龙头

📌 二、主线题材的三大识别原则

原则1：政策驱动

国家级政策（如"双碳"、"数字经济"、"人工智能"等）一旦落地，会形成数月甚至数年的主线题材。识别方法：关注政策出台后的"行业渗透率变化"。

原则2：产业拐点

技术突破或需求拐点会带来主线题材（如新能源车的电池技术突破、ChatGPT引发的AI革命）。识别方法：关注龙头公司业绩拐点。

龙头股是指在某个主线题材中，涨幅最大、走势最强、带动性最强的个股。它通常具备以下特征：

  • 涨幅领先：相同周期内涨幅大于板块其他个股
  • 回撤最小：回调幅度小于其他个股
  • 抗跌性强：大盘下跌时相对抗跌
  • 带动板块：它的涨跌直接影响整个板块

📌 三、龙头股的六大特征

  3. 带动性：它的涨停能带动板块其他个股
  4. 承接力：涨停打开后能回封

📌 一、集合竞价三大时段

时段时间特性实战意义
阶段19:15-9:20可挂单可撤单主力常用"挂大单诱多/诱空"，看挂单变化

📌 二、集合竞价三大定价原则

9:25的开盘价由三个价格共同决定：

  1. 最大成交量原则：选取能使成交量最大的价格
  2. 高于该价格的所有买单全部成交
  3. 低于该价格的所有卖单全部成交
开盘价 = max(成交量) 对应的价格 即：使"买价 ≥ 开盘价的委托全部成交" + "卖价 ≤ 开盘价的委托全部成交"的价格

📌 三、9:15-9:20 主力的诱多诱空

9:15-9:20主力常用的两种诱骗手段：

  • 诱多：9:15挂出巨额买单（买一买二），让散户以为有主力接盘，散户跟进后主力9:20前撤单
  • 诱空：9:15挂出巨额卖单（卖一卖二），让散户以为有主力出货，散户恐慌后主力9:20前撤单

📌 四、9:20-9:25 真实意图识别

9:20-9:25不可撤单，此阶段的挂单代表真实意愿：

  • 买单持续增加 → 多方强势
  • 卖单持续增加 → 空方强势
  • 买卖单同时增加 → 多空博弈激烈，看开盘后方向

⚡ 本课口诀

9:15-9:20看挂单，可撤单期主力演戏。
9:20-9:25看真实，不可撤单才是真意。
9:25开盘价，最大成交量原则定。

第2层 · 第9课

🎨 第9课：集合竞价八大形态（小白→高手必学）

🎯 学完你能：识别一字/L/阶梯/凹/拱/锥/尖角/复合八大竞价形态；理解每种形态的主力意图；学会在竞价阶段做出买卖决策。

📌 一、八大经典竞价形态

1️⃣ 一字型（涨停一字/跌停一字）

✅ 特征：开盘价 = 涨停价（或跌停价），开盘后股价不波动

主力意图：

  • 涨停一字：主力极度看好，封单巨大，散户买不到
  • 跌停一字：主力或重大利空，散户卖不出

实战策略：

  • 涨停一字排队买入（一般买不到）
  • 跌停一字不能急于抄底，可能连续跌停

2️⃣ L型（开盘后稳步上行）

✅ 特征：竞价阶段挂单逐步增加，开盘价接近昨收或小幅高开，开盘后稳步上行

主力意图：主力温和吸筹，不急不缓。

实战策略：可在开盘价附近低吸。

3️⃣ 倒L型（开盘后急跌）

⚠️ 特征：竞价挂单较多，但开盘后迅速下杀

主力意图：主力诱多后出货（9:15挂大买单→9:20撤单→9:25挂大卖单）。

实战策略：坚决不参与，可能持续下跌。

4️⃣ 阶梯型（挂单阶梯式递增）

✅ 特征：买一、买二、买三、买四、买五挂单量依次递增（如100、200、300、500、1000手）

主力意图：主力稳步吸筹，给散户"安全感"吸引跟买。

实战策略：可适量跟进，止损设在开盘价下方。

5️⃣ 凹型（开盘后探底回升）

✅ 特征：竞价小幅高开或平开，开盘后短暂下杀后快速拉起

主力意图：主力洗盘+吸筹，把不坚定的散户洗出去。

实战策略：在拉升过程中跟进，止损设在最低点下方。

6️⃣ 拱型（开盘后冲高回落）

⚠️ 特征：竞价高开较多，开盘后冲高但很快回落

主力意图：主力诱多出货（拉升后借散户接盘卖出）。

实战策略：不参与，可能是出货形态。

7️⃣ 锥形（开盘后单边上行）

✅ 特征：竞价量能大，开盘后单边上行，几乎不回踩

主力意图：主力强势拉升，资金涌入。

实战策略：可追涨买入，但要注意高位风险。

8️⃣ 尖角形（开盘瞬间暴涨/暴跌）

⚠️ 特征：开盘前最后一瞬间突然大幅高开或低开

主力意图：主力利用最后几秒钟突袭，打乱散户判断。

实战策略：观望，不轻易跟进。

📌 二、其他特殊形态

虎口夺食型

竞价阶段买卖双方激烈博弈，最终开盘价大幅高于昨收，主力成功"夺走"散户的筹码。

牵牛花型

竞价阶段挂单很弱，但开盘后被主力逐步拉起，像牵牛花一样向上盛开。

断线型

竞价阶段看似强势（买单巨大），但开盘后瞬间暴跌，主力"断线"出货。

滑坡型

竞价阶段持续走弱，开盘后单边下跌，类似"滑坡"。

复合型

多种形态的混合，需要综合判断。

🚀 第10课：开盘三种盘面与六区间

🎯 学完你能：识别开盘后的三种盘面状态（强势/弱势/震荡）；掌握分时图的六大价格区间；理解每个区间的实战意义。

📌 一、开盘后三种盘面状态

1. 强势盘面（多头主导）

  • 开盘后股价快速拉升，站稳均价线上方
  • 回调时均价线有强支撑
  • 量能温和放大

策略：持有为主，回调即机会

2. 弱势盘面（空头主导）

  • 开盘后股价快速下跌，跌破均价线
  • 反弹时均价线有强压力
  • 量能放大

策略：减仓离场，不轻易抄底

3. 震荡盘面（多空平衡）

  • 开盘后股价围绕均价线小幅波动
  • 买卖力量均衡
  • 等待方向选择

策略：观望等待方向突破

📌 二、分时图六大价格区间

区间位置实战意义
1️⃣ 涨停价+10%（或+20%）极端多头，是当日最高价
2️⃣ 最高价当日最高强压力位，突破则看高一线
3️⃣ 昨收价昨日收盘心理基准线，多空分水岭
4️⃣ 均价线实时均价多空分水岭，盘中支撑/压力
5️⃣ 开盘价竞价开盘今日强弱基准
6️⃣ 最低价当日最低强支撑位，破位则看空
7️⃣ 跌停价-10%（或-20%）极端空头，是当日最低价

📌 三、均价线的实战应用

  • 支撑作用：股价在均价线上方运行时，回调至均价线往往止跌
  • 压力作用：股价在均价线下方运行时，反弹至均价线往往遇阻
  • 方向判断：股价站稳均价线 = 多头强势；跌破均价线 = 空头强势
📍 雨禾心法："均价线是多空双方的成本线，站稳均价线就是站稳成本线"

📌 四、关键区间突破法则

  • 突破昨收：从下方突破昨收价，多头开始占优
  • 突破开盘：从下方突破开盘价，今日多头确定
  • 突破最高：突破昨日最高，今日强势特征确立
  • 跌破开盘：跌破开盘价，多头弱势

六区间：涨停、最高、昨收、均价、开盘、最低、跌停。

📌 一、什么是"拉旗杆"

拉旗杆是指个股在开盘30分钟内出现一根垂直拉升的分时线，就像一根旗杆一样竖起来。这是主力强势拉升的明确信号。

📌 二、拉旗杆的三大特征

特征具体表现主力意图
速度快3-5分钟内拉升3%-8%主力资金雄厚
量能大伴随成交量急剧放大资金涌入
突破关键位突破均价线、开盘价、昨收多头确立

📌 三、3%法则

📍 雨禾核心心法：早盘30分钟内，涨幅超过3%的个股值得重点关注。因为这意味着主力在短时间内投入了巨额资金。

📌 四、星舰发射

星舰发射是指个股开盘后像火箭一样单边上扬，几乎没有回调的强势拉升形态。

阶段特征
发射期开盘后1-3分钟内快速拉升
巡航期持续走高，量价配合
分离期突破关键阻力位后加速
登月期冲击涨停或阶段高点

📌 五、拉旗杆的实战操作

  1. 发现拉旗杆：早盘30分钟内重点盯盘，捕捉垂直拉升
  2. 确认强势：拉升后站稳均价线、回调不破拉升起点
  3. 入场时机：在首次回调至均价线附近时低吸
  4. 止损设置：止损设在拉旗杆起点下方
⚠️ 注意：拉旗杆后必须回踩确认，如果拉升后立刻暴跌，可能是"假拉升"诱多。

卖二/卖三巨量真压单洗盘吸筹
卖一持续1小时以上真压单坚决出货

压单实战意义

  • 真压单在高位 → 主力出货，坚决离场
  • 真压单在低位 → 主力洗盘，可以低吸
  • 假压单 → 主力试盘拉升，随时可能突破

✅ 定义：在买一买二买三位置挂出大量买单，托起股价不下跌。

托单实战意义

  • 真托单在低位 → 主力护盘，可以跟随
  • 真托单在高位 → 主力掩护出货，警惕
  • 假托单 → 主力试探下方承接力

📌 三、夹板

📍 定义：在买一和卖一同时挂出巨量委托单，把股价"夹"在一个狭小空间内波动。

夹板的典型特征

  • 买一挂 1000手，卖一挂 1000手
  • 股价在两价位之间窄幅波动
  • 挂单持续数分钟到数小时

夹板实战意义

  • 吸筹阶段：夹板下方吸筹，等待突破
  • 出货阶段：夹板下方出货，准备砸盘
  • 突破夹板：股价突破夹板区间，往往是真突破或假突破
⚠️ 夹板突破法则：
  • 放量突破夹板 → 真突破，跟进
  • 缩量突破夹板 → 假突破，警惕回落
  • 夹板被瞬间吃掉 → 主力意图明确

📌 四、蜂窝

蜂窝的特征

  • 挂单数量多，价位跨度广
  • 持续时间长

蜂窝实战意义

  • 吸筹型蜂窝：主力在多个价位挂买单，等待散户抛盘
  • 出货型蜂窝：主力在多个价位挂卖单，等待散户接盘
  • 识别关键：蜂窝出现在低位多为吸筹，出现在高位多为出货

成交密度是指在特定价格区间内的成交手数密集程度。密度高意味着主力在此区间大量吸筹或出货。

密度特征主力意图

低密度某价位成交<1万手散户交易为主

📌 二、上涨速度

上涨速度是指股价在单位时间内的涨幅。速度越快说明主力拉升意愿越强。

上涨速度分级

📌 三、价升量增原则

✅ 健康上涨：股价上涨 + 成交量放大 = 价升量增（健康）

📍 第14课：关键支撑压力位（均价线/中轴线/开盘价/高低价）

🎯 学完你能：识别分时图上的四大关键位；理解每个关键位的支撑与压力转化；找到最佳的买入卖出点位。

📌 一、四大关键位详解

1. 均价线（黄线）

作用：多空双方成本线，是盘中最重要的支撑压力位。

  • 股价在均价线上方：均价线是支撑
  • 股价在均价线下方：均价线是压力
  • 突破均价线：支撑压力转化

2. 中轴线（昨收价）

作用：多空心理基准线。

  • 开盘在中轴上方：多头占优
  • 开盘在中轴下方：空头占优
  • 突破中轴线：方向选择信号

3. 开盘价

作用：今日强弱基准线。

  • 开盘后站稳开盘价：今日多头强势
  • 开盘后跌破开盘价：今日空头弱势
  • 回踩开盘价：重要买点

4. 当日最高价/最低价

作用：当日极值，形成新的支撑压力。

  • 突破最高价：强势确立
  • 跌破最低价：弱势确立
  • 回踩最高价/最低价：支撑压力测试

📌 二、支撑压力转化法则

✅ 突破定律：股价突破压力位后，该压力位转化为支撑位
✅ 跌破定律：股价跌破支撑位后，该支撑位转化为压力位

📌 三、关键位实战策略

情景策略
股价回踩均价线支撑企稳→低吸
股价反弹到均价线压力遇阻→离场
股价回踩开盘价支撑企稳→加仓
股价反弹到开盘价压力遇阻→减仓
股价突破最高价突破有效→追涨
股价跌破最低价跌破有效→止损

📌 四、多个关键位的共振

📍 雨禾心法：当多个关键位重叠时（如均价线 = 开盘价 = 中轴线），这个位置具有超强的支撑或压力，是最佳买点或卖点。

📌 一、按时间长短分类的波形

1. 长波（持续30分钟以上）

主力单边拉升或打压的波形，持续时间长、幅度大。多见于主流题材的龙头股。

2. 中波（持续10-30分钟）

主力分批拉升或打压的波形，常用于震荡行情。

3. 短波（持续3-10分钟）

主力试盘或洗盘的波形，常用于关键位突破或回踩。

📌 二、按走势特征分类的波形

1. 拉伸波（单边拉升）

特征：分时线像一根直线持续上涨，几乎不回调。

主力意图：强力拉升，多见于涨停前夕。

操作策略：追涨买入，注意高位风险。

2. 推动波（阶梯式上涨）

特征：分时线呈阶梯状，每次上涨后小幅回调，然后继续上涨。

主力意图：稳健吸筹或拉升，多见于趋势股。

操作策略：在每次回调时低吸。

3. 锯齿波（震荡行情）

特征：分时线反复震荡，无明显方向。

主力意图：震荡吸筹或洗盘。

操作策略：观望，等待方向突破。

锯齿+拉伸先震荡后拉升洗盘后拉升

1️⃣ 高开高走（最强势）

✅ 特征：开盘价高于昨收价，开盘后持续上涨

主力意图：多头强势，多见于涨停股。

2️⃣ 低开高走（强势反转）

✅ 特征：开盘价低于昨收价，但开盘后强势拉升翻红

主力意图：主力诱多出货，多见于顶部。

操作策略：坚决离场，是最弱的走势之一。

4️⃣ 低开低走（最弱势）

⚠️ 特征：开盘价低于昨收价，开盘后持续下跌

主力意图：空头主导，多见于弱势股。

操作策略：坚决不参与，是最弱的走势。

  • 探底回升：开盘后探底再拉升

第4层 · 第17课

🐦 第17课：凤飞天模型（涨停低吸核心）

🎯 学完你能：识别"凤飞天"涨停模型的四大特征；掌握凤飞天的入场时机；理解涨停股的最佳低吸方法。

📌 一、什么是凤飞天

凤飞天是雨禾总结的涨停低吸核心模型，指个股盘中短暂涨停后回调，尾盘或次日再次强势封板的形态。如同凤凰起飞前先低伏，起飞后直冲云霄。

📌 二、凤飞天的四大特征

【涨停幅度】≥ 8%（曾触板或封板） 【回调幅度】< 3%（不能深幅回调） 【时间窗口】> 30分钟（回调时间要足够） 【强势再封】回调后再次冲击涨停

📌 三、凤飞天的形成机制

  1. 第一次拉升：主力资金推动股价冲击涨停，触及涨停价
  2. 短暂回调：因抛压或主力洗盘，股价从涨停价回落
  3. 强势再封：洗盘结束，主力再次推动封板

📌 四、凤飞天 vs 其他形态

形态涨停后回调幅度回调时间后续走势
凤飞天< 3%30分钟-数小时再次涨停
炸板3-5%瞬时可能再封或下跌
烂板3-5%反复可能再封或下跌
出货> 5%持续持续下跌

📌 五、凤飞天的入场时机

  1. 第一次回调低点：最佳入场点（第一次涨停后回调的最低点）
  2. 均价线附近：回调至均价线附近时入场
  3. 再次启动时：回调结束开始再次拉升时入场
📍 雨禾心法：凤飞天是涨停股中最具操作性的形态，因为它给了散户涨停价附近低吸的机会，是高手的标志性战法。

⚡ 本课口诀

凤飞天：涨停回调<3%，回调时长>30分，再次拉升冲涨停。
低吸就在第一次回调点，均价线附近是良机。

第4层 · 第18课

🌙 第18课：尾盘策略（拉尾+打尾+启示+多日分时图+T+0）

🎯 学完你能：识别尾盘拉升与砸盘的真实意图；掌握尾盘买入策略；理解多日分时图的关联；学会T+0操作。

📌 一、尾盘拉升的四种类型

1. 急升缓跌型（出货形态）

⚠️ 特征：尾盘快速拉升，但拉升后缓慢下跌

主力意图：借尾盘拉升掩护出货。

识别要点：

  • 尾盘最后5-10分钟突然拉升
  • 拉升幅度大但速度慢
  • 拉升后成交量放大但股价不能维持

2. 急跌缓升型（吸筹形态）

✅ 特征：尾盘快速下跌，但下跌后缓慢回升

主力意图：借尾盘砸盘低位吸筹。

识别要点：

  • 尾盘最后5-10分钟突然下跌
  • 下跌幅度大但时间短
  • 下跌后股价缓慢回升，成交量温和

3. 缓升缓跌型（实质走势）

特征：尾盘缓慢波动，无明显方向。

主力意图：真实的多空博弈结果。

4. 急涨急跌型（虚假走势）

⚠️ 特征：尾盘大幅波动后再回落

主力意图：制造异动假象，诱导散户。

📌 二、尾盘心法

急升缓跌=出货，急跌缓升=吸筹，缓升缓跌=实，急涨急跌=虚。

📌 三、尾盘买入策略

  1. 14:30方向选择：观察14:30后的方向，明确后跟进
  2. 14:50试盘：观察14:50的试盘动作
  3. 14:55决战：14:55的方向决定次日开盘

📌 四、多日分时图

多日分时图是指连续多日的分时走势图叠加分析，可以揭示：

  • 主力的吸筹节奏（每天的同一时间段是否相同动作）
  • 主力的成本区间（多日分时图的密集成交区）
  • 主力的拉升计划（连续多日的低开高走或高开低走）
📍 雨禾心法：多日分时图相同的形态，往往是主力刻意为之，是判断主力意图的重要工具。

📌 五、T+0 操作

由于A股实行T+1制度，T+0是利用已持有的股票进行日内高抛低吸：

  • 早盘冲高卖出部分仓位
  • 尾盘回调买回同样数量
  • 实现日内降低成本的目的
⚠️ T+0 风险：必须有底仓；高抛后必须能买回；不能满仓操作。

⚡ 本课口诀

急升缓跌出货，急跌缓升吸筹。
14:30定方向，14:55定开盘。
多日分时看主力意图，T+0降低成本靠节奏。

第4层 · 第19课

🐍 第19课：阶梯型涨停（贪吃蛇/N字形/三种阶梯）

🎯 学完你能：识别阶梯型涨停的三大类；理解贪吃蛇涨停和N字形涨停的区别；找到阶梯型涨停的最佳介入点。

📌 一、什么是阶梯型涨停

阶梯型涨停是指个股在涨停过程中，分时线呈现明显的阶梯状形态，每次拉升后稳定一段时间，再继续拉升，最终封板。

📌 二、阶梯型涨停的三大类

1. 贪吃蛇型（最常见）

📍 特征：分时线像贪吃蛇一样逐步向上推进，每涨一段后小幅整理，再涨一段。

形成机制：主力分批拉升，每次拉升后给散户跟进机会，但又不让股价大幅回调。

实战要点：

  • 每次阶梯高点抬高
  • 回调幅度小（<2%）
  • 成交量阶梯式放大

2. N字形

特征：分时线呈标准的N字形态，先上涨后回调再上涨。

形成机制：第一次拉升吸引眼球，回调洗掉不坚定者，再次拉升突破。

3. 三种阶梯

类型阶梯数持续时间主力意图
小阶梯3-5个15-30分钟快速拉升
中阶梯5-8个30-60分钟稳健拉升
大阶梯>8个>60分钟边洗边拉

📌 三、阶梯型涨停的入场时机

  1. 第一个阶梯高点：确认阶梯形成后跟进
  2. 第二/第三个阶梯起点：低吸位置
  3. 封板瞬间：涨停板排队

📌 四、阶梯型涨停的操作要点

  • 阶梯高点逐步抬高是关键
  • 回调时成交量萎缩（洗盘特征）
  • 涨停封单稳定（主力信心）

⚡ 本课口诀

阶梯型涨停像贪吃蛇，步步抬高不回头。
N字形先涨再洗再涨，三种阶梯看节奏。

📐 第20课：斜坡型涨停（45度角 + 大斜坡/小斜坡）

🎯 学完你能：识别斜坡型涨停的45度角特征；区分大斜坡与小斜坡；找到斜坡型涨停的最佳介入点。

📌 一、什么是斜坡型涨停

斜坡型涨停是指个股在涨停过程中，分时线呈现接近45度角的稳定上涨，最终封板。

📌 二、斜坡型涨停的分类

1. 大斜坡型

特征：

  • 涨幅大（开盘到涨停 > 5%）
  • 斜率陡（接近或超过45度）
  • 持续时间长（30-60分钟）
  • 成交活跃

主力意图：强势建仓或快速拉升。

2. 小斜坡型

特征：

  • 涨幅小（开盘到涨停 < 5%）
  • 斜率缓（小于45度）
  • 持续时间长（30分钟-全天）
  • 成交温和

主力意图：稳健吸筹或慢牛拉升。

📌 三、斜坡角度与主力意图

角度含义实战策略
< 30度弱势上涨观望
30-45度稳健上涨低吸
45-60度强势上涨追涨
> 60度急速拉升警惕回落

📌 四、斜坡型涨停的入场时机

  1. 斜坡初期：在斜率明确后跟进
  2. 斜坡中段：在回踩均价线时低吸
  3. 斜坡末端：在封板瞬间排队

⚡ 本课口诀

斜坡型涨停45度角，大斜坡快速小斜坡慢。
30度观望，45度低吸，60度追涨，60度以上警惕。

第4层 · 第21课

🌊 第21课：震荡型涨停（顺势+逆势立式+高低位）

🎯 学完你能：识别震荡型涨停的三大子类型；理解顺势涨停与逆势涨停的区别；找到震荡型涨停的最佳介入点。

📌 一、什么是震荡型涨停

震荡型涨停是指个股在涨停过程中，分时线呈现明显的震荡形态，股价在均价线附近反复波动，最终封板。

📌 二、震荡型涨停的三大子类型

1. 顺势震荡型

特征：股价在均价线上方震荡，每次回踩均价线都获得支撑。

主力意图：多头强势，高位震荡洗盘。

实战策略：回踩均价线低吸。

2. 逆势立式型

特征：股价在均价线下方震荡，但每次反弹都突破均价线。

主力意图：空头背景下的强势拉升。

实战策略：突破均价线后跟进。

3. 高低位型

特征：股价先低位震荡，然后向上突破。

主力意图：低位吸筹后拉升。

实战策略：突破震荡区间时跟进。

📌 三、震荡型涨停的入场时机

  1. 回踩均价线：顺势震荡型的最佳买点
  2. 突破震荡区间：高低位型的最佳买点
  3. 封板瞬间：所有震荡型涨停的共同买点

⚡ 本课口诀

震荡型涨停看均价，顺势回踩是低吸。
逆势立式要突破，高低位型看启动。

下一课学习脉冲式涨停——五大涨停体系的第四类。

第4层 · 第22课

⚡ 第22课：脉冲式涨停（横盘式+眼镜王蛇+缺口式）

🎯 学完你能：识别脉冲式涨停的三大类；理解"眼镜王蛇"形态的特殊性；找到脉冲式涨停的最佳介入点。

📌 一、什么是脉冲式涨停

脉冲式涨停是指个股在涨停过程中，瞬间或短时间内从某个价位直接拉升到涨停价，伴随成交量急剧放大。

📌 二、脉冲式涨停的三大子类型

1. 横盘脉冲型

特征：

  • 开盘后长时间横盘（30分钟以上）
  • 在某一瞬间突然涨停
  • 涨停前几乎没有拉升迹象

主力意图：横盘吸筹后瞬间拉升。

2. 眼镜王蛇型（最具特色）

⚠️ 特征：像眼镜王蛇一样突然攻击，涨停前往往有诱空动作
  • 开盘后先小幅下跌或横盘
  • 突然一根直线拉升封板
  • 拉升速度极快（1-3分钟内涨停）

主力意图：诱空后强势拉升，洗盘彻底。

实战策略：在拉升瞬间追涨，但风险较高。

3. 缺口脉冲型

特征：

  • 在拉升过程中出现跳空缺口
  • 缺口短时间内回补或不回补
  • 封板坚决

主力意图：强势突破关键位。

📌 三、脉冲式涨停的入场时机

⚠️ 风险提示：脉冲式涨停的入场时机较难把握，因为拉升速度极快。多数情况是提前埋伏或次日跟进。
  1. 横盘末端：横盘脉冲型的提前埋伏点
  2. 拉升瞬间：所有脉冲型的追涨点（难度高）
  3. 次日：稳健的跟进点

⚡ 本课口诀

脉冲式涨停快如电，横盘末端是买点。
眼镜王蛇最凶猛，诱空拉升防踏空。

下一课学习烂板破板——涨停失败的识别。

第4层 · 第23课

⚠️ 第23课：烂板破板（良性烂板+出货烂板+破板偷袭）

🎯 学完你能：识别良性烂板与出货烂板；理解"破板偷袭"的特征；找到烂板的最佳离场时机。

📌 一、什么是烂板

烂板是指个股触及涨停后无法维持，反复开板，最终收盘可能涨停也可能不涨停的状态。

📌 二、良性烂板 vs 出货烂板

1. 良性烂板（主力洗盘）

✅ 特征：
  • 涨停开板后成交量温和放大
  • 开板后股价在涨停价附近震荡，不大幅下跌
  • 最终能够再次封板
  • 封板后抛压较小

主力意图：通过开板洗掉不坚定的筹码。

实战策略：持有，甚至可以在开板时低吸。

2. 出货烂板（主力出货）

⚠️ 特征：
  • 涨停开板后成交量急剧放大（数倍）
  • 开板后股价快速下跌远离涨停价
  • 最终无法封板，收盘可能涨幅很小
  • 封板后抛压极大

主力意图：借涨停掩护出货。

实战策略：坚决离场。

📌 三、良性与出货烂板的对比

指标良性烂板出货烂板
开板成交量温和放大急剧放大（数倍）
开板后跌幅小（<2%）大（>2%）
能否封板最终能封最终不能封
封板后表现稳定持续抛压
后续走势可能再涨持续下跌

📌 四、什么是破板

破板是指个股前一日涨停（封死），但次日开盘未能继续上涨，反而走弱。

📌 五、破板的三种类型

1. 良性破板（洗盘）

特征：

  • 次日小幅低开（<2%）
  • 开盘后探底回升
  • 收盘仍能维持小涨

主力意图：洗盘后继续拉升。

2. 出货破板（出货）

特征：

  • 次日大幅低开（>3%）
  • 开盘后持续下跌
  • 收盘可能跌停或大跌

主力意图：彻底出货离场。

3. 破板偷袭（拉高出货）

⚠️ 特征：
  • 次日开盘诱多（小幅高开）
  • 开盘后瞬间冲高（诱多）
  • 然后快速下跌
  • 出货动作干净利落

主力意图：借开盘诱多快速出货。

实战策略：坚决不参与。

⚡ 本课口诀

良性烂板要持有，出货烂板要离场。
破板低开未必坏，破板偷袭最阴险。

💼 第25课：持仓管理三大操作思路（实战高手必备）

🎯 学完你能：根据涨停后走势决定加仓/减仓/止盈/止损；掌握三种持仓思路；理解高手与散户的核心区别。

📌 一、持仓管理的核心原则

  1. 截断亏损：亏损达到预期立即止损
  2. 让利润奔跑：盈利时不要急于落袋为安
  3. 控制仓位：单只个股不超过总仓位的30%
  4. 分散风险：同时持有3-5只不同板块个股

📌 二、涨停后的三种持仓思路

思路1：加仓思路（强势股）

适用情景：

  • 涨停封板坚决，封单巨大
  • 所属题材是当前主线
  • 技术形态处于上涨初中期
  • 大盘环境配合

加仓时机：

  1. 次日开盘高开高走时
  2. 首次回调到均价线附近时
  3. 突破前高压力位时

思路2：减仓思路（弱势股）

适用情景：

  • 涨停反复开板（烂板）
  • 所属题材开始退潮
  • 技术形态处于高位
  • 大盘环境转弱

减仓时机：

  1. 开盘价低于预期时
  2. 反弹到均价线时
  3. 跌破开盘价时

思路3：清仓思路（出货股）

适用情景：

  • 次日大幅低开
  • 开盘后快速下跌
  • 破板偷袭
  • 所属题材彻底退潮

清仓时机：开盘就走，不犹豫。

📌 三、实战决策流程

📍 雨禾决策流程：
  1. 次日开盘：观察开盘价是否符合预期？
  2. 早盘方向：开盘后是强势还是弱势？
  3. 量能配合：成交量是放量还是缩量？
  4. 盘口信号：是否有主力护盘或出货信号？
  5. 题材表现：所属板块是涨还是跌？
  6. 综合判断：加仓/持有/减仓/清仓

📌 四、止损止盈法则

法则触发条件操作
固定止损亏损达 5%立即止损
移动止损从最高点回落 8%立即止损

分批止盈盈利 30% / 50% / 100%分批卖出
目标止盈达到预期目标清仓
