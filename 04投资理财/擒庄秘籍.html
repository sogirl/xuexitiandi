第1节 · 三大原理之首

第1节 · 量价供需原理

一句话核心结论：价格波动的本质 = 供需关系的不平衡。A 股只能做多，因此介入时机 = 需求持续大于供应 的不平衡阶段。

📌 核心知识点

本节课开篇明确"市场运行的底层逻辑有三大"，分别是：① 供需原理；② 投产原理；③ 博弈原理。本节聚焦"供需原理"，它是底层的"第一性原理"——所有价格波动，本质上都可以归结为供需关系的变化。出自第1节第1段

1. 供需原理的核心定义

核心命题：商品价格波动的本质源于供需关系的变化，即供需关系决定价格波动。

  • 经典案例——中国房价的二十年史：10-20 年前买房需求旺盛而土地/房屋供应有限 → 房价持续暴涨；近几年刚需基本被满足，需求萎缩而供应仍在持续 → 房价下跌。
  • 教学要点：商品价格变化是"供需关系变化"的镜像；不仅仅是房产——任何商品（股票、农产品、大宗商品）的价格变化，底层都是供需。出自第1节第2段

2. 三大供需关系

供需关系有且只有三种状态：

  • 供大于求（供过于求）：卖的人多、买的人少，价格必然下跌。
  • 供小于求（供不应求）：买的人多、卖的人少，价格必然上涨。
  • 供需平衡：买卖基本持平，价格不涨不跌，处于平稳状态。

案例佐证——华为三折叠手机：数百万人预约，但首次出货量极少；黄牛价翻 2-3 倍；完美诠释"需求远远大于供应→价格暴涨"。出自第1节第3段、第4段

3. 趋势的本质：供需关系的不平衡

核心命题：市场产生趋势的本质源于供需关系的不平衡。

  • 震荡行情：供需关系平衡（窄幅震荡），利润空间几乎为零。
  • 趋势行情：供需关系不平衡，有大利润空间。
  • A 股特殊性：A 股只能做多（不能做空），因此 A 股只有"需求大于供应"的趋势才会引发暴涨。
  • 老师强调："一定要介入在供需关系处于不平衡的阶段，这一点无比的重要，这是真正交易的底层逻辑。"出自第1节第5段、第6段

4. 上升趋势：需求持续大于供应

底层逻辑：上升趋势 = 需求持续大于供应。

  • 买的人排队买，卖的人少；
  • 呈现"缩量上涨"或"放量后再缩量、再放量再缩量"的节奏；
  • 卖方"被吸收"——有人卖出，立刻被买方全部吃掉；
  • 买方需要不断加价才能买到。

买方优势盘口：买盘排的人多，卖盘排的人少。例如：想买 2000 股但卖一只有 200 股，必须把卖一、卖二、卖三、卖四、卖五的价格全部扫掉（加价到约 10.05 元），才能满足 2000 股的需求 → 价格不断上涨。出自第1节第7段、第8段

一句话总结股价上涨的底层逻辑：买方不断加价在买入（核心底层逻辑）→ 供应小于需求 → 需求持续大于供应 → 上升趋势。

5. 涨停板的本质

涨停板 = 买方持续加价买。具体推演：

  • 一天内买卖双方都有大量交易（有人买、有人卖）；
  • 但因为涨停，买方力量大于卖方力量；
  • 后续持续缩量 → 卖方吸收；
  • 买方稍加价就直接封涨停板；
  • 即使中途有放量卖出，但第二天仍以缩量涨停方式继续。出自第1节第10段

6. 下降趋势：供应持续大于需求

底层逻辑（镜像对应）：下降趋势 = 供应持续大于需求。核心特征：

  • 买方力量不足；
  • 卖方持续降价甩卖、无人接盘；
  • 卖的人远远大于买的人 → 价格一定下降。

卖方优势盘口：卖盘挂单远多于买盘。例如：想卖 1000 股但买一只有 100 股、买二只有 200 股、买三只有 300 股；想一次成交 1000 股，必须把买一、买二、买三的价格全部吃掉（降价到约 9.7 元）才能成交；如果只挂 10 元等单，对不起，只有 100 股给你；想要迫不及待兑现，必须降价；一降价 → 股价下跌。出自第1节第11段、第12段

核心机制：下降趋势的本质是"不断有人降价在卖"，进一步是"不断有人降价在甩卖"。

7. 多方成本 vs 空方城堡

  • 多方成本：多方在低位买入形成的"防守位"，需要持续买盘维护。
  • 空方城堡：空方在高位打压形成的"压迫位"。
  • 下降趋势中的博弈格局：偶有一点买方力量，很快被空方打穿底线；形成不了一座有效的多方力量城堡，"一个都没有"；买卖双方偶尔平衡，但很快"被空方力量打破"；形成不断向下的创新低。
  • 核心结论：下降趋势的本质就是"不断持续地有人在降价甩卖"。出自第1节第15段

🔍 典型案例

案例 1：日线连续阳线 + 缩量涨停（出自第1节第9段）
股票从底部翻三倍以上；日线几乎全是阳线，偶尔一两根阴线，次日又创新高；后期持续缩量，但买方迫不及待加价买入，导致瞬间涨停；偶有放量卖出（卖方力量出现），但次日马上被买方全部吃掉、新高继续。
关键信号链：缩量 = 卖方吸收（卖的人少）→ 买方稍加价 → 直接封涨停 → 即使中间放量卖出，仍是缩量方式继续涨停 → 买方力量一直在加价买入，是连续涨停的底层逻辑。
案例 2：华为三折叠手机（出自第1节第4段）
数百万人预约，首次出货量极少 → 黄牛价翻 2-3 倍 → 完美诠释"需求远远大于供应→价格暴涨"。该案例证明供需原理在消费品市场的普适性。
案例 3：中国房价二十年史（出自第1节第2段）
10-20 年前：买房需求旺盛，土地/房屋供应有限 → 房价持续暴涨；近几年：刚需基本被满足，需求萎缩，供应仍在持续 → 房价下跌。完美映射"供需关系决定价格波动"的第一性原理。

💡 系统性总结

本节要点：
1. 不介入供需平衡阶段：震荡行情无利润空间，只介入供需不平衡阶段。
2. A 股只做"需求 > 供应"：因为只能做多，所以要等供不应求才介入。
3. 看本质，不看表象：缩量上涨是"卖方被吸收"，不是"没人气"；放量下跌是"卖方砸盘"，不是"出货"。
底层逻辑一句话：股价上涨的底层逻辑 = 买方不断加价在买入；股价下跌的底层逻辑 = 不断有人在降价甩卖。
⚠️ 前置关联：本节为三大底层原理之首。建议在掌握 第2节·量价投产原理（投产比判定）后，再阅读 第3节·量价博弈原理（主力意图透视）以构成完整的量价分析底层逻辑。
第2节 · 三大原理之二

第2节 · 量价投产原理

一句话核心结论：量是兵力，价是地盘。当兵力更大但地盘更小（特别是高位），就是高危停止行为；当兵力更小但地盘更大（缩量十字星止跌后涨停），就是极点机会。

📌 核心知识点

1. 投产原理的核心定义与股市映射

开篇回顾三大底层逻辑：① 工具原理 → ② 投产原理 → ③ 博弈原理。本节重点讲投产原理。出自第2节第1段

  • 投产原理 = 投入与产出，亦即努力与成果。反差现象：有些人投入很大但没有产出；有些人投入一点点但产出很大。
  • 因果定律：一切结果，都必然由前面的投入而产生。在股市里同样存在投入与产出的关系。出自第2节第3段
  • 股市的映射关系（关键句）：投入（努力）= 成交量；产出（成果）= 价格涨跌的幅度。
  • 举例对比：案例 A 第一天成交量一般但价格大涨；案例 B 第二天成交量更大但价格只收十字星 → 后者的投入（量）更大，但产出（价）更小。出自第2节第3段
  • 核心比喻：量是兵力，价是地盘（全课最核心比喻）：投入 100 万兵力向前推进 10 公里（兵力少但地盘大）；投入 120 万兵力（更多兵力）但只向前推进 1 公里（兵力大、地盘小）。出自第2节第4段

2. 停止行为的底层逻辑

停止行为的定义：如果相同或更大的努力没有获取相应的成果，说明努力被市场吸收了，这是一种停止行为，需要引起警惕。出自第2节第5段

  • 吸收 = 你的需求被供应给抵消掉了。买方的进攻被卖方的防守抵消——你买多少，对手就卖多少给你。
  • 部队打仗比喻：你是一支部队想往前推进，遭遇敌方袭击，两军开始对峙，你打不过对方或只能打个平手（=吸收），没办法往前推进（=价格无法继续上行）。
  • 落到股票里：投入 100 万兵力推进 10 公里 → 进攻有效；投入 200 万兵力只推进 1 公里 → 投入更多但地盘更小，是停止行为；说明在这个位置遭遇了敌方（卖方）的吸收。
  • 警惕信号：如果敌方力量更强，后面敌方杀过来，多方被盖过，可能形成转折，要下跌。出自第2节第6段
  • 本质 = 多空力量在当前位置达到平衡或被卖方压制；兵力（成交量）投入了，但地盘（价格涨幅）没有相应扩张。出自第2节第7段

3. 停止行为的实战判定

核心法则：

位置停止行为含义
上涨至高位的停止行为预示风险见顶信号，要小心
上涨途中的停止行为通常视为机会极点，回调到位即将启动

量价形态的具体识别：

  • 价涨量平（高位） → 通常向下转折的风险信号；
  • 价平量增（高位） → 通常向下转折的风险信号；
  • 价跌量增 → 卖方开始加大力度在卖（板块四诱多出货铺垫）；
  • 缩量十字星（下跌途中） → 多空力量平衡，是止跌/滞跌信号。

4. 主力行为识别（B柱/C柱/D柱/E柱/F柱案例集）

B 柱高位停止行为：B 柱当天量特别大但价格并未扩张（实质 K 线/十字星）→ 高位的停止行为，要调整；后续连续第二天、第三天依然缩量、停止调整。出自第2节第12段

C 柱 vs D 柱对比（核心案例）：D 柱的成交量明显比 C 柱大了一倍；但 D 柱的价格没有大一倍（反而是十字星/实体小）→ 判断：D 柱是滞涨信号。结果：D 柱之后第二天开始下跌（停止行为被验证为风险信号）。触发原因：左侧压力（上方套牢盘）。出自第2节第12段、第9段

E 柱 vs F 柱——主力诱多出货教科书案例：

  • E 柱：涨停板，量正常；
  • F 柱：成交量比 E 柱更大（接近历史最大量），但只是十字星；
  • 对比：F 柱的兵力更大，但成果非常小 → F 柱当天卖方力量阻止了向前的拓展空间；
  • 触发原因：左侧压力（上方有大量套牢盘）；主力真实意图：暗中出货。

出货动作链：

  1. F 柱用大成交量把价格推到左侧压力位；
  2. 散户追高买入（被诱多）；
  3. 主力在大成交量中把筹码暗中卖给散户；
  4. 当天结果是十字星 → 主力已经"出货完毕"；
  5. 第二天：跳空低开——"跳崖"，一路下跌。

老师原话："把散户引诱上去，主力暗中在卖，卖完之后第二天跳空低开，这不巅峰跳崖吗？"出自第2节第13段、第14段、第15段

5. 极点（下跌停止 + 反转买点）

  • 上涨途中连续缩量 = 阻力来了：在上涨途中，如果出现连续的缩量 T 字线 → 代表阻力来了；主力在这个位置"没走"，但也推不动了。出自第2节第16段
  • 主力没走 + 缩量十字星 = 跌不下去：在阻力位形成缩量十字星 → 信号：跌不下去；性质：下跌的滞涨/下跌途中的"止跌行为"。
  • 空方力量来袭，下跌停止：主力开始下跌 → 跌到这个位置跌不动了 → 空方的力量已经释放完毕 → 此时属于兵力与地盘的"低谷阶段"。出自第2节第17段
  • 多方用大力直接涨停 = 极点（核心句）：空方力量已经不能向下再拓展空间；多方少有用力，而且是用大力（直接一倍的兵力投入） → 向上拓展的空间就开出来了。出自第2节第18段
  • 老师原话："这不就是我们的极点吗？这不就是我们的极点吗？为什么不停止住呢？停止之后就这么来的，下跌的停止，跌不动了。"

极点 = 下跌停止 + 多方大力涨停的反转组合点。

📊 关键判定标准

方法论公式：

公式含义
投入 = 成交量 = 兵力多空双方投入的总兵力
产出 = 价格涨跌幅度 = 地盘兵力推进出来的地盘
兵力更大，地盘更小 → 高危停止行为（特别是高位）→ 风险主力出货/见顶信号
兵力更小，地盘更大 → 投产比极高（涨停板+缩量止跌）→ 机会（极点）主力入场确认

停止行为判定速查表：

位置量价形态含义应对
高位巨量 + 十字星（兵力大地盘小）见顶 / 主力诱多立即减仓
高位跳空低开（破位）主力出货完毕必须离场
上涨途中缩量十字星回调到位极点 / 主力没走关注次日确认
上涨途中缩量十字星后次日涨停多方占优可作为买点
下跌途中缩量 + 跌不动空方耗尽潜在极点
下跌底部用大力直接涨停极点确立买点信号

🔍 典型案例

案例 1：通话金马 5 板后连续两天放巨量（出自第2节第8段）
标的：通话金马（2023 年牛股）；形态：连续 5 个涨停板后连续 2 天放巨量；巨量后第二天的价格：只收了十字星（不是大阳线）；这两天的对比 = 量更大但产出的地盘几乎没扩张，是明显的停止行为。
逐句逻辑链：第二天放量更大，但价格只是十字星 → 说明卖方把买方的努力"锁定"了；你买多少，我卖给你多少（=吸收）；买方已经没办法向前推进 → 形成"价跌量增"——卖方开始加大力度在卖；买卖博弈中"卖方更胜一筹"，要小心；后续复盘：第二天追跌停；多方的反弹在第三天已是回光返照。
案例 2：C 柱 vs D 柱（出自第2节第9段）
D 柱的成交量明显比 C 柱大了一倍；但 D 柱的价格没有大一倍（反而是十字星/实体小）→ 判断：D 柱是滞涨信号；结果：D 柱之后第二天开始下跌。
次日确认（缩量十字星+涨停反转）：在 D 柱下跌之后按理应继续跌，但第二天出了一根缩量十字星 → 信号含义：缩量十字星 = 多空力量的平衡（"下跌的滞跌"、"止跌行为"）；量也缩了，价也缩了 → 卖方力量已释放得差不多，跌不动了。第二天量比昨天大一点点（努力多了一点点）但成果却大了很多——第二天是涨停板 → 明显多方力量更占优，所以后面又创新高。这是非常重要的"反转确认信号"：上一根是缩量十字星（止跌）→ 下一根用相对小的努力封了涨停（多方占优）→ 新的极点诞生。出自第2节第10段
案例 3：E 柱 vs F 柱——主力诱多出货"教科书"（出自第2节第13-15段）
E 柱涨停量正常 → F 柱成交量接近历史最大量但只是十字星 → 含义：F 柱当天卖方力量阻止了向前的拓展空间，努力没有成果；触发原因：左侧压力。
主力真实意图：暗中出货。出货动作链 = F 柱用大成交量推到压力位 → 散户追买 → 主力暗中卖给散户 → 收十字星 → 第二天跳空低开——"跳崖"，一路下跌。
投资者对策：看到"努力大但没有成果"的柱子（F 柱）当天就应该减仓；如果当天没卖，看到第二天跳空低开就必须跑。

💡 系统性总结

本节要点（操作守则）：
1. 遇到"高位 + 巨量 + 十字星" → 见好就收，当天减仓或第二天跳空低开就离场。
2. 遇到"高位 + 价平量增 / 价涨量平" → 警惕向下转折。
3. 遇到"上涨途中 + 缩量十字星回调" → 准备进场，但要等次日确认。
4. 遇到"上涨途中 + 缩量十字星后次日涨停" → 多方占优信号，可介入。
5. 遇到"下跌途中 + 缩量 + 跌不动" → 空方释放完毕，等多方用大力的涨停确认 → 极点确立。
6. 始终：兵力（量）要与地盘（价）匹配；兵力大地盘小在高位必坏事；兵力小地盘大在底部往往是新机会。
底层逻辑一句话：把量看作兵力，把价看作地盘。当兵力大于应有的推进需求，而地盘却跟不上时，就是停止行为——主力的意图就会"暴露无遗、无所遁形"。看透了停止行为，机会与风险的把控就一清二楚。

第3节 · 三大原理之三

第3节 · 量价博弈原理

一句话核心结论：市场是零和/负和游戏，最大的两个博弈对手是主力与散户。散户唯一的选择 = 做主力的跟随者（银鲨），透过次日量价行为透视主力意图。

📌 核心知识点

1. 博弈原理的定位：市场运行的第三大底层原理

本节开篇明确三大底层原理的体系结构：

  • 第一大原理：供需原理；
  • 第二大原理：投产原理；
  • 第三大原理：博弈原理（本节核心）。

三者共同构成市场运行底层逻辑的完整框架。博弈原理是市场运行的"人性逻辑"，回答的是"谁在买、谁在卖、谁主导价格"这一核心问题。出自第3节第1段

2. 博弈原理的本质：零和游戏与献祭机制

零和游戏属性：市场（股票、期货、外汇）本质上都是零和游戏，甚至是负和游戏。因为除去手续费、交易所及券商佣金后，市场整体是亏损的——手续费被抽走，意味着参与者总体是亏钱的。出自第3节第2-3段

主力与散户的互为博弈对手：

  • 主力（机构）与散户互为博弈对手；
  • 主力与主力之间也是博弈对手；
  • 散户与散户之间也是博弈对手；
  • 但最大的两个博弈对手是主力与散户——主力的主要利润来源就是"割散户的韭菜"。

献祭机制：世界上任何市场行为都需要有人"送人头"，为主力提供流动性和献祭。大部分散户本质上是为主力献祭而来的。要在市场中赚到钱，就不能有散户思维，必须站在主力的角度思考——这就是"主力思维"。

3. 主力行为的量价表现：高量、倍量、批量的博弈战场

每一根成交量柱上必然同时存在买入和卖出双方。重点不是谁在买谁在卖，而是要判断主力是在买入还是卖出——这是我们要时刻关注的焦点。出自第3节第4段

  • 每一根高倍量柱都意味着主力来了，主力的行为必然通过高量、倍量、批量等异常成交体现出来。
  • 关注主力动向、透视主力意图、把握主力意图——这才是博弈原理的核心三步。

4. 主力意图的透视方法：透过次日的量价行为推演

核心理念：永远要紧跟主力思维，跟着主力行为，站在主力那一面去吃肉，而不是成为主力的鱼肉。出自第3节第5-6段

实战推演法则：

  • 如果主力在买入，我们应该积极跟随；
  • 如果主力在卖出，我们应该同时卖出；
  • 任何一只股票不断上涨，一定是有阻力（主力）在支撑。

关键推演技巧——"次日透视法"：

  • 当天放巨量，你不知道主力是买是卖；
  • 但第二天你就可以通过量价行为反推：
  • 若第二天"价涨量缩"，说明主力在控盘、吸收了昨日的卖盘 → 昨日主力在买入；
  • 若第二天快速上榜（缩量上涨），说明昨日大量被主力吸收 → 主力在买；
  • 若第二天破位下跌、价跌量增 → 说明昨日主力在出货。

分歧转移机制：每一根巨量的本质都是巨大的分歧——有人下车、有人上车。只有把对方的货吃完后，才会有更大的力量去上涨。所谓"换手"，就是你的筹码全部给了我，我拿到筹码后才有意愿去拉高价格获利。没有拿到货就拉升是"白拉"，所以每一次放巨量的行为都是重点要关注的。

重要提示：很多时候放巨量往往是主力出货的行为。但如果不是出货，反而第二天价涨量缩，就是一个绝佳买入机会——这就是博弈原理中的"分歧转一致"。

5. 散户的致命错误：抢在主力之前抄底

错误的散户思维：

  • 在下跌趋势中喜欢抄底是非常不明智的行为；
  • 下跌中一直是空方力量强，你怎么知道绝对到底了？
  • 在主力没有入场之前是没有底的；
  • 前面所有的抄底行为都是"无知者无畏"的愚蠢行为。出自第3节第7-8段

正确的跟随思维：

  • 主力进场后才有多方力量进场；
  • 应该买在主力调整时的"极点"位置；
  • 应该盯着城堡（主力建仓区）、大洋高倍量（主力入场标志）；
  • 主力没有入场之前，不要提前去抄底。

主力主导论：只有主力才能主导价格——价格的涨跌是主力（资金大）才能控制的。作为小散，唯一的选择就是做主力的跟随者。

6. 主力的四个动作：吸洗拉出

主力行为的核心四步：出自第3节第9段

  1. 吸货：主力来了（识别入场信号）；
  2. 洗盘：主力没走（识别洗盘信号）；
  3. 拉升：洗到极致（极点），空点出现，跟随咬住不放；
  4. 出货：主力开始出货（识别出货信号）。

所有交易行为和思想的根本目的：做好主力的跟随者。

7. 跟随者哲学：聪明的散户"银鲨"

角色定位：

  • 等资金大了（百亿千亿）后，你才可以做主力；
  • 在没有能力做主力之前，我们只做一个主力跟随者；
  • 这个定位至关重要。出自第3节第10段

银鲨比喻：

  • 主力是鲨鱼（大主力）；
  • "银鲨"就是聪明的散户；
  • 实时跟着鲨鱼，不偷吃，不愁穿——做一个坚定无比的跟随者。

📊 关键判定标准

主力行为次日量价表现判断应对

主力出货次日破位下跌，价跌量增分歧未能转一致同时卖出/离场

第4节 · 六柱霸天下之首

第4节 · 高量识主力

一句话核心结论：高量是高潮柱 = 发烧柱，70%-80% 后市常态看跌。只有被确认为主力入场的变态高量才有价值，通过极点 / 控点 / 转点三大确认方式构成完整买点体系。

📌 核心知识点

1. 六柱霸天下：高量是六大亮柱之首

课程提出"六柱霸天下"体系，六大亮柱分别为：高、低、平、倍、低、缩（高量、低量、平量、倍量、缩量）。本节聚焦其中的高量柱。出自第4节第1段

2. 高量之形：姚明柱——最显眼的最高量

形态定义：高量柱就是一组量柱当中最显眼、最高的那根量。形象比喻为"姚明柱"——人群一眼就能看出最高的那位。出自第4节第2段

  • 相对突出：在量柱群中明显高于其他；
  • 视觉识别：一目了然；
  • 异常放量：必然伴随着异常的市场行为。

3. 高量之魂：高量=高潮柱=发烧柱

三大别称：

  • 高潮柱：因为它是市场情绪的高潮；
  • 发烧柱：因为它"体温过高"了，物极必反。出自第4节第3段

物极必反原则：

  • 高潮之后必然退潮；
  • 高亮（高量）的后市常态是看跌——70%-80% 的时间大概率是下跌；
  • 变态看涨（少数情况不跌反涨）才是我们重点要关注的。

这就是"价值"高量的来源：一般的高量都是没价值的（常态看跌），只有变态高量（不跌反涨）才有价值，才是我们要捕捉的。

4. 高量的供需解读：买盘与卖盘同时大增

根据供需原理：市场出现高量表示有人大量在买，也表示供应与需求同时大增。出现巨大量，必然是有人大量在买，同时有人大量在卖。出自第4节第4段

博弈原理的关键追问：主力到底在买还是在卖？

  • 高量必然是主力行为（毫无疑问）；
  • 但重点是判断主力是买还是卖——这需要后续确认。

5. 高价值的变态高量：被确认为主力入场的高量

核心结论：被确认为主力入场的高量才是高价值的高量。如果是主力在跑（出货）的高量，那是没有价值的。出自第4节第5段

确认方式有三种——这三种刚好把最经典的三大买点（极点、控点、转点）全部含在里面：

  1. 高量的控点；
  2. 高量的极点；
  3. 高量的转点。

核心思维：在高量上寻找买点，是整个交易当中最核心的思维。因为高量代表着市场产生了巨大分歧，而机会往往产生于分歧当中——"分歧当中往往有巨大的机会"。

6. 确认方式一：高量的极点

定义：高量后市极点 = 回踩顶底腰区 = 极点的位置。出自第4节第6段

案例解读：

  • A柱：高量柱（近期最高亮）；
  • 调整后到 B柱和 C柱：明显的极点（停止柱形态）；
  • D柱：确认柱出现；
  • 后续稍微上涨到 E柱，又出现高量柱；
  • F柱：刚好在 A柱的跳空缺口地方停止（又一个底）；
  • G柱（基柱）：进行确认，后面继续上涨。

判断方法：

  • 透过极点发现这一天高量主力是买还是卖；
  • 如果这两天主力在买 → 后续应该持续价格创新高；
  • 如果这两天主力在卖 → 后续应该破底、继续下跌。

第二个案例：A柱高量 → B柱和 C柱明显是停止柱（进攻型）→ 后续连续上涨 → D柱又是个高量 → 后面连续调整几天都是停止柱 → H柱进行确认 → 后面连续打板。

结论：高量上出现的极点就是重要的买入信号。透过极点对高量进行确认，代表主力是买入行为而不是卖出行为。

7. 确认方式二：高量的控点

高量控点的两个变体：出自第4节第7段

  1. 次日控点：高量次日 + 冷量（缩量） = 价涨量缩；
  2. 跨日控点：高量后隔几日（跨日）+ 价格过顶 = 价涨量缩。

跨日控点案例：

  • 高量柱 A；
  • 中间隔了 1、2、3、4天到 H柱；
  • H柱过了高量的顶，形成价涨量缩——这就是跨日控点；
  • 实际上也是极点控点（先出极点，再出控点）；
  • 跨日控点 = 价涨量缩，后面连续大涨。

次日控点案例：

  • 高亮 H柱（高量）；
  • 第二天是一个价涨量缩的控点；
  • "价涨量缩，一次看多"；
  • 进一步说："价涨量缩，控盘本质是控盘"；
  • 第二天又涨停，这就是"高量的次日价格连锁"。

天龙股份案例：A柱：高量 → B柱：过 A柱的顶，价涨量缩（跨日价涨量缩）→ C柱：价涨量缩（次日控盘做多）→ 后面连续上涨，跨日紧跟次日。

8. 确认方式三：高量的转点

高量转点的本质：分歧转一致。出自第4节第8段

核心理念：所有的高亮本质都是分歧的（有卖就有买）。高亮之后如果能转为一致（次日快速上涨），就是转点。

烂板转点案例：

  • C柱高亮烂板（高量后烂板）；
  • 第二天直接一字板（价涨量缩）；
  • E柱高亮烂板，第二天价涨量缩涨停；
  • 这一天也是高量板，第二天价涨量涨停。

结论：每一次高亮之后放巨量的高量烂板，第二天如果能够价涨量缩快速上涨，都是买点——这就是分歧转一致的转点。

📊 关键判定标准

高量的三大买点体系：

确认方式核心特征买点属性
高量极点高量后回踩顶底腰区形成停止柱主力入场确认买点
高量控点高量次日或跨日价涨量缩控盘确认买点
高量转点高量烂板次日价涨量缩快速上涨分歧转一致买点

高量判定的黄金法则：

情况后市判断操作

方法论："价涨量缩，一次看多" → 进一步 "价涨量缩，控盘本质是控盘"。
案例 3：高量转点——烂板转点案例（出自第4节第8段）
C柱高亮烂板（高量后烂板）→ 第二天直接一字板（价涨量缩）→ E柱高亮烂板，第二天价涨量缩涨停；这一天也是高量板，第二天价涨量涨停。
结论：每一次高亮之后放巨量的高量烂板，第二天如果能够价涨量缩快速上涨，都是买点——这就是分歧转一致的转点。

💡 系统性总结

本节要点：
1. 高量的本质：高潮柱/发烧柱，70%-80% 后市看跌（常态），20%-30% 变态看涨（价值点）。
2. 高量价值的来源：不在于高量本身，而在于次日被确认为主力入场。所有高量分析的核心都是围绕"主力到底在买还是在卖"展开。
3. 三大确认方式构成完整买点体系：极点 → 主力洗盘结束，重新拉升；控点 → 主力控盘，价涨量缩；转点 → 分歧转一致，快速上涨。
4. 核心理念——机会在分歧中产生：高量代表巨大分歧，分歧中往往蕴含巨大机会。
底层逻辑：在高量上寻找买点，是整个交易当中最核心的思维。因为高量代表着市场产生了巨大分歧，而机会往往产生于分歧当中。

第5节 · 六柱霸天下之二

第5节 · 低量识主力

一句话核心结论：低量是停止柱 / 见底柱，是主力唯一无法控制的量柱。低量的超级密码 = 缩量 1/2，黄金搭档 = 低量 + 十字星 = 极点——终极买点。

📌 核心知识点

1. 低量之形：潘长江柱——最低的量

形态定义：低量就是在一群量柱当中，一眼看过去最低的那个量。形象比喻为"潘长江"——姚明（高量）对应的矮个儿。视觉上一眼就能看出的最矮最低的量。出自第5节第1段

三大别称：

  • 低量（基础称呼）；
  • 停止柱（行为意义：买盘停止）；
  • 见底柱（位置意义：底部的标志）。

2. 低量之魂：买卖双方都暂停的冰点

根据供需原理：市场出现低量表示市场供应与需求同时进入了冰点——买方也不愿意加大买入（意思一下），卖方也不愿意卖出（撤退）。出自第5节第2段

主力参与的判断：

  • 此时散户可能主力根本就没有动；
  • 纯粹是散户在里面动；
  • 主力没有参与的情况下，量一定是非常低的；
  • 主力唯一无法控制的就是低量——这是一个重要的反常识结论。

重要原则：主力为高量是主力行为，倍量是主力行为，但低量一定是主力没有参与的行为——买方暂停买入，卖方暂停卖出，本质就是主力没有参与。

3. 低量的博弈解读：主力取得绝对优势后的刻意洗盘

根据博弈原理：低量代表主力取得绝对优势后的刻意洗盘——通过清理浮筹、供应衰竭来形成低量。出自第5节第3段

低量的位置价值——主力底线：

  • 低量是主力的底线；
  • 出现在城堡（主力建仓区）的底线附近或顶线附近；
  • 是主力的攻防线——既是底线也是防线；
  • 是市场的平衡点——平衡是暂时的，打破是必然的；
  • 低量低价就是市场的平衡点。

4. 高价值的低量：必须依托高倍量

核心结论：并不是所有的低量都有价值——低量到处都有。但高价值的低量必须是确认高倍量的低量。出自第5节第4段

含义：只有在依托于高倍量之后的低量才是高价值的。即：先有高量/倍量（主力进来），然后调整时出现低量（主力没走）——这种低量才有价值。

低量+十字星=黄金搭档：

  • 第一辆（低量）+ 十字星 = 极点；
  • 这是低量的核心黄金搭档。

5. 低量的超级密码：缩量1/2原则

缩量标准：出自第5节第5段

  • 低量依托倍量和高量来讲的话，要缩量2分之1；
  • 这是低量的超级密码；
  • 有时缩量 3分之1，但很少用，主要以 2分之1 为主；
  • 一定要记住以 2分之1 为主。

实战应用：

  • 一旦倍量或高量之后出现缩量；
  • 缩到 2分之1 的地方；
  • 同时发现有个实心（十字星或小实体）；
  • 基本上调整到位，准备反攻。

6. 低量的两种买点

买点一：在起点上进行潜伏出自第5节第6段

  • 最好在完美极点去潜伏；
  • 优点：成本更低；
  • 风险：确定性稍弱。

买点二：等确认柱潜伏

  • 等确认住（确认柱出现）后再买入；
  • 优点：确定性比较强，没有浪费时间；
  • 缺点：可能会浪费一些空间，利润较低。

两者各有优势：潜伏成本低、确定性弱；确认确定性高、利润少。实战中可灵活组合。

低量判定黄金法则：

判定维度阈值/标准含义
缩量幅度缩量 1/2（以 2分之1 为主）缩量1/3较少用
形态搭配低量 + 十字星 = 黄金搭档即"极价极量" = 极点
前置条件必须依托高倍量才有价值（高量/倍量=主力进来）

低量买点对照：

买点位置优点缺点

案例 1：黄金搭档买点（出自第5节第7段）
案例走势：高亮 A 出现开始回调；回调时形成"虚底"（以涨停板为支撑柱）；A柱明显是低量+黄金大极价（极量）；第二天来涨停板；B柱涨停后又连续调整三天；C柱出现极量极价的停止柱；第二天经确认，后面连续上涨。
关键原则：第一量（低量）往往要跟极点做搭档（黄金搭档）；即价即量（极低价极低量）；一定要依托倍量或高量。
案例 2：依托倍量的极点买点（出自第5节第8段）
案例走势：A柱是倍量柱（高潮柱、高量柱）→ B柱回调后刚好达到 A柱支撑柱的底线；B柱 = 极价 + 极量 = 极点确认 → C柱出现高量柱（膏梁柱）→ D柱进行低量+十字星混搭确认 → 后面大涨。
关键发现：B柱买点优于 C柱买点；这两个低量实际上拖住了主力下跌的行为；形成"下跌中的价涨量缩的控点"；第二个极点的量比第一个极点量更低，但价格更高 → 这是极点控点；后面连续大涨。
案例 3：多组低量的终极买点（出自第5节第9段）
案例特征：F柱、D柱、B柱都是低量；每一根低量前面依托的都是高量或倍量；形成主力来了 → 主力没走 → 主力没走的循环；形成黄金搭档：低量+十字星=停止住；下跌停止住之后一旦确认就是买点。
终极秘籍：低量的终极买点 = 极点。极点的本质是：① 依托高倍量主力行为；② 最后调整的停止行为；③ 一旦确认就是精准买点；④ 潜伏也没问题。
买点策略：好的点（极点）→ 漂亮节点 → 标准节点 → 都可以赚钱；但一定要在上升途中趋势当中。

本节要点：
1. 低量的本质：停止柱、见底柱，是主力无法控制的唯一量柱，是买卖双方都暂停的冰点。
2. 低量价值的来源：不在低量本身，而在它是否依托高倍量。只有"高倍量 + 低量"组合才有价值。
3. 低量的超级密码：缩量 1/2 是标准，低量+十字星是黄金搭档。
4. 低量的两个买点：潜伏买点（成本低、确定性弱）；确认买点（确定性高、利润少）。
5. 低量的终极秘籍：极点 = 依托高倍量的停止行为 + 确认买点。
实战意义：低量的独特价值在于它代表着主力无法控制的"市场真实状态"——是市场情绪的冰点。当低量出现在高倍量之后，意味着主力虽然暂停了主动买入（缩量1/2），但并未离场（依托前高量支撑），这构成了绝佳的买点。

第6节 · 六柱霸天下之三

第6节 · 平量识主力

一句话核心结论：平量的本质 = 价涨量平 = 价涨量缩 = 控盘做多。低位平量=机会（主力低位吸筹后的控盘）；高位平量=分化（出货信号）。买点 = 尾盘买点 + 次日买点。

📌 核心知识点

1. 平量之形：两种平量形态

平量的两种基本形态：出自第6节第1段

  1. 并肩平量：
    • 形态：两根量柱并肩而立，量能相等；
    • 又叫"兄弟一样高"；
    • 今天跟昨天对比，两人一样高，称之为平量。
  2. 凹口平量：
    • 形态：左边站着一根量，右边站着一根量，中间两根量是平的；
    • 是在"凹口"当中的平量。

其他变体：

  • 凹口的这种也是平量；
  • 两个平量当中这个平量柱，又称之为确认柱或叙事柱——它在凹口中起到承上启下的作用。

2. 平量之魂：主力控盘的暂时平衡点

根据博弈原理：平量是主力控盘的信号，是买卖双方暂时的平衡点。出自第6节第2段

平量为何代表控盘？

  • 今天量跟昨天量一样多；
  • 但今天涨得更高（价涨量平）；
  • 按照正常道理，价格越高应该卖的人多才对；
  • 现在价格高了，但卖的人少了 → 说明主力不愿意卖，吸收了（控盘）。

平量的本质属性：平量是买卖双方暂时的平衡点。平衡是暂时的，它后面必然会打破——要么继续上涨，要么调整。

3. 高价值的平量：并肩与凹口的辨析

高价值平量的两种形态：出自第6节第3段

  1. 并肩平量；
  2. 凹口平量（中间套平量）。

凹口双平量：

  • 外面两个量是平量，里面两个量也是平量；
  • 平量当中套平量；
  • 凹口双平的本质 = 倍量 + 低量 + 平量 + 倍量 = 倍量 + 低量 + 倍量（缩写）；
  • 这是平量形态的高级组合。

4. 并肩平量的价值：取决于前一根量柱的身份

核心理念：并肩平量的前一根量柱的身份决定了这一组平量的价值。出自第6节第4段

机制：

  • 今天的量跟昨天量平（并肩）；
  • 如果昨天的量是"价涨量增"（主力来了）；
  • 今天"价涨量平"依然是控盘（吸收）；
  • 这就是对昨天"价涨量增"的加强与确认；
  • 再次确认昨天的"价涨量增"是主力行为。

结论：并肩平量的两根平量柱中，前一根量柱的身份决定了这一组平量的价值。

5. 不同位置的平量价值

低位平量 = 机会：出自第6节第5段

  • 在低位的平量（比如两个十字星小实体）；
  • 第二个实心比第一个实心价格更高；
  • 量是平的（缩量）；
  • 本质上是价涨量缩；
  • 这是机会，第一位的价涨量缩往往后面要转势。

增量平量 = 机会：

  • 价涨量增 + 平量 + 价涨量增 = 价平量增；
  • 价平量增等于价涨量缩（还在涨）；
  • 所以增量加平量 = 增量，这是机会；
  • 被量（倍量）低位的倍量平量也是机会。

高位平量 = 风险：

  • 高量平量（高位高亮加平量）；
  • 对于双高量来说，等于分化（出货信号）；
  • 高位平量往往是见顶信号。

核心原则：平量的价值取决于位置——低位是机会，高位是分化。

📊 关键判定标准

平量判定矩阵：

位置平量形态含义应对
低位十字星小实体 + 价涨量平控盘做多（机会）介入
增量价涨量增 + 平量 + 价涨量增等于价涨量缩（机会）介入
高位双高量 + 平量分化（出货信号）见顶信号，离场

平量本质公式：

公式含义
价涨量平 = 价涨量缩 = 控盘做多主力控盘的本质公式
"价涨量缩，一次看多" → "价涨量缩，控盘本质是控盘"理念升级（一阶 → 高阶）

🔍 典型案例

案例 1：连续平量的控盘走势（出自第6节第6段）
案例特征：A、B、C三天基本都是平量（差一点点都可以当成平量）；价格是价涨的；量是平的（价涨量平）；价涨量平等于价涨量缩（控盘）；后面 B 到 1 的四天又是一个平量，但价格微微在涨；价涨量平 = 价涨量缩（继续涨）；F跟 G又是个平量（隔了一天的平量）；隔日平本质上也是个价涨量平，等于价涨量缩。
走势结果：平量之后主力玩平台玩得非常溜，后面一路连续三个涨停板。
案例 2：凹口双平量的主力控盘（出自第6节第7段）
形态分析：A跟 B是个平量；中间两个也是平量（平量当中套平量）；B跟 C又是个平量；相当于三组平量；接近的两天可以当成接近平（也是缩一点点）。
控盘逻辑：B：价涨量平 = 价涨量缩 → 继续涨；C跟 B：价涨量平 = 价涨量缩 → 继续涨；后两天：价涨量缩 = 价涨量平 → 做多（控盘）；主力玩平台玩得非常溜 → 后面连续三个涨停板。
凹口双平的本质：对低量的确认 + 对最近高量的确认；高量又确认低量；形成"低量↔高量"的相互确认机制。
案例 3：平量+极点的综合买点（出自第6节第8段）
走势分析：A跟 B是个平量，价格上涨量是平的；价涨量平 = 价涨量缩 → 后面要涨；后面调整了一下（调整后没破底线）；B相当于是个高量；出现极点（C、D两天）；D柱是确认柱；C跟 D实际上又是个平量（价涨量平 = 价涨量缩）；后面加档量增、加档量缩一路把价格抬高。
核心发现：本质上只有两种模式：C跟 D、A跟 B。后面一路平量，很容易出现大牛。

本节要点：
1. 平量的两种形态：并肩平量（两根并列）与凹口平量（中间套平量，凹口双平是高级形态）。
2. 平量的本质：价涨量平 = 价涨量缩 = 控盘做多。这是对"价涨量缩"理念的高阶升级。
3. 平量价值的来源：并肩平量取决于前一根量柱的身份（低位+增量=机会，高位=分化）；凹口双平对低量的确认 + 对最近高量的确认，形成相互验证。
4. 平量的位置哲学：低位平量 = 机会（主力低位吸筹后的控盘信号）；高位平量 = 分化（出货信号）。
5. 平量的买点：尾盘买入（平量当日尾盘或控点尾盘）+ 第二天开盘也是买点。
实战意义：平量识主力是六柱体系中的"控盘识别"环节。平量的独特价值在于它揭示了主力控盘的"稳定状态"——买卖双方暂时平衡，主力通过吸收卖盘维持价格稳定。当平量出现在低位（主力建仓后）或与极点结合时，往往预示着后续的拉升行情。

第7节 · 六柱霸天下之四

第7节 · 倍量识主力

一句话核心结论：倍量 = 建仓柱 + 进攻柱，是主力行为最明确的标志。通过极点（缩量回踩顶底腰区）+ 控点（次日价涨量缩）双重确认，缩量 1/2 是最完美的确认。倍量+缩量交替是抓连板股的利器。

📌 核心知识点

1. 倍量之形：今天的量是昨天的一倍以上

形态定义：倍量就是今天的量是昨天的一倍以上（>100%）。出自第7节第1段

变体：

  • 小倍量：今天的量只是比昨天稍微高一点点，没有到达一倍；
  • 也称为"变异的倍量"；
  • 正常的倍量是大于昨天的一倍以上。

2. 倍量之魂：建仓柱=进攻柱

三大别称：出自第7节第2段

  1. 倍量柱（基础称呼）；
  2. 建仓柱（主力明显进来的标志）；
  3. 进攻柱（主力的进攻行为）。

3. 倍量的供需解读：供应与需求同时增加

根据供需原理：市场出现倍量表示供应与需求同时增加——因为有人买就有人卖。出现倍量就一定是有人比昨天加倍在买入（也有人加倍在卖出）。出自第7节第3段

主力行为的判断：

  • 上涨的情况下，加价再买时，主力买入的动作会比较明显；
  • 但到底是买还是卖？仍然需要后续确认。

核心理念：倍量必然是主力行为，但到底是买还是卖，要根据博弈原理通过后续确认来判断。

4. 高价值的倍量：被确认为主力入场的倍量

核心结论：被确认为主力入场的倍量才是高价值的倍量。我们要判断这个倍量是主力进场了，而不是主力退出了。出自第7节第4段

确认方式两种：

  1. 倍量的极点；
  2. 倍量的控点。

两大买点：极点（缩量回踩倍量的顶底腰区）+ 控点（次日价涨量缩）。

5. 倍量的控点：连板牛股的核心信号

定义：倍量控点 = 次日价涨量缩 = 倍量的控点。出自第7节第7段

  • 特别适用：在连板的牛股当中，倍量控点尤其明显。
  • 本质：还是分歧转一致。

案例分析：

  • B柱：倍量柱（也是高量柱）；
  • 分歧之后转 C柱一致；
  • C柱缩量（缩 1/2 以上）+ 价涨量缩；
  • 这就是缩量确认行为，确认昨天的倍量柱是主力进场信号；
  • E柱也是倍量柱；
  • F柱是缩量行为（价涨量缩）；
  • F柱确认 E柱是进场信号；
  • 这两天的平量后面确认了这两个倍量的平量属于主力入场行为。

通用规则：所有倍量柱，只要第二天来一个价涨量缩（缩量 1/2 是最完美的），就可以确认为昨天的倍量柱是主力的入场行为。

6. 倍量与高量交替的连板买点

走势分析：A柱：倍量柱 → B柱：缩量柱 → C柱：倍量柱 → B柱：缩量柱 → E柱：倍量柱 → F柱：缩量柱。出自第7节第8段

规律总结：每一次高亮或倍量之后，第二天进行缩量的确认，都是入场的信号。

实战意义：这种规律往往是抓连板股的利器——用控点抓连板股是最理想的。

第8节 · 六柱霸天下之五

第8节 · 梯量识主力

一句话核心结论：梯量 = 连续三根以上量柱递增，本质属于高量形态（尽头即高量）。高位梯量 = 诱多；低位梯量 = 主力抢筹。确认路径：极点（回踩底/腰）+ 控点（价涨量缩），尤其是缩量涨停是主升浪启动信号。

📌 核心知识点

1. 梯量的定义与基本形态

"梯量"是指成交量连续三根或三根以上递增，通常以连续三根为基本识别单位：第二根量柱高于第一根，第三根高于第二根，形似逐级上楼的阶梯。原文也将其称为"T量"（原文中的"踢量"统一修正为"T量/梯量"）。连续三根上涨量柱构成梯量后，最后一根通常会成为这一组量柱中的最高量，因此梯量的尽头本质上就是高量。出自第8节第3、6段

位置判断：梯量不能脱离股价位置判断：

  • 高位出现的梯量，多数是诱多柱，后市常态看跌；
  • 低位出现的梯量，则可能是主力连续抢筹的表现。
  • 也就是说，梯量多数情况下会导致调整，少数情况下才会继续上涨，而这类少数的"变态看涨"形态正是需要重点研究和确认的对象。

2. 梯量背后的供需与博弈逻辑

供需原理：从供需原理看，梯量意味着供应和需求都在连续增加：买方力量逐步加大，卖方力量也逐步加大。双方的量能都在快速消耗，容易形成"物极必反"。仅凭梯量本身，无法直接判断最终是多/空方力量耗尽，必须等待后续价格与成交量确认。出自第8节第4段

博弈原理：从博弈原理看，散户通常难以连续数日组织同方向、递进式的进攻，因此梯量必然包含主力参与，是一种主力行为。但梯量中的主力究竟是在连续买入、抢筹，还是借放量连续卖出、诱导跟风，仍然不能只靠量柱下结论，必须结合后续走势确认。出自第8节第5段

3. 梯量的价值判断

梯量的本质与高量相同，因为连续递增的量柱最终必然落到一根高量柱上。因此，梯量出现后应沿用高量的判断框架：多数情况下常态看跌，少数情况下出现强势延续。真正有价值的梯量，不是"看见梯量就买"，而是后续确认其代表主力入场。若确认主力是在退出、卖出，那么该梯量没有跟随价值，反而应当成为卖出或回避信号。出自第8节第6、7段

4. 梯量后的两个核心确认点

梯量的训练和实战确认，核心可归纳为两个位置：极点和控点。出自第8节第8段

梯量出现后，股价通常会缩量回踩这组梯量的"底"或"腰"：

  • 底：梯量起始柱的虚拟支撑位置；
  • 腰：梯量区间中的关键中位。

回踩不破底或腰，随后出现确认，说明主力并未放弃筹码，梯量可能由诱多形态转化为主力进场、洗盘后的上涨起点。

5. 梯量中的控点：价涨量缩

梯量控点的典型形态：梯量之后出现价涨量缩。出自第8节第11、12段

  • 正常情况下，连续三日递增的梯量大概率会转跌；
  • 如果不跌反而在次日或随后出现价涨量缩，则说明前面的梯量更可能是主力抢筹。

案例：连续三日梯量之后，B柱出现缩量快速涨停板，表明此前连续三天是主力连续买入，随后进入强势上涨。

腾达科技案例：股价连续四天梯量，梯量结束后在 B柱出现缩量确认。原本按常态应当调整，但实际出现价涨量缩，随后股价继续大涨，甚至翻倍再翻倍。梯量中的价涨量缩控点，在牛市、强势市场和龙头股中尤其重要，可作为识别抢筹与主升浪启动的绝佳节点。出自第8节第13段

梯量判定矩阵：

维度判定应对
形态定义连续三根以上量柱递增（最后=高量）识别为梯量
高位梯量诱多柱 / 阶段性见顶警惕 / 回避
低位梯量主力连续抢筹需后续确认

核心口诀：梯量本身只说明主力参与，不直接等于买点；"梯量+底/腰确认"偏极点逻辑，"梯量+价涨量缩"偏控点逻辑，最终目标是确认主力入场而不是跟随主力出货。

🔍 典型案例

案例 1：梯量底部的极点确认（出自第8节第9段）
案例中 A、B、C 三根量柱构成连续三日梯量，C 为该组梯量的最后一根高量柱。其后股价连续调整四天，在第三、第四天出现极价、极量，实际踩到的是梯量的虚拟底部，并在该位置完成确认，随后反弹上涨。之后又出现一组新的梯量（从 C 到 D），回踩时间更长，但最终回到该组梯量的起始柱 C 所对应的虚拟底部，在 E柱附近形成恐吓柱：当天价跌量增，表面像要跌破支撑；随后立即反包，证明前一日属于假跌，并引发后续大涨。
案例结论：梯量后的回踩可能测试梯量最高量柱的底，也可能测试整个梯量区间的底。只要关键底部没有被有效跌破，并且出现极点、反包等确认动作，就说明主力仍在场，前期梯量更可能是进场、洗盘，而不是彻底出货。
案例 2：梯量后的控盘做多（出自第8节第10段）
另一案例中，A柱之前出现梯量，随后 B柱附近发生调整，并确认出"即价即量"（语义修正为价格与量能同步确认的关键节点）。确认后又出现连续三根递增量柱，随后量柱降低，但股价仍上涨，形成"价涨量缩"。价涨量缩代表主力控盘做多，说明上涨并不依赖持续放量，主力能够用较少成交量推动价格，之后股价连续上涨十天。
案例结论：梯量的确认既可以通过回踩极点完成，也可以通过后续控点完成。二者的共同核心都是：梯量之后没有按常态转跌，而是出现支撑确认或价涨量缩，证明量柱递增区间中的主力行为偏向吸筹、抢筹或控盘，而非单纯出货。
案例 3：腾达科技——梯量后的价涨量缩（出自第8节第13段）
腾达科技案例中，股价连续四天梯量，梯量结束后在 B柱出现缩量确认。原本按常态应当调整，但实际出现价涨量缩，随后股价继续大涨，甚至翻倍再翻倍。
规律：梯量中的价涨量缩控点，在牛市、强势市场和龙头股中尤其重要，可作为识别抢筹与主升浪启动的绝佳节点。

第9节 · 六柱霸天下之末

第9节 · 缩量识主力

一句话核心结论：缩量 = 量柱连续递减。价涨量缩 = 控盘做多（控盘柱）；价跌量缩 = 退潮/供应衰竭（洗盘或自由下跌）。买点分极点路径（双阴/连续阴线缩量+反包）与控点路径（连阳/一日价涨量缩）。

📌 核心知识点

1. 缩量的定义与分类

缩量是指成交量一天比一天低，量柱连续递减。缩量既可能发生在上涨过程中，也可能发生在下跌过程中，因此要分别观察"价涨量缩"和"价跌量缩"。出自第9节第3段

  • 价涨量缩的量柱称为控盘柱，表示主力控盘做多；
  • 价跌量缩的量柱属于退潮或供应衰竭形态，需要进一步判断是出货后的自由下跌，还是主力吸筹后的洗盘。

2. 缩量的供需与主力意图

价涨量缩表示价格继续上涨，但成交量不再同步放大，通常说明流通筹码减少、主力控盘程度较高，主力能够用较小成交量推动股价上行。出自第9节第4段

价跌量缩则表示供应持续衰竭，卖方力量越来越弱，量能不断降低，直到出现低量，之后可能因供给耗尽而发生"物极必反"，形成反弹或反转机会。

价跌量缩的两种来源：出自第9节第5段

  • 第一种：主力前期已经出货完毕，股价失去承接后自由下跌，甚至可能跌跌不休，这种情况基本没有买点。
  • 第二种：主力前期已经吸筹，随后有意洗盘、清理浮筹，缩量下跌是洗盘过程；这种情况在低量、极点或其他确认信号出现后，可能形成买点。
  • 不能把所有缩量下跌都当作底部，也不能把所有低量都直接当成买入信号。

3. 缩量的本质与高价值条件

缩量的本质是低量：连续缩量的最后一根量柱必然属于低量，所以缩量的本质是低量。这个逻辑与"低量的本质是高量"相反：低量形态需要看其之前或之后的高量背景，缩量形态则要重点观察它最终确认了哪一根高量或倍量。出自第9节第6段

高价值缩量的判定：高价值缩量不是单独出现的缩量，而是确认倍量、高量、梯量，或确认这些量柱的顶、底、腰、缺口位置的缩量。由于梯量的本质也是高量，缩量确认梯量同样属于有效的高价值信号。换言之，缩量的价值来自它所确认的主力行为，而不是来自"量越来越小"本身。

4. 缩量的买点：极点逻辑

缩量买点可以分为起点和控点两大类。出自第9节第7段

双阴极点：连续阴线缩量时，常见的是两根阴线构成的"双阴极点"，也可以出现连续多根阴线的变异极点。案例中 B、C、D 连续三天缩量，B为高潮量柱，C、D为恐吓柱；其中两根阴线持续缩量，随后股价大涨，形成双阴极点（原文"节点"统一按语义修正为"极点"）。

连续三天缩量的完美极点：出自第9节第8段

  • 无论是缩量两天还是缩量三天，核心都不是机械计算天数，而是观察缩量之后是否出现极点确认：
  • 价格是否在重要支撑处止跌，是否出现反包、转强或其他能够证明供应衰竭的动作；
  • 确认成功后，缩量下跌才可能从退潮转化为洗盘后的买点。

5. 缩量的买点：控点逻辑

缩量控点包括连阳控点、一日控点等。出自第9节第8段

  • 连阳控点是连续上涨、同时量能逐日缩小，说明价格在上行，抛压却没有同步增加，主力处于高度控盘状态。

案例 1：F、G、H 连续三天价涨量缩，且前面有一根高量柱作为背景；高量之后仍能连续三天价涨量缩，说明主力高度控盘。出自第9节第9段

案例 2：A柱是高量柱，之后连续三天价涨量缩，股价因此能够持续大涨。这里的缩量不是弱势，而是主力控盘的外在呈现：筹码锁定后，市场卖压很小，少量资金即可推动价格。

第10节 · 第七柱主力识别

第10节 · 大阴识主力

一句话核心结论：大阴（跌幅≥5%）按量能分为缩量大阴与巨量大阴。缩量大阴 = 主力假跌，支撑位出现阳盖阴即买点；巨量大阴高位是出货、低位是洗盘，关键确认信号是缩量过巨量大阴顶（巨阴控点）。（出自第10节）

📌 核心知识点

1. 大阴的定义与两种分类

大阴定义：K线跌幅超过5%，甚至出现跌停的阴线，称为大阴线。出自第10节第3段

两种分类：按成交量相对前一日或近期量能的变化，大阴分为缩量大阴与放量（巨量）大阴。

缩量的判定：缩量是相对概念——若当天跌幅明显扩大，但成交量与前一日相比没有同步放大、甚至反而缩小，就是缩量大阴。原文强调不能孤立看绝对值，必须看相对变化。出自第10节第3、4段

2. 缩量大阴的本质：主力假跌与买点

本质：缩量大阴的本质是主力借助大盘走弱或市场恐慌环境，刻意打压股价，清洗不坚定筹码。由于价格跌幅很大但成交量没有相应放大，说明主力并未进行真实的大规模出货，更接近"假跌"或"缩量假跌"。出自第10节第5、6段

供需与博弈解读：

  • 供需角度：大阴线表面说明供应超过需求；
  • 博弈角度：大阴通常有主力参与，但缩量意味着主力更可能是制造恐慌、洗盘，而非真正撤退；
  • 假跌意图：通过制造恐慌让散户在低位交出廉价筹码。

3. 缩量大阴的买点：阳盖阴/反包

典型买点：缩量大阴出现后，随后阳线将前一根大阴线实体或关键区域完全收复，说明假跌被识破、空方打压失败，这即是"阳盖阴"或"阳线反包"。出自第10节第6、7段

位置加分：当缩量大阴恰好位于前期低点、支撑位附近时，反包确认的可靠性更高，可以直接视为买点。

案例验证：

  • 案例一（B柱）：B柱跌幅较大，但成交量并未明显放大，属于相对缩量大阴；位置靠近前期低点和支撑位；随后出现阳盖阴，形成买点。
  • 案例二：某一柱相较前面的小阴小阳跌幅显著扩大，但量能仍然缩小，说明是假跌；第二天反包时即可形成买点。出自第10节第7、8段

原文结论：相对缩量大阴只要出现有效反包，往往就是值得关注的买点。

4. 巨量大阴：风险与机会并存

定义：巨量大阴是"价跌量增"的大阴线。从供需角度，说明供应远大于需求；从博弈角度，巨量意味着大量卖出与大量承接同时发生。出自第10节第9段

核心问题：谁在买、谁在卖：

  • 关键不是"有没有人买"，而是确认谁在买、谁在卖；
  • 若主力借巨量大阴出货，后市风险很大；
  • 若主力在低位巨量大阴中偷偷吸收筹码、刻意洗盘，则后续重新转强时可能形成买点；
  • 因此需要等待价格和成交量的再次确认。

5. 巨量大阴的位置分类

高位巨量大阴：属于优先级最高的风险信号，往往意味着大量筹码在卖出，价格还在降价出货。出自第10节第9段

低位巨量大阴：不能简单判定为坏事，因为巨量大阴也可能出现"否极泰来"，孕育新的机会。需要进一步观察。

6. 巨量大阴的确认买点：缩量过顶

核心买点：巨量大阴后的核心买点，是后续出现缩量上涨并越过巨量大阴的顶部，即"缩量过巨量大阴顶"。出自第10节第10段

逻辑链：

  1. 股价收复了巨阴造成的压力；
  2. 没有依赖新的大量成交量；
  3. 说明前期巨量大阴中可能存在主力买入与洗盘；
  4. 主力仍然掌握筹码。

案例详解：

  • 案例A柱：近期以来最大的量柱，同时跌幅超过5%的巨量大阴；B柱出现价涨量缩，并越过A柱阴线顶部，形成绝佳买入时机，随后股价连续上涨。
  • 案例文一科技：A柱巨量大阴，B柱缩量越过阴线顶部，属于巨量大阴控点，也可称为巨阴控点。出自第10节第10、11段

主力行为解读：A柱当天虽然多空大量交战，但后续能够缩量重新站上顶部，意味着主力在借阴线洗出不坚定筹码的同时暗中买货。

2. 缩量大阴：跌幅大、量能相对小，常见含义是主力假跌洗盘；支撑位附近出现阳盖阴或反包，可作为买点。
3. 巨量大阴：价跌量增，供给和博弈都极度放大；高位优先视为风险，低位需等待主力是否吸筹的后续确认。
4. 关键确认：巨量大阴后若缩量上涨并越过大阴顶部，即"缩量过顶"，说明压力被消化、主力可能完成洗盘，构成重要控点。
5. 决策顺序：先看位置（支撑/高位/低位），再看量能（缩量/巨量），再看反包或过顶确认；不能把所有大阴都当作出货，也不能把所有缩量大阴都直接抄底。
6. 核心口诀：缩量大阴看假跌，阳盖阴看买点；高位巨量大阴先避险，低位巨量大阴等确认；缩量过巨量大阴顶，是主力重新转强的重要信号。

第11节 · 空方城堡

一句话核心结论：空方城堡 = 放量中大阴线形成的套牢区，按跌幅分3档（3%/5%/10%），核心压力位为顶/底/腰/缺四类。实战中先作拦路虎回避，攻克后可空转多转化为加油站。（出自第11节）

📌 核心知识点

1. 空方城堡的定义与本质

定义：空方城堡与此前的多方城堡相反，指股价下跌过程中，单根跌幅超过3%的中大阴线及其形成的套牢区域。由于这一区域聚集了套牢者，未来股价反弹到这里时，套牢盘可能解套卖出，从而构成重要压力。出自第11节第3段

本质：空方城堡本质上是套牢者站岗的阵地，不是一个单纯的K线名称。跌幅越大，通常意味着被套筹码越多、压力区域越明显，后续反弹越需要观察是否有足够资金消化套牢盘。

2. 空方城堡的3档跌幅划分

按跌幅划分：出自第11节第3段

  • 3%—5%：小空方城堡（普通套牢区）；
  • 5%—10%：大空方城堡（密集套牢区）；
  • >10%：超大空方城堡（极重套牢区）。

原则：城堡越大、压力越重，所需突破动能越大；超大城堡需要重点标记所有关键价位。

3. 空方城堡的四类压力位

核心压力位：出自第11节第4段

  1. 顶部：城堡阴线的最高点；
  2. 底部：城堡阴线的最低点；
  3. 腰部：城堡区间二分之一位置；
  4. 缺口：下跌过程中形成的跳空缺口。

分档观察：

  • 小城堡：腰部参考价值相对较低，主要看顶和底；
  • 超大城堡：顶、底、腰通常都要重点标记；
  • 跳空缺口：下跌过程形成跳空缺口时，缺口位置同样是压力位。

典型超大城堡：一个典型的超大空方城堡可能同时提供四个压力区域：顶、底、腰、缺口。出自第11节第4、5段

4. 实战应对：反弹受阻预期

反弹接近这些位置时，应预期可能出现：

  • 冲高受阻；
  • 放量滞涨；
  • 再次下跌。

不能只看到股价反弹就追涨，而要先检查左侧是否存在空方城堡及其关键价格带。

5. 有效空方城堡的核心要素

第一要素：放量。形成城堡的关键阴线必须是放量的中大阴线。出自第11节第6段

  • 若阴线缩量，往往可能是假跌、洗盘，不能直接当作有效空方城堡；
  • 只有放量大阴才更能说明真实卖压和套牢盘形成。

第二要素：未被有效突破。形成后，后续价格在规定观察周期内不能有效突破其顶或底，原文强调"第23日不破顶或底"用以确认空方城堡有效性。出自第11节第6段

核心并非机械死记日期，而是观察关键顶底是否被有效攻克。

识别空方城堡四要素：高倍量或高量背景、中大阴线、对应的顶与底、后续未被有效突破。出自第11节第6段

6. 拦路虎：空方城堡的主要实战价值

定义：左侧存在高倍量、放量大阴的空方城堡，称为"拦路虎"。出自第11节第7段

实战策略：股价上涨接近拦路虎时，交易者应主动撤退或至少降低仓位，除非已经确认该压力区被有效攻克。

本质：拦路虎不是普通压力，而是主力卖压、套牢盘和解套盘共同形成的关键阻力。

7. 案例：拦路虎 → 加油站

案例走势分析：出自第11节第8—10段

  • A柱：高量、巨量放量大阴，形成空方城堡；
  • 第一次反弹：回到A柱附近时遇到重大压力；
  • B柱：再次放量大阴，形成新的空方城堡；
  • C柱：触及B柱顶部但没有放量，随后调整过程逐步缩量；
  • 主力意图判断：B柱可能是假跌，前期卖压得到测试，主力可能借大阴洗盘和拿货；
  • D柱：一举攻克该大阴顶部，拦路虎由压力转化为加油站，随后股价进入主升浪。

动态判断：空方城堡首先按拦路虎处理，接近时回避；但若后续出现缩量测试成功、缩量调整以及放量大阴顶部被攻克，则说明城堡压力已被消化，原来的拦路虎可能转化为上涨加油站。出自第11节第9、10段

8. 多重空方城堡的压制

金融科技案例：A柱为放量大阴，股价反弹至A柱底部时受压；第二次反弹到A柱顶部附近，又再次遇阻并下跌。之后形成新的放量阴线空方城堡，后续股价一直受到A、B等多个城堡的压制，很难重新走强。出自第11节第11段

圣龙股份案例：放量巨阴A形成拦路虎，反弹精准触及前期顶部后回落；再次反弹时，B柱又形成新的放量阴线，股价到达B柱顶部附近再次下跌。A、B两个拦路虎叠加，构成连续压力带，因此接近城堡顶、底时应提前回避，除非确认站上关键位置。出自第11节第12段

关键启示：多个城堡叠加时，压力连续增强，不能只看单一反弹信号。

第12节 · 控点系列之一

第12节 · 一日控点

一句话核心结论：一日控点 = 首日高倍量/高量大阳突破左侧震荡区 + 次日成交量缩至约1/2但价格继续强势，它揭示主力已高度控盘、筹码锁定，常是主升浪或连板行情的开启点。（出自第12节）

📌 核心知识点

1. 一日控点的标准形态

标准定义：一日控点出现在股价突破震荡区之后。第一天以高倍量或近期高量的大阳线突破左侧震荡区，最好是涨停板；第二天继续上涨，但成交量缩小到前一日的二分之一左右，形成价涨量缩，这就是标准的一日控点。出自第12节第3段

最强组合：第一天涨停 + 第二天强势承接 + 缩量约1/2。缩量二分之一是最佳状态，涨停突破是最强的突破方式。

2. 标准结构的三项必要条件

  1. 突破位置：必须突破左侧盘整区、震荡区或左峰压力；
  2. 首日表现：突破当天量能显著放大、价格强势上行，最好涨停；
  3. 次日确认：次日量能明显收缩但价格不弱，最好达到前一日量能的约1/2。

一日控点不是普通的缩量上涨，而是"突破高量大阳 + 次日缩量确认"的组合。出自第12节第3段

3. 案例一：高量突破后的标准买点

案例中，A柱为高量柱，突破前期盘整区；B柱是标准一日控点。由于控点往往是主升浪的开启点，常见买入方式是在一日控点当天的涨停板打板买入。出自第12节第4段

逻辑解释：A柱用高量完成压力突破，B柱在更少成交量下仍保持强势，说明左侧筹码已经被解套、抛压没有如预期涌出，主力以较小成本即可继续推动价格。

4. 案例二：突破左峰、集合竞价抢筹

另一案例中，A柱为增量柱并突破左侧高点，完全突破左侧压力区；次日出现价涨量缩的控点。A柱若为涨停板，通常是更理想的突破方式。出自第12节第5段

复盘筛选要点：

  • 带量突破左峰；
  • 解套左侧筹码，完成压力区突破；
  • 次日高开；
  • 集合竞价出现抢筹；
  • 集合竞价承接强时，可在涨停板附近快速介入。

走势预期：这种形态常常开启一板、二板、三板、四板等连续涨停或连续上攻，因此一日控点被视为抓连板股、抓主升浪的有效工具。出自第12节第5段

5. 变体：涨停后的放量与再缩量

并非所有一日控点都严格表现为第二天立刻缩量。案例中：

  • A柱前一日：已经是放量、倍量涨停并越过左峰；
  • 第二天：因打开缺口等因素，仍处于放量状态；
  • 第三天：才出现价涨量缩，且缩量达到约二分之一，随后再次涨停；
  • 虽然确认延后一天，但第三天的缩量上涨仍然构成一日控点。

出自第12节第6段

6. 时间弹性：抓核心逻辑而非机械日期

识别一日控点要抓住核心逻辑，而不是机械限定为"突破次日"。核心是突破后出现缩量上涨确认：

  • 量能从突破阶段的高位明显回落；
  • 价格仍保持强势；
  • 证明主力没有因为突破而大量兑现；
  • 市场筹码处于较强控制状态。

出自第12节第6、7段

7. 一日控点的本质：主力高度控盘

核心本质：一日控点的本质是主力高度控盘。突破区间时主力以高量完成价格上推，突破后又能在缩量状态下维持上涨，说明：

  1. 抛压有限；
  2. 筹码锁定程度高；
  3. 主力不需要持续放大量即可维持上涨；
  4. 股价正进入主升浪。

出自第12节第7段

8. 控点体系的“提款密码”比喻

课程把控点比喻为"提款密码"、"提款钥匙"或"金钥匙"，强调每一种控点都对应特定市场场景。学习者不能只记概念，应至少寻找100个一日控点案例进行验证，掌握其在不同突破位置、题材强弱和连板阶段中的使用条件。出自第12节第8、9段

9. 三类买点与适用条件

一日控点的常规买点有三类：出自第12节第10段

  1. 尾盘买入：非涨停形态，在控点当天尾盘确认价涨量缩后买入；
  2. 涨停打板：若控点当天是涨停板，无法按普通尾盘方式成交，则在涨停板上打板买入；
  3. 次日跟进：若第一天没买到，第二天仍可考虑买入，但前提是形态仍有效，且个股属于当下龙头、当下题材中的核心股票。

10. 90%经验值的正确理解与风险边界

原文给出的经验是：当一日控点叠加当下题材和龙头属性时，精准抓住后续连板的概率可达90%以上。出自第12节第10段

风险提示：这个比例属于课程案例经验，不是无条件统计保证。实际应用仍需结合：

  • 整体市场环境（牛市/强势阶段更适用）；
  • 集合竞价承接；
  • 突破有效性；
  • 题材持续性与龙头地位；
  • 严格风险控制。

不能脱离条件机械套用，更不能把任意缩量阳线都称为一日控点。

本节要点： 1. 标准结构：高倍量/高量大阳突破左侧震荡区，随后出现约缩量二分之一的价涨量缩；涨停突破是最强形态。
2. 核心逻辑：放量负责突破，缩量负责确认；价格继续强、量能反而收缩，说明主力高度控盘、筹码锁定，主升浪可能开启。
3. 时间弹性：缩量确认可在突破次日出现，也可能因缺口、放量换手等原因延后一天；关键是突破后最终形成强势缩量上涨。
4. 买入路径：非涨停形态关注控点当天尾盘；涨停形态关注打板；错过首日时，只有在龙头和题材属性仍强、控点有效的前提下考虑次日跟进。
5. 选股场景：重点寻找突破左峰、解套左侧筹码、集合竞价抢筹、带量涨停且次日缩量强势的股票，尤其适用于牛市或强势题材中的连板、主升浪机会。
6. 训练方法：每类控点都应通过至少100个案例验证。
7. 核心口诀：一日控点不是单纯追涨，而是"突破放量、次日缩量、主力控盘"的确认结构；先确认突破有效，再结合龙头题材和市场环境执行。

第13节 · 控点系列之二

第13节 · 连阳控点

一句话核心结论：连阳控点 = 高倍量柱之后，连续2—3根小阳线逐日价涨量缩（价涨量平也视同）；每一根都体现控盘做多，连续出现说明主力已高度控盘、蓄势待发，往往是涨停或牛股爆发的起点。（出自第13节）

📌 核心知识点

1. 连阳控点的定义

定义：连阳控点是指股价在上升途中，高倍量（高量柱/倍量柱）之后，连续2到3天出现"价涨量缩"的小阳线所形成的控盘形态。出自第13节第1段

公式：连阳控点 = 高倍量柱 + 连续2—3根小阳线 + 每日价涨量缩。

这里的"连续"不仅要求K线收阳，还要求相邻量价关系逐根成立；如果只有价格连续上涨，却没有逐日量缩或量平，就不能机械认定为标准连阳控点。

2. 标准形态的三个要素

出自第13节第1段

  1. 前置条件：必须先出现一个高倍量柱，即高量柱或倍量柱A柱，这是主力启动的信号柱；
  2. 后续走势：其后出现连续2到3根小阳线（如B、C、D柱），呈现"一天比一天量少、一天比一天价格上涨"；
  3. 逐根比较：B与A比价涨量缩，C与B比价涨量缩，D与C比价涨量缩；每根都必须与前一根比较。

3. 连阳的命名规则

  • 连续两根符合条件的阳线，称为"二连阳"，也称"二连控点"；
  • 连续三根符合条件的阳线，称为"三连控点"；
  • 凡连续2到3根符合价涨量缩特征的阳线组合，统称"连阳"。

出自第13节第1段

4. 连阳控点的本质：价涨量缩，控盘做多

课程原理：连阳控点 = 价涨量缩，控盘做多。每一根价涨量缩的K线，本质上都是主力控盘做多的体现。出自第13节第2段

逐根买点解读：

  • F柱相对前柱，控盘做多，所以是买点；
  • G与F对比价涨量缩，控盘做多，依然是买点；
  • H与G对比价涨量缩，控盘做多，依然是买点。

也就是说，按课程逻辑，每一根这种价涨量缩K线都可视为买点；若连续2至3天形成连阳形态，则主力控盘更精妙，随时可能拉升。

5. 为什么连阳后容易爆发涨停

在正常上涨中，价格走高往往需要成交量配合；而连阳结构中，价格一天比一天高，成交量却一天比一天低，说明：

  1. 市场抛压持续减少；
  2. 筹码锁定程度持续提高；
  3. 主力用更小成交量即可将价格逐步推高；
  4. 主力的控盘时间久、控盘精妙；
  5. 一旦启动，爆发力可能很强，往往爆发涨停板。

出自第13节第2段

6. 连阳控点的买入意义

连阳控点出现意味着主力已经高度控盘，蓄势待发。课程对其特征概括为：出自第13节第2段

  • 出现频率比较少；
  • 一旦出现，往往是牛股爆发的起点；
  • 主力控盘时间久、控得精妙，因此爆发力较强；
  • 连续价涨量缩往往预示即将出现涨停启动。

7. 明确的买入时机

出自第13节第2段

  1. 第一个连阳控点：看到第一个连阳控点就可以关注，在控点出现的尾盘买入；
  2. 连续第二天：若连续两天仍形成连阳控点，可在第二天买入；
  3. 连续第三天：第三天仍符合价涨量缩时，课程称可继续加仓；
  4. 次日尾盘：连阳控点的尾盘，或连阳控点次日尾盘，均被课程视为相对安全的买点。

执行前提：每一次买入都必须建立在前置高倍量、上升途中、后续小阳、逐日价涨量缩的条件仍然有效之上，不能只因为连续收阳便追高。

8. 变体：价涨量平等于价涨量缩

课程补充了一种类似形态：A柱后面几天成交量几乎齐平（平量），B、C、D连续上涨。这种"价涨量平"形态在控点意义上等同于价涨量缩，同样属于连阳控点。随后出现涨停板，是主力涨停启动的机会。出自第13节第3段

注意：这里的量平是近似齐平、没有明显放大，而不是放量。若后续阳线成交量显著扩大，则不再属于本节所讲的缩量/平量控盘关系。

9. F-G-H与A-B-C-D两组观察法

课程使用两类字母标记帮助识别：

  • A-B-C-D组：A为高倍量前置柱，B/C/D为连续价涨量缩或量平的小阳；
  • F-G-H组：F、G、H逐根与前一柱比较，每一根都体现控盘做多。

这两组表达共同强调：不是只比较最后一根与A柱，而是相邻K线逐根比较。出自第13节第1、2段

10. 稀缺性、确定性与风险边界

原文称连阳控点出现频率低、确定性高，并提出"一旦出现，应重仓把握"、买后耐心等待主力拉升、不轻易下车。出自第13节系统性总结第4点

实战风险提示：以上是课程中的策略表达，不等同于无条件重仓建议。仍需核对趋势、题材、市场环境、前置高倍量是否有效，并设置破位风控；若价格转弱、量能异常放大、上升结构破坏，应重新评估，而非僵化持有。

3. 逐根关系：B比A、C比B、D比C都要价涨量缩，不能只看总趋势。

6. 买点：首个控点尾盘、第二个控点尾盘，以及结构持续有效时的第三日加仓点。
7. 走势预期：该形态频率较低，往往预示涨停板，是牛股爆发起点，但必须结合趋势和风控执行。

第14节 · 控点系列之三

第14节 · 极点控点

一句话核心结论：极点控点 = 极点 + 控点，先出现极致位置K线，再出现"价涨量缩"的确认柱；其中"极点涨停控点"以涨停确认，是牛股的起爆临界点。（出自第14节）

📌 核心知识点

1. 极点控点的定义

公式：极点控点 = 极点 + 控点，即先出现"极点"，再出现"控点"，两者叠加形成强大的买入信号。出自第14节第1段

极点：股价调整到极致位置时形成的K线，通常是极价即量或极量即价的缩量K线。

控点：确认柱与前面的高潮柱对比，形成"价涨量缩"的形态。

战略意义：极点控点 = 比单一极点确认度更强势的买点。

2. 极点控点的两大要素

  1. 极点要素：股价连续调整后形成的极致位置K线（极量级价 / 极价级量）；
  2. 控点要素：确认柱（启动阳线）与前期高潮柱对比形成"价涨量缩"。

出自第14节第1段

3. 跨日控点：极点和确认柱不必相邻

概念：极点出现后，可能不是第二天立即确认，而是隔几天才出现确认柱。出自第14节第2段

案例证据：案例中C柱与A柱对比，跨了1天、2天、3天、4天、5天，中间隔了5天仍形成控点。

实战意义：

  • 这种跨日控点给到更明确的买点；
  • 它比单纯的确认度具有更强的确定性；
  • 因此不应将确认柱机械限定在极点次日。

4. 实战价值：连续多次使用同一策略

老师用一个实战案例展示极点控点的强大威力：出自第14节第3段

  • A柱（高潮柱） → 调整两天 → 形成完美极点极量级价；
  • C柱确认，与A柱对比"价涨量缩"，既是确认B柱，又是确认A柱；
  • 这一天买入 → 第二天涨停；
  • D柱再涨停，E柱又是一个极点，F柱又是涨停板，F与前面的极点形成"价涨量缩"；
  • 整个DEF组合又是一个极点控点。

更经典的极端案例：同一只股票上，主力连续用了三个极点控点（极点控点、极点控点、极点控点），从底部3元多推到600多元，翻了200倍。这是非常经典的"极点 + 控点"组合。

战略解读：主力连续使用同一控点策略，说明主力控盘行为的稳定性与持续性，是擒庄的核心信号。

5. 极点涨停控点：更强的变种

形态定义：出自第14节第4段

  • 昨天视为极点；
  • 今天为涨停板（确认柱为涨停板）；
  • 涨停确认柱与极点对比，形成"价涨量缩"；
  • 这种形态是更为强烈的看涨信号。

战略定位：通常是牛股的爆发临界点 / 起爆点。

6. 极点涨停控点案例

出自第14节第5—6段

  1. 案例一：A柱高亮柱 → B柱极点 → C柱涨停确认 → C与A对比"价涨量缩" → 后面连续爆发涨停板；
  2. 案例二（双城药业）：A柱高潮柱 → 调整两天形成极点 → C柱涨停确认 → 与A对比"价涨量缩" → 后面连续大涨；
  3. 案例三：A柱高亮柱 → B柱一日极点 → C柱涨停板 → 与A对比"价涨量缩" → 后面连续5个涨停。

老师强调："极点控点为涨停板的，往往是牛股的爆发的临界点"。出自第14节第5段

7. 极点控点与其他控点的关系

极点控点与连阳控点形成互补：出自第14节系统性总结第5点

  • 连阳控点：连续2—3根价涨量缩的买点（侧重时间维度）；
  • 极点控点：极致位置 + 价涨量缩确认的买点（侧重极致位置）；
  • 两者都属于"价涨量缩，控盘做多"的擒庄体系。

5. 战略意义：主力在同一只股票上连续三次使用极点控点，从3元到600元，涨幅200倍。
6. 体系关系：与第13节·连阳控点形成互补——连阳控点侧重时间维度的连续确认，极点控点侧重极致位置的确认。

第15节 · 控点系列之四

第15节 · 双极控点

一句话核心结论：双极控点 = 上升途中两个极点 + 第二极点价格抬高 + 量能缩小或齐平；它是擒庄秘籍“核心中的核心”，代表主力已剑拔弩张、蓄势待发，往往就是牛股的起爆点。（出自第15节）

📌 核心知识点

1. 双极控点的定义

核心公式：双极控点 = 出现两个极点 + 两个极点之间形成价涨量缩（或量平）。出自第15节第1段

具体形态：

  • 股价在上升途中连续出现两个极点（不是下跌途中的两个低点）；
  • 将第一个极点P1与第二个极点P2进行对比；
  • 第二个极点的价格高于第一个极点，即两个低点抬高；
  • 第二个极点的量相对第一个极点缩量或平量；
  • 形成"价涨量平或量缩"，双极控点成立。

2. 双极控点四项成立条件

  1. 位置要求：必须在上升途中，不能是下跌途中；
  2. 数量要求：连续出现两个极点；
  3. 价格关系：第二个极点价格抬高于第一个极点；
  4. 量能关系：第二个极点量能缩量或平量于第一个极点。

出自第15节第1段

优先级：课程明确要求量只能缩量或平量，缩量比平量更好；若第二极点明显放量，则形态不成立。

3. 案例一：B点与D点价涨量平，连续5板

出自第15节第2段

  • A柱：备亮柱（高潮柱）；
  • 后面连续调整，刚好回调到A柱的底线；
  • B点：形成第一个极点；
  • C柱：进行确认；
  • 再连续调整4天（1、2、3、4）到D柱；
  • D柱：形成第二个极点；
  • B与D对比：D价格明显高于B（低点抬高），B与D量能齐平；
  • 价涨量平等于价涨量缩，双极控点成立；
  • 后面连续5个涨停。

老师强调："双极控点往往是牛股的起爆点"。

4. 双极控点的本质

主力状态：出现双极控点，说明主力已经高度控盘。出自第15节第3段

形象描述："剑拔弩张，蓄势待发"。

战略定位：双极控点是捕捉牛股的利器，往往是爆发的临界点。

逻辑解释：第二个回调低点比第一个更高，说明价格重心上移；第二次回调所需成交量不增反降，说明抛压衰竭、筹码趋于锁定。价位抬高与量能收缩同时出现，主力只需更少交易即可守住更高的平台，控盘强度显著。

5. 案例二：涨停后补缺形成双极控点，连续6板

出自第15节第4—5段

  • A柱：涨停板；
  • 后面连续调整；
  • B柱：刚好调整到A柱的跳空缺口（补缺位置），形成第一个极点；
  • C柱：确认，随后横盘调整；
  • D柱：缩量小阴，再次形成极点；
  • B与D对比：价格上涨（抬高），量能齐平；
  • 经典双极控点成立；
  • 后面连续6个涨停板。

6. 控点课程的战略地位

老师对整个控点课程体系作出总结：出自第15节第5段

  • "擒庄秘籍里的控点课程，每一招都是抓牛股的绝招"；
  • 把握好一招，就可以把牛股抓住；
  • 无论是什么形态启动，如何变化"马甲"，本质都是控点；
  • "无论选择哪一个控点，一个控点就可以支持我们至少几倍的学费"；
  • "你抓一个涨停板，一抓就几个涨停板"。

理解边界：这些话是课程对控点战略价值的强调，不构成收益承诺。实战仍需严格验证形态与市场条件。

7. 案例三：B-D与D-F连续控点、潜伏机会

出自第15节第6段

  • B柱：第一个极点；
  • D柱：第二个极点；
  • B与D对比：价格涨、量缩 → 双极控点成立；
  • 这天可以确认买入，也可以在极点确认前一天潜伏；
  • F柱：又出现极点；
  • F与D对比：价格涨、量几乎平 → 再次形成控点；
  • 后面又大涨。

课程总结："每一次只要是极点的控点上买入，可以做潜伏，一买就涨"。

8. 双极控点的买入时机

出自第15节第7段

第一买点：第二个极点上潜伏

  • 在第二个极点的当天尾盘买入；
  • 也可在第二个极点确认前的低点潜伏。

第二买点：第二个极点确认当天

  • 在第二个极点当天确认控点成立时买入；
  • 必须对比两极点的量；
  • 量只能缩量或平量，且缩量优于平量。

快速判断：前面已有一个极点，现在第二个极点的量比前面更低，同时价格更高 → 双极控点成立。

9. 与连阳控点、极点控点的区别

  • 连阳控点：连续2—3根价涨量缩，侧重连续时间维度；
  • 极点控点：极点 + 确认柱，侧重极致位置；
  • 双极控点：两个极点 + 价涨量缩/量平，侧重两个极点的比较，被称为最强势、核心中的核心。

第16节 · 控点系列之五

第16节 · 大阴控点

一句话核心结论：大阴控点 = 大阴（供应消耗） + 单枪测试压力 + 价涨量缩小阳（重新控盘）；它识别大阴线洗盘是否结束；按形态分曲线型 / 隔日型 / 直接反包三种。（出自第16节）

📌 核心知识点

1. 大阴控点的形态条件

大阴控点的成立需要满足以下形态条件之一：出自第16节第1段

条件一：大阳反包大阴

  • 出现大阴线后，被一根大阳线完全反包；
  • 即"大阳反包大阴"形态。

条件二：单枪最高价超过大阴顶

  • 大阴线第二天出现"单枪"（带长上影线的阳线）；
  • 单枪的最高价超过大阴的顶部；
  • 第二天再出现"价涨量缩"的阳线 → 大阴控点成立。

2. 大阴控点的本质：主力行为的三步骤

大阴控点的内在主力行为逻辑：出自第16节第2段

  1. 大阴线出现：说明供应已经消耗掉了，该卖的人已经卖得差不多；
  2. 单枪测试：中阳单枪是在测试上方压力，把大阴的套牢盘解套了一下，说明上方套牢盘已经不多；
  3. 缩量小阳：再出现"价涨量缩"的小阳线 → 主力重新开始控盘。

核心三步骤：大阴（供应消耗）→ 单枪（压力测试）→ 缩量小阳（重新控盘）。

3. 案例一：A-B-C-D-E-F 详解

出自第16节第3—4段

  • A柱：大阴线；
  • B柱：单枪，刚好把A柱的实顶给过了（说明A柱的套牢盘被测试了）；
  • C柱：与B柱对比是"价涨量缩"，C柱本身就是极点；
  • C柱当日尾盘就可以买入；
  • D柱：又是一个缩量大阴（跌得多但量没放大）；
  • E柱：单枪，把D柱的顶捅了一下（再次测试套牢盘）；
  • F柱：与E对比是"价涨量缩" → 控点 → 第二天大涨。

这是经典的大阴 + 单枪测试 + 小阳价涨量缩组合。出自第16节第4段

4. 案例二：缩量大阴的单枪测试

出自第16节第5段

  • A柱：缩量的大阴（价格跌得多但量没放出来）；
  • B柱：刚好把A的阴顶给捅了一下，但没有过顶；
  • C柱：与B对比是"价涨量缩" → 后面一路涨。

关键启示：缩量大阴比放量的大阴更值得关注，抛压已经衰竭。即使单枪没有完全过顶，只要随后出现价涨量缩小阳，仍可形成控点。

5. 最理想的大阴控点形态

出自第16节第6段

  • 今天出现大阴线 → 明天直接缩量反包；
  • 这是最理想的形态；
  • 但老师特别强调："这种出现的概率比较小"；
  • 所以曲线的大阴控点（带单枪测试）比较常见。

6. 隔日大阴控点

出自第16节第7段

  • A柱：缩量大阴；
  • B柱：十字星，把A的高点捅了一下（测试）；
  • C柱：与B对比是"价涨量增"，但与A对比：价格直接过了大阴的顶，量是平的；
  • C与A对比：价涨量平 → 等于价涨量缩 → 控点，称为"隔日大阴控点"；
  • 隔日大阴控点后面连续大涨。

关键启示：判断控点时既要与前一柱比较，也要与压力源A柱比较；只要相对A柱形成价涨量平/缩，即满足控点定义。

7. 买入时机：按形态分别确认

出自第16节第8段

形态类型买入时机
曲线大阴控点（带单枪测试）缩量小阳的尾盘买入
曲线大阴控点后续确认价涨量缩小阳的次日买入
隔日大阴控点（直接过顶）直接在过顶当天买入
最理想形态（直接缩量反包）缩量反包当天买入；概率小但确定性最强

8. 关键识别要点

  1. 缩量大阴比放量的大阴更值得关注，说明抛压已经衰竭；
  2. 单枪测试的关键是最高价是否触及或超过大阴的实顶；
  3. 缩量小阳必须是"价涨量缩"，与前柱对比成立控点；
  4. 缩量小阳的尾盘是最安全的买入点。

第17节 · 控点系列之六

第17节 · 极阴控点

一句话核心结论：极阴控点 = 连续暴跌尾声 + 三天价跌量增梯量 + 第二天缩量反包（最好涨停）；其本质是主力刻意制造恐慌、散户割肉、主力暗中吸筹，是逆向擒庄的最强买点。（出自第17节）

📌 核心知识点

1. 极阴控点的定义与形态

极阴控点的形态特征：出自第17节第1段

  • 位置条件：出现在下跌尾声——即连续暴跌之后；
  • 关键形态：在下跌尾声出现三天连续放量的"价跌量增"阴线；
  • 这三天阴线呈现"梯量"形态（量一天比一天大，价格一天比一天跌）；
  • 这种下跌过程中出现的尾声梯量，称为"极阴"；
  • 第二天出现"价涨量缩"的阳线进行反包（最好是涨停板）→ 极阴控点成立。

2. 极阴控点的本质逻辑

老师从主力行为角度深度剖析极阴控点的本质：出自第17节第2—3段

1. 极阴的本质 = 主力刻意制造的恐慌抛售

  • "批量阴线实际上就是主力刻意制造的恐慌抛售"；
  • 制造恐慌，让散户把手上的股票卖出去；
  • 卖完之后，主力悄悄在低位吸筹。

2. 价跌量增的反向逻辑

  • 下跌尾部的价跌量增，看似可怕，实则暴露主力行为；
  • "谁来买，谁来卖？"——往往最跌最狠的那一天放巨量；
  • 散户在不计成本地抛售；
  • 主力趁散户抛售时悄悄买入。

3. 关键问题：谁在买，谁在卖？

  • "任何K线上有人买就有卖"；
  • 量增的量从哪里来？一定是有散户割肉；
  • 散户卖出 → 主力买入；
  • 所以"主力趁恐慌下跌的时候再买"。

4. 第二天价涨量缩确认主力行为

  • 第二天缩量反包涨停，说明主力已经吃饱筹码；
  • 缩量大涨或涨停，说明主力不让别人再买了；
  • 透过第二天的"价涨量缩"反推前一天的极阴 → 当天就是主力在买、主力在吸筹。

3. 案例一：一诺华极阴控点

出自第17节第2段

  • 连续暴跌，暴跌的尾声这三天（1、2、3）：
  • 价格跌得越来越猛，跌幅越来越大；
  • 量也越来越大；
  • 形成"价跌量增"的态势；
  • 主力趁散户恐慌抛售时悄悄买入；
  • 第二天缩量涨停确认 → 极阴控点成立；
  • 极阴控点买进去后面继续大涨。

4. 案例二：大陆极光极阴控点

出自第17节第4段

  • 这几天连续下跌，中间还加了实心阴线；
  • A柱那天：涨停板，且量是缩的（价涨量缩）；
  • A柱当天就是绝佳买入时机；
  • 买完第二天再来一个板；
  • 本质上：这几天大跌时放的量，是主力在吸筹；
  • 散户在不计成本地抛售，形成价跌量增；
  • 通过A柱的"价涨量缩"反推前面的大跌 → 主力在悄悄买入；
  • 后面连续大涨。

5. 案例三：龙杰股份极阴控点

出自第17节第5段

  • 从这里连续下跌，形成梯量，价格连续跌；
  • 中间出现一个停止信号（跌幅越来越小）；
  • 重点观察："价格连续跌的情况下，来这个跌幅是越来越小的"；
  • "跌幅小了，量大了" → 说明什么？ → "说明有人在低吸"；

  • 后面连续大涨。

6. 极阴控点的买入时机

出自第17节第6段

第一买点：极阴控点当日尾盘买入

  • 在确认"价跌量增 + 第二天价涨量缩反包"成立的当天尾盘买入。

第二买点：涨停板打板买入

  • 如果第二天的反包是涨停板（缩量涨停）；
  • 直接在涨停板上打板买入；
  • 前提：一定是缩量的反包（缩量是关键，不是放量反包）。

第三买点：次日买入

  • 如果当天没买到（涨停板买不到）；
  • 第二天还有机会买入（开盘价附近）；
  • 同样有效。

7. 在控点体系中的位置

极阴控点是控点系列中处理暴跌形态的反向技术：出自第17节系统性总结第7点

  • 连阳控点 / 极点控点 / 双极控点：上升途中的控盘信号；
  • 大阴控点：处理单根大阴洗盘之后的买点；
  • 极阴控点：处理连续暴跌之后的反向买点。

三者共同构成擒庄秘籍中"主力制造恐慌 → 散户割肉 → 主力吸筹 → 反向拉升"的完整反向擒庄技术。极阴控点是擒庄秘籍中逆向思维的极致体现——在别人恐惧时贪婪，识别主力刻意制造的恐慌抛售，在低位跟随主力吸筹。

第18节 · 控点系列收官

第18节 · 单枪控点

一句话核心结论：单枪控点 = 面临左峰时长上影线阳线测试压力 + 后续出现价涨量缩或极点控点，标志着主力完全掌控局面、正式开始拉升，是擒庄秘籍核心控点系列的收官之作。（出自第18节）

📌 核心知识点

1. 单枪的定义

单枪（又称"单腔"）是K线形态的一种专有名称：出自第18节第1段

  • 形态特征：一根阳线，但带有长长的上影线；
  • 上影线长度：一般是实体的一半，或者大于实体都可以；
  • 判断原则：上影线越长，单枪信号越明显；
  • 出现位置：通常在股价面临左峰（左侧压力）时出现。

2. 单枪控点的形成条件

形成公式：出自第18节第1段

  • 面临左峰时出现单枪（测试左侧压力）；
  • 单枪之后出现价涨量缩或者极点控点；
  • 单枪 + 价涨量缩 / 极点控点 = 单枪控点成立。

3. 单枪控点的本质：测试+确认=拉升

本质逻辑：老师揭示单枪控点的本质逻辑——出自第18节第2段

  • "单枪控点的本质是主力透过单枪测试前面压力"；
  • 测试前峰压力后出现空点（控点）；
  • 说明主力已经完全掌控了局面；
  • 主力"正式开始要拉升了"。

这是单枪控点最重要的战略意义：测试压力 + 控点确认 = 拉升启动。

4. 案例一：单枪 + 两天价涨量缩

出自第18节第2段

  • A柱：打到左侧高点的单枪（左侧有压力）；
  • A柱本身就是一个空点（与昨天对比是"价等量缩"——加等量缩）；
  • B柱：与A柱对比，又是"价等量缩"；
  • B柱第二天还是个"价等量缩"；
  • 即A柱（单枪） + 连续两天"价涨量缩" → 控点成立；
  • 后面继续大涨。

5. 案例二：单枪 + 低量假跌 + 反包

出自第18节第3段

  • A柱：单枪大阳，留下长上影线；
  • C柱：低量小阴或低量中阴（假跌）；
  • 量缩得很厉害（是极量）；
  • 虽然价格没有"极"，但第二天D柱反包；
  • D柱：反包后，D与A形成空点（价涨量缩的空点）；
  • A是单枪 + D与A形成单枪空点 → 后面连续大涨。

6. 案例三：单枪 + 极点的极点控点

出自第18节第4段

  • A柱：高亮的单枪；
  • B柱：低点的极点；
  • C柱：与A柱对比是"价涨量缩"（单枪极点空点）；
  • 本质上这就是一个极点控点，但因为A是单枪，所以特别称为"单枪极点控点"；
  • 这种形态本身就是极点控。

7. 案例四：单枪 + 一日极点控点

出自第18节第4段

  • D柱：单枪；
  • E柱：一日极点；
  • F柱：空点（实际上是一日极点控点）；
  • 但因为这里有个单枪D柱，所以这是"单枪一日极点加控点"；
  • 后面又连续继续创新高。

8. 单枪控点的买入时机

出自第18节第5段

第一买点：单枪控点当日尾盘买入

  • 一般情况下，买在单枪控点出现的当日尾盘；
  • 这是最常见的买点。

第二买点：次日开盘买入

  • 也可以在次日开盘时买入；
  • 同样有效。

第三买点：涨停板打板买入

  • 如果单枪控点当天直接涨停；

  • 但老师特别强调："相对来讲比较少一点"（涨停板的单枪控点出现概率较低）。

第19节 · 云巅控点

一句话核心结论：在左峰这一必经压力区，通过转点/单枪/极点等形态消化抛压，并以价涨量缩重新确认控盘做多，从而捕捉牛股主升浪的起爆点。（出自第19节）

📌 核心知识点

1. 左峰与左峰控点的定义

所谓左峰，是股价左侧已经形成、形似山峰且较难逾越的历史高点。当股价再次上涨至该位置时，往往会受到显著压力并出现调整。（出自第19节第1—2段）

凡是在左峰位置形成的关键控盘形态，都可归入"左峰控点"。左峰控点主要包括三类：

  • 左峰转点控点：股价在左峰压力处先出现放量大阴等看似转弱的走势，随后被次日或后续阳线反包，并形成价涨量缩，说明走势由弱转强。转点本身也是控点。（出自第19节第1—3段）
  • 左峰单枪控点：在左峰压力附近形成"单枪"形态，随后直接出现价涨量缩的控点。（出自第19节第1、7段）
  • 左峰单枪—极点—控点：左峰位置先出现单枪，之后形成极点止跌，再出现相对单枪柱价涨量缩的控点。课程也将其概括为"左峰单枪极点控点"。（出自第19节第5—7段）

课程强调，控点可以由转点、单枪或极点体系演化而来；判断的共同前提是形态发生在左峰这一关键压力区域。（出自第19节第1段）

2. 左峰是牛股上涨的必经压力关口

所有大牛股在持续上涨、创出更高价格之前，都必须突破左侧历史高点，因此左峰是上涨过程中的"必经之路"。股价碰到左峰时通常不会毫无阻力地通过，而会以调整、分歧或洗盘的方式消化压力。

交易者的核心任务不是看到压力就简单回避，而是观察压力位附近是否出现极点、控点或转点，从中识别主力完成洗盘并继续做多的信号。（出自第19节第2—4段）

3. 左峰转点控点的识别逻辑

典型形态是：股价接近左峰后出现放量大阴线，按常规量价关系本应继续下跌，但次日出现反包阳线；若反包时呈现价涨量缩或价涨量平，则说明此前的下跌更可能是洗盘，行情已经发生转折。这个反包柱既是转点，也是控点。（出自第19节第2—3段）

课程案例中，一处左峰压力前先出现放量大阴，第二天以平量上涨反包，形成左峰转点控点；另一案例中，股价先以放量长上影线面对前方左峰，次日出现价涨量缩控点，之后再次在另一左侧高点前出现放量阴线，但随后又被价涨量缩反包。连续出现的左峰转点与控点表明压力正被逐步消化，后续股价继续上涨。（出自第19节第3—4段）

这类形态的关键不是阴线本身，而是阴线之后能否出现超预期反包，以及反包时成交量是否缩小。只有价格重新走强、成交量反而收缩，才体现主力控盘做多。（出自第19节第2—4段）

4. 左峰单枪、极点与控点的组合

  • 股价在左峰处形成单枪，随后出现极点，再出现价涨量缩控点；极点与控点叠加后，股价连续大涨。（出自第19节第5段）
  • 单枪正好对应左侧高点压力，之后形成极点；极点内又出现相对单枪柱价涨量缩的控点，这一完整组合可简称为左峰控点。（出自第19节第6段）
  • 另一案例中，C柱在B柱左峰处形成单枪，随后出现极点，D柱相对C柱价涨量缩，构成"左峰单枪—极点—控点"。（出自第19节第7段）
  • 还有一种更简洁的结构：左峰处出现单枪，第二天立即形成价涨量缩的单枪控点，第三天跳空大涨，不一定必须等待完整极点结构。（出自第19节第7段）

实际识别时不能机械要求所有环节都同时出现。左峰处可以直接形成控点，也可以先形成转点控点，或通过单枪、极点再形成控点；共同验证标准仍是关键压力位置与价涨量缩的控盘特征。（出自第19节第6—8段）

本节要点：左峰控点的完整逻辑是：历史高点形成压力 → 股价再次挑战左峰 → 主力通过大阴/单枪/极点等方式消化抛压 → 出现反包或价涨量缩 → 确认控盘做多 → 股价突破压力并延续上涨。
  • 位置是前提：形态必须发生在左侧历史高点附近。
  • 形态有三条主要路径：直接控点、转点控点、单枪—极点—控点。
  • 量价是确认标准：突破或反包时价涨量缩，说明浮筹减少、主力控盘增强。
  • 阴线不等于转弱：左峰处放量大阴若被迅速缩量反包，反而可能是由弱转强的转点。
  • 操作重在确认后的先手：优先考虑控点当天尾盘，其次是涨停确认或次日延续时介入。

第20节 · 巅峰控点

第20节 · 巅峰控点

一句话核心结论：股价上涨途中形成的巨量阶段高点（巅峰），经过洗盘后以价涨量缩的方式重新突破，缩量过前高即巅峰控点，标志主力控盘增强、洗盘完成、升势恢复。（出自第20节）

📌 核心知识点

1. 巅峰控点的定义

"巅峰"是股价上升途中形成的阶段高点，该高点通常由巨量阳线或巨量阴线构成。形成巅峰后，股价回落、横盘或洗盘；经过一周至数月的调整，股价重新突破该高点，并且突破时成交量低于原巅峰柱，形成"价格创新高、成交量反而缩小"的价涨量缩结构，这就是巅峰控点。（出自第20节第1段）

时间跨度不是限制条件：短则约一周，长则数月。关键不是相隔多少天，而是后来的突破柱是否越过原巅峰高点，以及成交量是否明显缩小。（出自第20节第1、5段）

2. 两类巅峰控点

巅峰控点分为两类：

  • 巨阳巅峰控点：前期连续上涨后形成巨量大阳高点，市场短期需求被消耗，股价进入休整；后续以缩量方式突破巨阳巅峰，代表洗盘完成、升势恢复。（出自第20节第2段）
  • 巨阴巅峰控点：左侧高点由巨量阴线构成。该阴线往往体现压力、获利盘出逃或主力刻意洗盘；后续股价重新站上阴线顶部且成交量缩小，说明供应与抛压已被消耗，股价可能重拾升势。（出自第20节第6段）

两类形态虽然原巅峰柱阴阳不同，但判断本质一致：缩量突破前期放量高点。（出自第20节第1—2、6段）

3. 巨阳巅峰控点的运行逻辑与案例

课程案例中，A柱表面呈假阴，实质属于阳线，并形成巨阳巅峰。股价随后调整约两周，B柱突破A柱顶部且成交量缩小，说明调整期间不坚定筹码已被清洗，主力不再需要大量成交即可轻松越过前高。B柱即A柱的巅峰控点，之后股价连续上涨。（出自第20节第3段）

上涨后，C柱再次形成高量巅峰，股价调整约一周，D柱再度构成巅峰控点。但D柱之前是连续放量上涨，形成"T量"结构，通常仍可能需要调整，因此随后出现大阴洗盘。由于大阴缩量，并且第二天又迅速以缩量走势重新走强、突破前方巅峰，所以这段曲折并未破坏控点逻辑，而是洗盘后的再次确认。（出自第20节第3—4段）

课程据此强调：每次股价创新高时，都应关注是否"缩量过前高"。如果新高不断出现而成交量一次比一次低，说明主力越战越勇、控盘越来越牢，拉升阻力越来越小。（出自第20节第4段）

另一案例中，A柱先形成大阳巅峰，之后洗盘约两个月；期间出现单枪、极点等结构。B柱又形成新的大阳巅峰，股价继续洗盘一个多月；C柱最终突破B柱高点，且C柱成交量小于B柱，形成跨越一个多月的经典巅峰控点。课程认为，这种经过较长时间洗盘后形成的缩量突破，当天是绝佳买入时机。（出自第20节第5段）

4. 巨阴巅峰控点的运行逻辑与案例

巨阴巅峰形成时，放量阴线往往给人强烈转弱印象，但它可能是在左侧压力处释放抛盘，也可能是主力主动洗盘。后续若股价经过调整，以更小成交量重新站上巨阴顶部，就证明原有供应已被消化，巨阴高点转化为控点参照。（出自第20节第6段）

案例中，A柱是巨量阴线巅峰。股价调整近一个月后，B柱突破A柱顶部，形成巨阴巅峰控点。在此之前，走势还出现单枪、极点以及极点控点，因此同一买点同时获得"极点控点"和"巨阴巅峰控点"两套逻辑确认，随后连续出现多个涨停并接近翻倍。（出自第20节第7段）

另一个案例中，A柱是放巨量的阴十字星。后续突破柱相对A柱形成明显价涨量缩，构成巅峰控点；同时中间还存在左峰与"峰中峰"结构。课程继续比较B柱与对应突破柱：价格越过B柱顶部而成交量缩小，再次形成巨阴巅峰控点。一个走势中可能连续出现多个巅峰控点，每一次都可作为观察和介入节点。（出自第20节第8—9段）

5. 巅峰控点与其他形态的叠加

巅峰控点并非孤立存在。调整过程中可能同时出现单枪、极点、极点控点、左峰或峰中峰等结构。若同一天既满足价涨量缩突破巅峰，又满足极点控点等条件，就形成多重确认，提高该位置作为买点的技术意义。（出自第20节第5、7—9段）

不过，不论叠加多少名称，判断主线始终是：原高点放量形成压力，调整消化浮筹，后来缩量越过顶部。这反映筹码趋于稳定、抛压下降和主力控盘增强。（出自第20节第3—9段）

💡 系统性总结

本节要点：巅峰控点的逻辑链条是：上涨途中形成巨量高点 → 股价回调或横盘洗盘 → 不坚定筹码与供应被消化 → 股价重新突破巅峰 → 突破量小于原巅峰量 → 确认控盘增强并重拾升势。
  • 原巅峰必须有辨识度：通常是巨量阳线或巨量阴线形成的阶段高点。
  • 突破必须看量：仅创新高不够，缩量过前高才是巅峰控点。
  • 时间跨度弹性很大：可从一周延伸到数月，重点是前后高点与量能比较。
  • 巨阳与巨阴殊途同归：前者偏向上涨后的需求耗尽与休整，后者偏向压力释放或洗盘；两者最终都以缩量突破确认。
  • 新高量越低，控盘越强：连续缩量创新高表示浮筹减少、主力拉升阻力下降。
  • 多形态叠加增强确认：与单枪、极点、左峰等共振时，买点意义更强。

第21节 · 巨阴转点

第21节 · 巨阴注转点

一句话核心结论：涨停启动后次日出现巨量阴线制造恐慌，随后以缩量涨停反包完成分歧转为一致，即巨阴转点——强势牛股的"渡劫"形态之一。（出自第21节）

📌 核心知识点

1. 巨阴转点的定义与本质

原文标题"巨阴注转点"及转写中的"巨婴、均匀、军营"等词，结合上下文均应修正为"巨阴转点"。所有转点本质上都是特殊控点，巨阴转点也不例外。（出自第21节第1段）

典型巨阴转点通常由三步构成：

  1. 前一天出现涨停板；
  2. 次日出现巨量阴线，即价跌量增，可能跌停，也可能未跌停；
  3. 第三天以涨停板反包巨阴，且常呈缩量上涨，形成价涨量缩。（出自第21节第2段）

按常规量价逻辑，价跌量增意味着抛压增强，后市应继续下跌；但随后出现涨停反包，说明巨阴日并非真正破位，而更可能是假跌、洗盘或资金换手。预期由"应跌"突然转为"强势上涨"，因此称为"转点"。（出自第21节第2、7段）

2. 形态过滤条件

巨阴转点通常出现在首板、二板或三板之后，其中首板之后的巨阴转点更优。位置越低，安全性与成功率通常越高；二板、三板后也可成立，但风险相对增加。（出自第21节第3段）

巨阴日往往以跌停或接近跌停的方式出现，但跌停不是必要条件。只要阴线明显放量、形成价跌量增，并带来强烈看跌预期，即可进入观察范围。（出自第21节第2—3、6段）

反包也不一定必须紧接巨阴次日出现，常见节奏有两种：

  • 标准三日结构：涨停—巨阴—缩量涨停反包；
  • 变异结构：巨阴后先缩量调整一至两天，形成洗盘或极点止跌，再以缩量涨停反包。（出自第21节第3—4、7段）

因此，识别时既要掌握标准形态，也要允许一至两天的缩量缓冲，不能因没有立即反包就机械排除。（出自第21节第3、7段）

3. 案例所揭示的量价逻辑

第一组案例中，A、B两柱为连续涨停，C柱出现价跌量增的巨阴，视觉上非常恐怖。随后股价调整两天，这两天形成极点、显示下跌停止；之后低位柱反包并覆盖巨阴，且呈价涨量缩。该形态既可称为巨阴转点，也可视为跨日控点，后续股价连续大涨并翻倍。（出自第21节第4段）

另一案例在首板后立即出现放量下跌，第三天直接缩量反包，随后连续约五个涨停并实现翻倍。这说明巨阴日的分歧并未破坏趋势，反而通过充分换手，为后续一致性拉升创造条件。（出自第21节第5段）

爱仕达案例同样是首板涨停后出现价跌量增，第三天缩量涨停，之后再连三个涨停，是标准的三日巨阴转点。（出自第21节第6段）

另一个案例中，前面为涨停或一字涨停，B柱出现近期最高阴量、价跌量增但未跌停。按常理次日应继续跌，实际却被阳线反包并继续上涨，证明"是否跌停"并非核心，关键是强烈看跌预期能否被超预期反包推翻。（出自第21节第6段）

最后一组变异案例是在连续两个涨停后出现接近跌停的巨阴，随后多调整一天，再以缩量涨停完成转点，之后连续上涨。它只是比标准形态多一天调整，本质仍为巨阴转点。（出自第21节第7段）

4. "转"包含两层含义

巨阴转点中的"转"有两层核心含义：

  1. 资金关系由分歧转为一致：巨阴放量说明有人大量卖出，也有人承接。后续能够以较小成交量上涨或涨停，说明筹码趋于一致，巨阴日的主要承接力量更可能来自主力。（出自第21节第5、7段）
  2. 行情预期发生转折：价跌量增本应延续下跌，实际却快速反包上涨，走势显著超出常规看跌预期。（出自第21节第7段）

因此，不能仅凭巨阴日判断谁在买、谁在卖；必须等待后续价涨量缩、涨停反包等结果，才能反推巨阴日是主力承接、散户卖出，而不是主力出逃。（出自第21节第5段）

本节要点：巨阴转点的逻辑链条是：涨停启动 → 巨量阴线制造恐慌与分歧 → 主力承接、浮筹出逃 → 次日或一两天后缩量反包涨停 → 分歧转为一致、看跌预期转为上涨 → 升势延续。
  • 本质是特殊控点，核心信号仍是后续价涨量缩。
  • 标准形态通常为三天：涨停、巨阴、缩量涨停反包。
  • 允许变异：巨阴后可缩量调整一至两天再反包。
  • 首板后成功率更高：位置越低，通常越安全。
  • 巨阴不要求必须跌停：明显放量下跌并形成强烈看空预期即可。
  • 确认来自后续，而非巨阴当日：只有后续缩量强势反包，才能证明巨阴更可能是假跌和主力承接。
  • 最佳操作窗口在竞价超预期：其次是盘中确认或涨停板确认。
⚠️ 三大转点体系：本节为巨阴转点，与第22节烂板转点、第23节炸板转点同属牛股"渡劫"形态，逻辑上分歧转一致、预期由弱转强高度一致。
第22节 · 烂板转点

第22节 · 烂板转点

一句话核心结论：涨停反复开板并放巨量形成"烂板"，次日却迅速缩量涨停反包，完成分歧转一致，即烂板转点——验证主力承接与强势牛股完成渡劫的关键形态。（出自第22节）

📌 核心知识点

1. 烂板转点的定位与定义

巨阴转点、烂板转点和炸板转点都属于牛股拉升过程中的"渡劫"形态。所谓渡劫，是指股价在继续大涨前必须经受一次明显分歧或风险考验；若成功化解分歧，后续往往进入更强的上涨阶段。（出自第22节第1、6段）

烂板转点的典型结构是：前一天涨停板反复打开、封板不稳，并伴随明显放量；第二天却再次涨停，而且成交量缩小，形成价涨量缩的涨停控点。课程建议烂板最好出现在三板以内，位置过高时风险更大。（出自第22节第2段）

2. 烂板的本质：资金分歧

烂板反复开板且放量，说明涨停价附近存在巨大分歧：一部分资金大量卖出，另一部分资金持续承接。仅看烂板当天，无法确定主力是在买入还是卖出。（出自第22节第4—5段）

判断答案要看第二天：如果次日能够迅速涨停，同时成交量低于烂板日，就说明分歧已经转为一致。由此可反推，烂板日更可能是主力在承接、散户或不坚定资金在卖出；筹码经过充分交换后，抛压减轻，后续更容易继续上涨。（出自第22节第4—5段）

因此，烂板本身不是买入结论，它只是"出现分歧"的事实；真正的转点确认来自第二天价涨量缩、快速封板或高开走强。（出自第22节第2、5段）

3. 案例与多转点叠加

第一组案例中，A柱涨停板反复打开多次，是严重烂板且明显放量。第二天仍能价涨量缩，形成控点，即烂板转点。（出自第22节第3段）

该股票此前还连续出现过两个大阴转点：一次大阴后休息一天，再以一字板完成转点；之后又出现大阴，再以价涨量缩完成反转；随后再叠加一次烂板转点。课程将其理解为连续三次"渡劫"成功，转点越多、强势确认越充分，后续上涨潜力越值得重视。（出自第22节第3段）

银宝山新案例中，A柱是近期最高量、反复开板的巨量烂板，盘面呈现沉重抛压。第二天却迅速涨停，证明烂板日主导承接的一方更可能是主力，随后形成烂板转点并连续大涨。（出自第22节第4段）

城市通案例中，A柱在收盘前约半小时持续烂板并放出巨量，第二天出现价涨量缩控点并继续上涨。该案例再次验证：前一天巨量分歧，第二天缩量迅速封板，代表分歧转一致，是牛股完成渡劫的一种方式。（出自第22节第5段）

4. 烂板转点与另外两种渡劫形态

课程归纳的三种主要渡劫方式是：

  1. 巨阴转点；
  2. 烂板转点；
  3. 炸板转点。（出自第22节第6段）

三者表现形式不同，但逻辑相同：前一交易日出现巨大分歧、恐慌或封板异常，后续却通过价涨量缩、快速涨停等方式恢复一致性。一旦转点成立，说明原本可能导致下跌的风险被强势化解。（出自第22节第1、5—6段）

5. 买入时机与风险控制

课程提到三种买入方式：

  1. 烂板当天尾盘买入：能够取得先手，但风险最大。因为当天已经放出巨量，如果第二天不能由分歧转为一致，可能出现较大亏损，因此课程并不建议一般交易者优先采用。（出自第22节第6段）
  2. 第二天集合竞价买入：这是更推荐的方式。巨量烂板后按常规可能低开；如果次日不仅不低开，反而直接高开，就属于超预期表现，可视为竞价买点。（出自第22节第6段）
  3. 涨停板确认时买入：等待第二天强势封板、转点基本确认后再参与，确定性更强，但买入价格也更高。（出自第22节第6段）

风险控制的核心，是不要把"烂"本身误当作强势。只有第二天高开、快速上涨、缩量涨停等行为出现，才能确认主力完成由分歧到一致的转换。（出自第22节第5—6段）

案例2（银宝山新）：A柱近期最高量、反复开板的巨量烂板，第二天却迅速涨停，烂板转点后连续大涨。（出自第22节第4段）
案例3（城市通）：A柱收盘前半小时持续烂板并放出巨量，次日价涨量缩控点并继续上涨。（出自第22节第5段）

💡 系统性总结

本节要点：烂板转点的逻辑链条是：涨停反复开板并放巨量 → 多空资金发生强烈分歧 → 主力承接、不坚定筹码卖出 → 次日高开或快速涨停 → 成交量缩小、分歧转为一致 → 牛股渡劫成功并延续上涨。
  • 形态前提：前一日是放量烂板，且最好处于三板以内。
  • 本质是分歧：烂板只说明大量买卖同时发生，不能当日直接判定主力方向。
  • 确认看次日：迅速涨停并价涨量缩，才构成烂板转点。
  • 可与巨阴转点叠加：连续多个转点意味着股票多次化解风险、持续超预期。
  • 竞价是优先买点：巨量烂板后不低开反高开，是重要强势信号。
  • 尾盘先手风险较高：若次日不能转一致，可能遭受明显亏损。
⚠️ 三大转点体系：本节为烂板转点，与第21节巨阴转点、第23节炸板转点逻辑相同，分歧转一致是其共同本质。
第23节 · 炸板转点

第23节 · 炸板转点

一句话核心结论：涨停后炸板且不回封放出巨量，次日却跳空高开+快速缩量涨停反包炸板高点，即炸板转点——三大转点中辨识度最高的龙头渡劫形态。（出自第23节）

📌 核心知识点

1. 炸板转点的定义与市场定位

炸板转点与巨阴转点、烂板转点共同构成课程所说的"三大转点"，是强势牛股在上涨过程中完成"渡劫"的关键形态。只要分歧被成功化解，股票往往继续走强，甚至连续涨停。（出自第23节第1、5段）

典型炸板转点通常出现在二板或三板阶段。股价先有首板启动，随后在第二板或第三板涨停后开板，收盘未能回封，即"炸板不回封"；第二天却再次涨停，反包炸板日的缺口或高点，并常形成价涨量缩，这一由弱转强的节点就是炸板转点。（出自第23节第2段）

原文中的"手板""回风""分期转移至"等转写，结合语义应分别修正为"首板""回封""分歧转一致"。（出自第23节第2、8段）

2. 炸板转点的本质

涨停后炸板，说明涨停价附近有资金大量卖出，多空出现显著分歧。按常规预期，炸板后股价应下跌或至少进行调整；但如果第二天直接高开、快速封板，并以更小成交量突破炸板日高点，就说明资金重新选择一致做多，走势发生超预期转折。（出自第23节第2—3段）

因此，"转点"同样包含两层转换：

  1. 资金由分歧转为一致；
  2. 行情由应跌、应调整转为继续上涨。（出自第23节第2—3段）

炸板日放量不是充分买入条件，次日能否高开、缩量、快速回封，才是判断分歧是否真正化解的关键。（出自第23节第2、4—5段）

3. 深圳华强案例

深圳华强是课程列举的2024年9月强势股。某日涨停后严重炸板，股价大幅回落，收盘未能回封，并放出近期最高成交量，表面上呈现强烈转弱信号。（出自第23节第4段）

但次日股价直接跳空高开并迅速涨停，成交量缩至炸板日约二分之一，形成价涨量缩的一日涨停控点。该表现说明炸板日的资金分歧已在次日转为一致，随后股票又连续约五个涨停。（出自第23节第4段）

这一案例说明，炸板越剧烈、放量越明显，次日若仍能以大幅缩量方式迅速封板，其超预期程度越高，转点信号也越有辨识度。（出自第23节第4段）

4. 大众交通与其他案例

大众交通同样先出现放量炸板，代表明显分歧；第二天却快速封板，成交量缩至前一日约三分之一，比二分之一缩量更明显。课程将次日视为绝佳买入时机，之后股价继续大涨。（出自第23节第5段）

启明信息案例中，股票连续两个涨停后，在第三板阶段出现巨量炸板；第二天直接跳空并迅速上涨，之后又延续两至三个涨停，再次验证炸板转点对强势牛股的识别价值。（出自第23节第7段）

另一案例是首板后第二天炸板，随后连续两个涨停并伴随一根假阴线。课程强调，不能脱离市场背景机械应用：炸板转点必须结合当下最强题材。当强题材中的核心股票炸板，次日又由分歧转一致时，才构成更有价值的买入机会。（出自第23节第8段）

5. 三大转点与龙头交易体系

课程将巨阴转点、烂板转点、炸板转点定位为捕捉牛股和强势龙头的"超级利器"。在没有龙头、适合低吸的市场中，可以更多运用极点；当市场存在明确龙头时，则重点运用控点和转点。（出自第23节第5—7段）

也就是说：

  • 极点更偏向无明确龙头环境中的低吸；
  • 控点与转点更适合强势题材和龙头股的主升阶段；
  • 三大转点专门关注龙头在上涨途中出现巨大分歧后，能否再次转强。（出自第23节第6段）

课程还要求至少寻找100个案例验证三大转点，目的在于通过大量复盘熟悉形态差异、题材背景与次日强弱，而不是只背诵定义。（出自第23节第10段）

6. 买入时机与安全性排序

炸板转点有三个主要买入节点：

  1. 炸板当天买入：要求交易者对当下热点题材和龙头地位有充分认识，可以取得最低成本和先手，但此时转点尚未确认，安全性最低。（出自第23节第9—10段）
  2. 次日9:25集合竞价结束后买入：若炸板后没有按预期转弱，反而跳空高开并呈高开高走倾向，说明市场超预期抢筹。课程认为这是安全性与性价比最优的买法。（出自第23节第9—10段）
  3. 次日重新封涨停瞬间买入：若竞价未买，可在反包封板时介入，作为最后的确认机会。确定性较强，但价格更高，也可能因上板过快而错失。（出自第23节第10段）

安全性排序上，课程明确认为第一种炸板当天买入风险较高，第二种竞价结束后买入综合性价比最高，第三种属于最后把握转点确认的机会。（出自第23节第10段）

本节要点：炸板转点的逻辑链条是：首板启动 → 二/三板涨停后炸板且不回封 → 放量显示巨大分歧 → 次日跳空高开或快速涨停 → 缩量反包炸板高点 → 分歧转一致、预期由弱转强 → 龙头继续主升。
  • 常见位置在二板或三板，前面通常已有首板启动。
  • 炸板必须是不回封或明显回落，从而形成真实的转弱预期。
  • 次日强势是确认核心：高开、快速封板、反包高点并价涨量缩。
  • 缩量比例越明显越有辨识度：案例中出现缩至前日二分之一、三分之一的情况。
  • 必须结合最强题材和龙头地位：形态不能脱离市场主线单独使用。
  • 最佳买点是次日竞价结束后：兼顾超预期确认、成本和安全性。
  • 三大转点服务于龙头交易：巨阴、烂板、炸板都是强势股化解分歧后继续上涨的不同表现。
  • 需要大量案例训练：课程建议至少复盘100个案例，建立对强弱、位置和题材的实战辨识力。

第24节 · 蓄势思维

第24节 · 蓄势思维

一句话核心结论：股价的一骑绝尘必然源自蓄势的量变积累，蓄势为因、趋势为果——这是量变质变定律在股市的应用，是后续所有牛股模型的哲学根基。（出自第24节）

📌 核心知识点

1. 蓄势思维的哲学基础

本节是额外补充的一节短课，但被定位为"非常重要"，核心是引入蓄势思维这一基础哲学框架，为后续学习所有牛股模型奠定底层逻辑。（出自第24节第1段）

蓄势思维的理论根基来自马克思的量变到质变定律：

  • 量变是质变的必要准备，任何质变必然是量变的必然结果
  • 没有充分的量变，不可能产生质变
  • 放在股市中：任何一只股票在上涨之前必须有足够的量变才能够产生一个质变
  • 这是一个"充分的过程"，而非偶然事件（出自第24节第2段）

2. 蓄势思维的生活化类比

讲师把这一原理推广到学习与工作层面：

  • 发财案例：看到一个人突然发财，不要只看结果，要研究他发财前的质变准备过程
  • 破产案例：破产这个质变结果，是由前面无数的量变累积导致的
  • 任何事情都不是一蹴而就的，前面必然有一个积累的过程，这就是蓄势思维的核心
  • 蓄势 = 积累过程 = 量变的过程（出自第24节第3段）

3. 因果定律：蓄势为因，趋势为果

根据因果定律：

  • 量变为因，质变为果
  • 要得到一个质变的果，必须去研究量变的因
  • 蓄势为因，趋势为果
  • 在股市当中：任何一只股票要大涨之前，必然经历充分的一个蓄势；然后才会产生一骑绝尘的上涨
  • 放在个人成长上：如果抱怨自己还没取得一定成就，本质上是量变累积的程度不够或没有充分的蓄势为未来的爆发做准备（出自第24节第4段）

4. 奥运冠军案例与持续成功的本质

  • 任何领域的冠军（如奥运会每一个项目的冠军），都是十年如一日的勤奋刻苦训练才可能得到冠军头衔
  • 老话：没有随随便便的成功
  • 所有的成功都因为前面有一个巨大的努力的付出
  • 如果一个"成功"前面没有量变的结果、没有产生量变，那这个成功是偶然的，无法持续，可能是昙花一现，就像股票一样（出自第24节第5—6段）

  • 为什么有些牛股能天天涨停、连续翻倍（涨2倍、3倍、4倍、5倍）？原因是因为前面做了足够长的准备
  • 这个思维会产生"醍醐灌顶"的概念，是对交易的巨大转变（出自第24节第7段）

6. 蓄势思维的核心定义与能量隐喻

蓄势思维的定义：

任何事物的发展不是一蹴而就的，股价大幅拉升之前必须经过一个充分蓄势的准备过程。

牛股的本质：

  • 都是主力蓄谋已久的爆发而已

案例：金融汽车

  • 这个准备过程叫做"蓄势"，是爆发前的积累

能量隐喻：

  • 任何爆发，必须是能量的累积与释放
  • 蓄势 = 能量累积过程（股票在内部积累能量、积蓄能量）
  • 上涨过程 = 能量爆发与释放（出自第24节第8段）

横竖哲学：

中枢来源：缠论的创始人"禅师"所创立的概念。

中枢定义：

  • 中枢分为上涨形态和下跌形态
  • 上涨中枢：在上涨过程中，有"上下上"或"上下上下"等结构，其中两段下跌所形成的共同重叠区间就是中枢
  • 下跌中枢：下跌过程当中两段反弹的重叠区间就是中枢

中枢的本质：

  • 主力刻意的洗盘区间
  • 把不坚定的筹码反复清洗
  • 等到再没有反抗力量之后，开始一骑绝尘
  • 中枢 = 夯实的行为（举例相当于压马路，需要不断把它压得紧紧的、压得实实的，然后才开始上涨）（出自第25节第2段）

2. 中枢的洗盘本质

  • 中枢的本质 = 多空双方反复激战（主力故意制造的分歧）
  • 中枢 = 主力的吸筹区间，把这些不坚定的人洗下车
  • 中枢 = 为主力蓄势准备的区间 = 蓄势未来的拉升
  • 下跌中的中枢：下跌过程中的两段反抗力量，主力用中枢把最后的反抗洗掉之后，继续暴跌

核心结论：

中枢是最重要的蓄势结构，主力反复震荡的目的就是把不坚定的人给洗下车，洗一次再洗一次，洗完之后一看没得洗了，就大涨。下跌也是一样，反抗力量反复洗干净了，然后继续暴跌。（出自第25节第3段）

4. 左峰的定义与压力反应

左峰定义：

  • 前期震荡蓄势后，必然要突破前期的这些高点
  • 这些高点就是左峰
  • 一般来讲，左峰就是最近的高点，也是最高的高点

左峰的压力反应：

  • 在左峰的时候，因为遭遇了左边压力，必然会做出反应
  • 反应三种结果：
    • 强力反应：往往直接空点上去（突破后直接拉升）
    • 稍弱反应：极点上去（洗盘后再拉升）
    • 最弱反应：暴力洗盘下转点上去（剧烈洗盘后才拉升）
    • 有时是巨阴转点

5. 左峰战略的操作要义

  • 等待它的：起点 → 痛点 → 转点
  • 这往往是真正抓住了主力的起爆点
  • 龙头股的起爆点就在左峰地方

核心结论：

股票所有最佳的买点都是在突破左峰附近的买点。（出自第25节第6段）

2. 零号蓄势结构的四部曲

零号蓄势结构的核心 = 四部曲 = ABCD模型

第一步：A - 供应耗尽

  • 散户全部跑光了，该卖的卖完了
  • 没有供应 = 没有卖压

第二步：B - 需求增加

  • 主力来了
  • 量价特征：价涨量增
  • 主力不会马上拉升，要先进行测试

第三步：C - 再次测试（供应筛选）

  • 测试一下散户是否真的走光了
  • 再次测试前面的主力、前面的散户也没走光
  • 测试成功

第四步：D - 需求正式发力

  • 主力正式进攻
  • 一轮上涨开始（出自第26节第3—4段）

3. 零号蓄势结构的图形详解

A阶段 - 供应耗尽：

  • 经过漫长的下跌
  • 量非常低（低量的极致）
  • 量非常小很小很小，缩到极致

B阶段 - 需求增加：

  • 主力开始发起
  • 开始放量、开始进攻、有量进来了
  • 量能特征：主力开始发起攻击

C阶段 - 再次测试：

  • 主力还要洗盘
  • 把前面没有绞杀干净的再次绞杀
  • 把所有不坚定的筹码全部洗出来
  • 测试完后，再次缩量，没有人在卖了

D阶段 - 需求发力：

  • 主力继续进攻
  • 增量进量、批量进攻
  • 过掉B柱的顶开始上涨（出自第26节第5段）

4. 四阶段的量价形态细节

A阶段（供应耗尽）的量价形态：

  1. 快速耗尽：连续暴跌时，出现阴天量大跌 → 价跌量增的尾声
  2. 慢速耗尽：慢慢跌、长时间横盘下跌、低量群（非常小的量）

B阶段（需求增加）的量价形态：

  • 倍量阳、高量阳、批量阳
  • 主力开始进攻
  • 价涨量增、倍量、高量、批量
  • 主力连续加大力度买入 → 需求增加

C阶段（再次测试/洗盘）的量价形态：

  • 连阴缩量
  • 出现缩量十字星
  • 一字星（一字群）或洗盘洗久一点
  • 慢慢的熬 = 供应衰竭

D阶段（需求发力/强势进攻）的量价形态：

  • 一旦供应衰竭 → 主力发现该卖的都卖完了
  • 继续发力 → 价涨量增、平量阳、增量阳、倍量阳、批量阳
  • 强势进攻、需求发力（出自第26节第6—8段）

5. 300座案例

300座的零号蓄势结构完美演绎：

  • A阶段：最低点开始下跌，量缩到极致
  • B阶段：开始有点量进来，这一天涨停板十倍量，然后连续批量
  • C阶段：洗盘，又再洗了洗，缩量缩到极致，小阴小阳
  • D柱：过了B柱的顶开始进攻

完美的零号蓄势结构：

先下跌 → 主力进来 → 二测试 → 这次进攻（完美的蓄势结构）

买入点：

  • 在过左峰的地方
  • 或在C柱起涨低点确认住的地方（这一天确认住）
  • 后面连续大涨

上涨的本质：

  • 这一档上涨不是凭空起来的
  • 是在A阶段已经耗尽了所有的卖家、所有供应全卖掉了
  • 然后主力悄悄进来
  • 进来之后再次洗盘
  • 然后再次发力，刚好趁着东风、趁着利好，一骑绝尘（出自第26节第9段）

6. 系统科学案例

系统科学（同样完美的ABCD模型）：

  • B阶段：开始倍量、批量进攻，主力进来了
  • C阶段：洗盘洗下去，洗到极致没有量
  • D阶段：发起进攻过左峰，天天涨停

额外信号：

  • 中间出现分歧
  • 第二天出现转点
  • 这就是标准的ABCD模型（零号蓄势结构）（出自第26节第10段）

  • C阶段：调下去，量一直缩
  • D柱：开始不断有新的价涨量增，一直拉高

  4. 开始走第三阶段（D阶段）（出自第26节第12段）

10. 四大蓄势密码体系

剩余的三大密码：

  • 一号蓄势结构
  • 二号蓄势结构
  • 三号蓄势结构

每个结构都可称之为蓄势密码，结构才真正体现出主力走势的特征。

记忆口诀（讲师强调要闭上眼睛都能记住）：

ABCD → A供应耗尽 → B需求增加 → C供应衰竭 → D需求发力（出自第26节第14段）

📊 关键判定标准：ABCD模型

阶段名称含义量价特征
A供应耗尽散户卖光了低量群 / 阴天量大跌 / 价跌量增尾声
B需求增加主力进场倍量阳 / 高量阳 / 批量阳 / 价涨量增
C再次测试洗盘测试连阴缩量 / 十字星 / 低量群 / 供应衰竭
D需求发力主力进攻增量阳 / 倍量阳 / 价涨量增 / 过B柱顶

🔍 典型案例

案例1（300座）：A阶段量缩到极致 → B阶段涨停十倍量后连续批量 → C阶段小阴小阳缩到极致 → D柱过B柱顶进攻。完美的零号蓄势结构。（出自第26节第9段）
案例2（系统科学）：A阶段量非常少 → B阶段倍量批量进攻主力进场 → C阶段洗到极致 → D阶段天天涨停。标准的ABCD模型 + 分歧 + 转点。（出自第26节第10段）
案例3：下跌到底后B阶段量开始放大 → C阶段量一直缩 → D柱不断价涨量增一直拉高。经典的ABCD蓄势结构。（出自第26节第11段）

💡 系统性总结

本节要点：
1. 终极蓄势结构体系（4个）：零号蓄势结构（基础，本节讲透）/ 一号蓄势结构（线下课）/ 二号蓄势结构（线下课）/ 三号蓄势结构（线下课）。
2. 零号蓄势结构 = ABCD模型 = 四部曲：A供应耗尽 → B需求增加 → C二次测试 → D需求发力（过左峰）。
3. 买入时机：突破左峰的位置 / C柱起涨低点确认的位置 — 这两个位置是最佳的起爆点。
4. 零号蓄势结构 vs 波浪理论：波浪理论：1浪-2浪-3浪（但不说前面要下跌）；蓄势密码：ABCD（前面有供应耗尽阶段，更完整）。蓄势密码远超波浪理论。

⚔️ 四、实战应用全流程

【第一步：选股】
  ↓ 战略筛选：寻找ABCD结构 → 蓄势充分 → 主升浪在即的标的

【第二步：买点判定】
  ├─ 强势龙头 → 转点买点（第21-23节）
  ├─ 上升途中 → 极点/双极控点（第14-15节）
  ├─ 突破左峰 → 左峰控点（第19节）
  ├─ 杀跌洗盘 → 大阴/极阴控点（第16-17节）
  └─ 测压阶段 → 单枪控点（第18节）

【第三步：买点执行】
  ├─ 稳健策略：尾盘买入（30%仓位）
  ├─ 果断策略：涨停板打板（全仓）
  └─ 激进策略：次日竞价（30-50%仓位）

【第四步：持有监控】
  ├─ 连续缩量创新高 → 坚定持有
  ├─ 顶部放量十字星 → 减仓1/3
  └─ 放量滞涨 → 立即清仓

【第五步：止盈/止损】
  ├─ 双平量顶部 → 主动止盈
  ├─ 破位大阴 → 立即离场
  └─ 跌破支撑 → 坚决止损（不补仓）

【第六步：复盘精进】
  ├─ 每周末：复盘本周所有操作，按26节框架归类
  ├─ 每月底：总结成功案例和失败案例
  └─ 每季度：补完所有控点的100案例库

💎 五、写给主人的擒庄心法

  1. 先有底层逻辑，再学技术形态——原理层（第1-3节）是地基，地基不牢一切技术都是浮云。
  2. 每课100案例，重复验证——这不是教学夸张，是擒庄秘籍反复强调的铁律。每个控点必须有100个真实案例支撑，才能形成"看到场景就能识别"的能力。
  3. 必须配合实盘，但先用模拟盘——开始时先用模拟盘验证，验证三个月稳定后再上小资金实盘。
  4. 控点系统化学习，不要孤立的点——擒庄秘籍的所有控点是一个体系，需要前后对照学习（如第12-15节正向控点、第16-18节反向控点）。
  5. 擒庄三密码要融会贯通——极点 / 空点 / 转点 是整课程的终极密码，所有买点都可以归到这三个里面。
  6. 蓄势思维是"道"，ABCD模型是"术"——前者告诉我们为什么，后者告诉我们怎么做。两者必须结合。
  7. 课程预告的"四个模型"是终极——擒庄秘籍不止26节，第26节预告的1-3号模型是线下课的高级内容，强烈建议继续深造。
