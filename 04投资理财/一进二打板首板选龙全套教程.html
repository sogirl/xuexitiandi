一核心共识：筹码好的十六字真经

这是全课程的第一性原理。68 篇文档无论讲择时、选股、买点还是心态，最终都收敛到这一条：筹码好。理解了它，后面所有章节都只是它的展开。

筹码好 = 缩量 + 窄幅震荡 + 均线粘合 + 轻松突破

十二字内核：原文亦称「十二字真经」——缩量 + 窄幅震荡 + 均线粘合 = 筹码好，而「轻松突破」是它的必然结果。这十六字是全书被反复背诵、去重后剩下的最简内核。

1.1 轻松突破的精确判定

  • 第一个涨停板的前一天，已经突破左侧压力（约半年时间跨度的左侧压力）；或
  • 第一个涨停板当天，只需涨一点点就能突破。
「轻松」是相对的（量化标准）：
· 涨 1%–2% 就能突破 = 轻松突破（极品）；
· 涨 8%–9% 才勉强突破 = 不轻松（打折扣）；
· 涨 20% 才能突破 = 严重打折，阻力极大。

1.2 极品筹码的「厚积薄发」四要素

四组量级越极端，筹码越极品：

  • 窄幅震荡的时间越长；
  • 窄幅震荡的幅度越小；
  • 缩量时间越长；
  • 各条均线距离越近（几乎成一条线）。

1.3 一个极其重要的认知纠偏：第几个板突破不重要

「筹码好」是唯一前提，第几个涨停板突破并不重要。有的第一个板就突破，有的第二、第三个板才突破（美邦股份、原中通客车），甚至处于「挖坑阶段」时把左侧压力忽略掉、就当它已经突破了。执着于「必须第一个板突破、必须突破左侧压力」会漏掉筹码极好的标的。

1.4 筹码好 = 龙头 = 每天新高、每天大涨

  • 筹码好是成为大牛股的最主要原因，可机械理解为唯一原因。
  • 筹码好比逻辑重要一万倍：逻辑是「讲故事」、是出货时别人替你安排的工具；一开始没人知道逻辑，长高了自然有人补逻辑；被逻辑绑架就错过牛股。
  • 选股公式优先级：筹码好（本质，第一位）＞ 非融资融券标的（最重要）＞ 价格低 ＞ 流通市值小 ＞ 个股逻辑、板块（明的，最不重要）。前三项是「暗的」（软件不直接显示，需自己判断），后两项是「明的」。
  • 完整涨停条件：轻松突破 + 流通市值小 + 价格低 + 非融资融券。

1.5 筹码好坏「程度」决定买不买、买多少

  • 首板可以宽容（买得低，只要突破第一个涨停板都能试）；但一进二越高、越靠后接力，越要求筹码极品（缩量、窄幅、均线粘合三个维度都要好）。
  • 筹码好坏的程度 → 决定「要不要买、买多少」；情绪好坏 → 决定「要不要空仓等待」。二者是全书两条并列主线。
  • 案例对照：电光科技（窄幅震荡 + 缩量，虽勉强突破但筹码好）＞ 新亚电子（宽幅震荡、上蹿下跳、无首板突破，筹码差）。

1.6 均线的本质

  • 均线 = 平均持股成本；均线都在脚下、K 线站上所有均线，就不存在均线下压的抛压——这是因果关系。
  • 256 线 = 年线（365 天刨去节假日后的纯交易日）。
  • 长期均线与短期均线距离越短，成本越靠近、越容易突破；距离越远，冲到该位置时越需要回调。
  • 均线粘合时大家成本一致、没有套牢盘抛盘，涨起来只有获利盘——这是最极品的筹码结构（浙江建投、天山乳业等老牛股均属此类）。

三择时：情绪周期 / 指数周期 / 四个时间节点

筹码好解决「买谁」，择时解决「能不能买、什么时候买」。择时是龙头高度的总闸门。

3.1 情绪是水龙头，高度是船

  • 情绪是总闸门：情绪好，水涨船高、龙头高度高；情绪不好，最高空间板也走不出来（华塑控股杀高标案例）。
  • 启动看筹码（80%），涨幅看情绪（80%）：筹码好决定「启不启动」，情绪好坏决定「涨幅高低」。启动是筹码的问题，涨多少是情绪的问题。
  • 情绪好 = 没有地天板、都一字 / 秒板；情绪不好 = 有负反馈、杀高标、跌停多 → 回避高标。
  • 情绪回暖转折点 = 转折龙头：分歧转一致转折点当天买，次日往往一字（买不到或买到即坑），本质是节奏 / 时间节点问题（华塑控股 8.13 案例）。

3.2 情绪的量价观测（两分法）

  • 用涨跌停家数判断情绪：上百只跌停 = 情绪不好、最高空间板高度降低、高位龙头（尤其补涨龙头）易一字跌停；没有跌停、跌停少时怼高标。
  • 看 15000 亿左右成交量判断情绪；情绪好筹码好的龙头（广博股份、粤桂股份、三维化学）总涨幅约 10 个涨停板高度。
  • 情绪周期批判（降维）：不要管复杂的情绪周期名词（「混沌期」是把简单问题复杂化），知道情绪好坏就够了。情绪好时「降智炒股」——大主升浪来临时不要当研究生，唯一关心这一波启动浪有多超预期。

3.2-补充 连板板块是市场温度计（竞价后第一步）

第二天早上 9:25 竞价后的第一步动作：打开「每日强势标的（连板）」板块，整体扫一眼判断当天情绪——它决定「今天情绪决定大势、决定仓位」：

很多低开绿色、出现一字跌停或接近跌停、-8 点开盘情绪退潮（迹象明显）防守为主、降仓、或高低切做低位首板

3.3 指数周期与大环境判断

  • 有大主流板块核心龙头引领保驾护航时 → 大干猛干（一字板多、确定性高、成功率高）。
  • 板块轮动、无大龙头、混沌期 → 休息，不追高、不接力、不买早上冲天炮（螳螂捕蝉黄雀在后）。
  • 指数弱势缩量 → 只能抱团辨识度龙头或空仓，题材越不持续抱团越强。
  • 大盘暴跌无利空 → 从资金面解释（配资爆仓被动清仓），但与首板突破模式无关，不影响做盘。

3.4 塞外书生的四个时间节点（择时总纲）

择时解决「何时做一进二」：每天的首板晋级率、炸板率、未来潜力空间都不同，并非每天都能参与，只在四个概率占优的时间节点出手：

  1. 情绪周期首日后的次日：小周期一般 3—4 天，其间板块个股以上涨为主；这天首板与情绪周期共振、未来潜力空间大；叠加大的题材共振，往往催生大龙头。例：10 月 31 日天鹅股份、11 月 24 日安奈儿 / 中交地产。
  2. 周期逆转的当日（冰点试错）：受深市异动次数监管影响，T 日 2 板往往不触发异动、走到 5 板才 2 次异动，利于吸引后续接力资金；本质是冰点试错。例：西安饮食（博弈次日情绪逆转而打 2 板）。
  3. 指数周期首阳后的次日：以上证指数为准，最理想是情绪与指数一起爆发；仅指数爆发、情绪一般，也可适度参与但预期要降低。例：次新龙头永泰顺。
  4. 三角形板块爆发的次日：集中爆发型题材「出道即巅峰」，随后每天淘汰赛；好的 2 板直接一字，部分 2 板给换手机会，尽快放量回封的都是参与机会。

3.5 六种节点龙（选时重于选股）

  1. 涨潮期超预期板；
  2. 涨潮期出利好的「先于龙」（四川金顶氢能源第一天先于龙竞价买）；
  3. 过节龙；
  4. 补涨龙 / 卡位龙 / 崩溃龙（龙头涨高后做补涨、低卡高的卡位、龙头首阴减一天节点的崩溃龙）；
  5. 退潮期回暖龙；
  6. 行情好的卡位龙。

3.6 龙头一生的三次分歧转一致

板块龙头 → 周期龙头 → 高潮博傻，三次分歧转一致对应上涨的三个台阶；每次分歧转一致都是买点，但位置越高风险越大。

3.7 地天板是「情绪大师」的专属时间节点

  • 地天板 / 大长腿必须抓情绪冰点、连续冰点的转折点（上塘路风格）。
  • 刚退潮时第一天做地天板会再跌停；前面已杀好几天、情绪冰点时做地天板才容易成功（康盛股份案例）。
  • 穿越 = 新题材股涨到半路时，顶着老龙头跌停的负反馈、与老龙头分离继续涨（周期衔接）。

3.8 监管决定龙头形态与两套持有规则

  • 不监管时：龙头连板、连续涨停、日内完成分歧转一致，一字板多买不到。
  • 监管时：断板反包、分歧加大时间变长，反而容易买到；共同特点仍是筹码好。
  • 两套持有规则：① 情绪不好、监管时——筹码好的龙头 N+N 板涨 1 倍基本见顶即卖；② 情绪好、不监管时——收盘不破 5 日线死拿，天空才是尽头。

四选股：逐条删除法 / 辨识度 / 最高空间板

选股是做减法，不是做加法。「无穷无尽的做加法，说明你内心着急，长远万劫不复。」逐条删除不合格项，剩下的就是标的。

4.1 选股框架总纲：五位一体

风格 ＞ 题材 ＞ 筹码 ＞ 流通市值 ＞ 分时抢筹（729 版排序）

等价表述：筹码好 ＞ 非融资融券 ＞ 价格低 ＞ 流通市值小 ＞ 个股逻辑 / 板块。

  • 风格是「暗的」（当下最强挣钱风格），它比明的行业题材更重要；看懂「暗风格」（10cm / 20cm / 30cm、高价低价、每天大阳线不停涨的图形）才能判断涨幅高低。
  • 风格案例：正丹股份打造 20cm 强趋势上涨风格后，20cm 赚钱效应一度优于 10cm；2024 年 7 月 29 日前大众交通又打出 10cm 连续上涨风格，主板与 20cm 纷纷模仿。

4.1-补充 市场定位前提（11月16日总纲的重要差异点）

市场定位（先定市场，再谈选股）：
· 北交所 30cm —— 做首板和接力；
· 主板 10cm —— 做一进二；
· 20cm（创业板 / 科创板） —— 持续性不行，不碰 20cm。

注意这是「最新提炼」与「历史内容」的关键转向：历史内容中 20cm 强趋势曾是主线（正丹、逸豪、杰美特），最新总纲已转向「20cm 持续性不行、暂不碰」；风格要动态切换——哪个风格挣钱效应最强就做哪个，不固执于某一风格。

4.2 逐条删除法（两套互补）

A. 塞外书生 10 条（1210，做减法的完整版）

序号标准删除 / 保留规则
1流通市值优选 100 亿以下（流通市值非总市值）；200 亿以上直接删；100—200 亿大部分删（除非板块龙一、形态优美、人气高、题材强）。
2股价一般 30 元以下（20 元以下更优），太高直接删。
3首板成交额不能太大，一般 10 亿以上都不好；例外是当日炸板回封、次日遇利好（中交地产 12 亿）。
4赛道股锂电池、储能等很少连板、多走趋势，直接删。
5股性看历史是经常连板还是经常断板，留股性活跃、有历史人气的。
6趋势股明显趋势型走法（步步走高但磨叽、少有连板、猛升后回落）直接删。
7题材预期三角形板块爆发次日多留其首板做 2 板；倒三角形爆发次日晋级很少、直接删；冷门题材删。
8K 线形态离上方套牢盘越远越好；同板块竞争时形态优势是关键。
9深市优先沪市一度因监管高度受限（最多 3 板），2 选 1 优先深圳。
10历史老妖老龙头再成龙仅约 20%，其首板 8 成时间可删，个别可留但要降低预期。

B. 龙头最佳射手删除清单（更凝练）

  • 非首板突破 → 删（N 形、跌下来反抽、宽幅震荡等，要么放弃、要么归入独立模式单独研究）；
  • 流通市值超门槛 → 删；
  • 融资融券标的（带 R）→ 减分；
  • 价格高 → 减分；
  • 筹码差（宽幅震荡、上影线多、放量）→ 删；
  • 无板块、无逻辑且筹码也不极品 → 删；
  • 没有更好的就空仓，任何时候都可以空仓等好机会。

两套删除法内核一致（都以筹码好 + 首板突破为第一标准、以做减法收敛标的），塞外书生版更细化为 10 条硬指标，龙头最佳射手版更强调「非首板突破一律删」的审美洁癖。

4.3 辨识度 = 最高空间板 = 官大一级压死人

  • 低位启动选龙头，最看重辨识度最高——新题材里多一个板、唯一最高空间板，就是「鹤立鸡群」，绝大多数资金都做最高空间板。
  • 低位叫「辨识度最高的」，高位确认后叫「龙头」；最高空间板也称先于龙头（先于板块打开高度的孤勇者）。
  • 筹码都不是特别好时，谁多一个板谁更可能成为新潜在龙头（与情绪好坏相关）。
  • 情绪好怼最高空间板（无跌停时），情绪不好回避（有负反馈时）。

4.4 流通市值门槛（次要但硬性的过滤项）

20cm ＜ 10 亿 · 10cm ＜ 20 亿 · 30cm（北交所）＜ 4 亿
  • 市值是次要决定因素，不是主因：决定龙头连续大涨的是「筹码好 + 板块强」（两项或占一项）。
  • 三种放宽 / 忽略的平衡：① 筹码好 + 板块当时最强 → 可放宽市值（大众交通、航天科技、中公教育）；② 筹码好 + 市值小 → 可忽略逻辑不正宗、能蹭题材（腾达科技）；③ 筹码好 + 市值小 → 可忽略无板块、不知炒啥的瑕疵（庄股抱团瞎炒）。
  • 反例：筹码不好、振幅大，市值再小也不碰（联动科技）；筹码好、市值大（大众交通、民德电子）也要坚决买。
  • 同板块、板块强、筹码相当的前提下，才优选市值小的；市值小但筹码不好也不买。
  • 放宽的具体数字：没有「市值又小、筹码又好」的标的时，可买「筹码好、市值稍大」的——10cm 三四十亿、20cm 15 亿左右仍可接受（大众交通、航天晨光这类 N 形，不机械要求市值小）。

4.5 筹码好的四种（五种）首板突破形态

  1. 极品飞机跑道型（正丹股份型）：缩量 + 窄幅震荡 + 均线粘合三方面都好，首板「旱地拔葱」直接突破左侧毫无压力，超级大龙头（至少翻倍）。
  2. 首板 N 形突破（大众交通型）：前面有过一个涨停回调很长时间，第一个涨停基本突破左侧压力。
  3. 超跌反弹筹码好（腾达科技型）：超跌过程中启动前缩量 + 窄幅震荡 + 均线粘合，忽略前面一段、看作首板突破（逻辑根本不正宗，但筹码好）。
  4. 大 N 形回调重启（航天晨光型 / 最多见）：前面涨过一波跌回起涨点、股性好，第一 / 二板可上车；超跌均线不粘合的往往受年线压制，第一次突破是假突破 → 回调 5 / 10 日线 → 第二次突破才是主升浪（博士眼镜、星星科技）。
  5. 挖坑不突破 / 次新横盘几天突破：美邦股份「挖坑又跌下来、平台又跌下来」，均线粘合后忽略左侧压力即算突破；次新需横盘沉淀足够久（筹码沉淀够、换手降下来）。

减分项：带可转债的股票是减分项（有大题材就没人做可转债、持续性不好）；次新股大部分时间不能碰——换手率高、上涨阻力大、「赔钱最快」。

4.6 龙头分级（729 版）

  • 大龙头 / 极品龙头：各维度都好，至少翻倍。
  • 板块特别强时的核心龙头（城门立木）：至少翻三倍。
  • 十倍龙头：可遇不可求，取决于板块纵深与分支是否支持核心龙头再走一波两波，需「走一步看一步」。

五买点：首板突破 / 一进二打板 / 竞价抢筹

三个买点构成一条买入链，是全课程的操作主轴。

首板启动买 → 二板接力打板胜出者 → 二板后 5/10 日线低吸缠打

对应龙头上涨三阶段：启动（靠筹码好）→ 中途（靠辨识度 / 市场地位吸引接力）→ 高潮（靠资金合力抱团）。

5.0 启动三重标准（11月16日总纲）

启动三重标准 = 轻松突破极品筹码 + 最强风格 + 竞价 / 9:35 前 90 度抢筹市场合力

三项同时满足，才是「启动」的完整确认：筹码好解决「买谁」、最强风格解决「买哪个市场」、90 度抢筹解决「何时下手」。三者缺一，启动的确定性就下降一档。

5.1 首板突破买（最早、最安全）

最安全暴利标准（做减法后的唯一标准）：
10cm + 板块强题材在线 + 非融资融券标的 + 筹码沉淀好 + 流通市值小 + 90 度抢筹一口气涨停 → 能看见就立即买。
  • 首板半路秘笈四要素：挣钱效应最强风格 + 板块在线 + 流通市值小 + 筹码好（筹码好是必备项，所有牛股的唯一共性）。
  • 「至少两项符合」宽容规则：筹码好 + 板块强（放宽市值）；筹码好 + 独龙 / 庄股（可无板块）。
  • 启动信号：盘中 100 万、200 万甚至几百万的单子 90 度抢筹。买一或买二出现几倍于前面成交金额的买单接住，同时至少几百万金额的大单连续直线 90 度抢筹——出现这个信号就要抢，等打板一般抢不到。

5.2 一进二打板（谁胜出打谁，客观确认）

  • 同身位 PK 客观化：首板买涨停最早的（一般次日竞价开最高）；二板起客观看「谁胜出打谁」，打板胜出者、失败者断板（3 / 4 / 5 板同身位 PK 同理），与首板买涨停早不冲突。
  • 优先日内龙：多股竞争晋级 2 板时，早盘最快上板并封住的潜力空间最大；但 2 板日内龙不一定是最终龙一，还需综合排除 K 线形态等不利因素。
  • 涨停早的多是量化抢筹（看不到 / 手慢抢不到），涨停晚的量化游资散户人工都买得到、换手好、人气好 → 反而易成抱团龙头。
  • 一字板强度＞换手：板块低位启动时一字板往往成龙头 PK 胜出继续涨，换手往往失败；一字买不到就第一时间买换手跟风龙头。
  • 10cm 为主、20cm 只是套利：主板一字涨停定方向 → 竞价看主板有一字，从创业板涨幅 / 市值排序找套利标的，第一天买 20cm；10cm 龙头能买到时 20cm 无套利价值、不接力。20cm 本质是跟风、不接力。
  • 一进二的定义：上一交易日以涨停板收盘，今天收盘前成功涨停收盘 = 「一进二成功」。

5.3 竞价抢筹（9:35 前解决战斗）

9:35 之前发现「低位的极品小美女」（筹码好 + 市值小 + 竞价 90 度抢筹）就立即抢 —— 顺人性、追涨但不追高
  • 竞价开最高、9:30 开盘就 90 度抢筹 = 龙头；上涨阻力大、上影线多、宽幅震荡、龙头涨停后才跟涨 = 跟风杂毛。
  • 竞价爆量判定：分歧预期 → 竞价承接转强 = 弱转强（可买）；一致预期 → 抢跑转弱 = 强转弱 / 坠机线（规避）。
  • 9:35 前解决战斗：作者本能更倾向首板二板低位、更果断主动，9:35 前结束交易（交易纯粹）。

5.4 一进二分时形态（海哥，六种分时形态）

形态分时特征参与方式
① 最强高开 5 点直线秒板 / 一字开炸板回封 / 高位大分歧回封在炸板回封位置打板（已确认强度）
② 较常见水下/水面开一波拉升；冲 5-7 点震荡后一笔上板；翻板炸开二次回封竞价爆量超昨日 8%-15% 则竞价参与一笔 + 板上确认，或直接打板
③ 换手板平开震荡拉升；震荡后下午秒板；尾盘直线板（最弱）只在板上参与；早盘爆量且逻辑正则开盘一笔 + 板上确认
④ 大长腿/地天板低开/跌停开拉升；水下震荡下午拉 15 点；地天板拉 20 点逻辑在 + 换手够 + 翘板处跟大单翘；回溯概率不到 10%

两个关键量能指标：① 竞价爆量 > 昨日成交额 8%–15%；② 回封时成交量达昨日 80%。

5.5 一进二五种内在逻辑（海哥）

  1. 挡刀：资金为引导行情方向，做一个快速拉升的二板引导当天方向。
  2. 留活口：板块阶段性上涨到中期，资金留一个小盘个股穿越打高度（补涨龙一般在此出现）。
  3. 跟风补涨：龙头打出高度后，资金挖掘低位同属性、题材重叠的小票蹭消息补涨。
  4. 消息加持：头一天多板块各出首板，当天某板块出利好，次日资金自然做该板块一进二。
  5. 独立预期差：并购、重组、收购或根本逻辑改变，独立于当前主线，更易走成周期类龙头。

5.6 五条「不打」风险（海哥）

  1. 板块内有快速涨停成龙一的不打龙二（全市场资金只参与龙一）。
  2. 板块内超过三个一字的不打该板块二板（你就是「龙 4」）。
  3. 同梯队涨停越靠前越好（昨天十个一板，今天 9:35 就上板的越快越好）。
  4. 集合竞价最后一笔单笔拉高 7-9 个点但无量、无题材历史、股性不好的不打（有资金恶意做竞价）。
  5. 庄股不打（分时走势非常难受）。

5.7 抓龙头核心：突破性缺口 + 丈量战法

主力目标价 = 缺口位 × 2　（口诀「高量不破，后市必火」）
  • 飞龙股份：前面高开 T 板后，长时间（一两个月）震荡始终没跌破 T 板最低价，这个低位突破缺口成为突破性缺口。
  • 更多案例：韩瑞工业（长时间震荡不破缺口）、科达制造、北方稀土（第一目标 15、回踩后目标 20、最高 24）。
  • 涨停基因的普遍规律：涨停-震荡-涨停-震荡、长时间箱体不破、多均线多头发散、涨了翻倍——说明前面已有涨停基因、主力之前就运作很久。

5.8 三种模式三种资金性质 + 中军平移

  • 10cm 连板——小游资、产业链资金参与（出发点坑人，高位容易一字跌停出不来），必须低位启动时买。
  • 10cm 强趋势上涨的中军（大众交通、金龙客车）——游资、大游资参与，比连板更安全、更有确定性。
  • 20cm 强趋势上涨 / 连板（青源 / 清源环境）——量化参与，量化只看当下、不看昨天涨跌。
  • 中军平移模式：锦江在线顶一字买不到 → 买同板块筹码好的中军大众交通；平移到 AI 眼镜：博士眼镜打开高度，卓翼科技、亚视光电顶一字，就买同板块中军创维数字。

六持股与卖出：5日线低吸 / 走一步看一步 / 补涨龙

6.1 两套持有规则（最关键的增量）

① 情绪不好、监管时：筹码好的龙头 N+N 板涨 1 倍基本见顶，一次反包涨到一倍左右就卖，切换下一个低位启动筹码好的龙头。
② 情绪好、不监管时：收盘不破 5 日线死拿，天空才是尽头（海能达连续穿越、双城药业连续涨停）。

6.2 不破 5 日线死拿 + 5 日线低吸

  • 龙头 5 日线上方分歧状态是买点、还会反包；抱团龙头是最大确定性、能对抗不确定性（跟风杂毛板块涨完、龙头涨 10 倍，跟风可能还亏钱）。
  • 卖出信号（两个）：高位出现大于 15% 振幅，或跌破 5 日线。
  • 跌停 + 15% 振幅两个信号同时满足 → 卖。
  • 总龙头（周期总龙头）至少涨三倍，不破 5 日线、不破 10 日线不卖（艾艾精工证明）。
  • 高位承接好因素越多越易承接：市值小、中间无连续一字（筹码不断层）、换手好、非融券标的（艾艾精工承接得住；克莱机电连续一字断层 + 融券 + 市值大 → 砸下来接不住）。

6.3 强者恒强：主升浪不碰 5 日线

强者恒强主升浪中，强者根本不碰 5 日线（大众交通、博士眼镜第一波），要第一时间无脑去买，不要等跌到 5 日线低吸——等低吸就买不到。

6.4 走一步看一步

  • 十倍龙头无法提前预判，只能走一步看一步：龙头上涨是「每天新高、每天大涨」，不预设立场、不活在未来。
  • 情绪好、不监管时死拿，就是「走一步看一步」的落地方案。

6.5 补涨龙 vs 跟风（时间节点决定）

  • 跟风「三碗不过岗」：龙头打开高度之前，下面跟风小弟最多涨 3 个涨停板（圣龙股份 20 板下面天龙、腾龙最多 3 板）。
  • 补涨龙头 = 龙头翻倍打开高度以后、首阴 / 断板的时间节点出来的相关小盘股，高度才相对更高（圣龙断板首阴时出的天龙股份；正丹翻 5 倍 10 倍后第一个补涨龙头涨幅最高）。
  • 补涨龙头也能接力、也能抱团，「只能首板买补涨龙不能接力」是错的（正丹后多个补涨龙、大科技分支龙都能抱团连续大涨）。
  • 但补涨龙头高位（一致后加速）不能接力（航天科技末端补涨龙头，首板二板错过高位就不看）；低位看出来买早买低才是对的。
  • 主升周期 三大阶段 × 三小阶段 = 九个小周期龙头，一个强主升阶段最多四轮补涨；所有补涨进高潮期 = 大阶段将结束、有出清。

6.6 分阶段买卖决策框架

  • 低位没涨够时：分歧、断板、盘中分歧、启动时果断买；中间：果断接力；高位：果断放弃。
  • 涨到高位不要抱有侥幸心理、不要去碰，才能躲开广博股份高位见顶天地板连续跌停。

6.7 买错处理 + 高低切换

  • 买错了当天被套，第二天不高开、不立即往上冲就立即扔掉，切最强。
  • 高低切换：必须等「高位出现极大亏钱效应」时（大众首阴时低位补涨一堆但不重要，因高位情绪还在延续）；只要高位一半以上健在，高低切节点就往后延。
  • 补涨龙头比高位龙头「多活一两天、多涨一两天」；周期末端：补涨一轮比一轮低，最后「1 进 2 都死」，龙头跌停或掉出 10 日线是周期末端表现。

七避开启动失败：错误本能清单

把「阻碍买龙头」的极端错误本能一一列出并破解，是知行合一的另一半。

7.1 三种排斥龙头的极端错误

  1. 看逻辑不正宗——短线情绪股就是「瞎炒」，一开始不要考虑逻辑正宗不正宗、业绩好不好；考虑这些会导致低位排斥不买、长高了又心痒痒去追。
  2. 看流通市值稍大（如大众交通）——市值是次要因素，筹码好 + 板块强可放宽。
  3. 看超跌均线压制、N 形二次突破就排斥——不要排斥「两次才能突破」的超跌 N 形启动（年线第一次假突破、第二次主升浪）。

7.2 完整错误本能清单

错误本能危害与破解
过于严格审美（完美主义）没有完美的牛股（正丹无板块、大众市值稍大、腾达逻辑不正宗）；等完美的，一万年不可能有 → 解放思想、实事求是：筹码好 + 资金认可看到就全仓干。
怕高躲龙头龙头启动时分时买点都让人害怕，本能怕高就万劫不复（怕高躲龙头 → 龙头涨停 → 追高跟风 → 被套割肉 → 恶性循环）。
买跟风熊出没（烂货横行）时乱买跟风杂毛，是赔光、腰斩最快的路。
追涨杀跌（标的错误）追涨杀跌本身必须做，但标的必须是龙头——追涨龙头 = 第一时间追（非追高），追涨跟风 = 赔光。
想结果 / 活在未来用上帝视角从结果看开始指导操作，但盘中要活在当下，不要预设立场后视镜后悔。
做加法无穷无尽做加法 = 内心着急 = 万劫不复。
主观判断题材本能觉得「这题材没什么可炒的」错误否定首板突破信号（山东矿机偏见导致错过）。
主观侥幸心理板块有消息 + 市值小 + 股性好但筹码就是不好，坚决不碰（新城市反面案例）。

7.3 易失败的启动形态（缩量脉冲坑）

日 K 线不是轻松突破、在坑里爬不出来、开盘第一分钟直线脉冲一两分钟、成交量不够、日线还是缩量的涨停——「缩量冲涨停容易，被量化砸盘容易失败，因为左侧尤其最近几天被套盘很难消化。大部分冲高回落涨停炸板都是这种不是轻松突破的、自不量力、筹码消化不够、9:30 开盘直线脉冲的。」

但启动失败即使冲高回落，5 日线附近支撑住基本上过两天就会涨回来（前提是筹码好）。

7.4 老妖二波陷阱

  • 老妖股老龙头主升浪结束、调整很长时间后妄想走大二波三板，容易出问题（大众交通、海能达、双城药业、常山北明）。
  • 主力正是利用「妄想大二波」的散户无脑接力二波反包三板。

7.5 破解方法

  • 每天背「筹码好立即就干，不要管逻辑正宗不正宗，不要管流通市值稍大」。
  • 定点爆破：从「知道」到「做到」之间，找出阻碍你的本能 / 心态（「业力」），用正确的东西把它「撵出去」，只剩正确的本能 = 知行合一。
  • 师出有名（分阶段看上涨原因）：启动靠筹码好 → 中途靠接力确认 → 高位靠资金合力 / 人气 / 市场地位；分阶段一清二楚才能启动主动买、涨高还敢买、拿得住不卖飞。

八进阶：抱团龙头 / 强者恒强 / 量化时代格局

8.1 抱团龙头 = 光杆司令、脱离板块

  • 脱离板块才称为抱团龙头，否则不叫抱团——龙头单兵突进、单独上涨、不带动板块。
  • 看板块选股会让你错过抱团龙头：大部分时间板块轮动不持续，但抱团龙头能穿越板块分歧连续上涨（连板或反包）。
  • 北交所 30cm 个股上涨基本与板块无关（艾融软件、天马新材、大地电气、聚星科技）；10cm / 20cm 与板块相关，独立者为庄股。
  • 板块驱动型股（上涨主因是消息刺激板块）在轮动期易坑人；筹码好的抱团龙头不受板块影响。
  • 指数弱势缩量 → 只能抱团或休息；题材越不持续抱团越强，抱团必须忽略题材和个股逻辑（杰美特做手机壳照样大涨）。

8.2 强者恒强 / 辨识度龙头

  • 强者恒强：主升浪中强者根本不碰 5 日线（大众交通、博士眼镜第一波主升浪），要第一时间无脑去买，不要等跌到 5 日线低吸。
  • 辨识度 = 最高空间板 = 官大一级压死人：做最高空间板的资金全市场最多，最高板发散带动板块和相关个股。
  • 连板 vs 强趋势 / N 形两大阵营，断板基本被淘汰（做连板资金断板就不看）。

8.2-补充 开拓者核心龙头 vs 模仿者 / 补涨龙头

龙头认知核心（贯穿全篇）：
开拓者核心龙头才能强者恒强、强韧有力、不坑人、反复不断上涨；模仿者 / 补涨龙头都是一波流，断板就完蛋。选股时要看清个股所处板块是「老题材末端补涨模仿者」还是「新板块新题材的开拓者」——后者才是真正要抓的核心总龙头。

高位趋同：高位品种会「趋同」——腾达晋级 10 板带动整个高位「分歧转一致」，同样处于高位的金龙、宗申、晨光、大众凭什么不可以？这些高位品种只是跑得快慢不同，根据竞价来选择，直到腾达见顶，情绪才会再次迎来较大分歧。

8.3 量化时代的格局变化

  • 量化成交量占比提高后，部分量价方法失效：历史上主力靠做多赚钱时下跌明显缩量，现在不明显。
  • 游资多选量化不易参与的股票（非转融通标的），这类股票量价分析（主力走没走）仍有效。
  • 涨停早的多是量化抢筹（看不到 / 抢不到），涨停晚的换手好、人工买得到——这改变了同身位 PK 的判断。
  • 10cm 短线连板太恶劣（天地板、一字跌停）→ 资金被虹吸到「不停涨涨不停」的 20cm 强趋势抱团（正丹、逸豪新材、杰美特）。

8.4 游资抱团 vs 量化抱团

  • 游资抱团（六一中路为首，夹杂小鳄鱼、养家、92 科比、呼家楼）：只拉核心标的不带板块（金龙汽车案例，什么都没带动）。
  • 量化抱团（围绕 300 创业板搞「大长腿」，香雪→博士眼镜、星星科技、广生堂）：量化龙头都是主力自己给自己抬轿子，每天都是新的。
  • 无脑接力资金（不怕赔钱头铁的人、踏空比赔钱痛苦的人）非常多，所以龙头会涨了又涨、超预期上涨；游资为流动性必须做高位龙头接力低吸缠打。

8.5 退潮期与转折点

  • 退潮期阶段划分：见顶后三四天是主杀期（A 杀），之后才是转折点。
  • 光杆司令（抱团龙头）在退潮期 A 杀最快，主跌期结束才谈转折点龙头。
  • 退潮期盯「往外切的新板块」，用一字板竞价引领发现新方向（新天科技案例）；一字板引领 + 各方面好 + 消息触发 = 可买点。
  • 高低切换：必须高位出现极大亏损效应才切换；高位一半以上健在则高低切节点往后延。

8.6 龙头与跟风的「反推」关系（分阶段理解，不可张冠李戴）

关系是反的、且分阶段：「一开始是龙头带跟风，龙头涨到高位了，需要跟风（新首板）反推它」，而不是永远龙头带跟风。把阶段搞反、张冠李戴，是徒弟最常犯的错。

  • 艾绒软件案例：最后两个 30cm 涨停板往前数第四天是天马新材启动（补涨龙头），天马新材连续快速涨停反推艾绒软件，又涨 2 个 30cm 涨停。
  • 正丹股份案例：涨到高位后脱离涨价逻辑，上涨主因变成「龙头市场地位引领整个 20cm 最强挣钱效应风格的总龙头」，补涨小弟不断反推正丹几波上涨 10 倍。
  • 操作含义：龙头弱时，小弟（一字板 / 补涨龙）会反推龙头反包，此时应坚定买「轻松突破的小弟」，而不是去追已经滞涨的老龙头。

一句话主线：换手达标 + 幅度适中 + 形态良好 + 主流题材 + 非次新 / 非庄股 = 量价共振的关注点，条件不符风险大、宁可错过。

  • 逆袭卡位要谨慎：「10 卡 9 死」——首板排位靠前、次日反转为小弟卡老大，场外资金不服、分歧分散易炸板；次日打 2 板最好选「首板老大到 2 板仍最先上板」的顺延股。

  • 一切皆是概率：资金受盘面消息影响无法预测全天走势，没有任何方法完全避免炸板，必须建立概率思维——没有确定性，只有概率游戏。

十心态与知行合一

10.1 心态总纲

  • 忘掉上一笔、活在当下：不预设结果、不活在未来、不后视镜后悔。
  • 宠辱不惊、冷血杀手：凡墙皆是门，宠辱不惊做好每一笔。
  • 心态归零：每一次交易都是新的一笔，不与任何人比、不定目标。
  • 归零与冷血杀手：每天账户都从零看，不以物喜、没有悲喜；挣钱了不能高兴，赔钱了也不能不高兴——高兴和悲伤的效果一样，都是情绪波动。要做没有情绪的「冷血杀手」。
  • 资金来源切割：钱是借的、自己的、刷信用卡的，与「能否出手」的判断无关，一码归一码，别让资金来源带来压力。

10.2 具体心法

  • 远离鸡群：不看股评、不跟原有人群谈股票，努力不是鹤立鸡群而是远离鸡群。
  • 艺不压身、不怕错过：各种模式都看明白才不怕错过；怕错过 = 下手晚 = 最要害。
  • 交易纯粹：9 点 40 / 45 就结束交易，好龙头早早就涨停，倒推必须这样操作才能轻松挣钱；收盘三点尽早交流、复盘。
  • 宁可错过、不要侥幸：情绪不好、没有好标的就空仓，「一定要淡定、宁静致远」，任何时候都可空仓等更好机会。
  • 解放思想、实事求是（类比邓公）：市场认可和自己冲突时要解放思想服从市场，不主观预设。

10.3 仓位与执行纪律

  • 满仓标的必须满仓（如精伦电子八连板时就是满仓去干的）；一个月抓两次满仓标的就够了，还不累。
  • 分仓原则：下不去手就分仓；可买可不买的分仓买也还行；但满仓标的必须满仓。
  • 不交易的控制：「跟我没关系、不出手」比技术更高阶；不买就不亏损。
  • 100 股试验法：先买 100 股试验、照样割肉、最后连 100 股都不买——一旦发现 100 股都赔钱，一下就改过来了。
  • 打猎比喻：做交易像打猎，不要乱开枪；想打到老虎，就得放过兔子；标准越严越容易尝到甜头，形成正向循环。
  • 守中 / 临界点：龙头出现时全仓干不能错过（错过是灾难）；但没等龙头出现就把子弹打光是提前（也是灾难）；「不能提前、也不能错过」。

10.4 直觉与第六感

  • 第六感 / 直觉是大脑里存了很多正确东西后产生的灵感；脑子里全是错的东西，直觉也是错的。直觉正确的前提是「脑子里的库存正确」。
  • 相信第一次的判断（第一直觉），具体问题具体分析。

10.5 知行合一（从知道到做到）

  • 这些知识很简单，做不到就是人性的错误本能；需要自己清晰认识哪些是错的，然后解决掉错误本能。
  • 定点爆破：找出「知道」到「做到」之间的障碍（本能、心态、业力），用正确的东西把错误的「撵出去」。
  • 反复输出、提炼成几个字，最后形成直觉，一看对上眼就干。
  • 情绪是虚假的、是错误的，该出手时必出手，不该出手时不出手，不能让情绪指挥操作。
  • 引用《中庸》「喜怒哀乐之未发谓之中」——用中情绪、恰到好处执行。

十一终极系统性总结 + 学习路径

11.1 一句话总结

在情绪允许的时间节点上，找到「筹码好（缩量 + 窄幅震荡 + 均线粘合 + 轻松突破）」的龙头，用首板突破 → 一进二打板 → 竞价抢筹三种方式第一时间买入，不破 5 日线死拿（情绪好）或涨一倍见顶即卖（情绪差 / 监管），全程用「错误本能清单」纠偏，进阶到抱团龙头与强者恒强。

11.2 三层体系（回顾）

  1. 认知层（为什么）：筹码好是第一原因、逻辑不重要；风格＞题材；辨识度 = 最高空间板。
  2. 执行层（怎么做）：择时 → 选股 → 买点 → 持股卖出。
  3. 心法层（做到）：错误本能清单 + 心态归零 + 知行合一。

11.2-补充 核心框架七大支柱（12月11日版，胜利模式总纲）

  1. 唯一标准：筹码好（缩量 + 窄幅震荡 + 均线粘合 + 突破）是牛股唯一共同特征，其余维度一律放松。
  2. 启动信号：90 度大单抢筹分时图（100 万 / 200 万 / 几百万单）是必备；竞价到 9:35 前确认合力认可。
  3. 买入动作：首板半路 → 一进二 → 二板后 5 日线低吸缠打；首板或一进二全仓干。
  4. PK 规则：首板买涨停最早的，二板起「谁胜出干谁」，客观确认不押宝。
  5. 择时：只看情绪好坏 + 监管状态 + 指数量能；抓最强挣钱效应「暗的风格」。
  6. 持有 / 卖出：5 日线为生死线，高位翻倍后看 15% 振幅；低位买、中位接力、高位放弃。
  7. 心理纪律：克服过于严格审美、怕高、完美主义、活在未来等错误本能，把细节刻成画面挂图作战。
