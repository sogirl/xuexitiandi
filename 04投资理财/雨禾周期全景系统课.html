第1节周期全景导学：四大周期核心定义与研判标准

📌 核心命题

  • 周期不是线性的，而是立体的、循环的、有规律的——这是整套课程的底层哲学。
  • 本课的核心主题是研究"周期之间的关联"，而非孤立看待某个周期。
  • "横看成岭侧成峰，只缘身在此盘中"——只有跳出个股，站在更高维度，才能看懂市场全貌。

🔑 核心论断：四个周期"不能画等号"

  • 板块 ≠ 指数
  • 个股 ≠ 板块
  • 个股涨跌 ≠ 市场情绪
  • 必须分别研究再综合——把不同特征归结于各自周期，再综合结合，站在多维、立体的角度看市场。
⚡ 重点这一板块是整套课程的骨架。难点在于"综合结合"的立体思维训练。

🏛️ 板块周期深度解析

  • 板块本质：团队，对个股起支撑、辅助、助力作用。个股=个人，板块=团队。
  • 板块 vs 题材：题材=事件，板块=发酵后的团队。事件→发酵→团队→板块（陈桥兵变→领头人→板块形成）。
  • 两种发展模式：
    • 倒金字塔模式（白手起家）：个股龙头先涨，慢慢带动板块发酵
    • 金字塔模式（大规模集团）：板块集体启动，一上来就是涨停潮
  • 活口机制：周期结束后残留个股/题材，可能引领下一周期（如《三国演义》匡扶汉室的活口）。

💓 情绪周期深度解析

  • 钟摆原理：在最左边（极度恐惧）→ 快速摆向右边（贪婪）；在最右边（极度贪婪）→ 快速摆向左边（恐惧）；中间停留的时间很短。
  • 经济学原理：经济运行不断在偏离本身价值之间摇摆，很少停在中间位置。
  • 实操价值：知道什么时候全力一波（all in）、什么时候空仓、审时度势做防守还是进攻。
  • 依据：统计学——情绪周期不是"我感觉"，是从过去的数字、历史上统计出来的规律。

📈 个股周期深度解析

  • 产业链炒作顺序（以碳中和为例）：公司本身→上游原材料→中游制造/代工/生产→下游应用端/销售→末端废物利用/回流。
  • 股价走势周期：发展期→试探期→主力建仓→试盘拉升→主升浪→再辉煌→回落。
  • 龙头之争：两个龙头有竞争，谁成为最后的龙头由市场资金和人气的选择——不做预判，只做跟随。

📌 核心命题

  • 启动期最具价值的判断标准：板块集体异动 + 概念认知统一 + 梯队完整。
  • 分歧期最具价值的判断标准：烂板弱转强 + 爆量分歧 + 强势封板 + 接力进攻。
  • 加速期最具价值的判断标准：甩开跟风 + 筹码断舍离 + 加速板+缩量一字。

📊 启动期 vs 分歧期 vs 加速期 三大上车时机

阶段上车方式关键信号
启动期龙头打板、二板低吸板块集体异动、概念认知统一、梯队完整
分歧期分歧打板大分歧换手（2-3倍）、烂板弱转强、爆量分歧+次日弱转强
加速期加速低吸甩开跟风、筹码锁仓、加速板+缩量一字

📋 启动期判断的3个核心问题

  1. 市场认知统一了吗？——少数资金炒作 vs 大众认知
  2. 梯队完整了吗？——龙头、中军、跟风是否都启动
  3. 机构进场共振了吗？——机构资金是否同步流入
⚡ 买入策略：4种方式
  1. 启动期打板：龙头打板、二板低吸
  2. 分歧期打板：分歧打板
  3. 分歧期低吸：加速低吸
  4. 弱转强打板：分歧→加速节点的转折

口诀："启动打板，分歧打板；分歧低吸，加速低吸。"

第7节人气龙头分歧：放量分歧与上车机会
🔍 双指可放大

📌 核心命题

  • 分歧不是风险，分歧是机会。只有换手充分，新资金进来才有上车的可能。
  • 启动期到分歧期的过渡是大概率事件——一个龙头不出现一次大分歧很难走下去。
  • 分歧的三大类型：前期分歧（建仓性质）、分歧期分歧（最重要）、加速期分歧（防A杀）。

📊 分歧类型详解

分歧类型特征机会等级
前期分歧0-3板内分歧，主力建仓性质良好
分歧期分歧龙头分歧，跟风集体跌停⭐ 重要
加速分歧5板/7板分歧，龙头跌停/巨阴注意风险
高位分歧加速后分歧，首阴回封/放量小仓试错

🎯 分歧期四上车时机

  1. 首次大分歧+烂板（最经典上车点）
  2. 烂板次日弱转强（情绪转折）
  3. 加速期分歧T板（高位博弈）
  4. 高位首阴回封（反包博弈）
