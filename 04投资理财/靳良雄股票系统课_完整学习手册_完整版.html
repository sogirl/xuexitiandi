第01节 CBN+++盘面真面目

深度总结

一、课程开篇：体系定位

靳良雄老师在德才苑开篇定调：本课程教授的是"可预见高确定性、高获利的三大盈利模式"完整体系。强调讲解语速较慢，需要耐心听讲。

二、CBN和三个加号的含义

  • CBN：超短线（C）、大波段（B）、主升浪（N）三种盈利模式的英文缩写
  • 三个加号（+++）：最高级玩法的标记
  • 盘面真面目：CBN不是普通玩法，而是同类模式中"最高级"、"涨幅最大"的演化形式

(出自第01节 第6段)

三、两大体系构成

课程体系由两个部分构成：

  1. 价值动能——与价值投资有关的体系
  2. 量价动能——与投机有关的体系

两大体系是融合的，对市面上"传统价值和传统技术形成双复合双砂体"的情况给出解决方案。

四、八大维度

实现两大体系依靠八大维度：

  1. 资金
  2. 分时均线
  3. K线
  4. 成交量
  5. 换手率
  6. 结构级别
  7. 板块轮动
  8. 大盘政策

按可见性分类：

  • 盘面可直接观察到：分时、K线、均线、成交量、换手率
  • 需通过推演得出：资金性质、资金结构级别、板块轮动、大盘

(出自第01节 第8段)

五、六大预判

通过八大维度实现六大预判：

  1. 大盘缓冲预判
  2. 长期趋势预判
  3. 板块轮动预判
  4. 龙头个股预判
  5. 涨跌时间高度预判
  6. 买卖时机（成熟度：何时启动、启动点、防几波、强度涨得快还是慢、强不强）

第六个预判包含5个细节：

  • 何时启动
  • 启动点
  • 防几波
  • 强度（涨得快还是慢）
  • 强不强
  • 买卖时机

(出自第01节 第10段)

七、三大盈利模式详解

模式A：超短线（3种战法）

战法1：99式——连板涨停

  • 个股特征：连续上涨一大波
  • 形态：一字板 → 后面放量（小熟练→再放量）
  • 适用：连续涨停的超短龙头
  • (出自第01节 第16段)

战法2：969式——空中接力

  • 99含义：前面的单边上涨
  • 6含义：横盘
  • 9含义：连续大涨
  • 战法名：高空接力
  • 操作的是"9"——横盘后连续大涨这一段
  • (出自第01节 第18段)

战法3：96式——地天板涨停（猛龙）

  • 形态：4板后一字板跌停 → 这里买入 → 享受后续上涨
  • 另一种：3个涨停后跌停板 → 做后面这一步
  • 特点：暴利股模式
  • (出自第01节 第20段)

老师提醒：为什么这些股能这么涨？"我们在买之前也不知道它能够连续上涨，但是我们有我们的判定方法。"

模式B：大波段（3种战法）

战法1：游资波段

  • 形态：连续上涨后进入横盘
  • 关键：横盘时就有标准验证后续是否有行情、能涨多高
  • (出自第01节 第20段)

战法2：主力波段股

  • 形态：一轮下跌 → 波段止跌 → 形成大波段
  • 标准覆盖：波段确认、中间持股、波段顶部分析
  • (出自第01节 第20段)

战法3：战略行情的波段

  • 定义：大市值核心板块、核心龙头、高级别个股
  • 适用资金规模：千万级、亿级资金
  • (出自第01节 第22段)
模式C：主升浪（3种战法）

战法1：快速涨停板建仓的主力资金主升浪

  • 主力资金组成
  • 我们做的是"后面这一段"（重仓大幅上涨）
  • (出自第01节 第22段)

战法2：隐蔽建仓的主力资金主升浪

  • 特征：前面有震荡 + 有推升
  • 全轨迹可预判：调整时间、周期
  • 适用：进入牛市的一轮主升浪
  • (出自第01节 第24段)

战法3：战略资金单边组成浪

  • 定义：大级别行情
  • 实战案例：宁德时代、长城汽车、比亚迪、阳光电源等
  • 战略资金集中在某一个大的行业建仓
  • 通过盘面轨迹可预判：未来上涨的时间、周期和高度
  • (出自第01节 第26段)

三、传统认知错误拨乱反正（重点）

错误认知1：鸡蛋不放在一个篮子里

错误传统解读：把鸡蛋分散放在多个篮子里更安全。

正确解读：

  • 重点不在鸡蛋，而在篮子本身和提篮子的人
  • 篮子本身有洞，多少鸡蛋放进去都会摔掉
  • 提篮子的人不小心摔了，鸡蛋也破
  • 结论：选股是第一位的

(出自第02节 第6段)

错误认知2：止盈止损只看数字

错误传统做法：

  • 亏损5%止损
  • 赚了10%止盈看账户

真实场景举例：

  • 买入后洗盘下跌8% → 5%止损 → 第二天涨停 → 后续主升浪（止损错的）
  • 刚涨10%心慌卖出 → 后续大幅上涨主升浪（止盈错的）

正确做法：

  • 不以盈亏定买卖
  • 不看账户，要看标准
  • 标准依据：八大维度对盘面理解的标准

(出自第02节 第8、10段)

错误认知3：贪婪和恐惧是失败主因

常见错误归因：

  • 没卖→亏了 → "我太贪了"
  • 涨了一点就卖 → "我太恐惧了"

老师纠正：

  • 贪婪和恐惧是人性，但不足以成为失败的理由
  • 真正的问题：没有具体执行的标准，即看盘标准
  • 重点：不以盈亏定买卖，不看账户看标准

(出自第02节 第12、14段)

政策层级对比：

政策类型影响范围行情级别
国家战略政策国家级最高驱动资金、最大行情
大行业政策大行业大级别上涨
小行业政策小行业小级别上涨
公司政策单个公司单一标的行情
突发重大事件视情况而定视情况而定

关键洞见：

  • 战略政策（国家级的）一般适用于科技类大行业
  • 传统行业（如纺织）一般只有行业性政策，很少有国家级战略政策
  • 公司政策是特例，只影响该公司的股价

(出自第03节 第6段)

三、政策与资金的隐喻

"政策为风，资金为水，政策越大风越大，吹的资金越大，风吹水水成事。"

核心逻辑：

  • 政策 = 风（决定方向和力度）
  • 资金 = 水（被政策吹动）
  • 风越大 → 推动资金越大 → 形成的行情级别越大

直接判断标准：

  • 政策大 + 资金大 → 大级别行情
  • 政策小 + 资金小 → 小级别行情

(出自第03节 第6段)

四、研究政策和背景的本质

"实际上研究政策和背景，主要是研究什么方向和风口。"

核心命题：选择大于努力

经典论断：

"一个时代一个特殊的经济背景，造就一类行业大发展，成就一类持续发展大公司，催生一类长周期的大盘回升行情。"

三要素联动：

  • 时代背景 → 行业大发展
  • 行业大发展 → 持续大公司
  • 大公司涌现 → 大盘回升行情

(出自第03节 第8段)

五、时代背景案例：WTO时代

事件：WTO以后外贸订单暴增

传导链条：

WTO → 订单暴增 → 制造业大发展 → 需要人/设备/材料/土地<br> ↓<br> 人口大流动 → 城市化<br> ↓<br> 城市化 → 住房需求 → 房价大涨

当时受益行业/标的：

  • 房地产（买房的都赚到钱）
  • 房地产股票（黑马辈出，涨得非常好）

结论：在那个时代背景下，买入房地产股票就是"选择大于努力"。

(出自第03节 第10段)

六、时代背景案例：科技时代

国家战略：经济结构转型——从粗放型走向高质量发展

目标行业：科技

科技行业的三大特征：

  1. 科技性大变革的行业（技术变革驱动）
  2. 全球竞争性行业（国际竞争）
  3. 科技制高点也是支柱产业（战略意义+经济规模）

替代逻辑：哪个行业能逐渐替代房地产这种"经济支柱广泛的大市场"？

资本动向：

  • 产业资本大量进入
  • 各地招商的热点争抢
  • 容纳大资金

总体判断：现在被写入国家战略的一些科技行业：

  • 有些现在表现不充分
  • 有些早就开始表现

(出自第03节 第12-14段)

七、实证对比：站对方向 vs 站错方向

对比图表（盘面表现）：

方向表现行业代表

站错方向一路下跌房地产

关键结论：

  • 站对方向：随便选择一只股都能长得很好

  • 两种结果是天壤之别

## 板块一：游资的识别与行情特点

深度总结

1. 资金的分类与传统认知差异

靳良雄老师开篇指出，我们把资金性质分为三类：

  1. 游资
  2. 主力资金
  3. 战略资金

与传统分类的核心区别：

维度市场上分类本课程分类
类别数量一般分两类（主力/散户）三类（游资/主力/战略）
关注点"主力"单一概念三类代表"操控资金的人的性格"
用途判断有无主力预判演化趋势、涨跌时间和高度

三大资金的核心差异：风险承受与投资收益目标不同 → 盈利模式不同 → 操作的个股不同 → 盈利目标不同。

(出自第04节 第4段)

2. 资金性质分析的功能
"资金性质分析要实现哪些功能呢？我们要前瞻性描绘股价动态运行的画面。"

即：一看到资金性质，脑子就要知道这个股的演化趋势。

具体功能：

  1. 预判股价运行轨迹和演化趋势
  2. 预判涨跌时间
  3. 预判涨跌高度

与传统资金分析的区别：市场上"普遍认为的资金分析"只看是否有主力，本课程要做前瞻性预判。

(出自第04节 第6段)

3. 游资的三大特点
  • 敏感性强
  • 机动性强
  • 突发性强

(出自第04节 第6段)

4. 游资题材炒作的三大特点
  1. 引导热点
  2. 热点转换
  3. 顺应主流板块

关键提醒：在主流板块趋势向上背景下的短线炒作要注意伪题材套利出货。

(出自第04节 第8段)

5. 游资的特征进一步分析

风险收益特征：来得快 → 去得快 → 风险大 → 收益也高

触发依据：

  • 政策热点事件刺激
  • 重大确定性事件
  • 超预期政策
  • 往往能出现大牛股

协作关系：主流板块趋势向上的行情，与板块中军蓝筹趋势协同的板块里有短线炒作。

(出自第04节 第10段)

6. 游资盘面实战识别

典型案例：

  • 短线突击炒作案例（类似证券板块的行情）：虽然不大但有波行情
  • 龙版传媒：典型的短线资金炒作
  • 盘面特点：来得快、去得快、稳定性差
  • 没有中长期结构和级别的趋势性行情

盘面识别要点：

  • 炒作时间短
  • 行情快
  • 暴涨暴跌
  • 稳定性差
  • 没有中长期结构和级别的趋势性行情

(出自第04节 第12段)

7. 游资盘面的关键指标：换手率

建仓期换手率：

  • 突击建仓往往大于20%
  • 一般情况下超过10%

读法：换手率超过10%-20%，一般是游资短线，易连板拉伸。

特点：

  • 成交量绝对量大
  • 攻击性强
  • 顶部形成快
  • 操作完以后容易大幅下跌

(出自第04节 第12段)

8. 游资炒作的三种演化趋势

根据行业属性和资金强弱：

  1. 直接炒单边（直上直下）
  2. 炒到这里横盘后跌下来
  3. 涨上去以后横盘又上去

(出自第04节 第14段)

9. 游资的两种识别信号

信号1：大的换手 + 涨停板

  • 强势 → 游资抢筹、参与

信号2：两个、三个连续涨停板（哪怕换手率不高）

  • 也可视为游资短线炒作

重要区分：主力也做连续涨停板，主力做主升浪也有连续涨停板，但：

  • 底部两板建仓时换手率很低 → 主力的资金突击建仓
  • 后期换手率变高 → 这里就是游资炒作

(出自第04节 第14段)

10. 游资炒作的整体特征总结
维度特征
行情启动起得快
稳定性很差
顶部形成时间快
下跌幅度比较大
下跌时间长
与主力区别有差距

结论：只要看到换手率高（盘中）或连续涨停2-3个（哪怕换手不高），都可视为短线炒作信号。

(出自第04节 第16段)

系统性总结（板块一）

游资是短线题材炒作的资金代表，三大特点（敏感/机动/突发）决定了其来得快去得快的高风险高收益特征。识别关键在于换手率（10%以上，突击建仓20%以上）和连续涨停板两种信号。要警惕伪题材套利出货，特别是在主流板块趋势向上背景下的炒作。三种演化趋势（单边/横盘跌/涨后横盘再上）覆盖了游资行情的主要形态。

## 板块二：主力资金的识别与特点

深度总结

1. 主力资金的整体特征

思维特点：

  • 更注重基本面
  • 眼光稍微长一点
  • 多布局预期较高的行业
  • 看重基本面和政策面

(出自第04节 第16段)

2. 主力的两种建仓方式
  1. 隐蔽建仓
  2. 强势快速建仓（涨停板建仓）

买入逻辑：经过充分调研 → 决定买入 → 盘面体现两种模式。

(出自第04节 第16段)

3. 主力的运作模式

典型流程：

  • 主力买入 → 潜伏运作 → 最终拉高套利
  • 触发拉高的时机：热点事件刺激催化
  • 卖出方式：拉伸实现大幅获利卖出

本质：打有准备之仗，前面收集足够多筹码 → 趁政策、趁风时拉伸兑现。

(出自第04节 第18段)

4. 主力放弃的特例
"主力也有运作中途放弃的个股。"

例如：调研后发现公司并没有预期的那种潜力 → 主力中途不运作 → 撤出 → 没有主升浪。

(出自第04节 第20段)

5. 主力资金识别的核心指标体系

指标1：建仓期换手率

  • 一般不超过10%
  • 超过10% → 多半是游资小盘股

指标2：成交量

  • 相对较大

指标3：涨停建仓

  • 涨停建仓是强势主力
  • 但建仓换手率也不会超过10%
  • 整个盘面（运行过程中）的换手率一般不超过10%

指标4：运作市值

  • 一般50亿左右（市值规模不决定）
  • 大的100多亿也能被主力做
  • **太大（上千亿）主力无法控盘去做主升浪，那种是"协同"的）

指标5：股价

  • 一般5-7元（不绝对）
  • 十几块钱的也能连续拉板

(出自第04节 第22段)

6. 主力盘面的全轨迹

盘面可以洞察主力：

  • 建仓
  • 震荡
  • 洗盘
  • 突破
  • 拉升

全轨迹可见，是技术分析的重要依据。

(出自第04节 第22段)

7. 主力运作前后的特征对比

未主升浪前：

  • 小的波段一点点比较多
  • 也有横盘不跌、中间也没有波段的
  • 稳定性非常高
  • 持续性较强
  • 运行时间较长

时长：一般从建仓、洗盘到拉伸之前的时间2到5个月。

(出自第04节 第22段)

8. 主力主升浪的特征

涨幅特征：

  • 在主流热点背景下多有主升浪
  • 涨幅一般在启动点开始50%以上
  • "这个算少的，这翻几倍的"

拉伸结构：

  • 强势主力运作盘面一般有三轮结构的拉伸

市场影响：

  • 有很强的板块效应
  • 对板块行情的中后期行情有趋势性的指导作用

(出自第04节 第22段)

9. 主力涨停板建仓的实战识别

典型信号：三个涨停板 + 换手率非常低

读法：

  1. 看到这种信号 → 主力资金进场
  2. 判断主力强度 → 涨停板建仓 = 强势主力突击建仓
  3. 预判后续画面 → 主力建仓轨迹（横盘震荡/调整/直接突破）
  4. 预判结果 → 主浪行情，将有主升浪

(出自第04节 第24段)

系统性总结（板块二）

主力资金更专业、更注重基本面，通过隐蔽建仓或涨停板快速建仓两种方式完成布局，潜伏运作后在热点催化下拉高套利。

核心识别指标：

  • 建仓期换手率<10%
  • 运作市值50亿左右
  • 拉伸前运行2-5个月
  • 主升浪涨幅50%以上
  • 强势主力有三轮结构拉伸
  • 盘面稳定性高，持续性强

风险点：调研失败可能中途放弃。识别主力后要预判全轨迹（建仓→洗盘→突破→拉升），并相信主升浪的出现。

## 板块三：战略资金的识别与特点

深度总结

1. 战略资金的整体特征

资金体量：体量大

  • 一般为社保、公募基金等

投资偏好：

  • 更加看重政策宏观面和基本面
  • 多以板块核心标的为主

市值范围：

  • 核心标的市值都比较大
  • 500亿、三五百亿、上千亿市值

技术面态度：不太注重技术面

行业选择：多以主流行业为主

市场影响：

  • 出现很强的板块性特点
  • 对大盘有非常强的带动性

(出自第04节 第26段)

2. 战略资金建仓期的核心指标

换手率：非常低，一般不超过5%

成交量：要超过5个亿，多则三五十个亿

(出自第04节 第28段)

3. 战略资金建仓的盘面位置与特点

位置：熊市末端的空头区域

空间：360年线附近

形态特征：

  • 偶尔涨停，但没有持续性
  • 会有几次单日放量建仓
  • 初期建仓后股价也会跌破建仓成本

时间：运行周期长达半年以上

(出自第04节 第28段)

4. 战略资金运作的稳定性

上涨前：

## 板块三：第二维度 —— 分时高开低开透露主力计划性

深度总结

1. 核心问题
"你给我表个态，你今天晚上想好了没有？这个股明天是买还是卖？"

——分时的开盘表现透露场内外资金的计划性。

(出自第05节 第10段)

2. 实战案例：大智慧大幅低开

盘面表现：几乎跌停板开盘 → 在5日线低开 → 往上连续放量

主力意图：这是超短线游资的动作

  • 这一天是大换手
  • 大回收以后
  • 这一天是大幅低开

(出自第05节 第12段)

3. 开盘形态的核心判断标准
开盘类型强度
高开最好
大幅低开（跌停板开盘）好
中途开一两个点（低开1-2个点）不好

核心：跌停板开盘或大幅低开比低开2-3个点不伦不类要好。

(出自第05节 第12段)

4. 大幅低开背后的逻辑

主力目的：恐慌盘杀出，主力为迅速收集筹码

操作过程：

  • 定价打到跌停板
  • 昨天前面买进去的人，很多人会挂跌停板卖出（割肉盘）
  • 主力通过这里吃割肉盘
  • 连续两根巨量 → 迅速吸收筹码
  • 这就是"吃货的分时上涨带量下跌缩量"

(出自第05节 第14段)

5. 开盘形态对比

大幅低开出货 vs 大幅低开吃货：

  • 大幅低开好
  • 但需要配合盘面放量情况验证
  • 进一步验证主力就是想什么在跌停板时候吃货

两个量都是什么：吃恐慌盘的筹码 — 这就是吃货分时。

(出自第05节 第14段)

6. 高开背后的逻辑

含义：场内场外的人都愿意用更高的价格去买入这只个股

口诀：愿意用更高的价接入你们想卖出的货，我们都能以更高的价格买进，你们去赚钱，这个是有计划的。

(出自第05节 第14段)

7. 高开强势的进一步刻画
  • 高开 → 早盘迅速带量 → 持续量往上拉
  • 这是非常强势的表现
  • 这种股是重仓对象

游资的真正龙头：基本上都在早盘五六十秒的时间就结束了全天战斗。一开盘就能知道大概就知道这个股能不能涨停，是不是妖股。

(出自第05节 第16段)

8. 高开 vs 大幅低开：都是强
"高开强大幅低开也都好，实际上它是一种比较好，非常强的表现。"

(出自第05节 第16段)

系统性总结（板块三）

第二维度揭示开盘方式透露主力计划性的规律：

  • 高开 → 主力愿意用更高的价格接走所有卖盘（强势且有计划）
  • 大幅低开（跌停板开盘） → 主力刻意制造恐慌吃割肉盘（强势且有计划）
  • 低开1-2点不伦不类 → 缺少明确信号（不好）
  • 关键验证：通过盘面放量情况确认主力是否在跌停板时吃货
  • 核心要义：开盘的"非常态"（高开或大幅低开）反而是强势信号

这背后的本质是"场内外资金有资金主导"。

## 板块四：第三维度 —— 分时上下行封闭

深度总结

1. 上下行封闭的核心概念
  • 上十个点 + 下十个点封闭
  • 下封闭的跌停板 → 破板大资金买入 → 一波拉升
  • 这里叫翘板资金（资金买入）

(出自第05节 第18段)

2. 翘板后的演化

主力继续买 → 拉升<br>主力不再买 → 自然回落

最高点到最低点 = 做T分时 = 盘中快速拉高

(出自第05节 第18段)

3. 80/80/80规律
"80%时间，80%的个股在80%的时间里都是这种，要么是先上后下，要么是先下后上。"

含义：

  • 80%的个股
  • 80%的时间
  • 都是震荡形态
  • 两种形态：先上后下 / 先下后上

(出自第05节 第18段)

4. 震荡形态的做T法则

震荡特征：上去有一个高点，下来有一个低点

做T操作：

  • 放量拉升卖出
  • 下跌区域买入

具体位置判断：根据盘面成交量判断买卖点位

术语命名：上下行空间封闭 — 每天有个高点，有个低点

(出自第05节 第18段)

系统性总结（板块四）

第三维度教分时上下行封闭的做T技巧。80/80/80规律说明震荡是市场常态。做T两大原则：放量拉升卖、下跌区域买。具体买卖点位需结合成交量判断。这一技巧适用于跌停板翘板、盘中高抛低吸等场景。

## 板块五：第四维度 —— 拉升涨停分时特征

深度总结

1. 识别速度
"60秒就能看出来。"

特别适用：短线股。

(出自第05节 第20段)

2. 攻击性分时买入特征

形态：开盘高开 + 量能持续性

命名：攻击性的分时买入

关键观察：

  • 几分钟的时间就定了
  • 只有几分钟决定了涨停板特征

(出自第05节 第20段)

3. 真龙头的特征
  • 早盘很快封涨停
  • 成交量在早盘基本上放出来
  • 连续带量突击式往上拔的分时
  • 都是涨停板
  • 分时非常强

(出自第05节 第20段)

系统性总结（板块五）

第四维度揭示拉升涨停分时的三大特征：

  1. 开盘高开（强势开盘）
  2. 量能持续性（量能不衰减）
  3. 突击式拉升（连续带量往上拔）

真龙头特征：60秒识别、几分钟决定、早盘封板、早盘放量。

## 板块六：第五、六维度 —— 游资主力买入出货分时与综合判断

深度总结

1. 第五维度A：高开 vs 低开 与 出货

核心规律：高开比低开强

主力想做盘的信号：

  • 高开 + 带量 → 主力想拉、继续炒

主力出货的信号：

  • 高开后 → 后面放量下行、放量下跌
  • 股价长时间在成本线以下
  • 涨停板后出现大量砸盘
  • 主力今天的目标就是出货（以出货为主）

(出自第05节 第22段)

2. 第五维度B：低开后快速拉升是强势信号

错误判断：很多人一看低开就判断不好

正确解读：

  • 看成交量
  • 量连续放量 + 迅速往上拉
  • 这是下行空间封闭

进一步观察：资金成交量的跟进回落，继续放量拉升 → 攻击性分时

形成机制：很快拉升 → 连续挂几个档买入 → 突发式 （不是慢慢推升的温和放量）

实战特征：盘面强势股都是突击式拉升的走势

(出自第05节 第24段)

3. 强度分析的两大维度

维度1：攻击性量的大小

  • 越大越强

维度2：持续性量价的时间

  • 越早越强（早盘放量 > 下午放量）
  • 上午半天越早放量越强
  • 量能要持续：连续的大放量
  • 不是单根的量，一根没了 —— 那是虚假的

(出自第05节 第26段)

4. 攻击性的价格形态对比
形态强度适用
非常陡峭的价格走势更强游资 / 主升浪拉升
温和推升的价格走势较弱主力 / 战略

(出自第05节 第26段)

7. 综合分时判断公式

量：攻击性的量是越陡越好，成交量是越持续越好

时间：以早盘一天的话，时间是越早越好，越早越好。上午要比下午好

价格：

  • 开盘是高开 → 好
  • 大幅低开 + 5日线附近 → 好
  • 低开2-3个点 → 反倒不好

逻辑对应：

  • 高开 → 愿意用更高的价格买入个股，让前面的人全部赚钱
  • 大幅低开 + 巨量 → 杀恐慌盘迅速拿筹码

量价持续性：价格陡峭 + 时间早 + 上午优于下午

第06节 第四维度 均线K线——研判支撑压力、结构级别、顶部底部、强弱

深度总结

本节课是"盘面分析多维度体系"的第四维度，专门讲均线和K线这两个核心工具的应用。老师重点讲了两根均线：5日线和360年线，并配合K线来分析股票的支撑压力、结构级别、顶部底部、强弱。

一、核心均线（5日线、360年线）

1. 5日线（最高级别均线）
  • 是最高级单边上行的线，超短线必须使用
  • 主升浪、最高级个股运行均要用5日线
  • 对于主力资金盘面有效，对游资盘面均线支撑基本无效
  • 战略资金盘面：5日线对股价有很强支撑
2. 360年线（独家年限指标）
  • 是本套体系独有的年限指标
  • 是牛熊分界线，孕育大量机会
  • 是大级别行情的变盘点，对股价形成强力的支撑或压制
  • 与结构、级别配合使用
  • 必须突破到年线上方才能成为行情主流
  • 周线和月线对游资盘面无效
3. 其他均线（10日、30日、60日、120日）
  • 5日、10日、30日、60日、120日、360日构成均线系统
  • 上行时顺序：最上方360，中间120、60、30，下方5日
  • 下行时顺序相反：最上方360，最下方5日

二、均线的核心用途

  1. 做结构和级别的预判
  2. 分析股价的支撑和压力
  3. 分析顶部和底部
  4. 分析强弱、行情启动点、确定性

三、支撑压力的有效背景（重要前提）

  • 没有结构和级别的股（小市值垃圾股）→ 均线支撑压力基本无效
  • 超短线龙头股 → 分水岭是5日线
  • 主力运作盘面/战略资金盘面 → 不管涨跌均线支撑压力非常有效，还可捕捉大级别盈利机会

关键误差提示：很多股因为没有级别、没有结构，用金叉死叉分析压力支撑经常出错，所以必须有背景。

四、5日线的双重作用

  • 上涨时：支撑极其有效
  • 下跌时：压制极其有效
  • 在战略资金层面，5日线是加速级别均线，支撑最强

五、360年线的应用

  • 熊市结构末端，360天线附近多为大资金建仓区域
  • 必须突破360天线才能启动行情
  • 是主力资金走牛的必经门槛
  • 配合结构级别使用极其有效

六、均线的顺序性（多头排列）

  • 多头排列要求一根都不能错，顺序不能错
  • 是进入大级别行情的必经之路
  • 每一只牛股必须均线多头
  • 下行时级别越走越低（最高360→最低5日），是熊市结构特征

七、K线的研判

  1. 大阳线（涨幅）判断强弱：振幅越大、强度越大；涨停板最强；大阳线越大越强
  2. 持续大阳线：连续两三个大阳线可能是主力吃货，是强势表现
  3. K线覆盖（前后两天分时重叠）：
  • 震荡洗盘或走势变弱的表现
  • 或者吃货表现
  1. 高开K线比低开好

八、均线K线组合信号（行情启动预判）

  • 重要均线上出现的K线信号，可洞察主力做多做空真实意图
  • 主升浪与趋势上涨行情的K线必须在多头上方
  • 主升浪必须是完全多头排列之上
  • K线大阳线和持续性明显加强主力运作盘面
  • 均线完全多头、完成首板后，在重要均线位置出现的K线 = 主升浪信号
  • 在刚开5日线上出现的K线 = 确认信号
  • 突破后持续放量 = 主升浪进行中

九、顶部底部的研判（均线多头+K线组合）

  • 游资、主力、战略资金盘面都会形成局部底和系统性大顶
  • 演化时间长短不同
  • K线和均线组合配合盘面结构，可准确预判顶部和系统性大顶
1. 结构性顶 vs 系统性大顶
  • 结构性顶：会突破上去（局部回调）
  • 系统性大顶：上去以后下来几年不会创新高（历史大顶/大级别顶部）
2. 顶部性质的预判意义
  • 顶部性质分析可以预判未来行情演化趋势
  • 可判断是结构性顶、历史大顶还是大级别顶部
3. 顶部形成过程（主力运作）
  • 主升浪经过三级拉伸
  • 沿5日线最高级运作后
  • K线覆盖开始
  • 构筑顶部 → 形成大顶
  • 大顶形成后规避大级别顶部风险

十、关键案例与场景

  • 战略资金盘面在360年线下方是建仓期
  • 突破360天线后进入多头结构 → 牛市启动
  • 沿5日线运行 = 最高级别主升浪
  • 顶部形成前K线覆盖是关键预警

系统性总结

本节课是盘面分析多维度体系的第四维度，主题是均线和K线。核心知识点可归纳如下：

1. 双均线体系：5日线（最高级别短线均线）+ 360年线（独家大级别牛熊分界线）。其他均线（10日、30日、60日、120日）辅助判定级别。

2. 均线四大用途：①预判结构级别；②分析支撑压力；③分析顶部底部；④分析强弱和启动点。

3. 支撑压力有效性三原则：

  • 垃圾股无效（无结构级别）
  • 超短线看5日线
  • 主力/战略资金盘面最有效

4. 关键纠偏：金叉死叉经常出错，必须结合"背景"（结构级别）。

5. 均线的双重作用：5日线上涨支撑+下跌压制，360年线牛熊分界+变盘点。

6. 多头排列：完全多头排列是大级别行情必经之路，每只牛股必备。

7. K线三重研判：

  • 大阳线强弱判断（振幅）
  • K线覆盖判断（洗盘/吃货）
  • 高开低开判断强弱

8. 均线K线组合：在重要均线（如刚开5日线、首板后均线）出现K线信号 = 主升浪启动信号，可洞察主力真实意图。

9. 顶部预判双分类：结构性顶（可突破的回调顶）vs 系统性大顶（几年不破的顶部）。顶部性质决定后续风险等级。

10. 操作体系位置：本课是均线K线维度的总论，为后续讲成交量换手率、结构级别等维度做铺垫。

第07节 第五维度 成交量换手率——研判资金性质

深度总结

本节课是"盘面分析多维度体系"的第五维度，专门讲成交量和换手率。核心功能是预判资金性质，还可预判顶部底部、主力强弱、止跌区域、头部滞涨区域，以及辅助仓位配置。

一、成交量与换手率的核心功能

1. 识别多空力量
  • 上涨时：分子是主动性做多的量 → 做多动能
  • 下跌时：分子是主动性卖出的量 → 做空动能
  • 分析"这个量是怎么形成的"→ 可指导行情演化预判
2. 三大实战功能
  • 预判资金性质（核心）
  • 预判顶部和底部（抄底逃顶）
  • 预判仓位配置（依据成交量大小调整仓位）
  • 成交量太小（小市值）→ 仓位较轻
  • 成交量较大（三五十亿）→ 可重仓配置
  • 预判行情持续性

二、3类资金军团的换手率识别

老师将资金分为3类：游资、主力、战略资金。各类资金在不同阶段的成交量和换手率特征完全不同，是本课最核心的内容。

1. 游资盘面识别（换手率20%以上）

两种游资初始涨停建仓：

  • 情况A（低位）：低位成交量小、换手率较低（10%以内）
  • 情况B（相对高位）：高位换手吃货、成交量大、换手率20%以上

案例数据：

  • 3个涨停板 = 游资
  • T字板破板换手率13% + 当日21%涨停 = 游资盘面
  • 换手率28%、成交12亿 = 资金大、决定仓位配置
  • 换手率29%、成交13亿 = 游资盘面
  • 换手20%、22% = 游资盘面
  • 底部位一个板+一个板：换手7%/5%、成交1.4/1.1亿（低位吃货）→ 主力/游资吃货
  • 关键判断：两板前建仓换手率低=游资；建仓期换手率高=主力
2. 主力资金盘面识别（换手率10%以下）

建仓期特征：

  • 成交量相对较小
  • 换手率较低，往往不超过10%，甚至更低（因市值不同，看换手率更准确）

出货期特征：

  • 换手率达到建仓期的三倍以上（有游资参与则更高）
  • 主力盘面会有主升浪（这是主力盘面与游资盘面的关键区别）

典型主力盘面：换手率低 + 涨停板强势 → 做强势股主要看涨停板

3. 战略资金盘面识别（最关键！）

建仓期特征：

  • 换手率极低（往往10%以下）
  • 但总市值大（数十亿到上百亿）
  • 案例：换手3.75%、45亿市值 / 换手4.14%、54亿成交

出货期特征：

  • 换手率仍很低（与主力不同！）
  • 但绝对成交量会达到建仓期的5倍以上
  • 例：原10/20亿，到顶时80亿（股价涨几倍后换手率仍仅4%）

战略资金的核心特征：

  • 底部区域出现 = 战略资金建仓表现
  • 未来行情 = 大级别牛市行情
  • 运行时间 ≥ 6个月，长达1年
  • 股价翻好几倍
  • 这是预判大级别行情的最强信号

三、3类资金军团的顶部形成特征（对比表）

资金类型顶部形成速度顶部特征形成过程
游资快高位横盘/直接跌停大量股价不涨、出现大量顶部
主力慢较慢，时间较久放量到缩量的过程
战略资金更慢几重顶，时间最长出货更慢、顶部形成更慢，放量到缩量

关键判断：

  • 游资顶部换手率可达50%以上（极限量），顶部形成非常快
  • 高位横盘 + 出现大量 → 注意顶部
  • 主力盘面顶部：上涨数量持续不久，缩量是主旋律
  • 战略资金顶部：成交量高位不破新高、缩量，前面经过几重拉升 → 大顶大级别顶部，未来风险极大

四、3类资金军团的底部特征

游资底部：快速上涨 + 快速下跌，反弹要看热点

主力底部：放量到缩量的过程（与顶部相反）

战略资金底部：形成更慢、更复杂，时间最长

止跌信号：底部区域成交量要缩量，如果再带量 → 波段止跌

五、顶底分类（结构性 vs 系统性）

1. 结构性顶/底（局部性）
  • 结构性顶：回调后能创新高（如牛市中的波段顶部），未来会突破上去
  • 结构性底：是阶段性底部
  • 80%的个股和80%的时间都是结构性行情
2. 系统性顶/底（历史性/大级别）
  • 系统性顶（历史大顶/大级别顶部）：未来几年都破不了新高
  • 历史大顶：经过几年上涨大牛市后形成的大顶
  • 大级别顶部：主升浪形成后的大顶或历史大顶
  • 系统性风险：下跌幅度大

关键结论：

  • 结构性风险 vs 系统性风险，下跌幅度完全不同
  • 游资大幅炒作后可能形成大级别顶部
  • 通过结构级别、三级结构、成熟度可预判

## 板块一：结构和级别的概念与稳定性问题

深度总结

1. 结构和级别的核心问题（为什么需要它？）

股票操作常遇到的四大问题：

  1. 什么时候上涨
  2. 能涨多久
  3. 能涨多高
  4. 行情有没有结束，有没有到大顶

这些问题都通过结构和级别来实现预判。

2. 结构和级别的四大核心功能
  1. 解决稳定性问题（为什么有时赚有时亏）
  2. 预判行情加速的时间窗口和运行周期
  3. 预判大级别行情的牛熊大拐点
  4. 预判大盘的运行性质、顶部和底部
3. 稳定性的根本原因——背景问题

经典命题：同样的技术，有时赚钱，有时亏钱。

答案：不是技术失效，是背景错误了。

  • 牛市结构背景：每一次放量或调整 → 放量买入 → 哪怕调整后仍创新高 → 赚钱（为新高做准备）
  • 熊市结构背景：每一次放量拉升 → 都是为新低做准备 → 亏钱

结论：技术必须与背景配合。背景决定一切。

4. 适用范围（重要前提！）
  • 主力和战略资金盘面才能谈结构和级别
  • 游资没有结构——没有稳定性，完全是题材炒作、突击式，没有准备过程
5. 关键指标体系
  • 360天线 → 判定结构（牛/熊/结构式）
  • 5日、10日、30日、60日、120日均线 → 判定级别
  • 通过均线的级别 → 判定运作成熟度
  • 通过成熟度 → 预判股价涨跌的时间与高度
  • 通过成熟度 → 预判顶底是结构性还是大级别历史性

系统性总结（板块一）

结构和级别维度的根本价值是解决稳定性问题——通过识别背景避免"同技术不同结果"的困惑。它将"结构"（牛/熊/结构式大盘背景）与"级别"（均线层次反映的运行成熟度）分层处理，前者定方向，后者定加速与高度。前提是只适用于主力和战略资金盘面（游资不适用）。

## 板块二：结构和级别的均线识别体系与顶底研判

深度总结

1. 3类结构的均线定义
结构类型均线位置
熊市结构360天线下方
初级360年线下方、空头区域（起步）
中级360天线以上、30天线以下
高级30天线以上、5日线以下
最高级（加速单边行情）沿5日线运行
2. 主力盘面结构的完整演化路径

360年线下方（主力建仓区）<br> ↓ 突破年线<br>进入牛市多头结构（初级）<br> ↓ 每次回落均线提高<br>120天线 → 60天线 → 30天线 → 5天线<br> ↓ 沿5日线运行<br>最高级（主升浪加速行情）

3. 主力盘面的两种风格
  • 隐蔽型：横盘震荡控盘，没有波段，没有套利空间
  • 张狂型：攻击性强，涨停、大阳线明显

强度识别方式：

  • 资金性质 → 成交量换手率看强度
  • 涨停和大阳线 → 看强度
  • 单边推升周期长 → 也是强势表现
4. 顶部的双分类与识别
  • 结构性顶部：后面都会被突破（波段回调顶）
  • 大级别/历史性顶部：未来几年不能突破新高 → 系统性风险/大级别风险

顶部预判的K线信号：

  • 头部出现K线覆盖
  • 股价不涨
  • 换手大、成交量大
  • → 多数人亏损，顶部形成
5. 战略资金盘面的对比
  • 战略资金顶部形成时间更长
  • 经过几重拉升形成的顶部 = 大顶、大级别顶部
  • 风险极大（远超结构性顶部）
6. 中信证券案例（战略资金实战）
  • 战略资金建仓 → 突破360年线 → 进入多头结构
  • 初级结构 → 一轮拉升 → 沿5日线高级别行情
  • 顶部判断方法：①演化时间 ②上涨周期高度 ③前面准备时间
  • 战略资金建仓 → 顶部形成时间长 → 大顶 → 后面就是熊市

系统性总结（板块二）

通过均线系统可以清晰刻画主力和战略资金盘面的"结构—级别"演化路径。结构定方向（牛/熊），级别定成熟度（初/中/高/最高级）。每一级均线的回落支撑被突破 = 级别提高一档，沿5日线运行 = 最高级主升浪。顶部的性质（结构性 vs 大级别）直接由"演化时间+上涨高度+准备充分度"三个维度共同判定。这一板块是"3类结构"和"3个级别"的完整技术化定义。

## 板块三：结构级别演化、加速时间窗口、大盘性质预判

深度总结

1. 结构级别演化的核心应用
  • 既可预判上涨加速行情，也可预判下跌行情
  • 既可对个股，也可对大盘
  • 可预判行情加速的点和大致运行时间
2. 演化的核心原则

核心原则：瓜熟蒂落——加速需要政策、热点相匹配

  • 主力的级别演化是隐蔽型或张狂型
  • 主力从初级结构 → 5日线加速 = 行情的终极结构（最终形态）
3. 大级别牛熊大拐点的预判逻辑

多头结构 → 熊市结构的反转路径：

多头结构（最高级，沿5日线）<br> ↓ 顶部形成（结构性顶或大级别顶）<br>熊市结构（初级）<br> ↓ 级别越走越低<br>熊市结构（中低级）<br> ↓<br>系统性风险（最大风险）

关键：牛市最高级别走完 → 进入熊市 → 级别逐渐降低 → 系统性风险出现。

4. 建仓周期与上涨幅度的关系（重要）
  • 建仓时间越长 = 准备越充分 = 树大根深 → 上涨时间越长、高度越高
  • 主力建仓：2-6个月可拉升
  • 战略资金建仓：时间要长得多（这是战略资金和主力的关键区别之一）
  • 特别适合千亿大机构和私募机构
5. 大盘性质的历史演变
  • 以前只有两种：牛市和熊市
  • 后来增加：结构式（行业轮动、板块轮动为主）
  • 当前未来两年均为结构式大盘
6. 结构性行情的两大特征
  • 80%时间 + 80%个股 = 结构性顶部（局部性顶部，正常波动）
  • 游资大幅炒作后可能形成大级别顶部
7. 系统性风险特征
  • 牛市终结 = 熊市来临 = 系统性风险
  • 不管有什么利好，通通下跌
  • 往往是全球性的
8. 大盘的系统性大顶特征
  • 经过几轮最高级上涨
  • 通过三级结构、三个级别的成熟度
  • 形成大级别顶部/历史大顶
  • 全是系统性风险
9. 多空双向研判（涨/跌都适用）
  • 上涨时：多头结构，级别越走越高 → 通过准备充分度预判周期和高度
  • 下跌时：空头结构，360年线下方 → 级别越走越低 → 均线压制
  • 起涨点的确认：开花+结果 → 需配合其他维度
10. 大盘顶部和底部预判
  • 历史大底和结构性顶
  • 牛市终结顶部形成 = 系统性风险（全球性）
  • 结构性很强时，阶段性顶底部基本是结构性顶
  • 战略资金/主力资金的顶底都可通过结构级别预判

系统性总结（板块三）

本板块是结构级别维度在大盘研判层面的高阶应用。核心要点：

  1. 瓜熟蒂落原则：加速需要级别演化与政策、热点匹配
  2. 建仓时长 → 上涨高度：建仓时间越长，上涨空间越大（战略资金 > 主力）
  3. 大盘3性质：牛市、熊市、结构式（当前主流）
  4. 大级别牛熊大拐点：通过结构级别演化路径可清晰识别（多头最高级 → 熊市初级 → 级别递减）
  5. 系统性风险：牛市终结后的全球性下跌
  6. 当前定调：未来两年均为结构性行情，应对策略聚焦板块轮动和个股选择

2. 板块轮动的两大操作要点
  1. 抓住当前正在上行的主流板块
  2. 同时跟踪2-3个正在演化的主流板块，等待切换信号
3. 板块轮动的难度与价值
  • 难度：很高
  • 价值：巨大
  • 是大方向选择的核心工具
4. 板块轮动的底层逻辑链

要做板块轮动必须先解决：

  1. 知道主流板块是哪些（不知道就没法追踪和切换）
  2. 知道资金的性质（主力？游资？战略资金？）
  3. 分析板块运行结构（主力板块、中军、几大核心股的运行结构）
  4. 知道顶底判断（不知道顶底就没法切换）
  5. 知道时间问题（切换的时机）
5. 切换成功的核心条件

催化条件：

  • 主流板块运行中出现行业性影响（利空或外围影响）→ 加速顶部形成
  • 消息削弱 + 新政策出现 + 运行结构级别配合 = 切换时机

关键问题：

  • 跟踪的几个板块中，哪一个会脱颖而出？ → 通过它们的运行结构和级别判断
  • 选错主流板块 = 主流板块也抓不住

切换的最高境界：

  • 分析结构顶部、底部
  • 分析几大中军的运行结构
  • 在切换窗口上配合政策和事件的催化

系统性总结（板块一）

板块轮动是整个体系的高阶应用，必须建立在前面所有维度（分时、均线K线、成交量换手率、结构级别）的基础上。它的底层逻辑是多板块并行跟踪 + 信号识别 + 政策催化的综合性判断。这不是单一技术能解决的，而是多维度的立体综合。

## 板块二：板块轮动的8大核心维度详解

深度总结

维度1：行业分类（基础分类）

两大分类：

  • 传统价值：银行、证券、资源、消费类
  • 科技成长：芯片、ChatGDP、人工智能、AI

资金性格对比：

行业类型资金性格追求目标
传统价值保守稳健稳健增长
科技成长激进利润要快

两种性格的资金分别主导不同行业的趋势——要么稳、要么快。

维度2：主流 vs 非主流

主流板块举例：

  • 传统价值大金融：银行、证券
  • 科技成长：芯片（大市值集中）
  • 新能源汽车：比亚迪、长城汽车
  • 新能源：阳光电源、农牧（农机）

非主流板块举例：

  • 纺织板块（传统行业但不是主流）
  • 不在轮动参考范围内
维度3：核心中军运营结构（核心个股跟踪）

核心要点：

  • 在主流板块中必须有一个龙头个股
  • 从建仓开始就要跟踪
  • 代表性个股案例：长城汽车、宁德时代（底部都有主力/战略资金建仓）

演化路径：

空头结构 → 牛市结构 → 三级拉升行情 → 结构性大级别顶部

  • 大级别顶部出来后，其他板块才开始轮动
  • 中军和几大核心个股要配合分析
维度4：板块内个股的同步性（关键判断）

核心问题：板块内个股是统一还是分化？

判断标准：

  • 同步上涨 = 板块一致性强
  • 有的涨有的跌 = 没有同步性，切换分析困难
  • 同步性决定轮动时点和板块持续性
维度5：主要板块运行的结构和级别（指数层面）
  • 在指数层面分析
  • 与个股层面的结构级别分析完全对应
维度6：新旧主力板块的顶底判断（切换核心）

旧板块顶部判断：

  • 必须先判定结构顶还是大顶
  • 结构性顶部 ≠ 真正切换 → 只是运行途中的回调
  • 回调后还得上，结构没走完 → 其他板块很难切换上去
  • 在回调时切换到其他板块 = 错误时机（资金会回流）

新板块底部判断：

  • 判断是大底还是结构性底部
  • 跟踪的几只主流板块运行到"底部已经出现，慢慢往上去，仍在横盘震荡，没有突破迹象"
  • 关键问题：成熟度和结构
  • 不知道顶就不会预判底 → 无法做到准确切换
维度7：政策和重大事件催化（切换时间）

逻辑关系：

  • 旧板块在高位出现政策利空 → 加速顶部形成
  • 新板块出现利好或新政策 → 加速上行
  • 两者共振 = 形成切换

关键认知：

  • 切换是一个区域，不是某一天
  • 绝对的时间切换几乎不可能
  • 我们追求的是区域内的切换
  • 当主流板块行情渐进式结束 + 其他板块逐渐抬头 = 真正切换时机
维度8：旧板块调整时间预判（规避风险）

核心能力：

  • 当新能源汽车板块（宁德时代）出现大级别顶部 → 预判未来调整时间周期很长
  • 意味着该主流板块将来上行时间也将比较长（反推：新主流板块上行周期长）
  • 作用：
  1. 规避老的板块下跌风险
  2. 享受新板块上涨利润

系统性总结（板块二）

板块轮动的8大维度构成一个完整的、立体的分析框架：

  1. 行业分类（基础认知）
  2. 主流vs非主流（筛选范围）
  3. 核心中军运营结构（龙头跟踪）
  4. 板块内同步性（一致性判断）
  5. 主要板块的结构级别（指数层面）
  6. 新旧板块顶底判断（切换前提）
  7. 政策和事件催化（切换时机）
  8. 调整时间预判（风险规避）

  • 多个权重板块统一建仓
  • 都有表现：涨停板 / 大阳线 / 涨在买
  • 攻击性强是显著特征
  • 但其他板块不一定都是涨停板，有些只是"在涨在买"

第11节 双K确认技术

深度总结

一、双K的核心定义

双K指的是两根K线（多为大阳线、涨停板、高开异动K线或大振幅K线）的组合应用，可以"间隔较长时间"也可以"相邻两根"。通过观察这两根K线的形态、位置与组合方式，可以对盘面进行多维度的预判与确认。

二、双K的五大应用方向（出自第11节 第2段）

  1. 确认底部——跌下来之后出现大阳线，再次跌下来后又出现一根大阳线，两根形成"双K"，可作为波段见底信号。
  2. 确认趋势——在相对平台或高位平台，一根阳线、一根阴线再来一根阳线，反复确认"跌不动"，趋势向上。
  3. 确认主力意图——上影线阴线后次日高开上走，确认主力是洗盘而非出货；连续涨停后阴线次日高开，确认资金未走、主力做多。
  4. 确认变盘——通过相邻两根K线的方向判断短期方向变化。
  5. 确认涨停板——单根阳线之后对应一根阳线，根据强势分析做单日双K后面K线的涨停板溢价机会。

三、双K在不同场景的应用要点

1. 确认底部（出自第11节 第3段）
  • 形态：下跌后第一根大阳线 + 再次下跌后的第二根大阳线
  • 操作：双K确认底部后即可在波段见底处买入
  • 注意：一定是"跌下来以后大阳线"，不是顶部反转的大阳线
2. 确认主力建仓（出自第11节 第4段）
  • 形态：跌下来后一根大阳线 + 再次下跌后一根高开K线
  • 双K形态多样：可以是大阳线、涨停板、大振幅K线，也可以是两根对应的高开异动K线（不管涨幅多少）
  • 这是大底部、阶段性底，主力资金建仓信号
  • 大阴线后反弹阳线 + 次日阳线高开 = 又一次双K确认
3. 确认波段底部与单日涨停（出自第11节 第5段）
  • 单阳双K：出现一根阳线后，对应后面再出现一根阳线
  • 单日涨停板：依据强势分析，做后面这根K线涨停板的机会（有溢价）
  • 双K确认波段买点：可在双K当天买入
  • 高开位置也是买入点
4. 确认趋势与平台止跌（出自第11节 第6段）
  • 适用场景：相对平台、高位平台
  • 形态：下跌后一根阳线、阴线后阳线、平台震荡后高开、平台震荡后大阳线
  • 反复确认的相邻两根，体现"跌不动"特征
  • 趋势向上的确认手段
5. 确认涨停板趋势（出自第11节 第7段）
  • 下跌后阳线涨停板 + 大阴线后涨停板 = 底部双重确认
  • 阴线后阳线反包相邻两根 = 资金回流确认
  • 大阴线 + 大涨停板 = 跌不动、趋势确认
  • 高位相邻两根：上影线后次日高开 = 洗盘确认，非出货
6. 确认短线主力做多意图（出自第11节 第8段）
  • 连续涨停后高开阴线：若次日高开，则为洗盘（资金未走、主力做多）；若次日低开下跌，则为出货
  • 短线相邻两根也可去确认主力做多意图
7. 确认顶部（出自第11节 第9段）
  • 形态：上涨过程中出现下跌阴线 + 次日低开
  • 双K既可确认底部，也可确认顶部
  • 趋势是否延续，可用相邻两根的双K来确定

四、双K的核心价值（出自第11节 第6段）

"你要会双K确认的话，我们可以在任何盘面都可以去分析主力的意图。"

双K是看盘的基本功夫，是分析主力意图的核心工具，覆盖短线、波段、高位横盘止跌、趋势、顶底等所有场景。

  • 一字板 × 2
  • 实体阳线 + 一字板
  • T字板 + 涨停板
  • 一字板 + T字板
  • 任何"两个涨停"的K线组合都算

二、99式的两大主力盘面模式（出自第12节 第3段）

  1. 主力盘二波拉升——主力资金运作的两个涨停起来的个股
  2. 游资接力——两个板以上的接力个股

两者后续在"换手日"与"买点判断"上会有所不同。

三、99式的三大禁忌（出自第12节 第4段）

为保证安全性与确定性，必须避开以下三类标的：

  1. 非主流核心板块的短线股——非主流热点板块的短线股风险大
  2. 非第一龙头跟涨股——手里股不能连板，龙头在外面，自己的可能是跟涨股
  3. 非第一买点买入——99式的重要起点是"换手日"那一天，不在第一买点的地方买入

四、99式的三大操作性风险（出自第12节 第5段）

  1. 不确定性追高打板——看到涨停板就想去打板或追，结果吃大面
  2. 大阴线买入抄底——大阴线在5日线下方抄底，可能第二天大幅低开被闷
  3. 高位站岗——在高位区域还在买入，后面就是一波大的下跌

控制这三大风险，做超短线时"不要急、不要随意买，要有严格标准"。

五、选股标准的优选逻辑（出自第12节 第6段）

  • 前面有四个涨停板的股：实体阳线、一字板、T字板都算，肯定进自选股
  • 龙头起步往往厉害：四个板 > 三个板 > 两个板
  • 优选顺序：跟踪优先四个涨停的，再考虑三个，再考虑两个

六、龙头股的核心特征（出自第12节 第7段）

  • 主流板块的中军（代表证券行业等核心领域）
  • 成交量大、市值大
  • 两个涨停板的力量非常大
  • 对板块行情有巨大共振作用

  • 比如"炒华为"是一个很大的题材，有高确定性

  • "三板有四板不选三板，有三板不选两板"
  • 优选个股时，资金的性质要确定：
  • 游资做的99式
  • 主力资金建仓以后主升浪行情里的99式
  • 资金接力程度不同
  • 主力法做99式成功率更高（要达到目标价位）
  • 例：两板介入，要翻一倍，后面还有五天要上涨
4. 资金性质与换手强弱的判定（出自第13节 第5段）
  • 游资拉了两个板后也换手了，但后来没了，确定资金性质
  • 最强的、最健康的换手是"大振幅的涨停板"（换手板）
  • 换手板最强，但不代表最强的涨停板后面能继续走涨停
  • 具体后面怎么走，同样要看资金的态度
5. 八个关键确认点（出自第13节 第6段）

确定先手买点和第一买点：

  • 新学员：先手买点是不允许做的（因为会出现很多问题）
  • 第一买点：必须要确认
  • 两个确认：第一买点确认 + 买入确认
  • 持股标准确认：什么样的才能是持股标准
  • 卖出标准确认：卖出标准是什么

八个维度具体为：

  1. 第一条：通过热点板块严格确定板块内符合妖股特征的个股
  2. 第二条：通过K线振幅确定换手日波次
  3. 第三条：通过盘面的三级结构确定先手买点、第一买点
  4. 计划性和一致性：分时集合竞价、分时高开低开，通过开盘的分时确定买入时机
  5. 在分时走势和结构相匹配的情况下确定持股区域
  6. 在分时走势和结构相匹配的情况下确定卖出区域
6. 战略资金案例：证券中军股（出自第13节 第7段）
  • 大市值个股、证券板块的中军股
  • 战略资金进入 + 两个涨停板 → 优选
  • 资金体量大要优选，资金小也要优选
  • 因为中军板块个股出现两个涨停板，是很大的力量

系统性总结（板块一）

板块一确立了99式战法的整体框架：千里挑一 + 严格标准 + 八个维度。其中：

  1. 稀缺性是99式的本质——99式不是高频战法，而是针对极少数顶级黑马个股的精准狙击
  2. 龙脉龙骧是底层逻辑——题材是否真有市场潜力，决定了战法成功率
  3. 资金性质决定策略——主力盘面 vs 游资盘面，操作手法有显著差异
  4. 八个维度是操作清单——本节给出八个维度的确认要求，每个都必须满足

这构成了板块二、板块三中具体买卖判断的前提。

## 板块二：换手日概念与判断标准

深度总结

1. 换手日的核心地位（出自第13节 第8段）
  • "两板以后最重要的一个点是什么？是换手日"
  • 换手是行情新起点的开始
  • 做超短线一定要把换手日（行情重新开始的地方）标记清楚
  • 这一天会出现分化，对未来行情有分化（上涨或下跌）
  • 必须把这一条分界线画出来，这是非常重要的
2. 换手日的定义（出自第13节 第8段）
  • 不涨停的任何K线都是换手日
  • 换手日可以有多种形态：
  • 下跌的K线
  • 一字板跌停
  • 大振幅的涨停板（即"换手板"）
  • T字板
  • 长腿的T字板
3. 不算换手日的形态（出自第13节 第9段）
  • 小振幅秒板：高开七八个点、六七个点就秒板的不算换手
  • T字板：连续一字板后的小T字板不算换手（T字板以后买进去容易吃大面）
4. 最健康的换手（出自第13节 第10段）
  • 换手大振幅涨停板
  • 例：从开盘一个点然后一直拉到涨停板
  • 大振幅也叫换手日，也叫换手涨停板，简称"换手板"
5. 换手日的操作要点（出自第13节 第11段）
  • 换手日是不能买入的，因为不知道明天是跌还是涨
  • 换手日的意义：标记分界线，区分行情阶段
  • 战略资金进去两三个板以后破板的日子是典型的换手日
  • 后面的行情趋势可能发生变化，能不能上涨取决于主力资金后面运作的态度
6. 换手日第二天的买入条件框架（出自第13节 第12段）

换手日第二天的买入条件：高开或者大幅低开。

两个概念必须区分：

  • 时间确定：今天要干活。今天确定今天要干活。
  • 能否干活：能不能做？能不能的问题。

第一天后是换手日，第二天后是干活日——换完手之后的这一天才是我们今天要干活的这一天。

买入判断的两个标准（针对高开）：

  1. 集合竞价开盘
  2. 开盘的情况
  3. 分时（必须与开盘两个配套）

系统性总结（板块二）

板块二是99式战法的核心技术环节——换手日的识别与应用：

  1. 换手日是99式的"分水岭"——它将行情划分为"第一波"（连板期）和"第二波"（换手后）两个阶段
  2. 换手日不等于买入日——换手日本身不能买入，买入是换手日的"次日"
  3. 换手板是最健康的换手——大振幅涨停是优质换手，T字板和小振幅秒板则不算
  4. 换手日的两种典型后续走势——高开（强势）和大幅低开（弱势但可转强），分别对应不同的买入判断框架
  5. 时间确定 vs 能否干活——99式买点的两个独立判断维度

这一板块是99式从"选股"过渡到"操作"的关键桥梁。

## 板块三：买入条件判断（高开 vs 大幅低开）

深度总结

1. 开盘的两种情形（出自第13节 第13段）

99式买点的开盘分为两种：

第一种：高开

  • 集合竞价九点半以后能够确认高开
  • 这种股一定要重点关注
  • 99式一定要专注

第二种：低开

  • 大幅低开5日线
  • 破5日线开盘都可以
2. 高开下的两种分时（出自第13节 第14段）

高开满足条件后，分时有两种：

第一种：打下来一点点再上

  • 有人卖，他在上
  • 是有人砸过，但后来反了
  • 高开前提下资金跑，打一下还好，关系不大
  • 资金在分时确认强势以后，再进——高开要加分

第二种：直接拉伸

  • 直接开盘就是放量
  • 柱子多少不一：
  • 有的两根柱子就直接秒板
  • 有的连续拉30根才涨停
  • 有的拉了以后还回落再涨停
  • 关键是开盘放量拉升
3. 低开的弱势属性（出自第13节 第15段）
  • 有的股会低开两三点
  • 低开往往都是弱势的表现
  • 真正的强势股往往用高开表现
  • 特别强调：游资盘面 vs 主力盘面
  • 主力盘面可以低开往上拉，因为是主力自己掌控的盘面
  • 游资是接力和场内场外之间互相接力的，所以开盘集合价高开是非常重要的
4. 大幅低开下的买入判断（出自第13节 第16段）
  • 大幅低开：低开5日线
  • 分时要迅速放量
  • 跟高开差不多的形式
  • 分时放量要强势分时
  • 开在5日线强势分时
5. 大幅低开后的恐慌盘处理（出自第13节 第17段）
  • 大幅低开的个股分时因为有恐慌盘
  • 有人追涨停板追进去，大幅低开破5日线，就有恐慌盘杀出来
  • 分时可能继续下杀，开盘后继续下杀
  • 注意"弱转强分时"
  • 弱转强的分时出来以后，才可以去买
6. 分时的三种情况（出自第13节 第18段）

分时里面和开盘分三种情况：

  1. 高开 + 强势分时
  2. 大幅低开 + 弱转强分时
  3. 其他情形需具体判断
7. 大智慧案例：T字板与直接晋级第一买点（出自第13节 第19段）
  • 大智慧三板以后，T字板不算换手日
  • T字板以后买进去容易跌停（很多人砍掉）
  • T字板是不买的，不做先手买入
  • 真正的买点：直接晋级第一买点
  • 形态：直接大幅低开
  • 前面全是涨停板
  • 来一个大幅低开5日线
  • 这是99战法里的"直接晋级第一买点"
  • 买点条件：
  • 时间确定（这一天）
  • 分时：集合竞价开盘大幅低开
  • 分时要强势分时
8. 杭州热电案例：换手板 vs 先手买入（出自第13节 第20段）
  • T字板不算，所以是两个涨停
  • 换手板形态：略高开一点点，拉到涨停板
  • 换手板不做先手买入
  • 进阶同学不做先手买入，因为有很多失败的，会吃大面
  • 主力盘面可以做先手，但要理解什么是主力盘面
  • 真正的买入时间是换手板次日
  • 买入条件：集合竞价开盘强势分时就做买入
9. 杭州另一案例：双K确认（出自第13节 第21段）
  • 四板以后，T字板不算换手日
  • 确认买入的时间是第二天
  • 这是双K确认：
  • 它高开确认
  • 前面资金想做多
  • 后面的资金也想接力
  • 双K确认做多确认
10. 中科信息案例：次新股（出自第13节 第22段）
  • 次新股同样适用
  • 前面是连续的一字板
  • 连续一字板这天没有涨停板，是个小T字板——不算
  • 后面有一天没有涨停的这一天全部是换手日
  • 换手日不买
  • 买入就是后一天：集合竞价开盘 + 强势分时
  • 后面持股：5日线持股

系统性总结（板块三）

板块三是99式操作中最具体的买入判断环节：

  1. 两种开盘情形：高开 vs 大幅低开，对应不同的分时确认
  2. 高开 + 强势分时是标准买入形态；高开 + 砸过再上拉也可加分
  3. 大幅低开 + 弱转强分时是另一个合法买点
  4. 主力盘面 vs 游资盘面对低开的容忍度不同——主力盘可低开上拉，游资盘高开更重要
  5. 特殊买点：直接晋级第一买点——前面全涨停板后大幅低开5日线
  6. 双K确认在高开场景下用于确认做多意图
  7. T字板是常见陷阱——不算换手、不做先手买入

这一板块把"换手日次日"的买卖判断从抽象原则变成了可操作的具体规则。

## 板块四：波次划分与持股/卖出标准

深度总结

1. 波次划分的重要性（出自第13节 第23段）
  • 波次的划分很重要
  • 三波不做
  • 对于单纯的99式、1994，以游资盘面来看
  • 前面两板是第一波
  • 换手日开始确定分界线：前面是第一波，后面进入第二波
2. 顶部卖出原则（出自第13节 第23段）
  • 连板以后有数量、有加速、有数量的连板
  • 前面是连板以后有数量的，这个地方一定要注意顶部卖出
  • 一旦放量就要换手，一换手就要做卖出
  • 注意：提前于K线
  • 这是最后卖出的地方
  • 有的股直接跌停了不卖出（这种技术另外课程详细讲）
3. 第二步与第三步的识别（出自第13节 第24段）
  • 前面第一次换手第一步
  • 这里第二步
  • 再到后面，看这个也没涨停，这里开始没有涨停的这一天，后面进入第三波
  • 原则上第三波不做，或者是第三波都是卖出区域
  • 如果第三波非常符合买入标准，只能清仓、非常低的仓位去买
4. K线覆盖的定义（出自第13节 第25段）
  • 什么叫K线覆盖？
  • 前一天和后一天有重合的地方
  • K线覆盖开始意味着又换手
  • 后面进入第三步，这里开始进第三步
  • 这是第二步，这是第一步
  • 我们做的是第二步：第二波波次
5. 第二波的两种典型路径（出自第13节 第26段）

路径一：中间不破5日线

  • 连板中间不破5日线，只要不破5日线都可以做一波
  • 第一波以后这天开始不破5日线涨停板的都可以做第二波

路径二：覆盖进第三波

  • 后面再出现覆盖，进第三波
  • 中间间隔了一个不涨停的——也可以当作不破5日线的处理
  • 四板以后换手日后面连板连续一日板没破过5日线，持股标准高开持股
  • 低开分时迅速上拉也是可以持股强势
6. 持股标准与强势表现（出自第13节 第27段）
  • 高开持股
  • 低开分时迅速上拉
  • 都是强势表现
7. 破5日线的卖出原则（出自第13节 第28段）
  • 第二步后面覆盖后面K线，K线很明显的覆盖了两天三天
  • 破5日线是最后卖出区域，是最终的防守
  • 破5日线是一定要卖出的
  • 不破5日线就还可以持股
  • 针对真正已经在这里成功的个股、换手成功的个股
  • 有些人这里换手不成功，你就不能等到五日线都要做卖出
8. 99式持股的关键点（出自第13节 第29段）
  • 中间几乎都是连板，所以这种股非常少
  • 操作的标准要非常严格
  • 从选股（行业热点选股）、换手日、到持股、到卖出的全流程
  • 中间还有经常会卖飞的情况
  • 一旦穿越99以后，一旦穿越94换手成功，很可能就会有连板
  • 才能走出真正的龙头

系统性总结（板块四）

板块四是99式战法的卖出与波次管理：

  1. 三波结构：
  • 第一波：连板期（不操作）
  • 第二波：换手日后的主升段（主要操作区间）
  • 第三波：覆盖后的高位震荡（不操作或极低仓位）
  1. 顶部信号：放量 + 换手 = 卖出（提前于K线）
  2. K线覆盖：相邻两根K线有重合 = 新换手启动 = 进入下一阶段
  3. 5日线是核心分界线：破5日线必卖，不破可继续持股
  4. 强势表现的判断：高开持股、低开但分时迅速上拉也属强势
  5. 99式的稀缺性：连板几乎不破5日线的股极少，标准必须严格

波次管理是99式战法的"安全阀"——通过严格区分三波，避免在第三波高位接盘。

## 板块五：99式的整体总结

深度总结

1. 99式的核心特征（出自第13节 第29段）
  • 99式是黑马的主机，黑马的地方，综合信息的
  • 99式操作的股是连板连续涨停的稀缺标的
  • 中间几乎都是连板
  • 操作的标准要非常严格
2. 99式的全流程要素
  1. 选股：行业热点、两板起步
  2. 换手日识别：标记分界线
  3. 买入：换手日次日的开盘+分时判断
  4. 持股：5日线为基准，强势表现可继续
  5. 卖出：放量换手 / K线覆盖 / 破5日线
3. 99式的成功路径
  • 一旦穿越99（成功换手）
  • 很可能就会有连板
  • 才能走出真正的龙头
4. 99式的常见陷阱
  • 卖飞（中间经常会卖飞的情况）
  • 假强势（分时看似强但实际是出货）
  • T字板陷阱（T字板不算换手日）

系统性总结（板块五）

板块五是对整个99式战法的系统性收束：

  1. 99式 = 黑马战法——专注最强势连板股
  2. 严标准 = 必胜法则——八个维度严格确认
  3. 波次管理 = 风控核心——三波不做原则
  4. 5日线 = 操作基准——不破持股、破位必卖
  5. 换手日 = 时间锚点——所有操作的起点

99式战法的完整闭环为：<br>选股（两板+热点） → 等待换手日 → 次日高开/低开 + 强势分时买入 → 5日线持股 → 放量/K线覆盖/破5日线卖出

致命选股2：非第一龙头跟涨股（出自第19节第5段）

识别规则：

  • 当你发现市场上有一只股是龙头的时候，你要注意你手里的股是跟涨股

风险场景：

  • 短线的套利跟涨股
  • 一旦龙头确立，跟涨股就要出局

  • 赌新高的结果就是高位站岗

第20节 黑嘴惯犯票

深度总结

一、课程主题与重要性（出自第20节 第1-2段）

本节主题为"黑嘴恶庄惯犯股"。老师特别强调：做超短线要特别注意这一类股票。惯犯股、黑嘴、恶庄属于"九世的禁忌"，看到的都走得远远的，不能做。

二、什么是"黑嘴"（出自第20节 第2段）

  • 黑嘴的定义：那些在很多群到处拉人退票的"黑水票"的大V、推荐人。
  • 恶庄的来源：每个主力每个个股里面都有一些资金在做，上市公司老板或朋友也可能参与，实力不强但想赚钱。
  • 操作手法：喜欢通过"诱惑的方法"去做盘（吸引散户接盘）。

三、黑嘴恶庄惯犯股的四大盘面特征（出自第20节 第3-4段）

注意：老师强调这不是某一只股的特征，而是一种方法的识别。

特征一：市值普遍较小
  • 市值普遍较小，比如小于21亿（指21亿元市值）的股。
  • 原因：黑嘴票拉得动，小庄、小实力的资金能拉起来。
  • 200亿、300亿的大票他们"玩不动"，无法成为黑嘴/恶庄。
特征二：横盘特征，成交量与换手率极低
  • 中途成交量很小，长时间换手率都很低。
  • 死气沉沉的盘面，K线振幅非常小（如1%、0.几%）。
  • 横着不动、不跌，长期低迷。
特征三：曾表现过连续涨停，且有"一字板"
  • 以前曾连续两天、一个、两个、三个涨停。
  • 关键特征：经常有一字板（中间或最后）。
  • 一字板的目的：在散户认知里"一字板=最强"，最能吸引眼球，引来打板跟风盘。
  • 结果：打板客跟进后，主力正好"交货交筹码"，完成派发。
  • 后续：股价破新低（这是惯犯的共同特点）。
特征四：不是主流板块核心标的
  • 不是主流行业（华为、无人驾驶）这种正儿八经、未来成长预期很大的行业。
  • 不是什么主流板块核心标的。

  • 往前翻看K线发现是"惯犯"，已进黑名单。
  • 做进去以后都是大跌。

案例三：厦门信达

  • 已经进入"我们黑名单"的股。
  • 未来若再出现连板、一字板，根本不用考虑，直接不做。

案例四：时空科技

  • 前面是惯犯、是恶庄。
  • 后面若突然两板、一字板，直接不能进90，直接卡掉。
  • 曾经出现23点亏损，三天三四十个点的跌停。

六、典型案例分析（出自第21节 第5-9段）

案例一：天龙股份
  • 主力还是游资？先看有没有结构、是否在连线附近。
  • 一个涨停板 → 不是超短（无连续）。
  • 换手率低 → 不是超短。
  • 换手率有点高 + 只有两板又下来 → 主力把面快速建仓、快速启动。
  • 意义：知道稳定有一波拉升就够了。
  • 风险点：断板要注意卖出。
案例二：通话解码类股
  • 重要原则：成交量看在年线（360日线）下方还是上方。
  • 关键判断：选股一定要在年线上方选择。
  • 因为年线是"流行分界线"，特别是主力盘面。
  • 年线以下的基本不选、不操作（优质股除外）。
  • 战略意义：在选股上就起点高，"已经赢了很多人"。
案例三：3个涨停板的主力盘
  • 资金性质：低换手 → 主力（不是超短线）。
  • 这里有洗盘（跌停板）。
  • 涨停板后均线开始多头排列。
  • 两个涨停板突破 → 这是级别（不是主力运作周期）。
  • 有级别、有结构、但无板块效应 → 独立运作个股。
  • 结论：很有主升浪。
  • 三板后资金回杀越快、时间越短 → 股越强。
  • 高位横盘 + 成交量均匀 + 振幅不小 → 主力快速建仓 + 强势 + 必有主升浪。
案例四：长白山
  • 前看多头均线3.0上方。
  • 现象：追涨停追进去赚不到钱。
  • 真相：低换手，是主力在拉高建仓。
  • 波段很小，没有给其他资金做波段套利机会。
  • 有控盘迹象，吃货主力。
  • 涨停板 + 均线多头 + 极限量（最后一次下跌）+ 运行时间非常长。
  • 定性：强势主力建仓 + 控盘 = 憋大招的个股。
  • 等待：要等有热点。
  • 关键提示：这种涨停板起来"可以追"！
案例五：中信证券
  • 8个月前面 + 1年后面看。
  • 重点放量地方 → 大资金活动。
  • 涨停板 + 低换手 + 50个亿的成交量 = 建仓。
  • 重要认知：建仓后跌破成本很正常（"出货一样"的形态）。
  • 战略资金看更高远、不在乎调整。
  • 应对：不一定是涨停板建仓，都有建仓痕迹。
  • 结论：可以判断行情演化的时间。

## 板块五：第二大盈利模式——波段

深度总结

1. 波段的两个核心难点（出自第22节 第13段）

波段操作需要解决两个难点：

  1. 起波段的时间要短——买入以后要快速起波段。
  2. 起波段起的高——波段涨幅要大。
2. 三种波段类型

##### A. 游资波段（出自第22节 第14-15段）

形成方式：

  • 前面三个板以后94。
  • 94以后1-2-3天没有资金回流形成波段。

确认买入：

  • 波段止跌后，有大阳线或双K确认。
  • 涨停板高开 → 两根K线就确定双K确认。
  • 后面是阴线的话，再来一根阳线，也是底部的双K确认。

关键特征：

"它就要起得快，涨得多。"

风险：风险非常小。

卖出信号：进第三波就卖出（贯穿式）。

##### B. 主力资金波段（出自第22节 第16段）

###### 强调要点一：均线

"主力资金波段大家要会用均线。因为主力资金它有相对稳定性的话，均线对于股价的支撑是很重要的。"

###### 三线金叉（最重要的三大配套）

  1. 均线（最重要）
  2. 双K（K线）
  3. 成交量

三者形成三线金叉，配合双K确认。

###### 提升概率的关键

  • 板块效应 + 三线 + 双K = 起波段成功率"非常非常高"。

###### 大波段基因

  • 这只股喜欢起波段。
  • 是什么资金在做？基因是什么？

###### 主力波段K线特征

  • 主力做的股：经拉伸后在高位横盘。
  • 跌下来后出现双K + 均线联合 + 大阳线 → 双K确认。
  • 三线 + 双K + 均线 + 成交量 → 起波段成功率极高。
  • 若板块共振 → 确定性更高。

###### 主力波段买点（出自第22节 第17段）<br>两个买点：

  1. 双K确认以后都是买点。
  2. 长阳线也可以买。

##### C. 主力资金波段的卖出（出自第22节 第18段）

波段必有顶部。

关键认知：

  • 它也进90了。
  • 90的覆盖第几波？
  • 波段不是纯粹走得那么干净。

顶部形成：

  • 用K线覆盖。
  • 用双K确认两根下跌的阴线（如低开的阴线）来形成顶部。

##### D. 主力资金波段的持股原则（出自第22节 第19段）

"主力资金的波段它都会创出前面的高点。"

关键认知：

  • 高点不一定是顶。
  • 这个地方它会突破。
  • 波段目标：奔着前高，要突破前高。

卖出标准：五日线标准可以做。

3. 战略资金的波段（出自第22节 第19段）

战略资金的稳定性更高。

四大关键：

  1. 知道是战略资金。
  2. 盘面运行结构（是不是牛市结构？）。
  3. 经过第几次拉升？
  4. 均线（重要指标）。

"经过一、二、三次拉伸以后就会见大顶，会见大顶，那个顶是一定要逃的。"

##### 战略资金的稳定性特征（出自第22节 第20段）

  • 一轮上涨时间长。
  • 横盘震荡时间不短。

  • 缩量突破=假突破
  • 大盘弱势时仓位减半
  • 不追高，不打板
