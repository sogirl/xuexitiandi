  • Codex 与 ChatGPT 同一产品，数据互通

第三步：Plus 充值（关键门槛）

  • 为什么必须充值：免费版无法满足建站项目需求
  • 套餐选择：20 美元/月（8 美元和 100 美元档均不需要）
  • 支付障碍：中国大陆信用卡无法支付（不论美元还是人民币信用卡）

  • 如果仅用于建站，充一个月即够
  • 验证：ChatGPT 账号刷新后出现 "Plus" 标识即成功

第四步：七项关键配置（直接影响建站效率）

设置项推荐值原因
访问权限（常规）三项全勾选确保 Codex 有足够权限执行操作（自动审核、完全访问）
速度标准（非快速）快速模式消耗 1.5 倍 token，不急于完成选标准即可

运行时防止系统休眠打开防止休眠导致运行中断

05服务器和域名解析（下）+ WordPress 安装

  • Spaceship：域名管理 → Name Server and DNS → Custom Name Server → 粘贴两条 Hostinger DNS 地址

  1. Hostinger 后台 → 网站 → 添加网站 → 选择 "WordPress"

08营销漏斗 —— SEO 的底层逻辑
理论起点

营销漏斗五步转化流程

  1. 用户遇到痛点问题 —— 生活中各种需求和困扰（吃什么、用什么、怎么解决问题）
  2. 用户上网搜索寻找答案 —— 搜索引擎成为解决问题的入口，这是 SEO 发挥作用的环节
  3. 用户通过搜索发现你的网站 —— 因做了 SEO 排名优化，用户搜索时匹配到你的网站，阅读文章解决疑惑
  4. 用户对网站和品牌产生兴趣 —— 获得专业信息后认可网站专业度（兴趣阶段）

📐 核心定位：关键词调研是 SEO 最基础也最关键的部分，必须在建站动手之前完成。关键词好比开车上路前的路线和目的地——决定了运营方向。

四步流程：输入 → 导出 → 分组 → 分配

第一步：谷歌关键词规划师（Keyword Planner）实操

  • 入口：谷歌广告后台 → 关键词规划师 → "Discover New Keywords"
  • 参数设置：语言选 English，排除中国地区，选择针对所有位置
  • 数据范围：过去 12 个月的搜索数据
  • 蓝色柱状图 = 所有设备搜索量，红色柱状图 = 移动端搜索量
  • 案例：受疫情影响，"office chairs" 在 3-4 月搜索量大幅上升
  • 一次调研可获取上千个关键词（如 1900 个），导出为 Excel 进行分析

第二步：关键词三类分法（按营销漏斗标记）

类型标记颜色特征用途

10什么样的词是好关键词 —— 三条判断标准

标准一：月搜索量不能太低

  • 常规产品底线：月搜索量低于 10 的词，没有必要浪费时间
  • 例外场景（可做低搜索量词）：行业非常冷门、门槛极高、专业性极强（如精细化工品），虽然搜索量低但搜索意图极其精准——"要么不搜，一搜就是对产品有需求"
  • 理想长尾词区间：月搜索量 100-1000——难度较低，较容易获得排名

标准二：月搜索量上万的大词难度极大

  • 新站点应避开超级大词（如 "office chairs" 月搜索量 13万+）
  • 预计最少需要一年才能做好大词的 SEO
  • 优先选择搜索量在 1000-10000 的中大型词

标准三（核心方法论）：低搜索量 + 高 CPC 出价 = 好词

  • 低搜索量 = 竞争小，容易获得排名
  • 高 CPC 出价 = 很多人愿意出高价投广告，意味着商业转化价值已被市场验证
  • 两者结合：易排名 + 高商业价值，是做 SEO 的优质选择
  • CPC 出价是判断关键词商业价值的可靠代理指标
💡 黄金公式：好关键词 = 低搜索量（易排名）× 高 CPC 出价（高商业价值）。这是 SEO 选词的核心方法论。

Title 优化的六大规则

  1. 字数限制：50 个字符以内，超出部分在搜索结果中被截断

14Heading 标签优化 —— 页面内容标题体系
⚠️ 概念区分（重要！）：
  • Title 标签：HTML 中给搜索引擎看的网站标题，出现在搜索结果页蓝字部分
  • H 标签：页面正文内容的标题标记（H1-H6），是给用户和搜索引擎看的内容标题

H 标签权重体系

H1 > H2 > H3 > H4 > H5 > H6（权重从高到低递减）

核心优化原则

  • 优先优化 H1，其次是 H2
  • 越靠上的 H 标签越要尽量包含目标关键词
  • 一篇文章一般只有一个 H1（文章标题）
  • H2 是子标题，同样建议包含核心关键词

WordPress 实操三步法

  1. 前端页面右键"检查"→ 查找 <h1>、<h2> 等标签 → 确认当前 H 标签结构
  2. 后台编辑器 → 选中标题文字 → 工具栏 Heading 下拉菜单 → 修改层级
  3. 更新后刷新前端 → 再次检查元素 → 确认已正确修改

15图片 Alt 标签优化 —— 让爬虫"读懂"图片 + 获取图片搜索流量

Alt 标签存在的根本原因

谷歌爬虫只能识别文字内容，无法直接识别图片中的物体（是一部手机还是一台电脑，爬虫无从判断）。Alt 标签以文字形式告诉爬虫图片内容。

两大优化目标

  1. 让爬虫通过 Alt 文字理解图片内容
  2. 提升 Google Image 搜索排名——为网站带来额外的图片搜索流量
    • 实操验证：搜索 "iphone kisses" → Google Image 中出现的产品图片 → HTML 中 alt 标签值为 "iphone kiss XS" → 证明了 Alt 标签对图片搜索排名的直接影响

图片优化的完整要求

维度标准说明
文件命名用英文命名不要用中文或乱七八糟的符号
Alt 内容自然描述图片内容禁止关键词堆积
单张图片大小常规图/产品图：100K 以内直接影响加载速度
Banner 图大小100K-200K首页 Banner 三张每张几百 K，总大小近 1MB，首页极慢
优化理念治本优于治标上传前压缩本身 + 缓存加速插件辅助 = 真正的速度提升

WordPress 实操

后台 → Media（媒体库）→ 找到图片 → 右侧 Alternative Text 字段 → 填写描述关键词 → 保存。最核心的是 Alternative Text 字段（Title 和 Caption 可选填）。

16网站页面 URL 优化 —— 三个维度的优化

维度一：URL 内容优化 —— 包含关键词

  • URL 应包含目标关键词，让 URL 本身具有语义价值
  • 示例：二级目录 /my-shirt/，三级目录 /black-color-shirt/

维度二：URL 结构优化 —— 层级越短越好

  • 优：首页 > 产品目录 > 产品详情页（三层结构，两次点击）
  • 劣：首页 > 第一级 > 第二级 > 第三级 > 产品详情页（层级过长）
  • 较短的 URL 结构对谷歌更友好

维度三：WordPress 系统配置 —— Permalinks 设置

  • 路径：后台 → Settings → Permalinks（固定链接）
  • 必须选择：Post name（文章名）格式
  • 原因：URL 干净整洁，如 example.com/product-name/，对 SEO 最友好
  • 避免：带问号参数格式（如 ?p=123），不美观且可能导致 404，对搜索引擎不友好

17网站内链建设（理论）—— 站内 SEO 的重中之重

核心概念定义

  • 内链：网站某个页面中的某个关键词，以锚文本形式加上超链接，指向同一网站域名内的另一个页面
  • 锚文本（Anchor Text）：被添加了超链接的那个关键词

内链的三大核心价值（首尾相连的完整逻辑链）

  1. 有利于谷歌爬虫抓取 → 爬虫顺着内链从一个页面深入另一个页面，提高收录效率
  2. 提高用户体验 → 用户读到不理解的术语点击内链即可跳转获取解释
  3. 延长用户停留时间 → 停留时间越长 → 谷歌信号越好 → 排名越靠前

内链建设的六大规范

规范具体要求
禁止过度滥用一个段落不能有十个八个内链，否则视为作弊
关键词位置靠前锚文本关键词放在文章靠前位置，搜索引擎给予更高权重
高度相关性锚文本链接的页面必须与所在页面具有内容相关性
文本多样性锚文本用关键词但保持多样性（如"笔记本电脑"可换为"手提电脑"）
密度控制锚文本关键词密度控制在 1%-2% 左右
自然优先不能为了做锚文本故意堆满关键词——属于作弊

22编写 robots.txt 文件 —— 搜索引擎爬虫的行为指引

核心概念

robots.txt 是放在网站根目录（public_html）的 TXT 文本文件，专门给搜索引擎爬虫看的。爬虫按照其中的指令判断：哪些要抓取收录、哪些不抓取。

默认情况

WordPress 可自动生成 robots 文件，无需刻意编写。路径：后台 → Settings → Reading → Search Engine Visibility。

手动编写的语法

指令含义说明
User-agent: *目标搜索引擎* = 所有引擎。可指定单个 "Googlebot"/"Baiduspider"/"Bingbot"
Disallow: /wp-admin/禁止抓取路径禁止爬虫抓取网站后台（安全+无价值内容）
Allow: /允许抓取路径/ = 网站根目录，允许抓取所有内容
Noindex不收录可抓取但不收录到搜索引擎数据库

建议设置 Noindex 的无商业价值页面

  • Thank You Page（感谢页面）——提交询盘后的跳转页
  • Cart Page（购物车页面）
  • Checkout Page（结账页面）

上传操作

编写 robots.txt → 进入服务器后台文件管理器 → 进入 public_html 文件夹 → File Upload 上传 → 必须上传到根目录，不能上传到任何子文件夹中

23Sitemap 生成和提交 —— 主动告知谷歌来抓取

  • 第一步（爬取）：谷歌蜘蛛来网站爬取内容——sitemap 在此环节发挥作用
  • 第二步（收录）：内容进入谷歌数据库
  • 第三步（排名）：在搜索结果中获得位置

有了 sitemap 文件，爬虫会顺着站点地图中的每个链接挨个到达网站的每一个页面，抓取每个页面的 HTML 内容。Sitemap 极大地便利了谷歌爬虫访问网站页面和读取页面内容。

  • 浏览器访问 https://你的网站.com/sitemap.xml 可查看
  • 按内容类型分类的子地图：
    • page-sitemap.xml：页面站点地图
    • post-sitemap.xml：文章站点地图
    • product-sitemap.xml：产品站点地图

生成方式

📐 提交的意义：主动通知谷歌搜索引擎，让爬虫主动来爬取站点地图上的所有页面信息，加速网站被收录。

核心操作链

29什么是外链 —— 外链建设模块总纲

方法论定调 —— 白帽 SEO vs 黑帽 SEO

类型说明
白帽 SEO（本课程全部基于此）使用干净、正规的手段将网站排名做上去
黑帽 SEO（不提倡、不学习）用作弊手段、黑色技术排上去——风险：
  • 排名只是临时性的
  • 谷歌更新算法后排名被降下来
  • 严重情况：网站被永久拉黑，打入沙盒（Sandbox）——永无天日，永远得不到排名

本课程：不做垃圾外链（Spam Links）、不做链接农场（Link Farm）

外链的定义与本质

  • 定义：外部网站上的某个页面有一个链接指向我们的网站。用户点击从外部网站跳转过来，这个链接就是外链
  • 本质：网站信用的投票机制——得到的外链越多，说明信用越高（相对而言）
  • 比喻：网站像一个人在社会上立足，行业前辈给你投一票说你德才兼备有发展潜力，这就是外链的作用

外链是影响网站排名的前三因素之一

  1. 首要因素：外链
  2. 内容质量（Content Quality，偏重 SEO 层面）
  3. RankBrain：谷歌约 2016-2018 年推出的 AI 算法，模仿人类神经网络判断网站内容质量

数量与质量的关系

数据表明排名越靠前外链数量越高（正相关），但质量比数量更为重要。

30外链的 DA 和 PA —— 权重衡量标准

历史背景

谷歌早期的 PR（PageRank）虽已书面宣布取消，但业内共识是网站权重依然非常影响排名。

DA 和 PA 的来源与定义（来自 Moz）

指标全称含义分值范围特点
DADomain Authority域名权重，反映整个域名的权威性0-100所有页面共用同一个 DA 值，不变
PAPage Authority页面权重，反映单个页面的权威性0-100每个页面不同，随页面内容变化

权重传递机制

通过 Dofollow 外链实现权重传递。案例：如能获得 DA 值 80 分的网站外链（权重极高、域名历史悠久），自己网站排名会提升得非常快。

MozBar 工具

  • 安装：Chrome 扩展商店搜索 MozBar
  • 功能：即时查看任何网站的 DA 值和 PA 值
  • 应用场景：寻找外链来源时，快速判断目标网站权重，辅助判断是否值得作为外链来源
  • 推荐深入学习：访问 moz.com

31Dofollow 和 Nofollow 外链 —— 两种链接传递类型

技术本质

Dofollow 和 Nofollow 是 HTML 标签属性（rel="nofollow"），用于告诉谷歌搜索引擎：

  • Dofollow：可以传递权重（传递 Link Juice）
  • Nofollow：不能传递权重

水杯比喻

一大杯水代表 100% 的权重 → Dofollow 可以把水分配给下面的杯子（传递权重）；Nofollow 不传递水，对网站实际权重提升没有直接帮助。

代码层面识别

  • 右键点击链接 → 检查（Inspect）→ 查看 HTML 代码
  • 有 rel="nofollow" = Nofollow
  • 没有标记 = 默认 Dofollow
💡 Nofollow 的重要价值——引流（Referral Traffic）：
  • 典型案例：Facebook、Pinterest、Instagram、YouTube 等社交媒体上的链接都是 Nofollow 的
  • 虽然不传递权重，但因为社交媒体流量大，引流作用非常高
  • 策略建议：外链建设不能只做 Dofollow，也要建立 Nofollow 外链——Dofollow 负责传递权重提排名，Nofollow 负责社交媒体引流

32锚文本外链 —— 选词与位置策略

锚文本的两种类型

  • 锚文本内链：点击后跳转仍在同一网站内部 → 详见 [17. 内链建设](#doc17)
  • 锚文本外链：点击后跳转到网站之外的其他网站

核心选词原则：尽可能使用目标关键词来做锚文本

  • 举例：专业手机壳网站 → 锚文本用"手机壳批发"或"手机壳制造"——属于相关性强的锚文本外链
  • 反面例子：在微波炉或办公桌椅网站上用锚文本指向手机壳网站——不相关，对用户体验和排名都不好

锚文本外链的位置策略

尽可能放在正文比较靠上的位置。原因：越靠上越容易被谷歌蜘蛛及时发现和爬取 → 谷歌将此纳入排名考量。

技术验证方法

找到外链锚文本 → 右键检查 → 查看是否有 rel="nofollow" → 无标记 = Dofollow（传递权重）

  • 企鹅算法之后：谷歌严厉打击垃圾外链——只要是与你的行业没有任何相关的外链，都会被列入垃圾外链范畴并受到惩罚

34E.A.T. 站点外链 —— 外链质量的最高标准

EAT 定义

  • Expertise（专业性）
  • Authoritativeness（权威性）
  • Trustworthiness（可信赖性）

谷歌偏好外链来源于这种专业、权威、值得信赖的网站。

YMYL 站点与 Medic 算法

  • 2018 年谷歌 Medic 算法（Medical Update）专门针对 YMYL（Your Money or Your Life）类网站
  • YMYL 行业：医药类、财产类（保险、基金等金融类）
  • 对于这类网站的 SEO，EAT 站点的外链尤为关键

EAT 外链示例

  • 卖药网站 → 获取来自 FDA（美国食品药品监督管理局） 的外链
  • 卖药网站 → 获取来自 美国医药协会（American Medical Association） 的外链
💡 核心逻辑链：行业里专业权威的网站给了你一个外链（投了一票） → 向谷歌传递信号：你的网站也值得信赖 → 谷歌因此更认可你的网站

策略指导

在外链建设时，尽量寻找专业、权威、信任度高的站点作为外链来源。切勿只看 DA/PA 数值，还要看来源是否具备 EAT 属性——尤其对于 YMYL 行业。

竞品外链分析四步法

第二步

  • 筛选技巧：只导出 Dofollow 链接、精确匹配域名、锚文本关键词等

36查找行业博客 —— 谷歌搜索指令精准定位

核心搜索技术 —— intitle: 指令

  • intitle: 是谷歌高级搜索指令，意思是在网页 Title 标签中查找指定关键词
  • 语法示例：intitle:"office furniture blogs" → 搜索结果中所有页面的 Title 标题都包含此关键词

实操演示（以办公家具为例）的搜索组合

  • intitle:"office furniture blogs" —— 在标题中搜索办公家具博客
  • best office furniture blogs —— 搜索最佳办公家具博客

搜索结果分类及处理策略

结果类型特征处理策略
资源页面型如"Top 50 Office Furniture Blogs"整合集，含大量博客链接——可直接进入下一课 Resource Page 策略
博客型网站专门的博客站找 Contact Us 页面 → 发邮件联系
电商/商城型（附带博客）如在线零售网站有 Blog 板块同行但不构成直接竞争 → 仍可联系获取外链
服务型企业如办公家具安装/搬家/维修公司非直接竞争对手 → 同属行业生态，可联系获取外链

非竞争关系判断

你是 manufacturer 制造商，对方是安装/维修服务商——非直接竞争对手，属于有效外链来源。

37查找 Resource Page 的外链 —— 最高效的规模化获取方法

Resource Page（资源页面）的特征

  • 页面上汇总列出 N 多种同类资源的介绍
  • 典型格式：Top 10/Best 10/Top 50 榜单、"Helpful Resources" 页面
  • 关键特征：不光列出资源名称，还给每个资源加上外链指向被介绍的网站

查找 Resource Page 的搜索指令组合

  • 关键词 + inurl:links
  • 关键词 + helpful resources
  • 关键词 + useful resources
  • 关键词 + useful links
  • 关键词 + resource page

外链质量验证

通过右键检查确认 Resource Page 上的外链通常为Dofollow，可直接传递权重。

38补充：Schema Markup（结构化数据标记）—— 提升搜索点击率

定义

Schema Markup（纲要标记/结构化数据）是一种用于帮助搜索引擎理解网站信息类型的代码标记。将网页上的不同信息类型用代码进行分类标注，使搜索引擎能识别什么是价格、什么是评分、什么是链接等。

在搜索结果中的实际效果（Rich Snippets）

  • Rating（评分/星级）：以星星图标显示
  • Price（价格）：直接显示价格信息
  • Site Links（网站子链接）：搜索结果下方显示的子页面链接
  • Review（评价数）：显示评价数量

核心价值

让搜索结果的展示更丰富、更突出、信息量更大，直接提高用户点击率（CTR）。

WordPress + WooCommerce 优势

如果使用 WordPress 配合 WooCommerce 电商插件，谷歌蜘蛛会自动抓取 Schema 信息，不需要额外操心。自定义开发才需要与技术团队配合添加。

与外链的协同关系

外链负责提高排名位置，Schema Markup 负责在已有排名的位置上最大化点击率——两者协同，共同提升搜索流量。

三、15 个核心知识点回顾（必背）

  1. 独立站本质：服务器和域名的完全自主所有权 —— 不是 SaaS 平台上的子站点，而是自己拥有"土地和门牌号"
  2. Codex+WordPress 方案逻辑：WordPress 是成熟的"车"，Codex 是 AI 驱动的"支架系统"——人在关键节点介入决策，AI 负责执行。纯 Codex 全栈方案对小白不可控
  3. 20/80 法则：人工做 20% 的基础配置，Codex 做 80% 的内容搭建
  4. 营销漏斗→关键词：不同漏斗阶段对应不同类型关键词——意识阶段用信息类/博客词，行动阶段用商业转化词，关键词调研必须建站前完成
  5. 好关键词 = 低搜索量 + 高 CPC 出价：CPC 出价是判断关键词商业价值的可靠代理指标，低竞争+高商业价值是最优组合
  6. Yoast SEO 是站内 SEO 操作枢纽：Title（50 字符/绿色达标）、Description（150 字符/绿色达标），两者关键词必须一致
  7. Title 优化六大规则：50 字符限制、必含关键词、层级差异化分配、关键词位置前置、与内容高相关、禁止关键词堆积
  8. 图片优化：单张 100K 以内（Banner 100-200K），上传前压缩是"治本"，缓存插件是"治标"，首页总大小控制 1-2MB
  9. 内链是站内 SEO 的重中之重：爬虫抓取效率 + 用户体验 + 停留时间延长 → 三者共同作用于排名。锚文本密度控制在 1%-2%
  10. 建站期间安全设置：Settings → Reading → "阻止搜索引擎索引此网站"——全程勾选，建站完成后再取消
  11. 服务器占加载速度 40%-50%：好服务器是速度的"引擎"，其他优化（图片/插件/视频嵌入）是辅助
  12. 响应式网站是谷歌推荐方案：WordPress 主题天然支持响应式，无需额外担忧 Mobile First Index
  13. 外链本质是"信用投票"：质量（DA/PA/EAT/行业相关性）> 数量。白帽 SEO 是唯一正途，黑帽 SEO 有沙盒永久拉黑风险
  14. Dofollow 传递权重/Nofollow 引流：两者互补缺一不可——Dofollow 提升排名，Nofollow（如社媒平台）负责引流
  15. Resource Page Outreach 是最高效的规模化外链获取手段：配合验证过的邮件模板，可批量操作。搜索指令是 关键词 + inurl:links 或 关键词 + helpful resources
