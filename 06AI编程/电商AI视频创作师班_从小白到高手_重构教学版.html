01

建立判断力：先知道每个平台在链条里负责什么

平台没有绝对的“最好”，只有与输入、控制需求和预算是否匹配。

练习台

豆包

适合提示词练习、市场分析、脚本、基础生图、改图、反推正负向提示词和免费替代方案。它的价值是快速沟通与低成本试错，不是所有最终画面都必须在这里完成。

正式创作

即梦（集梦）

用于图片、视频、主体绑定、九宫格图生视频、SD 2.0 与提示词优化。课程策略是 mini 测试，满意后用 2.0 fast；长视频或明确需要时才考虑 2.5。

电商工具箱

海螺

光影工作室、全视角工坊、多宫格分镜是电商链路的强项。图片可按排版、多图合成、动漫、写真选择模型；视频优先 H3，2.0 做首尾针，2.3 做单参考图，A 准自动模式仍建议手选模型。

真实与可控

可灵

3.0 适合音画同步、多分镜、多人和剧情；2.6 适合单人讲话；2.5 Pro 适合无对白的单镜头产品片。图片 3.0 用主体库与风格，2.1 用于更专门的特征控制。

工作台

哩布 / WebUI / ComfyUI / LibTV

哩布是多模型集合；AI 应用适合直接跑，WebUI 适合参数控制，ComfyUI 适合节点链和复用工作流。LibTV 用画布把脚本、资产、模型串起来，积分分为礼部 AI 与 TV 专属体系。

剪辑出口

剪映专业版

营销成片、AI 文字成片、成片助手、智能/图片分镜、配音音乐、声音分离、字幕、调色与最终导出都在这里完成。AI 生成不是交付，成片才是。

三个术语先记住：Token/词元是模型处理文本的单位；抽卡是同一提示词反复生成筛选；资产是可反复引用的角色、商品、场景、道具、声音和参考图。高手不只是会“抽到好图”，而是会把好结果沉淀成资产。

会员与成本的底层规则

课程记录中出现的 69 元/月、300 积分、每日赠送、七天优惠、会员积分和自动续费等，都属于平台当期规则。通用做法是：免费练习 → 低画质低张数测试 → 确认参考图 → 正式生成 → 批量生产 → 关闭自动续费并记录余额。

任务 01｜平台选择卡

给一个“15 秒耳机卖点视频”写选择理由：练习用豆包；商品主视觉用海螺/即梦图片；一个无台词特写用可灵 2.5 Pro；多镜头剧情用可灵 3.0；最终剪映交付。每个选择必须写出输入、输出和成本理由。

02

素材与商品：先让模型“看懂”你要卖什么

生成效果的下限由素材决定。产品错一个细节，后面所有镜头都可能错。

2.1 素材包的最低标准

商品层

白底主图、正面/侧面/顶部三视图、接口与材质细节、尺寸比例、logo 与颜色说明。三视图可用 SD 4.0：上传参考图，明确“正面/侧面/顶部”，生成 3 张并人工核对。

环境层

目标场景、桌面/人物/手部/光源参考图。商品与背景分开准备，方便后续换背景、换装、局部重绘与光影合成。

策略层

竞品截图、用户痛点、卖点排序、价格/优惠、投放平台和 CTA。先让豆包做市场分析，再决定镜头，而不是先生成漂亮但无销售目的的画面。

2.2 商品放入场景：精度优先的两条路

可控路：PS + 哩布溶图

  1. 打开背景图；置入嵌入对象作为产品图。
  2. 调整位置、大小、透视并抠图；保存 JPEG/PNG。
  3. 进入哩布光影合成工作流，上传合成图并生成。
  4. 检查接触阴影、方向光、反射和产品边缘；不自然就回 PS 或重新生成。

这是商品位置最可靠的路线。

快速路：豆包直接描述溶图

把商品、场景、摆放位置和光线写进描述，适合简单场景与快速探索；随机性较大，位置和透视不准时必须多次修改，正式交付仍建议回到 PS 合成。

2.3 电商图片工具

爆炸图 / 分解图

里布底部搜索“爆炸图”“分解图”→上传耳机、手柄、充电宝等产品→选模板与智能图片或 SD 5.0 Pro→设置比例和画质→生成。先用图检查结构，再决定是否进入视频。

光影与高清

里布光影工作流补环境光；ComfyUI/LibTV 的高清放大可提升分辨率、恢复细节、做人像调节和去 AI 感，去 AI 感建议强度 0.05–0.1，课程演示常用 0.1。

任务 02｜商品资产卡

为一个真实商品建立“商品名_视角_用途_版本”的文件命名；准备白底、三视图、细节、场景、竞品和光源参考。验收：陌生人只看资产包，就能说出商品的形状、材质、卖点和可拍镜头。

03

画面控制：从会写描述，到会给模型下可执行的指令

提示词不是文学；它是给模型的镜头计划。越能被画面验证，越有用。

3.1 统一提示词骨架

主体（商品/人物/角色） + 外观关键细节 + 场景与空间关系 + 动作/状态 + 景别/机位/运镜 + 光线/色彩/质感 + 比例/时长/声音 + 必须保留项 + 禁止项

图片重在“构图、材质、风格、比例”；图生视频要额外写“怎么动、何时动、镜头如何移动、起始与结束状态”。不要让一个镜头承载多个互相冲突的动作。

3.2 图片模型如何选

任务课程中的优先选择判断依据
日常生图、练习豆包基础模型低成本熟悉描述、改图、擦除、扩图、变清晰。
复杂合成/高质感SD 5.0 Pro、GPT-Image、集梦 5.0/全能图片需要材质、商品细节和多图关系时先测试参考图兼容性。
排版含文字海螺 TGPD更适合主图排版；仍应人工检查文字，乱码文字放到后期。
动漫角色悠传风格一致优先，不要混用太多风格词。
写实写真海螺自带图片模型适合照片感，不等于自动保证人物一致。

3.3 改图、局部重绘和反推

  1. 豆包可做擦除、抠图、标记修改、扩图、变清晰；先圈选准确区域，再描述“保留什么、只改什么”。
  2. 局部重绘要保留主体与光线，避免整张图重新随机。
  3. 免费反推：豆包进入“对话任务”（不是工作任务）→素材区上传图→要求输出正向与负向提示词→记录并迭代。
  4. 收费平台可用阿里百炼等反推；视频反推还要补充动作、镜头、时间轴和声音，不能把静态图片描述直接拿来生成视频。

3.4 哩布 WebUI、ComfyUI 与 ControlNet

WebUI 基础

正向提示词、负向提示词、宽高与批量参数；风格模型控制画风；图生图和局部重绘用于保留结构、修正局部。

ControlNet 三种控制

硬边缘：线稿上色；姿态：保持骨架换人物；法线贴图：尽量保持表面方向做材质替换。三者都是上传参考→选控制→写提示词→生成→检查。

ComfyUI 思维

节点是输入、处理和输出；不要从零搭复杂流程，先下载别人做好的工作流拖入复用。中文可先让豆包翻成英文，或使用翻译节点。

复杂度选择：简单效果用哩布 AI 应用；要改节点参数进入 ComfyUI。应用界面是“直接运行”，工作流界面是“逐步检查”。精修流程常见为抠图 → 放大 → 精修，含瑕疵实拍图可关闭不需要的节点再运行。
任务 03｜同一商品做三种控制

用同一产品完成：①一句商品主图提示词；②用局部重绘替换一个材质；③用 ControlNet 法线贴图做材质替换。每次只改一个变量，并保存输入、参数、输出与失败原因。

04

一致性：让人物、商品和场景跨镜头不“换人换货”

一致性不是一句“保持一致”，而是把可引用的主体、视角和控制条件提前建好。

4.1 可灵图片与主体库

可灵 3.0 的结构是“参考素材 → 主体管理 → 提示词 → 风格 → 参数”。主体可以是人物、商品或场景；主体库用于连续多张图与多镜头视频。单张参考图时可用风格词库和提示词推荐；两张以上参考图时提示词推荐可能不可用，需要自己写。

可灵 2.1 更偏特征控制：风格转绘、单独参考、脸部/服装/发型/场景锁定、多图参考合成。3.0 更综合，不是简单替代关系。

4.2 可灵四种视频模式

主体参考

主体库加入人物、场景、道具、特效；提示词用 @主体 引用，可一次加入多个主体并分别指定位置和动作。

图片视频

最基础的图生视频：一张图作为起点，描述单一动态。适合先验证动作，不适合复杂连续剧情。

指令变换

必须先切换到模式再加视频；上传目标视频与参考素材，用 @视频 和素材描述：增减元素、换装、换道具、换人、换背景、局部修改、风格转换、颜色修改、视角切换。多人要明确“左边/右边分别替换谁”。

视频参考

用参考视频借鉴动作、节奏或运镜，再配合主体与提示词控制结果；先确认参考素材有使用权。

4.3 数字人与灵动画布

可灵数字人可用官方预设或本地图片，人物、卡通形象、动物都可以；中文可直接输入台词，其他语言先用外部网站生成音频再上传，AI 自动匹配口型，720P 足够初测。灵动画布用“+”加节点、拉线连接，逐步生成并检查；一个画布可串多镜头，每步提示词可查看、修改和复用。

任务 04｜一致性压力测试

为一个人物和一个商品各建立主体；做“人物拿商品、换背景、换衣服、侧脸”四个镜头。验收：脸、服装、商品形状和位置在四个镜头中可辨认；失败时能指出是参考图、主体引用、动作还是模型能力的问题。

05

叙事与分镜：把卖点翻译成观众能看懂的动作

脚本不是台词堆；每个镜头必须服务一个信息或一个情绪变化。

5.1 从市场洞察到分镜

人群痛点→产品卖点→视觉证明→信任/情绪→CTA

在豆包中先拆竞品、受众语言、使用场景、卖点排序，再生成分镜脚本。脚本至少写：镜号、时长、景别、画面、主体动作、镜头运动、旁白/字幕、音效和转场。人物剧情要补角色关系、对白、场景目标和结尾行动。

5.2 三种视觉计划

九宫格分镜

海螺/即梦生成 3×3 镜头规划图；GPT-2.0，画质中等以上、2K/4K，16:9 或 9:16，只生成 1 张节省积分。之后把九宫格作为 SD 2.0 视频参考图。

脚本截图

在豆包/即梦生成含景别、运镜、时长和画面内容的完整脚本，截图保存；用脚本截图 + 产品参考图输入 SD 2.0。

故事版

海螺/里布用 GPT-2.0 生成带文字分镜图，1–4 张产品参考图，16:9/9:16，中等以上画质、2K/4K；下载后以故事版图作视频参考，豆包 10 秒、即梦/可灵 15 秒按平台设置。

5.3 AI 漫剧是同一套方法的长链路

  1. 豆包写剧本大纲，粘贴到哩布 TV 脚本节点。
  2. 生成分镜脚本，准备角色、场景、道具资产。
  3. 角色准备正面/侧面/背面三视图，上传资产区，在脚本用角色名字触发自动匹配。
  4. 生成分镜图，再生成视频，导出剪映。

角色绑定和场景合成同样适用于商品片：先 PS 合成产品与场景，再做光影，检查位置和透视，最后视频化。

任务 05｜15 秒卖点脚本

为商品写 6–9 个镜头：前 2 秒提出痛点，中段用动作证明卖点，结尾给 CTA。每镜只写一个主要动作；输出“镜头表 + 九宫格图提示词 + 视频提示词 + 后期字幕”。

06

生成镜头：先选方法，再选模型，最后才按生成键

模型决定下限，提示词决定上限；但输入图与控制方式决定你能不能得到想要的结果。

6.1 四种生成方法的决策

方法适合代价与风险
单镜头逐帧简单产品特写、快速验证传统、镜头之间容易断；每个镜头都需独立生成。
九宫格一键先统一规划多镜头分镜图质量和格子关系影响后续，文字可能乱码。
脚本截图需要明确景别、时长、运镜的广告模型对截图文字的理解不稳定，仍需补文字提示。
故事版剧情、角色关系、多镜头叙事图片成本更高；先只生成 1 张，满意后再视频。

6.2 模型选择地图

平台/模型最适场景限制与策略
即梦 mini提示词抽卡、低成本测试先 mini，满意后 2.0 fast；2.5 不要作为默认。
即梦 2.0 fast日常正式生成性价比优先；先确认图，再用视频额度。
即梦 2.5 / 2.0 / 1.0按长视频、旧能力或兼容需求选择模型能力会变，依据实际效果和额度选择。
海螺 H3电商视频性价比首选人物交互、物理逻辑可能弱；手动选比 A 准可靠。
海螺 2.0 / 2.3首尾针 / 单参考图按输入形式选择，不要盲目追新。
海螺 A 准自动化试验课程记录中尚未接入 H3，重要任务手动指定。
可灵 2.5 Pro5 秒/720P 单镜头、产品特写无多分镜、无人物讲话和音画同步；可添加音效。
可灵 2.6单人出镜、口播、产品介绍音画同出；复杂口音、多语言、多人对话稳定性有限。
可灵 3.0多分镜、剧情、多人、音画同步自然真实强，画质质感可能不如即梦；优先选多分镜版。
SD 1.0 智能多帧首帧→过渡帧→尾帧的无缝衔接课程记录中旧模型支持；3–4 张图，过渡描述，3–4 秒/段，总约 15 秒。
SD 2.0九宫格/故事版/脚本截图转视频参考图清楚比提示词堆长更重要。

6.3 图生视频提示词的时间轴

0–2 秒：主体处于什么起始状态；2–5 秒：发生唯一主要动作；5–8 秒：镜头如何推进/环绕/拉远；结尾：停在什么可读画面。写清楚“保持商品形状与 logo，不新增文字，不改变主体身份”。

智能多帧流程：选旧 SD 1.0 → 智能多帧 → 加 3–4 张参考图（首/中/尾）→ 两图之间写过渡描述（如“镜头推进到 logo 特写”）→ 每段 3–4 秒 → 检查过渡是否改变产品。

任务 06｜同一脚本三种生成

用单镜头、九宫格和故事版各生成一个版本；记录输入图、模型、时长、积分、错误类型。不要只比较“哪张最漂亮”，要比较商品准确度、动作完成度、镜头连续性和可剪辑性。

07

成片交付：把生成素材变成能传播、能转化的作品

剪映不是最后的“装饰”，而是把碎片组织成信息节奏的编辑器。

7.1 剪映三条入口

营销成片

打开剪映 → AI 文字成片/营销成片 → 上传实拍或 AI 素材 → AI 分析剪辑 → 选择音色 → 生成。适合已有素材快速出信息流广告。

AI 文字成片

输入或生成剧情 → 选公共/自定义角色 → 选真实/动画风格 → 选智能分镜或图片分镜 → 生成。图片分镜先出图、再逐镜生成，适合无会员和想逐镜控制的人。

成片助手

描述需求 → 选风格 → AI 生成脚本 → 填回剧情内容 → 继续设角色、风格、分镜。适合慢剧、小说或初学者从文字开始。

7.2 声音、动作与后期补救

  • 声音：音乐生成、配音生成、声音克隆、数字人；背景音乐提示词要写情绪、速度、乐器、时长和不要抢人声。
  • 动作模仿：先准备动作参考和主体，注意镜头稳定、身体比例与遮挡，结果不稳时拆成更短动作。
  • 音频：剪映声音分离保留人声或环境声，再替换音乐；必要时使用视频翻译。
  • 水印：有授权的素材优先使用平台会员导出；图片可用 Photoshop 选框工具框选水印 → 右键填充 → 内容识别 → 保存。视频可用 AI 消除，但不能用来去除他人版权标识后冒用。
  • 字幕：生成模型文字常乱码，去掉画面内文字，后期在剪映加可编辑字幕。

7.3 交付前质检

  • 前 2 秒出现问题、结果或强视觉变化。
  • 商品颜色、结构、logo、材质与原始资产一致。
  • 人物身份、服装、场景和动作在镜头间一致。
  • 字幕在手机安全区内，字号足够，文字没有乱码。
  • 人声、音乐、环境声有层次，CTA 能听懂也能看懂。
  • 比例、分辨率、时长、封面、文件名符合投放平台。
  • 确认素材来源、真人肖像/声音授权和平台水印规则。
任务 07｜剪出两个版本

同一批镜头剪一个“15 秒转化版”和一个“30 秒解释版”。前者只保留一个卖点和一个 CTA；后者补充使用场景、细节和信任证明。比较留存和点击，而不是凭感觉争论。

08

系统化：把偶然生成，变成可复制的工作流

高级能力不是会更多按钮，而是能快速定位问题、复用成功配置、控制每次试错的成本。

8.1 哩布 / ComfyUI / LibTV 的三层工作流

应用层：快

找“产品精修”等应用 → 运行 → 上传图片 → 生成 → 下载。适合不想理解节点的任务。

工作流层：稳

在 ComfyUI 查看节点 → 修改抠图、放大、精修、模型等参数 → 执行完整处理链 → 查看每一步结果。万物迁移、换装、高清放大、反推提示词都可在工作流中复用。

画布层：串

LibTV 登录后进入画布 → 上传图片/视频 → 选择阿里、即梦、海螺等模型 → 连接脚本、资产与生成节点。普通会员适合基础使用，至尊会员适合高频；先核对礼部 AI 与 TV 专属积分。

可灵灵动画布：查

添加节点、拉线、逐步生成、逐步验收；多镜头可在一个画布完成，每一步提示词可查看复用，减少来回切换。

8.2 问题定位四问

产品不对？

回到参考图、三视图、主体绑定、透视和模型能力。不要先怪提示词。

动作不对？

拆短动作，补起止状态、镜头运动和时间轴；必要时用动作参考/智能多帧。

画面不自然？

检查光影、接触阴影、材质、ControlNet 和是否过度 AI 修图；先 PS 合成再溶图。

文字乱码？

画面文字后期做；不要反复耗积分让视频模型排版。

积分不够/很慢？

低画质低张数、先图后视频、免费模型练习、批量生成；检查是否选错高成本模型。

会员扣费？

开通后立即检查自动续费并关闭，记录优惠期、余额和到期日。

8.3 一套可持续的项目记录

记录项必须保存
输入原图、参考图、脚本、主体库名称、提示词与负向词。
配置平台、模型、比例、分辨率、时长、张数、seed/工作流（若平台提供）。
输出候选编号、选中原因、错误标签、积分消耗、最终剪辑文件。
复盘首帧、3 秒留存、完播、点击/转化、评论中的真实疑问，下一轮只改一个变量。
合规底线：不把未经授权的真人脸、声音、品牌资产、音乐或他人视频当作自己的素材；不借助去水印绕过版权；不用数字人制造误导性身份。生成前检查，发布前再检查一次。

毕业任务：独立完成一个可交付的电商视频项目

完成下面 10 步，才算从“会操作”进入“会交付”。

  1. 项目简报：写商品、人群、平台、比例、时长、核心卖点、CTA、预算和截止时间。

板块2：AI 行业专业名词解析

深度总结

1. 词元（Token）

  • AI 消耗的计量单位，不同平台叫法不同：
    • 集梦：换算为"积分"
    • 海螺：叫"贝壳"
    • 官方术语：Token
  • 消费公式：会员积分 ÷ 单次消耗 = 可用次数
  • 出自 [F4-电商AI视频创作师班] 第20段~第25段

2. 抽卡

  • AI 生成具有随机性，同样提示词每次效果不同，无法保证 100% 准确。
  • 需要反复测试、调整提示词才能接近预期效果。
  • 集梦生成 3 分钟视频约消耗 5000+ 积分，不代表一次成功，错误需重跑。
  • 出自 [F4-电商AI视频创作师班] 第25段~第30段

3. 资产

  • 在各 AI 平台中生成过的素材（图片、视频）记录，相当于"历史记录"。
  • 只要不主动删除，可一直保存、重新下载。
  • 集梦资产位置：左侧"资产"选项；海螺同理。
  • 豆包资产位置：左侧"AI 创作" → "我的创作"。
  • 出自 [F4-电商AI视频创作师班] 第30段~第35段

系统性总结

名词 含义 平台差异
Token/词元 AI 消耗计量单位 集梦=积分，海螺=贝壳
抽卡 随机生成需反复测试 所有平台通用
资产 生成历史记录 各平台均有资产库

重点/难点：抽卡概念是理解 AI 成本的核心——需要预算反复试错的成本，而非一次生成。

1. 5.0 模型（通用生图）

  • 特点：消耗较低，效果稳定，适合大部分电商图片需求。

2. 5.0 Pro 模型（改图专用）

  • 核心优势：
    • 精准改图：通过框选、箭头、画笔标记指定区域，AI 按标记修改。
    • 文案一致性：尽量保持图片中原有文字的准确性（但不能 100% 完美）。

  • 典型操作：
    • 框选区域 → 描述修改需求 → 生成。

  • 通过海螺或集梦接入 API。
  • 优势：文字准确性远高于 5.0，适合电商海报等有大量文字的图像。

板块一：视频生成基础流程与原则

深度总结

  • 基本流程：AI 视频生成的常规路径是「文字 → 图片 → 视频」，而非直接用文字生成视频。直接文生视频可控性差，缺少主体参考时，生成的人物长相、场景、物品都不可控（出自[文档名] 第00:13-00:31段）。
  • 先图后视频的优势：图片已有景别、场景、主体样貌信息，视频生成时只需指定「画面中怎么动」和「镜头怎么动」，准确度显著提升（出自[文档名] 第00:27-00:41段）。
  • 提高准确度的额外方法：脚本方式和宫格图参考方式，后续课程会讲到（出自[文档名] 第00:36-00:40段）。

系统性总结

  • 核心原则：文生视频可控性弱，图生视频更准；凡是需要精确主体（人物/产品）的场景，务必先生成参考图。
  • 注意事项：不要完全依赖文字描述来控制主体样貌。

板块二：集梦平台核心功能与主体绑定（AT键）

深度总结

  • 集梦的限制：不能参考人脸生成视频；不能生成知名影视角色、明星（如钢铁侠会被驳回）；不能以真人照片作为人脸参考（出自[文档名] 第04:48-07:10段）。
  • 主体绑定（AT键）：选择 2.0 任意模型 → 全能参考模式 → 点击 AT 键 → 添加主体（人物或产品）→ 绑定为主体。绑定后绕开人脸检测，可正常使用真人/产品参考图（出自[文档名] 第07:58-10:58段）。
  • 主体添加方式：本地添加（电脑素材）/ 资产添加（平台之前生成的素材）。人物绑定后需描述名字；产品绑定可不加音色（出自[文档名] 第10:12-14:28段）。
  • AT 键不可见时的处理：关闭集梦页面重新进入，或切换到「视频生成」模式、选择 2.0 模型（出自[文档名] 第08:16-09:48段、17:56-18:46段）。
  • 主体使用：生成视频时通过 AT 键调用主体；人物最好是绑定为主体；场景可作为素材直接添加但不能加人（出自[文档名] 第15:13-16:54段）。
  • 画质与模型：豆包生成图片通常 2000+ 分辨率，不算模糊；集梦人物/肢体细节更好；4.6 模型在保持人物一致性上更准确（出自[文档名] 第31:24-37:25段）。

系统性总结

  • 主体绑定本质是把参考图先提交平台审核，审核通过后后续生成不再被人脸/版权规则拦截。
  • 关键操作顺序：选模型 → 全能参考 → AT → 加主体 → 生成。

板块三：集梦 vs 豆包对比与使用策略

深度总结

  • 集梦优点：视频模型效果国内最好；主体绑定准确；能处理真人出镜（通过绑定）；细节更精准（出自[文档名] 第11:49-12:19段、37:25-39:13段）。
  • 集梦缺点：收费；首次使用需注意消耗；AT 键有灰度限制，部分新用户暂不开放（出自[文档名] 第11:49-12:19段、08:16-09:48段）。
  • 豆包优点：免费、每天有免费次数；生图可用参考图（最多约 10 张）；适合简单背景/主体生成（出自[文档名] 第13:47-13:56段、36:41-37:25段）。
  • 豆包缺点：生视频不能 AT 主体的参考图；人物容易出错或被驳回；不能绑定主体；准确性较弱（出自[文档名] 第33:31-35:38段、41:53-42:51段）。
  • 配合策略：豆包用于简单素材/试效果；集梦用于最终高精度生成。豆包积分用完时可用其生图辅助（出自[文档名] 第39:13-41:53段）。

系统性总结

  • 豆包 = 免费试错 + 素材生成；集梦 = 高精度主体合成。两者可串联使用（集梦出脚本/图 → 豆包免费生成视频）。

板块四：声音处理：音乐生成 / 配音生成 / 声音克隆 / 数字人

深度总结

  • 音乐生成：集梦与豆包均可生成背景音乐；可指定风格、乐器、BPM（BPN 数值越高节奏越快）；支持参考图片生成对应场景音乐；支持多语言（英/日/韩）；生成后播放器要切换到扬声器才能出声（出自[文档名] 第44:15-50:44段）。
  • 豆包音乐模板：可直接使用官方模板，也可删除模板自由创作；建议把参考图和描述一起给（出自[文档名] 第53:41-56:37段）。
  • 配音生成 / 声音克隆：
    • 集梦配音生成：可选择自带音色或克隆自定义声音；克隆需先导出音频（>5s，清晰无人声背景）；支持本地录音（出自[文档名] 第01:13:39-01:21:22段）。
    • 剪映配音：也可克隆音色，但通常需会员（出自[文档名] 第01:21:22-01:22:43段）。
  • 数字人：人物 + 声音 + 动作合成；适合产品介绍/口播类；缺点是无法切镜，只能单画面；可提前把人物和产品合成一张图再上传（出自[文档名] 第01:37:12-01:46:49段、01:55:52-01:59:16段）。
  • 版权提示：使用明星声音/角色容易被驳回或触发版权限制；建议使用自己的声音或 AI 合成音色（出自[文档名] 第01:31:29-01:32:21段）。

系统性总结

  • 声音处理三条路径：音乐（平台直接生成）→ 配音（剪映/集梦克隆）→ 数字人（人物+声音合成）。
  • 关键约束：克隆素材需 >5s、清晰、无背景音乐；数字人不支持分镜。

板块五：动作模仿

深度总结

  • 定义与用途：参考别人的动作（舞蹈/武术/热梗）生成到自己的角色上，比文字描述动作更准确（出自[文档名] 第02:00:57-02:01:16段）。
  • 操作要点：
    • 使用平台提供的模板或本地上传参考视频
    • 素材景别必须与参考一致（人脸特写对应人脸特写，全身对应全身）
    • 比例建议选 1:1 正方形（出自[文档名] 第02:01:48-02:05:38段）
    • 添加人物参考图后，直接生成即可，无需写提示词（出自[文档名] 第02:04:33-02:04:50段）
  • 适用场景：抖音热梗、舞蹈、武术类视频（出自[文档名] 第02:03:21段）。

系统性总结

  • 动作模仿 = 参考视频模板 + 景别匹配；适合大幅度、重复性动作，不适合精细口播。

板块六：A准模式与一站式工作流（脚本→图片→视频）

深度总结

  • A 准模式特点：只给一个想法，平台自动生成脚本 → 故事版 → 图片 → 视频；无需手动切来切去（出自[文档名] 第02:12:36-02:17:02段）。
  • 使用建议：
    • 第一遍先生成脚本和故事版，检查再生成图片/视频
    • 描述时写清楚时长（如 10 秒）、平台（抖音/小红书/淘宝）、风格
    • 生成图片后保存，再基于故事版生成分镜参考图（比例 16:9）（出自[文档名] 第02:17:52-02:28:00段）
  • 成本控制：
    • A 准模式每一步都可能扣费，生成图片/视频时才扣款
    • 平台默认自动选择最贵模型，建议关闭自动、手动选模型
    • 豆包免费额度可接：生成脚本/故事版基本不扣费（出自[文档名] 第02:15:10-02:21:20段、02:48:16-02:49:05段）
  • 故事版导出到豆包：下载故事版（MD/PDF 格式）→ 豆包新对话 → 添加参考素材 → 生成视频；豆包一次最长约 10 秒（出自[文档名] 第02:40:21-02:47:46段、02:53:46-02:55:12段）。

系统性总结

  • A 准模式适合不熟悉平台操作的用户，但需警惕自动扣费；推荐流程：集梦 A 准出脚本/故事版 → 豆包免费生成视频。

板块一：平台概述与积分机制

深度总结

1. 平台定位

  • 海螺AI是一个国内AI创作平台，风格偏向国外效果，默认生成外国人面孔
  • 更适合产品类内容，物理逻辑与人物交互较弱
  • 图片模型针对性强，每个模型对应特定场景
  • 出自 [1.3 海螺AI核心功能全玩法拆解] 第1段~第41段

2. 积分机制

  • 新账号赠送积分（有效期3天，300积分足够了解全部功能）
  • 仅赠送一次，不可重复（与极梦每天赠送不同）
  • 微信/手机号登录均可
  • 出自 [1.3 海螺AI核心功能全玩法拆解] 第42段~第56段

系统性总结

  • 平台定位：电商场景工具集合，风格偏国外，性价比高于集梦，但物理逻辑与人物交互弱于集梦
  • 积分策略：仅赠送一次，300积分足够入门，不适合长期依赖
  • 重点：海螺是电商指向型平台，复杂人物/剧情内容建议切换到集梦/可灵等平台

板块二：图片创作模型体系

深度总结

1. TGPD API模型（参考文字排版）

  • 电商主图/海报首选
  • 优势：文字排版准确性高、字体风格一致、不易乱码
  • 可AT参考图片的文字/排版/颜色，产品可替换
  • 适合海报、电商主图，不适合多图合成
  • 出自 [1.3 海螺AI核心功能全玩法拆解] 第60段~第100段

2. 集梦5.0 / 全能图片

  • 适合多图合成（人脸/产品一致性高）
  • 全能图片画质更好但消耗更高；集梦5.0消耗更低
  • 出自 [1.3 海螺AI核心功能全玩法拆解] 第100段~第120段

3. 悠传（动漫/角色）

  • 适合设计动漫形象、慢剧角色
  • 不能加参考图片，一致性弱，适合纯文字描述生成
  • 出自 [1.3 海螺AI核心功能全玩法拆解] 第120段~第140段

4. 海螺自带模型

  • 主要用于人脸精细化/电影写真，效果有限，一般少用
  • 出自 [1.3 海螺AI核心功能全玩法拆解] 第140段~第160段

5. 比例与画质设置

  • 比例选择：电商常见 1:1、3:4、9:16；4:3 与 3:4 需区分；5:4 很少用
  • 画质/分辨率/张数：简单海报选中或低画质；文字复杂的详情页选高画质；张数默认4张，建议练习调低
  • 出自 [1.3 海螺AI核心功能全玩法拆解] 第160段~第200段

系统性总结

  • 选模型原则：排版参考→TGPD；多图合成→集梦5.0/全能图片；动漫角色→悠传；真人写真→海螺自带
  • 比例优先：9:16（竖屏）、3:4、1:1，避免选错导致图片变形
  • 重点：TGPD模型是海螺的特色，适合电商文字排版，其他平台难以替代

板块三：视频生成模型与操作

深度总结

1. 海螺视频模型

  • H3（最佳，5秒2K约60积分）、2.0（首尾针）、2.3（单参考图）、1.0（早期，已淘汰）
  • H3 支持图片/视频/声音多模态参考，可多镜头同出，消耗比集梦便宜（约0.3-0.5元/秒 vs 集梦1-1.5元/秒）
  • 出自 [1.3 海螺AI核心功能全玩法拆解] 第200段~第250段

2. 2.0/2.3 模型限制

  • 2.0/2.3 仅做单镜头，不能做首尾针过渡；2.0支持首尾针
  • 2.3只能添加一张参考图，2.0可添加首尾帧
  • 出自 [1.3 海螺AI核心功能全玩法拆解] 第250段~第300段

3. A准模式

  • 自动选择模型，目前未接入H3，易误选集梦扣费，尚不如工具手动生成好用
  • 出自 [1.3 海螺AI核心功能全玩法拆解] 第300段~第350段

4. 运镜与提示词优化

  • 运镜可通过描述或预设添加
  • 优化提示词勾选后画面无人脸时更优质，有人脸可能变形
  • 出自 [1.3 海螺AI核心功能全玩法拆解] 第350段~第400段

系统性总结

  • 视频生成优先用工具手动选模型；A准适合初步构思，不做精确控制
  • H3性价比最高，消耗比集梦便宜约60%
  • 重点/难点：A准模式尚未接入H3，实际使用时手动选择模型更可靠

板块四：电商专用小工具

深度总结

1. 光影工作室

  • 上传白底图/人物场景图，选风格与张数，调整打光与场景氛围，不改变主体
  • 适合产品人物打光调整，前期拍摄无需专业灯光设备
  • 出自 [1.3 海螺AI核心功能全玩法拆解] 第400段~第450段

2. 全视角工坊

  • 单角度生成其他视角（左/右/俯视），累计计算张数，每次至少保留一个视角
  • 适合产品多角度展示，只有一个正面素材时可生成侧面/俯视
  • 出自 [1.3 海螺AI核心功能全玩法拆解] 第450段~第500段

3. 多宫格分镜

  • 提供参考图+故事大纲，生成3×3/4×4/5×5分镜图
  • 格数越多单张画质越差；可用于广告/剧情分镜，再导入视频生成
  • 3×3画质最佳，5×5画质明显下降

“单独参考”用于在改变其他元素时尽量保持人物脸部或服装等指定特征。参考强度越高，指定特征越接近原图；参考强度越低，模型随机性越强。例如，希望保持人物脸部不变但更换服装、发型或场景，可以提高脸部参考强度；希望保持服装或发型不变而改变人物脸部，则可以提高对应特征的参考强度。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 541—568 行]

单独参考可能导致脸部边缘轻微虚化或不够自然，因此课程也强调，很多时候可以直接在 3.0 中通过提示词实现类似效果，例如要求“保持人脸不变，更换服装”，这样操作更灵活。2.1 的价值在于把“保持脸部”和“保持服装”等控制项做得更明确。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 568—597 行]

2.1 的“多图参考”用于将多个人物、场景或对象组合到同一画面中。课程指出，3.0 同样可以通过主体库和提示词实现类似效果，因此日常可以优先使用 3.0。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 583—603 行]

系统性总结

2.1 是“特征控制型”工具，适合需要明确锁定脸部、服装、发型或场景的图像任务；3.0 是“综合创作型”工具，适合更广泛的合成、风格化和自由生成。两者的关系不是替代，而是针对不同控制需求的分工。

重点： 参考强度决定“保持原图特征”和“允许变化”之间的平衡。
难点： 过度锁定可能造成脸部边缘不自然，需要根据输出效果调整参考强度。
适用场景： AI 模特、角色换装、人物脸部保持、服装保持、多图合成。

板块五：可灵视频生成模型——2.5 Pro、2.6、3.0 的能力与成本差异

深度总结

可灵视频生成主要有 2.5 Pro、2.6 和 3.0 等模型。课程建议根据是否需要讲话、是否需要多分镜、是否需要口音以及预算来选择合适的模型，而不是默认使用最贵的模型。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 676—710 行]

2.5 Pro 适合生成单镜头视频，不能生成多分镜，也不能实现音画同步或人物讲话；它可以添加音效，适合香水、手镯、服装、产品特写等不需要人物台词的产品视频。课程演示中，5 秒、720P 的消耗相对较低，因此在“只需要一个镜头、不需要声音”的场景下性价比较高。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 681—705 行]

2.6 可以音画同出，适合单个人物出镜的口播、产品介绍或数字人式视频，但仍只能生成单个镜头。它可以处理中文、英文等较简单的语言，但课程指出复杂口音和多国语能力有限；多人对话的效果也可能不如单人对话稳定。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 719—748 行]

3.0 是可灵视频生成的主要推荐模型，支持音画同步、多分镜、多个人物和较丰富的语言表现，能够带上部分地方口音。它适合短剧、剧情类视频、人物对话和需要自动分镜的内容。课程强调，3.0 的画面真实感和人物表情动作相对自然，但画质和视觉质感可能不如即梦等平台，因此需要根据“真实自然”与“画质质感”之间的取舍选择工具。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 752—818 行]

3.0 还存在一个单镜头版本，能够音画同出但不能一次生成多个分镜。课程建议日常优先使用支持多分镜的 3.0 版本，因为价格差距通常不大，而多分镜能力更适合完整剧情视频。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 810—820 行]

系统性总结

视频模型的选择可以按需求分层：

  • 只需要产品特写、单镜头、无台词： 优先 2.5 Pro，成本较低。
  • 需要单人出镜、口播、音画同步： 使用 2.6。
  • 需要剧情、多分镜、多人物、口音和自然对话： 使用 3.0。
  • 只需要单镜头但需要音画同步： 可使用 3.0 的单镜头版本。

重点： 模型越高级，通常消耗越高；不要为了“高级”而忽略实际需求。
难点： 音画同步、分镜、口音和多人物能力不是所有模型都具备。
交叉提示： 第 6 板块的 3.0 流程是视频生成部分的核心操作。

板块六：可灵 3.0 视频生成完整流程——参考图、脚本、分镜、参数与下载

深度总结

使用 3.0 生成视频前，最好先准备一张参考图。参考图可以是人物剧照、产品图、电商主图或课程中使用的分镜图。参考图的作用是约束人物、场景、构图和整体视觉方向；如果没有参考图，模型会随机生成人物和场景，结果可能不够准确。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 822—855 行]

课程建议先根据参考图生成剧情脚本。参考图可以交给豆包或其他问答工具，让它补充剩余剧情、人物对白和分镜内容；如果是电商产品视频，可以要求生成广告脚本；如果是短剧，可以要求生成剧情脚本，并明确人物数量、场景、台词和时长。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 856—892 行]

在可灵中生成视频时，将参考图放入参考画面区域，将脚本放入脚本区域。勾选“智能分镜”后，平台会根据脚本自动安排镜头；如果希望更精确地控制每个镜头的秒数、画面内容和对白，可以选择“自定义分镜”，逐段输入镜头内容。智能分镜操作简单，自定义分镜控制更准确。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 893—931 行]

自定义分镜的基本格式是按时间顺序拆分镜头，例如第 1 秒到第 3 秒、第 3 秒到第 5 秒、第 5 秒到第 7 秒等，并为每个镜头填写画面内容、人物动作和对白。课程建议一个 8—10 秒的视频设置 3—5 个镜头，单个镜头通常保持 2—3 秒；镜头过密会导致画面切换过快，镜头过少则剧情不完整。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 905—970 行]

生成参数包括总时长、分辨率、是否需要音画同步等。纯产品视频如果没有人物讲话，可以关闭音画同步，从而节省约三分之一的消耗；剧情、口播或有人物对白的视频需要保留音画同步。分辨率方面，课程认为 720P 或 1080P 通常已能满足练习和基础发布需求，关键是根据预算和画面要求选择。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 1003—1045 行]

视频生成完成后，会员账号下载时可以选择“无品牌水印”选项，并选择 MP4 或 MOV 格式。课程指出，MP4 和 MOV 的画质基本相同，主要区别是文件格式；下载后应检查人物、画面、台词、分镜和音效是否符合要求，再提交作业或用于后续剪辑。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 1116—1123 行]

系统性总结

3.0 的完整工作流可以概括为：

准备参考图 → 生成剧情或广告脚本 → 粘贴到可灵 → 选择智能或自定义分镜 → 设置时长、分辨率和音画同步 → 生成视频 → 检查并下载。

这个流程的核心不是“直接输入一句话生成视频”，而是先通过参考图锁定视觉方向，再通过脚本控制内容，最后通过分镜控制节奏。参考图和脚本是可灵 3.0 视频生成的两个关键前置条件。

重点： 参考图决定画面准确性，脚本决定剧情准确性，分镜决定节奏。
难点： 脚本格式、分镜时间、音画同步和主体名称需要前后一致。
适用场景： 电商广告、短剧、人物口播、剧情视频、产品讲解。
交叉提示： 主体库中的角色和道具应在生成前绑定，以降低人物脸部、服装和道具不一致的风险。

板块七：视频水印去除与音频分离——后期补救方案

深度总结

课程指出，收费平台在开通会员后下载视频通常可以去除平台自身的水印；免费体验或免费生成可能会带有平台水印。若视频来自其他免费平台，或者画面中出现了不需要的字幕、动画文字，则需要使用外部工具处理。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 1228—1246 行]

视频水印可以使用“开拍”等平台的 AI 消除功能处理。进入平台后选择 AI 消除，上传视频，平台会自动识别右下角或左上角的水印区域；如果需要去除固定位置的字幕，也可以手动框选字幕范围。点击开始后，平台逐帧处理，通常需要数分钟，免费次数和可处理时长有限，因此大量处理时可能需要付费会员。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 1247—1310 行]

AI 消除无法保证每一帧都完全完美，处理后的局部可能轻微模糊。因此，水印去除属于后期补救，不能替代生成前的画面检查。图片水印可以使用 Photoshop 处理，但 Photoshop 不能直接去除视频水印；视频水印需要专门的视频处理平台或逐帧编辑工具。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 1302—1330 行]

音频后期可以在剪映中处理。将视频加入轨道后，右键素材选择“声音分离”，可以保留人声或保留环境声；部分版本还提供音乐分离，可以把吉他、鼓等乐器声音从背景音乐中拆出。课程强调，音频分离可以在不重新生成画面的情况下替换音乐或环境音，从而避免重复消耗视频生成积分。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 1367—1413 行]

如果视频需要翻译，剪映专业版还提供视频翻译功能，但通常属于会员功能，并会消耗 AI 积分；课程演示中提到可以翻译为英文、日文、西班牙语等，但实际支持语言和消耗以当前版本为准。音频分离和翻译都属于后期制作能力，目标是减少重复生成和重新付费。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 1401—1419 行]

系统性总结

后期补救分为两类：

  1. 画面补救： 使用 AI 消除去除视频水印、字幕或不需要的元素；图片问题优先使用 Photoshop。
  2. 音频补救： 使用剪映的声音分离保留人声或环境声，再替换音乐；必要时使用视频翻译。

课程的核心建议是：生成前尽量检查画面和脚本，生成后先做后期调整，不要仅因为音乐或环境音不满意就重复生成整段视频。

重点： 视频去水印不能保证逐帧完美；剪映声音分离可以降低重复生成成本。
难点： 外部平台的免费次数、处理时长和会员价格会变化，应以实际页面为准。
交叉提示： 音频处理是剪映课程模块的前置知识，可与第 2、8 板块交叉学习。

课程最后提到，可灵还有“多模态”工具，可用于视频修改，例如改变人物服装、调整画面元素或进行视频内容变换。本次课程主要讲解可灵的基础生成能力，视频修改和多模态工具将在后续课程中进一步演示。[出自 1.4 可灵AI基础功能及AI采访视频_原文 第 1487—1498 行]

全文系统性总结

本讲围绕“可灵平台的基础生成能力、视频模型选择、视频生成流程以及后期补救”展开，核心不是单纯认识按钮，而是建立一套可复用的电商视频生产流程。

一、平台选择逻辑

  • 海螺模板适合快速复制热门效果，但自由度和可修改空间有限。
  • 可灵适合图片合成、人物一致性、剧情视频和多分镜生成。
  • 2.5 Pro 适合低成本单镜头产品视频。
  • 2.6 适合单人出镜、口播和音画同步。
  • 3.0 适合短剧、剧情、多人物、多分镜和较自然的对话。

二、内容生产逻辑

可灵 3.0 的稳定流程是：

参考图 → 脚本 → 分镜 → 参数 → 生成 → 检查 → 下载。

其中，参考图用于锁定视觉方向，脚本用于锁定剧情，分镜用于控制节奏，主体绑定用于保持人物和道具一致。只有这四项配合，才能减少随机生成和反复重做的成本。

三、成本控制逻辑

  • 模板和短时长视频消耗较低。
  • 2.5 Pro 适合无台词产品视频，成本最低。
  • 2.6 和 3.0 具备音画同步能力，但消耗更高。
  • 3.0 的多分镜和多语言能力强，适合剧情视频。
  • 会员优惠必须注意自动续费。
  • 音频不满意时优先在剪映中分离和替换，不要重复生成视频。

四、后期处理逻辑

  • 图片水印可以用 Photoshop 处理。
  • 视频水印需要 AI 消除等视频处理工具。
  • 剪映可以分离人声和环境声，必要时还可以处理音乐和翻译。
  • 后期补救不能完全替代生成前检查，尤其是人物脸部、服装、道具和脚本一致性。

五、学习路径建议

  1. 先掌握海螺模板，理解“参考效果—替换素材”的基本模式。
  2. 再学习可灵 3.0 图片生成和主体绑定，建立人物、商品、场景一致性的基础。
  3. 然后比较 2.5 Pro、2.6、3.0 的视频能力，按需求选择模型。
  4. 最后练习“参考图 + 脚本 + 分镜”的完整视频流程，并配合剪映完成水印和音频后期。

一、可灵多模态创作工具 — 图片生成与主图模式

深度总结

1. 多模态 vs 普通生成

  • 多模态创作工具（左侧绿色小圆圈）与"生成"模块有重叠，但多模态选项更多，核心区别在于支持主图模式和视频级主体绑定等高级功能。[出自1.5 第12-19段]

2. 主图模式（核心功能）

  • 主图模式需上传参考图后才会出现，不勾选时为普通生图（每张图相互独立、抽卡式生成）；勾选后，生成多张图片之间具有内容关联性，适合做系列分镜图。[出自1.5 第21-59段]
  • 作用一：系列组图/分镜生成 — 提供1张参考图+剧情描述，AI推测后续内容，最多一次性生成9张关联分镜图，每张可挑选使用。[出自1.5 第30-41段]
  • 作用二：多图引用 — 可同时添加多张参考图，指定某张图作为主角A、主角B、场景等，精准控制画面元素。[出自1.5 第33-35段]
  • 作用三：风格批量转换 — 同一参考图可一次性生成卡通/3D/油画等多种风格的图片。[出自1.5 第57-62段]
  • 作用四：电商多图合成 — 将人物图与服装/鞋子/帽子图等分别作为参考，组合合成新图（如"图片1的人物穿上图片2的鞋子、图片3的帽子"）。[出自1.5 第157-164段]
  • 触发条件：①必须添加参考图；②在主图模式开启状态下使用。[出自1.5 第91-94段]

3. 限时一口价与智能数量

  • 智能数量模式：无论生成2张还是9张，扣费相同（一口价），适合一次性生成较多图片（如9张分镜），更划算。[出自1.5 第71-84段]
  • 手动勾选数量模式：按实际生成张数计费，适合只需生成1-2张时选择，更便宜。[出自1.5 第81-85段]
  • 智能数量与限时一口价配合使用：勾选智能数量后自动生效一口价计费；手动选张数则按张计费。[出自1.5 第101-105段]

4. 画质与模型选择

  • 画质可选1K/2K，2K消耗积分更多。[出自1.5 第70-71段]
  • 模型默认选择图片3.0欧米即可，无需更改。[出自1.5 第88-89段]
  • 比例默认识别参考图比例，也可手动选择（如4:3、9:16竖屏），建议尽量与素材比例一致，避免画面变更。[出自1.5 第137-139段、第256-259段]

5. 使用指南入口

  • 在多模态界面，先切换到"图片生成"，再点击上方"使用指南"即可看到官方推荐页面和提示词格式。[出自1.5 第47-50段、第143-146段]

系统性总结

核心要点：主图模式是可灵多模态图片生成的核心特色功能，通过上传参考图解锁，支持"一张图推九张分镜"、"多图精准引用"、"风格批量转换"三大应用。智能数量+一口价适合大批量生成（≥4张），手动选张适合少量生成（1-2张）。

重点：主图模式的关联生成特性是区别于普通生图的核心；多图引用时需@对应素材编号。

难点：智能数量与一口价的关系需理解清楚；主图模式必须在上传参考图后才能勾选。

二、可灵视频生成四大模式详解

深度总结

可灵多模态视频生成提供四个模式，各有不同适用场景：

模式一：主体参考（最常用）

作用：精准控制画面中出现的人物/物体，保持主体一致性，适合多主体合成视频。[出自1.5 第199-217段]

操作方法：

  1. 进入"主体参考"模式。[出自1.5 第196-198段]
  2. 在主体库中添加主体（可自己创建，也可使用官方素材）：人物、场景、道具、特效均可。[出自1.5 第208-216段]
    • 创建主体：点击加号 → 上传参考图 → 设置分类（仅影响查找位置）→ 命名保存。[出自1.5 第231-244段]
    • 特效/传送门等素材可自行上网下载PNG格式图片作为主体。[出自1.5 第221-228段]
  3. 在提示词中用**@符号引用主体**，如"@主体A在场景B中"。[出自1.5 第259-260段]
  4. 可一次性添加多个主体，分别指定位置和动作。[出自1.5 第212-216段]

智能分镜功能：

  • 勾选"智能分镜"后，AI自动按时间分配镜头，适合时长7秒以上的视频。[出自1.5 第250-253段]
  • 也可选择"自定义第一分镜"，手动描述每个镜头的作用。[出自1.5 第250段]

关键技巧：时间轴描述

  • 视频时长建议写清楚时间点：如"第0秒到第3秒做A，第3秒到第5秒做B"。不写时间轴，分布安排可能不准确。[出自1.5 第46-48段]
  • 一个镜头约2-3秒，10秒视频约4-5个镜头。[出自1.5 第697-700段]

音画同步：

  • 勾选音画同步，视频生成时自动匹配音效或讲话声音。[出自1.5 第252-253段]

分辨率建议：720P足够，无需追求更高。[出自1.5 第307-309段]

核心优点：保持主体一致性，可重复组合，适合电商广告（固定人物/产品反复出现在不同场景）。[出自1.5 第271-275段]

模式二：图片视频（最基础）

作用：普通图生视频，支持首帧/尾帧模式，与普通生成界面操作相同，无特殊功能。[出自1.5 第330-335段]

提示：此模式与昨日内容重复，不作为重点。[出自1.5 第331段]

模式三：指令变换（核心差异化功能）

作用：对已有视频进行修改——增加/减少/替换画面中的元素。[出自1.5 第338-346段]

适用场景：

  1. 增减画面元素：画面有两个人，只保留其中一人；或添加新物体。[出自1.5 第342-344段]
  2. 换装/换道具：给人物换衣服、加墨镜、换手持道具等。[出自1.5 第344-346段]
  3. 换人：保留场景，替换画面中的人物（需提供目标人物图片）。[出自1.5 第367-370段]
  4. 换背景：人不变，背景替换。[出自1.5 第398-399段]
  5. 局部修改：将小道具画成不同效果。[出自1.5 第400-401段]
  6. 风格转换：将视频转为卡通/漫画/赛博朋克等风格（需参考图或描述知名风格）。[出自1.5 第401-409段]
  7. 颜色修改：如菩提变为红色变蓝色；绿幕抠图等。[出自1.5 第411-412段]
  8. 视角切换：正脸改为侧脸。[出自1.5 第393-395段]

操作方法：

  1. 先点击切换到"指令变换"模式（必须先切换才能添加视频）。[出自1.5 第513-514段]
  2. 添加目标视频作为素材。[出自1.5 第515段]
  3. 添加需要替换的参考素材（图片）。[出自1.5 第516-517段]
  4. 在提示词中@视频和素材，描述替换内容。[出自1.5 第58-520段]
  5. 多个人物时需分别描述（如"左边的人替换成A，右边的人替换成B"）。[出自1.5 第58-549段]

价格说明：消耗取决于上传视频的时长，5秒视频生成约等于5秒修改的价格。[出自1.5 第421-423段]

与极梦对比：

  • 可灵对影视素材、出名人物限制较少（可把叶问换成钢铁侠），极梦有版权审核会驳回。[出自1.5 第406-409段、第485-487段]
  • 极梦生成效果更好，但可灵限制更少、价格更便宜。[出自1.5 第1337-1343段]

关键限制：

  • 指令变换适合单个分镜，不适合多镜头切换视频（需提前切出单镜头再替换）。[出自1.5 第373-377段]
  • 无法模仿剪辑效果（如化妆过程的连续变化）。[出自1.5 第372-374段]

系统性总结

核心要点：指令变换是可灵区别于其他平台的强项功能，支持对已有视频进行内容增减、换装换人、风格转换等多种修改，且对影视素材限制较少。

重点：①先切换到指令变换模式才能添加视频；②多主体替换需分别描述方位；③适合单镜头修改，不适合多镜头视频。

难点：风格转换时需提供参考图或描述知名风格（如"美式卡通""赛博朋克"）才准确。

模式四：视频参考

作用：基于参考视频生成新镜头（上一个/下一个镜头）或参考其运镜/动作，不是修改原视频内容。[出自1.5 第573-580段]

三种核心用法：

用法一：生成下一镜头（续写）

  • 基于已生成视频的结尾，生成后续内容。[出自1.5 第579-580段]
  • 提示词格式："@视频 生成下一个镜头，下一个镜头发生……"[出自1.5 第584-586段]
  • 示例：原视频是人物下车，续写镜头可描述为"切换到车内视角，人物翻身，左侧右侧……"。[出自1.5 第627-630段]

用法二：参考运镜

  • 上传一段具有理想运镜的参考视频（如白膜/轨道镜头），将自己的图片与参考视频结合，让AI参考运镜方式生成新视频。[出自1.5 第595-601段]
  • 适合复杂运镜难以用文字描述的场景。[出自1.5 第602-609段]

用法三：参考动作（多人适用）

  • 参考视频中人物的动作，让AI生成相似动作的新视频。[出自1.5 第576-578段]
  • 相比动作控制的优势：视频参考支持多人动作参考（可分别@不同人物），动作控制只能参考单人。[出自1.5 第638-653段]
  • 多人对打场景：可在参考图中用不同颜色区分人物，然后@图1的黑色人物替换成角色A，@图2替换成角色B。[出自1.5 第645-653段]

与指令变换的区别（易混淆点）： | 维度 | 指令变换 | 视频参考 | |------|----------|----------| | 目的 | 修改原视频内容 | 基于原视频生成新镜头/参考运镜 | | 输入 | 原视频+替换素材 | 原视频（作为参考而非修改对象）| | 输出 | 修改后的同一视频 | 新的续写镜头或运镜参考视频 | | 适用 | 换装/换人/增减元素 | 续写/运镜模仿/动作模仿 |

核心记忆：指令变换=改视频；视频参考=参考视频做新内容。[出自1.5 第689-691段]

系统性总结

核心要点：视频参考的核心价值是续写镜头和参考运镜/动作，特别是支持多人动作参考，弥补了动作控制只能单人的不足。

重点：①续写提示词格式固定；②多人动作必须用视频参考而非动作控制。

难点：指令变换与视频参考的区别需反复理解（改 vs 参考）。

三、可灵数字人功能

深度总结

入口：左侧生成 → 视频生成 → 右侧"数字人"选项。[出自1.5 第866-868段]

核心特点：

  1. 数字人不限制真人，卡通形象、动物形象均可。[出自1.5 第870-871段]
  2. 支持上传本地图片作为数字人形象（不强制使用官方预设）。[出自1.5 第891-892段]
  3. 支持多语言配音（中文、英文可直接在可灵内生成；其他语言需借助外部网站）。[出自1.5 第754-758段]

操作步骤：

  1. 添加AI形象（官方预设或本地图片）。[出自1.5 第743-750段]
  2. 描述讲话内容（中文直接打字；外语需先在外网生成音频再上传）。[出自1.5 第752-753段、第809-814段]
  3. 可选：上传本地音频（外语配音流程）。[出自1.5 第824-825段]
  4. 选择帧率和分辨率（720P即可）。[出自1.5 第821-823段]
  5. 点击生成。[出自1.5 第836-837段]

外语配音流程：

  1. 使用外部网站生成目标语言音频（推荐免费网站，微信登录即可）。[出自1.5 第759-762段]
    • 选择语言（如韩文需打韩文，不是中文）。[出自1.5 第774-778段]
    • 挑选音色，点击开始转换。[出自1.5 第782-783段]
  2. 下载音频文件。[出自1.5 第767-769段]
  3. 在可灵数字人界面上传本地音频，AI自动匹配口型。[出自1.5 第809-814段]

中文配音替代方案：

  • 剪映朗读功能支持方言（如粤语等），可导出MP3后上传。[出自1.5 第847-854段]
  • 剪映也支持音色变换（如将成人音色转为童声）。[出自1.5 第957-960段]

价格：消耗取决于视频时长，建议控制时长在合理范围（单镜头约2-3秒）。[出自1.5 第783-785段]

技巧：

  • 同一人物动作模板做好后，后续只需换衣服/场景即可复用，降低成本。[出自1.5 第914-919段]
  • 一个分镜约2-3秒，6个镜头约12-15秒。[出自1.5 第697-700段、第882-885段]

系统性总结

核心要点：数字人支持卡通/动物形象，外语配音需借助外部网站（可灵仅支持中/英），剪映可补充方言配音。

重点：外语需打对应语言文字才能正确朗读；动作模板可复用降低成本。

难点：外部网站与可灵的配合流程需熟悉。

四、可灵灵动画布（工作流画布）

深度总结

定位：可灵内的工作流模式，将文本生成图片、图片生成视频、视频生成声音等功能集成在一个画布中，一站式完成，无需频繁切换界面。[出自1.5 第1110-1130段]

适用场景：

  • 电商广告视频制作
  • 短剧类视频制作
  • 需要多步骤精确控制的生产流程

操作入口：左侧"全部工具" → "灵动画布" → 点击"立即创建"（不要在首页直接描述，否则会直接生成视频）。[出自1.5 第1113-1124段、第1252-1256段]

画布操作：

  1. 添加节点：点击"+"号添加节点。[出自1.5 第1134-1135段]
    • 文本节点：写描述/备注。[出自1.5 第1140段]
    • 文生图节点：文字生成图片。[出自1.5 第1147-1148段]
    • 图生视频节点：图片转视频。[出自1.5 第1141-1142段]
    • 首尾帧视频节点：添加首帧和尾帧生成视频。[出自1.5 第1142段]
    • 音效节点：添加声音效果。[出自1.5 第1143段]
  2. 连接节点：从上一步节点拉线连接到下一步节点，形成工作流。[出自1.5 第1176-1178段]
  3. 逐步生成：每一步生成后检查效果，满意后再进行下一步。[出自1.5 第1197-1200段]

画布快捷键：

  • 放大/缩小：按住 Control + 鼠标滚轮。[出自1.5 第1185-1186段]
  • 移动画布：按住 空格键 + 鼠标左键拖拽。[出自1.5 第1187-1188段]

提示词优化：

  • 文生图节点有"优化提示词"功能（免费），可让AI润色描述。[出自1.5 第1158-1160段]
  • 优化后需检查，避免生成奇怪内容。[出自1.5 第1224-1226段]
  • 建议添加"无字幕/无旁白"要求，文案后期再配。[出自1.5 第1152-1165段]

模型选择：画布内可使用所有可灵模型（图片3.0欧米、2.5等），价格与单独使用相同。[出自1.5 第1167-1172段、第1206-1208段]

核心优势：

  1. 一站式生成，无需切来切去。[出自1.5 第1120-1122段]
  2. 每一步可检查调整，精确控制。[出自1.5 第1197-1199段]
  3. 可做多镜头工作流，一个画布完成整条视频。[出自1.5 第1321-1326段]
  4. 每步提示词可查看，便于修改和复用。[出自1.5 第1329-1332段]

与普通生成的关系：

  • 灵动画布不是新功能，只是将已有功能集成在一起。[出自1.5 第1331-1333段]
  • 如觉得不习惯，仍可使用普通生成流程（文生图→导出→图生视频→……）。[出自1.5 第1347-1348段]

系统性总结

核心要点：灵动画布是可灵的工作流集成界面，将多步骤生成流程集中管理，适合需要精确控制和多镜头衔接的生产场景。

重点：①点击"立即创建"进入画布，不要在首页直接描述；②快捷键Control+滚轮缩放、空格+拖拽移动；③每步检查后再进行下一步。

难点：节点连接逻辑需要熟悉；不适合追求速度的简单任务。

五、参考视频下载工具推荐

深度总结

问题背景：在抖音、B站等平台找参考视频时，常因平台设置下载权限而无法直接下载（或下载带平台水印）。[出自1.5 第979-986段]

推荐工具：微信小程序「肥猫创作」[出自1.5 第994-999段]

支持的平台上限：抖音、快手、抖音、即梦、西瓜视频、小红书、哔哩哔哩等。[出自1.5 第997-998段]

使用步骤：

  1. 在微信搜索"肥猫创作"小程序。[出自1.5 第994-995段]
  2. 复制目标视频链接。[出自1.5 第999段]

板块一：PS合成产品与场景（基础操作）

深度总结

PS合成目的：

  • AI生成的产品位置/大小/透视不准确
  • 手动合成更可控，效果更准确
  • 先PS合成，再加光影效果

  1. 打开背景图（场景图）
  2. 置入嵌入对象（产品图）

  3. 调整产品位置和大小

  4. 抠图处理

  • Delete：删除选区
  • 置入嵌入对象：文件→置入

合成注意事项：

  • 产品位置先粗略调整
  • 光影效果后续添加
  • 保存为JPEG格式（透明背景用PNG）

板块一：产品分解爆炸图制作（里布）

深度总结

适用场景： 电子产品、有复杂构造的产品，需要展示内部结构的电商视频。

核心问题： 直接用豆包等AI文本生成工具描述"分解图"，理解能力差，效果不稳定。原因在于机器内部构造复杂，AI凭空难以理解，容易产生逻辑错乱。

解决方案：使用里布（Liblib）平台。

  • 里布平台内有大量现成的爆炸分解图模板，直接套用即可，准确性远高于一键生成。
  • 模板的本质是风格参考：选择模板后，点击"使用模板"，自动跳转到生图界面，并将该模板的风格加为参考，确保生成效果接近模板风格。
  • 推荐模型：智能图片（GPT模型）效果最好，其次是SD 5.0 Pro（国产较优，但复杂结构仍一般）。
  • 画质建议：至少选标准/中等画质，低画质容易出现变形、细节丢失。
  • 比例选择：参考原图比例，1:1适合方形产品，16:9适合宽幅展示，根据产品形态（上下分解/左右分解）灵活调整。

操作要点：

  1. 在里布底部搜索框搜索"爆炸图""分解图"等关键词，找到合适的模板。
  2. 上传产品参考图（如耳机、手柄、充电宝等）。
  3. 选择模板+模型（推荐智能图片或SD 5.0 Pro）。
  4. 设置比例和画质，生成。

说明：分解图效果仅适合快速展示机身构造，不适合做详情页说明书，因AI拆解不一定准确。准确说明书需在PS中手动制作。

板块二：AI电商视频前期准备——素材收集与市场分析

深度总结

第一步：收集产品素材

电商视频制作的第一步永远是收集素材，包括：

  • 产品本身的照片（清晰主体图）
  • 产品的三视图（正面/侧面/背面，用于绑定主体，防止换角度时变形）
  • 产品的细节图
  • 产品分解图（爆炸图）
  • 想要的场景背景图（可手动合成）
  • 同行参考案例（保存风格参考，避免AI凭空理解）

核心原则：给AI充分的参考，效果才准确。 不给参考，AI每次生成结果不可控。

第二步：用豆包做产品市场分析

将产品图上传至豆包，使用预设提示词让豆包分析：

  • 产品适合的目标人群
  • 产品的竞争力/卖点
  • 视觉风格建议（色彩、色调、氛围）

提示词模板思路（发给桌面上的文档）：上传产品图后，让豆包分析上述信息，结果可直接用于后续脚本生成。

第三步：结合分析结果生成分镜图和脚本

  • 分析完成后，继续在同一个对话中生成分镜图（连环图）和脚本。
  • 分镜图建议做15-20张，预留容错率（大约2/3可用）。
  • 关键提醒：分镜图中尽量避免出现文字，文字后期在剪映中手动添加，效果更好。

豆包做分镜的缺点：连贯性较差，效果不稳定；如需高质量分镜，建议用海螺多宫格。

板块三：四种视频生成方法详解

课程系统讲解了四种AI视频生成方法，各有优劣：

方法一：单镜头逐帧生成（最传统）

流程： 挑选图片 → 选择支持首帧/首尾帧的模型 → 逐镜头生成视频 → 导入剪映拼接、配乐、加转场效果。

特点：

  • 可控性最强，每个镜头手动控制运镜、时长
  • 耗时较长（单个视频可能需30分钟以上）
  • 适合追求精准控制的场景

适用模型： 各平台支持首帧/首尾帧生成的模型（海螺、可灵、里布等）。

方法二：九宫格图一键生成

流程： 在海螺/里布生成九宫格图 → 直接用该图生成完整视频。

特点：

  • 快速出成片，无需剪辑
  • 九宫格图本身不含文字/台词
  • 随机性较高，效果需多试

适用模型： 海螺多宫格、里布模板等。

详见课程 1.4（可灵AI基础功能）和 1.3（海螺AI核心功能）。

方法三：脚本截图生成视频

流程：

  1. 在豆包/极梦中生成完整分镜脚本（含景别、运镜、时长、画面内容等）
  2. 将脚本截图保存为图片
  3. 使用SD 2.0模型，以脚本截图+产品参考图作为输入，生成视频

提示词格式（核心）：

参考脚本截图中的分镜脚本，
时长：XX秒，
景别：XX，
镜头角度：XX，
画面内容：XX，
运镜：XX，
音效/音乐：XX，
生成一个XX秒的电商广告视频。

优点：

  • 可绕过人脸审核限制（脚本中描述有人物，但图片不直接给真人人脸，AI自行生成模特）
  • 脚本截图提供完整分镜参考，准确性高

适用模型： SD 2.0（极梦、豆包、海螺、里布均可接入此模型）。

方法四：故事版（Storyboard）生成视频

流程：

  1. 在海螺/里布用GPT-2.0模型生成故事版图片（带文字描述的分镜图）
  2. 将故事版截图+提示词输入视频生成模型，生成完整视频

故事版图片特点：

  • 每张图包含文字台词、镜头描述、主体信息
  • 类似"有台词的九宫格"
  • 生成时用GPT-2.0模型，画质至少中等，分辨率2K/4K

关键要求：

  • 生成故事版图片必须使用GPT-2.0模型，其他模型生成的故事版文字会乱码、效果差
  • 画质选择中等及以上，分辨率2K以上，否则文字难以辨认
  • 比例建议16:9（横屏）或9:16（竖屏，按平台需求）

生成视频提示词示例：

参考以上故事版，生成一个XX秒的精华液TVC广告视频。

注意：故事版中有人脸时，豆包/极梦可能审核驳回，需多试几次；海螺不卡人脸，可直接使用。

板块四：智能多帧（无缝衔接效果）

核心概念： 多张图片通过SD 1.0旧模型实现一镜到底的无缝衔接，不切镜头，直接过渡。

适用场景：

  • 产品从整体→局部细节的镜头推进
  • 风景场景之间的自然过渡
  • 不需要剧情、不需要声音的展示类视频

操作要点（极梦/可灵）：

  1. 选择旧模型 SD 1.0（新模型不支持此功能）
  2. 选择"智能多帧"模式
  3. 添加3-4张参考图（首帧→中间过渡帧→尾帧）
  4. 在两张图之间添加过渡描述文字，如"镜头推进到logo特写"
  5. 设置每段过渡时长（建议3-4秒，总长约15秒）

注意：

  • 模型较老旧，效果不如新模型自然
  • 不适合有人物出现的场景，适合产品展示
  • 消耗较低，成本低
  • 豆包不支持此功能，需在极梦/可灵操作

板块五：分镜脚本生成

流程： 产品分析完成后，直接在豆包对话中生成脚本：

结合以上分析内容，生成适合电商广告的分镜脚本，
共9个镜头，包含景别、运镜、画面内容、音效/音乐描述。

脚本字段说明：

  • 景别： 远景/中景/近景/特写
  • 运镜： 推进/拉远/环绕/固定
  • 画面内容： 每个镜头的具体画面描述
  • 音效/音乐： 背景音乐类型、音效描述
  • 时长： 每个镜头/整体视频时长

脚本用途： 脚本截图可作为方法三/四的输入参考，也可直接复制给视频生成工具使用。

豆包VIP用户可使用"工作任务"功能，自动整理为Word文档并下载。

板块九：避坑指南

人脸审核问题

  • SD 2.0模型对真人人脸有限制，可能直接驳回
  • 解决方案：方法三（脚本截图生成）或方法四（故事版生成），不直接给人脸参考图
  • 海螺H3模型不卡人脸，可直接使用

文字乱码问题

  • 故事版中文字在低画质下易乱码
  • 解决：画质至少中等，分辨率2K以上

生成效果不稳定

  • 同一提示词多次生成结果不同
  • 解决：多做几张预留容错，挑选最佳结果

    • 单镜头逐帧：精准控制，耗时但可控
    • 九宫格：快速出片，随机性高
    • 脚本截图：可绕人脸审核，准确性较高
    • 故事版：完整成片，效果较好，需GPT-2.0模型
