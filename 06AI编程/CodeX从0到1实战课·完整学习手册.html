第 1 章 · CodeX 是做什么的？为什么一定要学？

课程定位：本节是 CodeX 板块入门课，目标是认识 CodeX 的功能与优势。

一、CodeX 介绍

核心定义：CodeX 是 OpenAI 官方推出的 AI 编程工具，其"出圈能力"在于不局限于编程，应用范围广泛。

关键认知：CodeX 不是聊天机器人，是围绕真实项目"干活"的 AI 工程助手；想法 → 代码 → 可展示作品。

二、CodeX 与传统大模型对比

维度传统对话大模型（豆包/DeepSeek/GPT）CodeX
能力问答、文案生成（帮你"想和写"）进入项目干活的 AI 工程助手
工作方式单纯聊天围绕真实项目执行任务
输出形式文本回复可运行的可交付作品

三、CodeX 能做什么

  • 将模糊想法 → 页面结构 → 真实代码 → 可打开的作品
  • 交互、设计、创意类作品
  • 视频剪辑类（如 HyperFrames 自动根据素材和文案完成剪辑）
  • 建站、写工具、做动效、生成 API 调用

四、CodeX 与 Cos 对比（关键认知）

维度CosCodeX
定位智能体工厂AI 工程师
优势门槛低，快速搭建对话、查资料、跑流程的智能体把网站、工具、系统真正做出来
核心能力组装问答、知识库、工作流围绕项目执行与迭代，从想法到代码再到可展示作品
🎯 课程预告：后续课程中，先整理脑海中的想法，然后逐步用 CodeX 把想法转化为作品。
⚠️ 学习障碍预警：CodeX 最大门槛是登录，而非网络或技术（多数人卡在此步放弃）。解决方案见 第 2 章 和 第 3 章，二选一即可。

系统性总结

① 身份：OpenAI 官方 AI 编程工具

② 定位：AI 工程助手（区别于"想和写"的传统大模型）

③ 与 Cos 差异：Cos 是"智能体工厂"（组装问答/知识库/工作流，门槛低），CodeX 是"AI 工程师"（把网站、工具、系统真正做出来）

第 2 章 · OpenAI 账号注册 / 手机接码 / 充值 一站式解决

路径 A（官方 GPT 账号）：需海外手机号 + 海外银行卡，本章给一站式方案。

↔ 备选路径：嫌麻烦可直接看 第 3 章 中转站 API 登录（免验证、免海外卡、按量一折）。

一、核心问题与核心逻辑

用原生账号登录 CodeX 需解决两大障碍：

  1. OpenAI 账号注册/登录：需海外手机号解码
  2. 充值 Plus/Pro 会员：需海外银行卡

核心逻辑：Codex 与 ChatGPT 同属 OpenAI，账号通用。充值 GPT 会员 = 充值 Codex 会员。

二、账号注册（创建 ChatGPT 账号）

  1. 进入官网 → 点击右上角【免费注册】
  2. 输入邮箱 → 点击【继续】→ 接收验证码
  3. 填写年龄：建议填 20-25 岁（可随意填写）
  4. 注册成功：成为 GPT 用户

三、登录 Codex

  1. 打开 Codex → 选择【GPT 账号登录】
  2. 输入已创建的 GPT 账号 → 接收验证码 → 点击【继续】

登录结果：大概率直接登录成功，跳过手机验证码；小概率触发随机检查，需手机验证码。

四、接码验证（5sim 平台）

原理：获取国外手机号 → 接收验证码 → 验证通过后使用；后续大概率无需再次验证。

  1. 打开 5sim 网站 → 左侧【服务】→ 选择【OpenAI】
  2. 选择国家：推荐美国或英国（接码成功率更高）
  3. 选择运营商：选第一个（接码率高）
  4. 复制手机号 → 粘贴至 GPT 平台验证页面
  5. 接收验证码 → 复制粘贴至 GPT 平台

五、充值会员（两条路径）

路径 A：Codex 内直接充值（需海外卡）

  1. 点击【设置】→【升级】→【获享更高限额】
  2. 选择【Plus】（日常使用足够）→【获取升级至 Plus】
  3. 输入卡号充值：月费约 20 美金

路径 B：代充网站（推荐）

  1. 打开代充网站 → 选择【GPT Plus】→【单次订阅】
  2. 登录 GPT 账号 → Ctrl+A 全选 → 复制
  3. 返回代充页面 → Ctrl+V 粘贴 → 微信支付（约 1 分钟完成）
  4. 验证激活：重启 Codex → 输入任意内容 → 显示返回结果即成功
❗ 银行卡限制说明：国内 VISA / American Express / S Card 均无法成功刷卡。原因：账单地址必须与注册地址完全一致（英文地址难以实现）。无海外卡的用户建议走代充路径。

系统性总结

整个流程是一条清晰的问题解决链：账号注册 → 登录 Codex（大概率免验证码）→ 触发时走 5sim 接码（美国/英国号码）→ 充值（直充需海外卡；代充支持微信支付）

重点：①Codex 与 GPT 账号通用；②5sim 接码完整操作序列；③代充激活验证方法

第 4 章 · CodeX Windows 本地满血版部署

Windows 用户的部署手册：桌面版 + Git + Node.js 三件套。

一、检查网络环境

前提：解决登录 OpenAI 的"魔法"问题。验证方法：浏览器搜索 openai.com，若能打开则网络正常。

🌐 节点配置要点：
  • 推荐节点：日本、新加坡、英国、美国
  • 禁用地区：台湾、香港、澳门（无法登录 OpenAI）
  • 常见误区：能上 YouTube/Twitter ≠ 能上 OpenAI（OpenAI 对大陆地区不开放）
  • 切换节点技巧：打不开网页时 → 彻底关闭整个浏览器 → 更改为正确节点 → 重新打开登录

二、Codex 安装方式分类

方式适用人群操作
桌面版（推荐零基础）所有学员官网下载 Windows 版，独立 AI 编程工具
IDE 插件已有开发基础者集成至 VS Code / Cursor / JetBrains
Codex CLI高级配置者在 PowerShell/终端中运行

本系统课以桌面版为主（UI 体验更好、功能更全）。

三、Codex 桌面版的安装

  1. 下载：浏览器搜索"Codex" → 认准白底黑 logo（域名 openai.com）→ 点击"Download for Windows" → 选择保存位置
  2. Microsoft Store 安装：打开安装包 → 自动跳转 Microsoft Store → 一路按提示安装 → 自动打开
  3. 创建桌面快捷方式（两种方法）：
      方法一：Win + R → 输入 shell:AppsFolder → 确定 → 找到 Codex → 直接拖拽至桌面
      方法二：Win 键 → 开始菜单搜 Codex → 右键 → 固定到任务栏

四、安装依赖说明

核心结论：Codex 桌面版不强制要求提前安装 Git 和 Node.js；但后续做网页、React、Next.js 项目必然依赖，建议一次性部署。

五、安装 Git

Git 定义：代码版本管理工具；核心功能是记录代码变化（Codex 修改了哪些文件、新增/删除了什么、哪里改错能否撤回）。

  1. 浏览器搜索"Git" → 官网 git-scm.com
  2. 点击 Download for Windows → Standalone Installer → x64 版本
  3. 选择安装位置 → 一路 Next → Install → 取消勾选 → Finish

六、安装 Node.js

Node.js 定义：前端项目运行环境。常用命令：npm install / npm run dev。

  1. 浏览器搜索"Node.js"（白底绿 logo）
  2. 上方 Download → 选 LTS 版本（长期稳定版，零基础首选，不要追求最新版）
  3. Windows Installer → 选保存位置 → 一路 Next → 勾选协议 → Next → Install

七、测试 Git 与 Node.js 是否安装成功

Win 键 → 搜索"PowerShell" → 以管理员身份运行

git --version   # 显示 git version 2.x.x → 成功
node -v         # 显示 v18.x.x 或 v20.x.x → 成功
npm -v          # 显示数字 → 成功

系统性总结

Windows 三件套公式：Codex 桌面版 + Git（版本管理） + Node.js（前端运行环境）

部署顺序：网络准备 → 下载桌面版（官网 → Microsoft Store → 快捷方式）→ 装 Git → 装 Node.js → PowerShell 验证

验证命令：git --version / node -v / npm -v

第 5 章 · CodeX macOS 本地满血版部署

Mac 用户的部署手册：原理与 Windows 完全对称，安装载体差异。

一、网络准备

测试方法：浏览器搜索"Codex"，点击 OpenAI 白底 Logo，验证能否正常打开。

  • 节点推荐：日本、新加坡、美国
  • 不可用地区：台湾、香港、澳门
  • 切换节点技巧：关闭所有网页 → 切换正确节点 → 重新打开浏览器

二、安装 Codex 桌面版

  1. 浏览器搜索"Codex" → 官网 → 下载 macOS 版 → 选择对应位置，点击保存
  2. 访达中找到安装文件 → 双击打开 → 双击"Install Codex" → 点击"打开"
  3. 跟随步骤，点击"下一步"自动安装
  4. 若提示"是否允许打开来自网络下载的应用" → 点击"允许"
  5. 固定到 Dock 栏：打开 Codex → 右键 → 选项 → "在程序坞中保留"

三、安装 Git（极简易方法）

  1. Command + 空格 → 搜索"终端" → 回车打开
  2. 输入命令：xcode-select --install → 回车
  3. 若系统弹出安全提示 → 点击安装 → 同意协议 → 等待自动安装完成
  4. 关闭终端 → 重新打开终端
git --version   # 显示 git version 后带数字 → 成功

四、安装 Node.js

  1. 浏览器搜索"node.js" → 点第一个结果 → 顶部"Download"
  2. 版本选择：最高版本号，带 LTS（长期稳定版，零基础首选）
  3. 点"Mac Installer" → 选文件夹 → 保存
  4. 打开下载文件 → "继续" → "继续" → "同意" → "安装" → 输入密码 → "安装软件"
  5. 显示"安装成功"后，关闭并重新打开终端
node -v    # 显示 v 开头数字 → 成功
npm -v     # 显示数字 → 成功

注：版本号可能不同，属正常更新。

系统性总结

Mac 三件套公式：Codex 桌面版（macOS 安装包） + Git（xcode-select --install） + Node.js（LTS 版）

与 Windows 版流程结构完全对称，差异点仅在安装载体：终端命令 vs 安装包、Dock 栏 vs 桌面快捷方式

macOS 用户后续优选带 mlx 后缀的模型版本（对苹果芯片更友好）

第 6 章 · CodeX 桌面端功能调试详解

学会完整使用 Codex 客户端：三层结构（个人层 / 能力层 / 运行层）。

一、初始设置

  • 语言切换：左下角 设置 → Setting → 语言 → 简体中文
  • 设置界面：左侧分区为个人设置、集成、能力、编码工具、归档管理
  • 工作模式：编程模式（默认）/ 日常工作模式

二、权限配置（核心安全主线）

权限风险推荐场景

  • 画布区域：中央空白区域，可无限向四周延展
  • 手掌工具：拖动画布

工具定位：本地无线画布插件；核心优势：自动化程度更高——图片生成后直接进入本地画布，无需手动下载、打开文件夹、拖拽

  1. 生成示例图片

  3. 标注操作（与 Excalidraw 类似）
  4. 将当前画布截图发给 Codex → 指令："根据标注内容进行修改"
  5. Codex 处理完成后，将相同尺寸的修改结果放回画布
  6. 在同一个画布中直接对比原图、标注图、修改结果

适用场景简单标注、一次性修改连续性工作（不断生成、标注、修改）
效率特点需频繁切换文件夹和浏览器流程连贯，无需切换
