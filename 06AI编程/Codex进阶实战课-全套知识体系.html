0 小白入门准备 · 学习心法

在学任何一节课之前，请把这一章读三遍。它能让你少走 80% 的弯路。

🧠 三个必须相信的"心法"

① 用嘴巴解决问题：你不需要懂英文、不需要懂代码、不需要读技术文档。把你想做什么用大白话告诉 Codex 就行。
② 不懂就问 AI：遇到任何新工具、新功能、新报错 —— 截图发给 Codex 或粘贴相关链接，直接问它"这是啥？有什么用？怎么用？"。
③ 让 AI 对抗 AI：一个 AI 工具出问题时，用另一个 AI（如 Codex）来诊断和修复 —— 这叫"让 AI 对抗 AI"，是最高效的排错方式。

📍 三条学习路径，按时间选

路径一：零基础 2-3 天速通（目标：能用起来）

3

路径二：进阶深度 1-2 周（目标：建立完整工作流）

1
Week 1：路径一全部 + 第 6 课（自制 Skill）→ 第 8 课（GitHub 打通）→ 第 9 课（Obsidian 知识库）

路径三：按业务场景（目标：解决具体问题）

  • 自媒体创作者：第 9（知识库）→ 第 13（PPT）→ 第 14（视频）→ 第 15（公众号）→ 第 17/18（采集）→ 第 19（得到导入）
  • 实体店老板/销售：第 17（抖音获客）→ 第 18（小红书获客）→ 第 20（GEO 优化）
  • 职场办公人群：第 10/11（微信/飞书）→ 第 13（PPT）→ 第 6（自制 Skill 重复工作流）

⚠️ 学习中常见误区

  • ❌ 把 Codex 当聊天玩具 → ✅ 它是能动手干活的 AI 智能体，能操控你电脑
  • ❌ 想把所有功能一次学完 → ✅ 先跑通一个场景，再扩
  • ❌ 报错就放弃 → ✅ 截图发给 Codex，让它自己修
  • ❌ 觉得 Memory 能跨对话记住一切 → ✅ 实测结论：仅当前线程有效
  • ❌ 追求一键魔法 → ✅ 多数工作流需要 1-3 轮迭代
  • ❌ 想记住所有提示词 → ✅ 关键句式记住即可，其他交给 AI 生成

1 第一阶段 · 环境搭建（4 课）

这一阶段的目的是：让你的 Codex 能跑起来、用起来、说得动。

📘 第 1 课：Codex 安装部署（中转站方案，不需梯子） 基础必学

为什么必须学这课

直接用 ChatGPT 官方订阅有三大门槛：需要国外信用卡、需要国外手机号（这个会难倒 99% 的同学）、需要魔法上网。这会难倒 90% 的人。中转站方案完全绕开这些限制。

完整安装流程

1
注册与充值：访问中转站网址（已提供给学生），注册账号。充值方式二选一：
• 按量付费（10 元、20 元起，适合新手）
• 订阅模式（109 元/月）
👉 建议路径：先小额按量付费体验，玩明白了再考虑订阅
2
创建 API 密钥：进入 API 管理面板 → 左侧"API 密钥" → 创建密钥（名称随意如 123）
👉 分组选择关键：按量付费选"公开使用余额"，包月选对应分组。分组不对会导致 Codex 使用出问题
3
找到配置文件：Windows 系统下打开 C:\Users\[你的用户名]\.codex\config.TOML，用记事本打开
4
填入配置：把中转站提供的配置代码（包含 model、OpenAI、base URL 等信息）复制到文件开头，API 密钥填入 Codex 客户端界面指定位置
5
首次启动：Codex 会经历约 20-30 秒的"正在设置空间"等待时间，耐心等待即可
⚠️ 防跑路提示：不要买季卡或超过 150 元的长期套餐 —— 中转站有跑路风险。充 10、20、50 元不心疼即可。

Windows vs Mac

Codex 在 Windows 上运行偶尔会出现命令适配问题，处理速度偏慢。Mac 的原生环境对 AI 工具更友好。建议有条件上 Mac，但 Windows 最终也能跑通。

核心知识点：通过 API 中转站实现 Codex 安装部署，绕开梯子、国外手机号和国外信用卡三大障碍。
难点：找到并正确编辑 config.TOML（路径 C:\Users\[用户名]\.codex\）。

📘 第 2 课：Codex 设置成中文版（需要梯子） 基础必学

两个核心前提

前提 1：必须准备科学上网工具（梯子/VPN），节点配置方法讲师无法展开，需学员自行解决
前提 2：通过 File → Settings → Language 选"中文（中国）"

核心两步走

步骤操作关键
第一步把 VPN 节点切换到海外节点语言包下载依赖海外节点
第二步完全退出 Codex 后重新启动必须杀掉进程，不能最小化
关键细节：必须"完全退出"Codex（杀掉进程），而非最小化或关闭窗口。只有彻底退出并重启才能触发语言包的自动下载和切换。

方案优先级

  1. 🥇 从 OpenAI 官方渠道下载 Codex（最佳）
  2. 🥈 上述两步切换为中文
  3. 🥉 第三方汉化包（体验不如官方）
  4. 🏅 直接适应英文界面（核心功能"新对话"不受影响）

📘 第 3 课：Codex 基础配置（不是重点，简单了解） 配置

板块一：工作模式

  • 编程模式 Programming Mode：显示较多技术细节（命令行调用、底层操作）。讲师偏好，能看清"它是怎么整的"
  • 日常工作模式 Daily Work Mode：不显示用户看不懂的命令行操作，界面更简洁，非技术用户首选

板块二：权限管理（重要！）

模式行为风险
默认权限只能读取和编辑工作区目录下的文件主要限制写入，读取仍可跨盘
请求额外权限需要时 Codex 主动申请每次操作都会弹窗确认
完全访问权限不再经过允许，直接操控整个电脑⚠️ 银行卡密码等敏感信息也可能被读取
讲师建议：普通用户保持默认权限；信任度高且电脑无敏感信息的用户可考虑完全访问（讲师本人使用完全访问）。

板块三：外观个性化

  • 主题模式：Dark / Light（讲师偏好浅色）
  • Codex 主题：可切换 GitHub 主题等
  • UI 字体字号：最大 16
  • 代码字体大小：默认 12
  • 宠物 Pet：任务完成提醒功能（"小火苗"、"Rocky 岩石"等）

板块四：配置页核心功能（Config）

所有配置信息保存在 codex-config.toml 文件中。

  • 个性化/语气：亲和（Friendly）/ 务实（Concise/Professional）
  • 自定义命令 Custom Commands：Codex 的"灵魂"设定，本质是自定义 System Prompt
  • 记忆功能 / 重置：有记忆功能，一般不用重置
  • 键盘快捷键：玩熟了记一下

板块五：MCP 服务器（Model Context Protocol）

MCP 是 Codex 连接外部工具和服务的协议。讲师比喻为"U盘插件"，即插即用。

核心案例：chrome-devtools MCP
让 Codex 直接控制一个 Chrome 浏览器页面，实现浏览器自动化操作。
应用场景：打开抖音、小红书、百度、企业 ERP 系统；自动化搜索、数据采集。

板块六：连接、Git、环境与归档

  • 手机端连接：手机下载 ChatGPT 应用连接电脑 Codex。Windows 尚未跑通，部分 Mac 用户已成功
  • Git 版本管理：非当前刚需，核心价值"写代码不怕写坏"。可以在 Codex 里学 Git
  • 环境与项目管理：支持添加多个项目，适合多工作区场景
  • 对话归档：归档后对话不会丢失，可重新查看

📘 第 4 课：语音输入法（微信输入法） 效率神器

为什么必学

"学习任何新鲜事物时，不应一上来就给自己设定难度，而应该选择最符合直觉、最轻而易举能够完成的方式去互动。" —— 语音输入消除了打字的心理负担。

安装步骤

1
浏览器搜索"微信输入法"，找到 qq.com 域名下的官方页面
2
根据操作系统下载对应版本（Windows / Mac）
3
下载后安装部署

语音输入使用方法

1
打开微信输入法 → 点击左侧三条横杠 → 选择"插件"
2
找到"语音输入文字"选项
3
默认快捷键：Ctrl + Alt + T（三个键挨在一起）
4
在 Codex 对话框先点击一下鼠标 → 按住 Ctrl+Alt+T → 弹出绿色小框 → 开始说话 → 松开按键 → 文字自动打出
💡 讲师建议：每一位安装完 Codex 的朋友，都应该下载一个微信输入法 —— 它能让你和 AI 对话时心理负担降到 0。

2 第二阶段 · 核心操作能力（3 课）

这一阶段的目的是：把 Codex 的核心交互体系玩明白，跨过"能用"到"会用"的门槛。

📘 第 5 课：保姆级斜杠命令（一定要使用） 核心入口

斜杠命令是 Codex 中通过输入 / 触发的功能菜单，包含大量实用功能入口。

命令分类详解

① 模型与工具层

  • MCP：外接工具连接机制（浏览器自动化等）→ 详见第 3 课板块五
  • 推理模型：可设置低/中/高等级，也可在界面右侧直接设置
  • 状态 Status：查询账户余额。使用 API 密钥登录的用户无法使用此功能

② 行为模式层

模式特点适用场景
个性 Personality亲和 vs 务实务实模式更简洁、专注、直接
聊天 Chat脱离项目工作切到纯 Chat 环境，不再"在项目中工作"
计划 Plan会议式规划不立即执行，列出 1234 待办事项，反复确认细节
目标 Goal"需求推土机"调用更多算力自动完成目标，不需反复对话推进

③ 辅助功能层

  • 代码审查 Code Review：检查复杂代码项目中的 bug，无代码经验也能用
  • 记忆 Memory：详见下方 ⚠️ 重要发现

④ 扩展层

  • 技能 Skills：Skill 功能入口，可安装和调用各类自动化技能
⚠️ 记忆功能边界（重要发现）：
① 当前对话有效：在当前对话框（线程/Thread）内可以记住聊天内容
② 跨对话无效：在新对话中，Codex 无法记住上一对话中的偏好
③ 不生成全局记忆：Codex 不会把每一句闲聊变成全局个人记忆
④ 明确要求也不行：即使说"请把我喜欢吃西瓜作为长期偏好的记忆"，也无法跨新对话永久生效

这正是许多用户对记忆功能的常见误解。记忆仅在当前会话（线程）内部有效。

📘 第 6 课：Codex Skill 技能（全网最简单制作一个技能） 核心方法论

Skill 的本质

Skill 是一套 SOP（标准操作流程），是一套 12345678 的流程。它把工作流程节点固化下来，每一步要做什么非常清晰。

什么时候适合封装成 Skill

  • ✅ 工作流程 SOP 化需求：步骤清晰，没有歧义
  • ✅ 具有可复用性：一旦存在可复用的环节，就可以封装
  • ✅ 即使流程很简单（只有一个环节），只要环节清晰，也符合封装条件

核心方法论：先跑通，再沉淀（三步法）

1
遇到不懂的直接问 AI"这是啥？有什么用？"
2
在对话中先跑通流程
3
说一句话"请把这一套流程沉淀为技能"
🎯 讲师金句：做 Skill 的前提是这个流程得先跑通。它能够实际完成你的工作流之后，再说把它沉淀成技能。

实操案例：短视频稿润色技能

Step 1：在对话中建立工作流

我想让你做一个工作流程。我每次会给你发布一个原始的文稿，
因为我是一个自媒体的博主。请把这个原始的文稿润色成一个更
符合短视频风格的逐字稿。

Step 2：用实际文稿测试流程（测试文稿）

我觉得Codex是这个世界上老少皆宜的智能体工具，不管是一线高管、
老板还是员工都在使用。我希望每个同学都能认真地去把这些技能、
这些对话、这些项目都至少跑一遍。

Step 3：将流程沉淀为 Skill

谢谢你，你刚刚润色的那个版本非常好，我希望你把咱们刚刚跑通
了的这个版本沉淀成一个技能Skill，方便我下次调用，然后给我润色。

AI 会自动调用 skills-create 工具，将流程固化到本地 Skills 目录（C:\Users\用户名\.codex\Skills\）。

Step 4（可选）：修改技能名称为中文

你的技能名称能不能设置成中文的，我好找到。

调用 Skill 的两种方式

方式操作适用
手动点击技能面板 → 找到 Skill → "在对话中使用"初次使用或确认
自动触发对话中说触发话术（如"帮我润色成短视频稿"）日常频繁使用（零操作）

补充建议

  • 如果目标是让它产生结果、产生效益：只需要会用即可
  • 如果是做研发、做工程、做设计：才需要琢磨工程化内容
  • Mac 下做 AI 工作流更丝滑（编码识别问题少），Windows 也可用
  • 完全访问权限可减少确认弹窗提升操作流畅度

📘 第 7 课：GitHub+Skill · 沉淀一个段永平 Skill 蒸馏名人

核心方法论：不懂就问 AI

遇到看不懂的技术内容（密密麻麻的英文/代码），不要硬读 —— 直接复制链接粘贴给 Codex，用大白话问它"这是什么、怎么用"。

核心思维方式：让 AI 去告诉你它是什么东西，而不是自己费力去理解。

寻找 Skill 的两种方式

  • 方式一：GitHub 上搜索关键词"skill"，通过星数（Star）判断受欢迎程度和可信度
  • 方式二：通过博主/他人分享的 GitHub 链接访问

女娲（Nvwa）Skill 详解

功能定位：一个帮你打造 AI 思维顾问的工具。

核心能力：输入一个人名，研究该人物的公开资料，提炼出一个可调用的 Skill（即 AI 思维顾问）。

关键术语："蒸馏"的本质就是把别人的好处/优点/思维方式提炼出来。

应用示例：

  • 用芒格的视角拆解投资策略
  • 用费曼方式解释复杂概念
  • 用乔布斯的产品品味审视你的 APP
  • 蒸馏任意名人的思维方式

一次性可安装的明星 Skill：马斯克、费曼、Sam Altman、乔布斯、张一鸣、张雪峰、纳瓦尔、野兽先生、塔勒布、孙宇晨、川普、段永平……

蒸馏段永平思维方式的完整流程

1
说"女娲帮我蒸馏一个段永平的思维方式"
2
女娲自动搜索公开资料 → 提取关键思维模式 → 整理成 Skill 文件
3
检查安装结果（如果 Skill 没出现，可截图+自然语言告知 Codex）
4
刷新界面，"段永平思维方式"Skill 出现在技能列表中

安装 Skill 的标准操作（最简单方式）

1
说"帮我安装这个 Skill"
2
粘贴 GitHub 链接
3
Codex 自动使用 skills 插件完成安装

3 第三阶段 · 平台扩展（5 课）

这一阶段的目的是：把 Codex 与外部世界打通，让它能取数据、能发消息、能连平台。

📘 第 8 课：Codex 打通 GitHub 平台 开源宝库

GitHub 的重新认识

GitHub 本质上是 项目托管平台，而非单纯的代码托管平台。上面不仅有程序员开源的项目，还有攻略教程、APP 软件、网站项目。现在非程序员也可以在 GitHub 上推送和分享项目。

用 Codex 打通 GitHub 的"四步法"

步骤操作
1用 Codex 在 GitHub 上搜索推荐项目（按活跃度和 Star 筛选）
2让 Codex 解释项目（功能和适用场景）
3让 Codex 教你使用（获取安装和使用教程）
4在项目基础上满足自己的需求（二次开发或定制）
核心原则：从头到尾不需要直接打开 GitHub 网址搜索，全部流程借助 Codex 完成。

实操案例：寻找量化交易工具

在 Codex 中输入"请在 GitHub 上找到辅助我炒股的项目和软件"，Codex 按活跃度和 Star 数量筛选。

  • Star：相当于"点赞"，越多说明需求越大、项目越受欢迎（本次案例最热门项目 Star 数 41.4K）
  • 最终选择：vnpy —— Python 开源量化交易平台框架（4 万+ Star）
  • 注意：vnpy 不是"一键推荐股票"的软件，而是搭建完整量化交易的工具箱
⚠️ 安全提示：通过 Star 数量判断项目安全风险
• 高 Star 项目（如 vnpy 4 万+ Star）：大量用户已安装，风险相对较低

📘 第 20 课：GEO 医美豆包搜索案例拆解（上下集） GEO 方法论

什么是 GEO

GEO（Generative Engine Optimization，生成引擎优化）是面向 AI 搜索引擎（而非传统搜索引擎）的内容优化策略，本质是通过影响 AI 的语料来源来影响搜索排名。

🎯 核心态度：如果预算不充足，应该先理解 GEO 的底层概念然后手动操作。只有年营收达到几个亿级别时，才值得花十几万、二十几万购买 GEO SaaS 专业服务。

豆包搜索结果结构分析

模拟搜索"北京热玛吉机构推荐"后，豆包给出结构化推荐结果：公立三甲和私立精品两个类别，总共六个推荐位置。

  • 公立三甲：北京大学第三医院、中国医学科学院（八大处）、北京协和医院 —— "地位似乎无法撼动"
  • 私立精品：北京美天医疗美容、华晨医美、伊美尔 —— 这才是"动脑筋的地方"

搜索结果仅参考 10 篇文章，10 个参考位置极其珍贵。

案例一：三九健康网陈丽娟院长文章

标题精准度分析：标题"北京热玛吉排名前十的医院"极其精准，四个关键词全部命中。豆包搜索出的标题实质上就是用户问题的"翻译版本"。

发布者身份分析：陈丽娟的"院长"头衔是 AI 判断内容权威性的关键信号。

逻辑链条：AI 面对海量网络信息 → 无法逐一核实每条信息的真实来源 → 只能依赖标题/头衔/Tag 等显性信号做判断 → "院长"头衔暗示专业背景 → 内容被赋予高可靠性。

案例二：红商网文章与"交叉验证"机制（全文最核心发现）

时效性原理：标题中"2026 年"非常关键 —— 所有被收录的文章都没有超过一个月。"豆包的潜台词是搜索出来的内容全部都是相对实时的，要么本周，要么本月。不可能把一年前的东西推荐出来。"

"交叉验证"机制：

1
文章 A 将"北京大学第三医院整形外科"排名第一
2
文章 B 也将同一机构排名第一
3
多篇文章在同一机构上形成共识 → 豆包将其视为"被多方验证的事实" → AI 以最高置信度输出

反面案例：某机构在单篇文章中排名第二，但其他 9 篇均未提及 → 缺乏交叉验证 → 被豆包 pass 掉。

案例三：搜狐网文章

验证了同一套逻辑：精准标题 + 时效性控制 + 权威引用 + 结构化内容 + 交叉验证协同。以"美天医疗"为成功案例 —— 红商网（结构化详细展开）+ 搜狐网（排名第一）= 交叉验证成功 → 被豆包收录推荐。

GEO 优化七大维度

#维度核心要点
1平台维度垂类平台优先，老牌机构平台次之，自媒体平台补充
2标题维度必须有精确结构，包含用户搜索关键词（如地区+项目+排名/推荐）
3时间维度发布时间在最近一个月内，最好是本周。AI 偏好实时/近期内容
4内容结构化文章内容有清晰结构，便于 AI 读取和理解
5权威引用内容中引用权威机构的数据/报告（如白皮书、官方公布）
6渠道类型找垂类平台、老牌机构平台、自媒体平台多渠道发布，形成矩阵覆盖
7发布者身份（Title）院长、主任医师等高级 title 能显著提高 AI 对内容权威性的认可。AI 相信 title

关键数据总结

• 豆包单次结果参考 10 篇文章
• 仅 6 个推荐位置（公立三甲 3 个 + 私立精品 3 个）
• 内容时效不超过 1 个月，最好 1 周内
• 需要至少 2 篇文章在不同平台的交叉验证

可迁移性

本方法论不限于医美行业。任何行业的从业者可通过搜索自己行业的关键词（如"北京水光针""上海牙齿矫正"），参照七大维度反向分析当前的搜索结果来源，然后制定自己的 GEO 优化策略。

🏆 全课程最重要的 20 个关键要点

  1. API 中转站是零门槛入门的关键：不需要梯子、不需要国外信用卡/手机号
  2. Skill 的本质是 SOP：将可复用的工作流程固化为"技能"
  3. "先跑通再沉淀"是制作 Skill 的唯一正确方法
  4. "不懂就问 AI"是贯穿全课程的核心方法论
  5. "让 AI 对抗 AI"是排错的最佳策略
  6. 记忆功能仅在当前线程有效：经实测验证，不要误以为有全局长期记忆
  7. 上下文积累是 AI 时代的核心竞争力：谁积累足够的上下文，谁就能产生更精准的答案
  8. Obsidian 不是给人看的，是给 AI 看的：笔记让 AI 帮你读
  9. 权限管理是安全的底线：默认权限限制写入，完全访问权限便捷但有风险
  10. GitHub 是"打开新世界"的钥匙：不仅是代码托管平台，更是攻略/软件/项目的宝库
  11. Star 数量是 GitHub 项目可信度的重要参考：万级相对安全，个位数有风险
  12. "借鉴优于原创"是 AI 内容创作的核心策略

  15. 标题必须精确包含搜索关键词：AI 不看粉丝量、不看阅读量，只看标题

❓ 常见问题 FAQ

Q1：Codex 一定要梯子才能用吗？

A：不一定要。用 API 中转站方案完全不需要梯子（详见第 1 课）。只有"设置成中文版"和"官方订阅"才需要梯子。

Q2：Codex 的记忆功能能跨对话记住我吗？

A：不能。实测结论：记忆仅在当前会话（线程）内部有效，跨对话无效（详见第 5 课）。需要长期记忆请用 Obsidian 知识库。

Q3：我不会写代码，能用 Codex 吗？

A：完全可以。本课程的所有案例都不需要写代码 —— 用大白话告诉 Codex 你的需求即可。

Q4：Codex + DeepSeek 和 GPT 5.5 哪个好？

A：讲师毫不犹豫选择 GPT 5.5。DeepSeek 便宜但不是多模态（无法识别图片），适合作为成本/风险备选（详见第 12 课）。

Q5：Windows 还是 Mac？

A：Mac 更丝滑（编码识别、命令兼容性），Windows 也能跑通但更折腾（详见第 14 课）。建议有条件上 Mac。

Q6：Codex 安全吗？我应该开"完全访问权限"吗？

A：默认权限更安全（限制写入）。完全访问权限便捷但 Codex 可能读取到敏感信息。建议普通用户保持默认。

Q7：做 Skill 一定要先懂代码吗？

A：不需要。"先在对话中跑通流程 → 说一句话'沉淀为技能'"即可（详见第 6 课）。

Q8：抖音/小红书能自动发布吗？

A：不能也不建议。这些平台对自动化操作限制严格，违规会被封号。Codex 只能做"低频搜索 + 数据采集"，最后一步人工操作（详见第 17/18 课）。

Q9：公众号能自动发布吗？

A：可以。微信公众号官方提供 API 接口，可通过 Codex 调用自动发布到草稿箱，最后手动点发表（详见第 15 课）。

Q10：什么是 GEO？我也能做吗？

A：GEO（生成引擎优化）是面向 AI 搜索的内容优化策略，本质是影响 AI 的语料来源。任何行业的从业者都可参照七大维度做（详见第 20 课）。

Q11：怎么获取 Codex 的最新资讯？

A：
① 关注 OpenAI 官方公告
② 关注中转站公告
③ 让 Codex 自己告诉你：直接问"Codex 最近有什么新功能？"
④ 用 context7 MCP 拉取最新文档

Q12：token 太贵怎么办？

A：讲师建议每月 100 元，每天消耗大量 token 练习肌肉记忆。如果觉得贵，可以用 DeepSeek 方案（月 30 元），但功能会受限。

Q13：学习中遇到报错怎么办？

A：让 AI 对抗 AI —— 把报错截图发给 Codex，让它自己修（详见第 10 课排错思路）。
