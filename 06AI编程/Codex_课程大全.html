编号 1 — Codex 到底是什么（与 "Cloud Code / 豆包" 的本质区别）

来源：78.1.Codex到底是啥 + 79.1.Codex到底是啥（与 78 完全重复，已合并保留 78 版本）

深度总结

本节是 Codex 课程的开篇第一节，从"AI 入口"角度讲清楚 Codex / Cloud Code / 豆包 的根本区别。

1. 三句话定义三者

  • 豆包：只会回答问题。
  • Cloud Code / Codex：可以进入你的电脑帮助你干活。
  • 一句话区分：豆包是"问答 AI"，Codex / Cloud Code 是"执行 AI"。

2. 全球使用 Codex / Cloud Code 的真实规模

  • 即便今天 AI 新闻满天飞，真正使用 Cloud Code 和 Codex 的人，全世界只有几百万人。
  • 全世界总人口有几十个亿 → 这是非常小的比例。
  • 绝大多数人还停留在用豆包，甚至很多人豆包都没用过。

3. 入口的根本区别：普通入口 vs 生产入口

维度豆包（普通入口）Codex / Cloud Code（生产入口）
核心定位聊天、问答、搜索执行、操作、改造
输入用户提问任务目标 + 授权
输出文字、图片、内容文件读写 + 命令执行 + 可验收结果
工作方式模型给答案，用户粘贴复制到自己想用之处代替人去执行电脑上的操作
性质给你一个答案替你完成一系列动作

4. Agent 的本质

  • Agent = 会操作电脑的助手。
  • 工具举例：看文件（通过命令行看文件夹中的目录）、打开文件、搜索关键词、像人一样翻资料理解整个文档。
  • 执行命令的原理：鼠标点击左键右键、上下左右、复制粘贴 → 背后都是电脑命令在运行 → Agent 可以直接运行这些命令，达到同样的粘贴复制效果。
  • 结果校验：执行完后，Agent 像人一样去看最终结果（文本是否满足要求、截图是否对、代码运行后是否失败），不合格 → 再修正，直到你能验收。

5. Agent 能做但豆包做不到的事

  • 批量改几百个文件名；
  • 搜索并下载网页资料；
  • 生成一个可运行的网页。
  • 这些都更适合交给 Cloud Code 和 Codex 去做。

6. 终极金句

豆包解决的是"问"，而 Cloud Code 和 Codex 解决的是"做"。

系统性总结

  • 入口性质：豆包 = 普通入口（问答）；Codex / Cloud Code = 生产入口（执行）。
  • Agent 本质 = 大模型 + 工具调用（看文件、打开文件、搜索关键词、执行命令）。
  • 工作流程：目标 → 读写文件 → 执行动作 → 检查结果 → 用户验收。
  • 核心心法：从"问"到"做"是 AI 使用的范式转移；Agent 不是黑魔法——只是把鼠标键盘操作变成模型可调用的工具；学习方向不是学提问技巧，而是学任务拆解。
  • 起步建议：从简单的"整理电脑文件夹"开始，亲身感受 Agent 的工作方式。

编号 2 — Codex 颠覆哪些行业

来源：01.2.Codex的出现会颠覆和改变哪些行业

→ 相关：[编号3](#lesson-3)（先会用才能变革）

深度总结

1. 颠覆级案例作开场

2025 年 5 月 OpenAI 发布全新 Codex。一位完全没有专业编程背景的产品经理，仅用一天时间就让 Codex 帮他开发出一套完整的智能客服系统——前端、后端、数据库部署上线全部搞定，"一天一个人一个完整的产品"，这是正在发生的现实。

2. Codex 的两阶段进化

  • 初代 Codex（2021 年 8 月）：本质是 GPT-3 的代码专项微调版，120 亿参数，基于 GitHub 上 5400 万个仓库（159GB 代码）训练，能力边界是"你描述一句，它生成一段代码片段"。
  • 新版 Codex（2025 年 5 月）：不再是单纯模型，而是"软件工程智能体"。能自主理解目标、拆解任务、写代码、跑测试、修 bug，最后提交一个可直接合并的 PR。

3. 软件开发行业的剧烈变化

  • AI 写代码占比：2020 年大厂 AI 生成代码占比 20%-25%，2024 年飙升至 60%-70%，两年翻三倍。开发速度平均提升 6 倍。
  • 程序员工作内容：从"写代码"转向"审核代码"——质检员角色；高级工程师从"实现功能"转向"设计架构和拆解任务"——任务级编程。

4. 六大非传统编程行业的落地场景

行业核心场景价值
金融支付校验代码、对账自动化、经营分析报告客户经理每人每天省 60-90 分钟
医疗临床研究 0 代码、医保审核、新药研发工具医保拒付率从 23% 降到 9%，一年挽回几百万
教育少儿编程从语法到思维、教学改革、老师自制教学工具编程价值从"技能"变成"思维方式"
法律判例法条检索、合同文档自动化跨"懂业务"与"懂技术"的鸿沟被填平
电商运营小工具、内容生产、京东/李宁 AIGC 设计中小卖家也能玩数据分析与动画运营
游戏UI/技能/NPC/数据配置脚本自动化小团队也能做出大团队的游戏

5. 三个根本性变化

  • 效率乘数效应：每个行业涉及软件/数据/自动化的工作效率乘以 3-10 倍系数。
  • 技术民生化：业务人员、行业专家也能直接实现想法——最懂问题的人终于可以自己动手。
  • 试错成本更小：验证一个想法的成本可能只有原来的 1/10 或 1%。

6. 三类人群的应对策略

  • 开发者：把 AI 当成"超级实习生"，精力从"怎么写"转向"写什么和怎么设计"，学会任务拆解。
  • 行业从业者：未来每个行业都需要"懂点 AI 编程"的人，重点不是学写代码而是学编程思维。
  • 学生/新人：放弃刷题思维，转向项目实战 + AI 协作。

系统性总结

  • 底层逻辑：编程正在从一项专业技能变成一种通用能力。
  • 金句："在这个时代，淘汰你的从来不是 AI 本身，而是那些会用 AI 的。"

编号 3 — Codex 注册安装与 AI 身份设定

来源：02.3.Codex 注册安装和账号配置 + 05.3.设定 AI 的工作身份和角色

→ 相关：[编号1](#lesson-1)（先理解入口区别再看安装）

A. 安装配置部分

1. 两种安装方式与两种登录方式

  • 安装方式：Windows 和 Mac（Mac 与 Windows 流程大体相同，Mac 在后续课程讲解）。
  • 登录方式：
    • ① Plus 会员（官方充值）：每天有额度限制，用完只能等几个小时刷新。
    • ② API 中转站（通过 API 接口使用）：几乎没有限制。
  • 选择建议：每天工作量大、用量需求高，优先使用中转站。

2. Windows 系统的下载与安装流程

  • 打开电脑 → 打开浏览器 → 输入 Codex → 打开 OpenAI 官网 → 在官网里找到 Codex 产品。
  • 点击下载 Windows 版本，开始下载安装包。
  • 通过微软商店安装：双击下载的安装包，会自动调起微软商店进行安装（当前版本的 Codex 已经整合到 OpenAI 客户端中，不再需要额外的安装管理工具）。
  • 安装完成后点击"完成设置"→点击"开始使用"。

3. API 中转站获取密钥的完整流程

  • 操作：打开浏览器 → 进入中转站 → 输入邮箱密码登录 → 可选自行充值 → 在 API 密钥板块直接点击"创建密钥"。
  • 输入密钥名称（如 "pro 版本"）→ 点击创建 → 复制密钥 → 回到 Codex 客户端粘贴 → 点击"继续"。
  • 课程评价该方式"比较方便"——完全不需要再安装 Codex 客户端之外的额外管理工具。

4. Codex 的基础设置

  • 语言切换：点击"设置" → 把语言从默认英文切换为中文。
  • 外观主题：可在白色/深色等主题间切换。
  • 权限访问：把权限访问全开起来——开启后 AI 可以全自动运行。
  • 插件与技能：进入技能/插件目录，按需选用。

B. 设定角色部分

1. 问题作开场——为什么要设角色？

  • 不设角色（GPT 默认回答）：罗列基本步骤，"像正确的废话"——没有 get 到用户的实际痛点。
  • 设了角色后的差距：经过调教后的 GPT 给到的回复包括市场分析与定位、店铺选址与设计、产品策略、财务计划目标时间节点等——"非常具体和详细"。

2. 设立角色的标准模板

你现在就是一名专业的市场营销专家，拥有资深的学历背景和三十多年的市场研究经验。
不仅熟知产品营销和店铺推广，而且深谙人性和心理学，知道非常清楚用户想要什么样的产品，
以及对应的产品该怎么打造。以下是你的身份和背景，明白请回复 OK。

3. "角色 + 详细需求"组合指令（以杭州女装店为例）

基础信息："我是 25 岁年轻女性，我想在杭州的滨江区开家英伦风格的潮流女装店……"

三段式追问：①不少于 3000 字的店铺经营方案；②不少于 3000 字的 10 款服装产品策划；③不少于 3000 字的半年利润 100 万推广方案。

收尾指令（关键）：
"注意以上三段话分别为三个不同的问题，请分别详细回答，且每个问题回答结果都不少于 3000 字。回答详细具体。考虑到输入限制三个问题，你可以分三次回答。现在请你先回答第一个问题。"

4. 核心金句

"有些时候我们还是要对这个 GPT 进行一个模板和视频的训练。有句话说的很好，就是你给到这个 GPT 的那个指令任务越清晰，那么它给到你的回复和答案也就越准确。"

系统性总结

安装侧要点：①登录选择（Plus / API 中转站）；②安装极简（微软商店）；③关键设置三件事（语言切中文、主题按审美选、权限全开）。

角色侧要点：①角色模板是"上下文切换"开关；②指令清晰度决定输出质量；③"分段提问 + 字数要求 + 引导语"三件套稳定产出大篇幅方案；④永远可以追问深化。

编号 4 — 喂养和训练 AI 的系统方法

来源：06.4.如何喂养和训练AI的系统方法

→ 相关：[编号3](#lesson-3)、[编号5](#lesson-5)

深度总结

1. 用 Custom Instructions 给 GPT 设"标准工作模板"

  • 打开 GPT → 点击左下角头像 → 倒数第三个 "Custom Instructions"（定制 GPT）→ 点开功能。
  • 上面板：输入角色信息（如"我是某博士，专注于特定主题，比如职场、财经、美食、旅行、科技"）。
  • 下面板：输入回复要求、语气、态度、表达方式。
  • 点 "Save" 保存——就给 GPT 设定了一套标准化的角色工作模板。

2. 建立"爆款公众号文本模型"的完整流程

Step 1：让 GPT 进入学习模式

接下来我会发你一篇爆款公众号进行学习，目的是为了建立爆款公众号的文本模型。
当你学习之后，你只需要回复已学习。

Step 2：把爆款公众号原文复制粘贴给 GPT，GPT 回复"已学习"。

Step 3：要求 GPT 总结模型：

请你为这个公众号的文风文笔建立模型，找出其中六个重要要素，并详细描述这个模型。

3. 用"参考模型"反向精修

老师觉得 GPT 总结得太一般，给它一个标准模型反推："我感觉你总结的很一般，请参考下面的六个重要要素的模型。"

4. 命名 + 锁定调用方式

很好，我们把上面的这个模型命名为假模型。接下来我只要以假模型开头向你提问，

编号 13 — 创建自己的专属 AI 助理（GPTs）

来源：15.13.如何创建自己的专属AI助理

→ 相关：[编号4](#lesson-4)、[编号9](#lesson-9)

深度总结

1. GPTs 的核心能力

GPTs 比通用 ChatGPT 更擅长处理特定任务，因为可以自定义指令、知识与动作。

2. 合规红线

  • 名字不得含脏话、不得描绘或宣传暴力。
  • 不得用于培养"虚拟女友 / 虚拟男友"等浪漫伴侣关系或社会监督活动，否则会被举报下架。

3. 进入与两种创建方式

  • 入口：点击 Explore GPTs → GPT Store → 右上角 Create。
  • 左侧为创建区，右侧为预览区（实时对话测试）。
  • 模式 A —— Create（对话式创建）：适合脑中构想不够清晰的场景。
  • 模式 B —— Configure（填表式创建）：适合思路明确的场景，直接填入字段并完成。

4. 必填与可选字段

  • 头像、名字、描述、指令（构建者预先给 AI 的系统提示）。
  • Conversation starters：对话开头的示例。
  • Knowledge：上传任意文件补充 AI 自身不具备的专业知识。
  • Capabilities：勾选三项能力——Web Browsing（联网）、DALL·E（绘图）、Code Interpreter（代码解释器）。
  • Actions：接入外部 API 时使用，普通用户一般用不到。

5. 实操案例：佳佳老师（虚拟家教）

设定：作为一名虚拟家教老师，每天自动生成针对孩子当前学科水平的试卷和练习题；可处理数学、语文、英语；根据学生需要调整题型与难度；能基于答题提供效果分析和个性化改进建议。

6. 测试与迭代

  • 在右侧预览区测试："请帮我生成一份初二数学试卷"。
  • 通过回形针上传更多试卷/题库当作 Knowledge，再次发令。
  • 进一步限定："每种题型的题目至少 10 个，整张试卷总题目在 50 道左右"。
  • 最后点击 Create 完成正式创建。

编号 21 — AI 绘画的发展史和工作原理

来源：23.21.AI绘画的发展史和工作原理

⚠️ 前置知识：[编号22](#lesson-22)

→ 相关：[编号23](#lesson-23)

深度总结

1. 标志性事件

美国设计师 Jason Allen 用 Midjourney 创作的《太空歌剧院》获得 2022 年科罗拉多州艺术博览会第一名。

2. AI 绘画的起源

  • 20 世纪 70 年代：加州大学 Cohen 教授开发能控制机械臂绘画的程序"Aaron"（亚伦）。
  • 早期 AI 绘画并非由 AI 直接画图，而是通过电脑连接机械臂、按程序指令在纸上绘画。

3. 硬件转折点：GPU 取代 CPU 训练

  • 2007 年 NVIDIA 发布 CUDA：使用 GPU 训练神经网络的性能比同期 CPU 整整提升 5 倍。

4. 关键模型演进

  • 2013 年：Kingma 与 Welling 提出变分自编码器 VAE。
  • 2014 年：Goodfellow 提出生成对抗网络 GAN——博弈思维（生成器乙方 + 判别器甲方）。
  • 2015 年：Google 工程师开发基于 CNN 的图像生成工具 DeepDream。
  • 2016 年：Luke Metz 将 CNN 与 GAN 结合，提出 DCGAN。
  • 2018 年：AI 创作艺术品《贝拉米肖像》以 43 万美元高价拍卖成功。

5. 核心原理：Stable Diffusion 的扩散模型

  • 2020 年：加州大学伯克利分校提出去噪扩散模型 DDPM。
  • 工作流：①输入关键词 → ②单词转化为特征向量 → ③同时调出随机噪声图 → ④两者一起进入图像编辑器 → ⑤编辑器把噪声图一步步降噪。

6. 详细原理拆解

  • CLIP 模型 + 数据库：全网抓取 4 亿多张图像-标签对；输入关键词后从庞大数据库中找到相似或对应的语义描述。
  • 噪声图 + 编码器：512×512 RGB 图片运算时需要 79² 条数据；进入编码器前会被压缩到浅空间，最终降为 64×64。
  • 采样方式：影响最终图像质量。
  • 图像解压器：把浅空间向量释放到像素空间，得到最终图像。

7. 商业化里程碑：DALL·E 与开源浪潮

  • 2021 年 OpenAI 推出 DALL·E：AI 绘画行业里程碑。
  • 后续出现了 Midjourney 和 Stable Diffusion 大获成功。
  • Stable Diffusion 对消费级设备做了优化：4G/6G 普通显卡也能在几秒内生成高质量图。

编号 41 — 深度探索 AI 技术的本质和未来趋势

来源：单篇总结 41

→ 相关：[编号42](#lesson-42)、[编号43](#lesson-43)

深度总结

一、学习 AI 的逻辑前提——抓住本质

  • 无论做任何事情，都要掌握事物背后的本质，才不会被别人的只言片语误导。
  • 信息爆炸的时代不缺碎片，缺的是完整体系和框架。

二、人类智能的"输入—处理—输出"模型

  1. 输入：把各种信息灌进大脑，形成基础知识和信息。
  2. 处理：分类——哪些有用、哪些没用、该怎么用。
  3. 输出：整理表达，形成反馈与解决方案。
  4. AI = 把"处理"环节做成智能模块。

三、AI 替代脑力工作的必然性

  • 凡是涉及脑力与思考的事情，90% 都可以被 AI 替代。
  • 案例对比：文案/编剧 10 分钟可搞定；MJ、Niji 等 AI 绘画工具一秒出图；纹身图/纹身视频仅需简单需求描述。

四、AI 的版本演进

  1. 1.0 版本：模拟真人对话的智能体；强调算力与逻辑推理。
  2. 2.0 版本：强调"人性与情感"，能像人类一样思考、判断、理解、学习。
  3. 未来更高阶版本：可与人类任意交互；可自动下达、自动执行命令；产生类似人类的意识。

五、AI 现状的冰山一角

当前看到的 GPT、Midjourney 等只是表象，真正顶级核心的技术都被封锁，难以被大众知晓。AI 的发展远不止现在这样精彩。

编号 42 — AI 技术的演变和发展里程碑

来源：单篇总结 42

→ 相关：[编号43](#lesson-43)

第一阶段：知识学习阶段（1950s–1970s）

  1. 科学家手动给机器搭建知识库和代码库。
  2. 通过对已有知识的学习和逻辑推理实现机器智能化。
  3. 失败原因：规则和机制编不完；知识学不完；人类生命有限。
  4. 结论：一味追求无限知识是愚蠢的。

第二阶段：机器学习阶段（1980s–1990s）

  1. 开始使用机器学习技术让机器自我进化。
  2. 通过大量数据训练提高智能水平。
  3. 三类学习方法：监督学习、无监督学习、强化学习。
  4. 代表案例：CYC 项目、MIT CSAIR 项目。

第三阶段：深度学习阶段（1995 至今）

  1. 背景：计算能力提升 + 大量数据验证，使深度神经网络成为可能。
  2. 原理：模拟人类大脑神经元的工作方式构建神经网络。
  3. 成就：实现更复杂的图像识别、语音识别。
  4. 代表案例：谷歌 Translate、苹果 Siri、AlphaGo（2016 年击败柯洁）、特斯拉自动驾驶。

第四阶段：Transformer 阶段（2017 至今）

  1. 2017 年，谷歌高级程序员发表论文，提出 Transformer 模型——采用自注意力机制构建的深度学习框架。
  2. 成果：自然语言处理取得显著进展，出现各种预训练模型（BERT、GPT-3 等）。
  3. 代表案例：GPT-3.5、GPT-4。

核心规律

每个阶段都是"上一阶段瓶颈的解决方案"。商业产品越来越贴近大众（CYC → Translate/Siri → AlphaGo/特斯拉 → GPT-4）。

编号 49 — AI 的到来究竟是新机遇还是失业潮

  • 自从 GPT 出来后，各大论坛都在讨论 AI 是否会造成大规模失业。
  • 亚当·斯密在《国富论》中举过"针织工"的例子：一个工人手工一天连一根针都做不出来，但通过分工协作和机器辅助，一人一天可生产 5000 根针。
  • 1889 年威尔斯混淆了"工作的目的"与"工作的手段"——工作不是为了工作本身，而是为了提高效率、节省人力物力。

二、机器替代人工的长期正向效应

  • 棉纺机案例：1760 年棉纺机发明后 30 年内，棉纺业从业人数从 8000 人增至 40 万人，增长 55 倍。
  • 针织业案例：到 19 世纪末袜子针织业劳工人数比 19 世纪初至少增长 100 倍。
  • 结论：从长远看，机器替代人工反而会增加就业。

三、麻省理工《人与机器的战争》模型

  1. 第一阶段（AI 1.0）：AI 提升劳动生产率、减少企业对人力资源需求；同时新 AI 技术引起新资本投入，带来全新就业岗位。
  2. 数据佐证：1980-2007 年美国总就业人口增长 17.5%，其中一半由新职业带来。
  3. 平台期机制：当某行业失业人数过多，从业人员工资被压低 → 人力变便宜 → 资本失去 AI 动力。

四、劳动力流动的逐层递进

新职业出现高薪 → 吸引其他行业优秀人才加入 → 其他行业出现空缺 → 下一层级的人往上晋升。

福耀玻璃纪录片案例印证了这一流动机制。

五、短期阵痛与应对建议

关键警示：从长远看 AI 不会导致失业，但3-5 年内会有短暂痛苦。

行动建议：如果不能接受落差，请尽快学习新技能，成为这一波红利中第一波吃螃蟹的人。

编号 56 — 如何提高短视频的爆款概率

来源：单篇总结 56

应用到短视频：视频的第一印象就是开头 5 秒、甚至开头 1 秒。必须想尽办法让用户在开头不划走。

完播率最重要：完播率 = 完整播放的次数 ÷ 播放总次数。

编号 61 — 平台四个算法的底层原理

一、抖音的四大核心算法

1）流量池算法（多级推荐）

  • 视频发布且无违规 → 系统给300-500 初始播放量进行测试。
  • 根据用户行为反应好坏 → 决定是否推到下一个流量池。

推送到极致会产生"信息茧房"——只推送你喜欢的内容。

3）抖加算法（DOU+算法）

  • 抖加 = 抖音的视频加热付费工具。
  • 本质限制：投钱只是让更多人"看到"，是否点赞评论还是取决于内容质量。

4）去中心化算法

抖音上的去中心化含义：你的视频面向的不是平台/审核人员，平台只是载体，视频好不好完全由用户评价决定。

重要纠偏：抖音没有"养号"这一说！网上传的"养号"都是伪命题。

  1. 热门算法：触发条件：作品点赞和播放破百万甚至千万。行为：抖音把作品推送给不同喜好、不同标签的人。别名：猜你喜欢。

对内容创作者的启示：

  • 想扩大流量池 → 内容必须能做"爆款"——触发热门算法。

编号 62 — 审核机制的拆解与分析

来源：单篇总结 62

深度总结

一、抖音审核机制的两步骤（系统审核 + 人工审核）

审核 vs 推荐的关系：

  • 算法 + 用户行为 = 决定能否上热门。
  • 审核机制 = 决定能否被放出来（能否进入推荐池）。

Step 1：系统审核

系统根据两类要素判断视频质量：①图像：图片、视频画面；②文字：视频标题、标签、文案。

硬性条件（直接 pass 掉）：图像涉黄赌毒、恐怖恶心、违反公序良俗；文字涉军涉政、耸人听闻、污蔑抹黑、造谣党和国家领导人。

软性条件：画面模糊、画质不清晰、画面拍摄时抖动。

Step 2：人工审核

系统处理结果分流：审核成功 → 直接放出；不成功或存疑 → 打上预警标签（红色或黄色）→ 转人工审核。

二、审核通过后的冷启动与重新推荐

视频审核通过进入初始流量池 → 流量池算法给予 300-500 初始播放量 → 进入账号冷启动阶段。

冷启动的流量构成

亲戚朋友、同城、附近的人。

重新开始算法（回到初始值）

为做到公平，不冤枉优秀的视频：算法每隔一段时间，把账号里的所有视频重新推荐给新的人群。

两大数据定义

  1. 内容本身：画面清晰度、音乐清晰度、文案优秀程度、画面整体契合度。
  2. 用户行为：点赞、评论、收藏、下载、转发。

编号 69 — 爆款内容的底层公式（一）

深度总结

本节围绕"爆款内容的底层公式"展开，从"开头诱因"、"内容呈现"、"文案公式"、"创作注意事项"四个维度系统拆解了可复用的爆款方法论。

一、八大诱因模型——开头吸引用户的核心武器

在写文案时共有八大诱因模型可被用于内容开头吸引用户。

  1. 创造焦虑 + 激发认同——"20 岁的年纪不好好赚钱，等到了 30 岁你想赚钱也没有机会了。"
  2. 简单聚合 + 强调数字——"如果你是一名职场小白，想要快速升职加薪，那么这三本书一定要去看……"
  3. 观念对比 + 引起吐槽——观点具有争议性时，会出现认同派与反对派在评论区互相反驳，从而拉升评论数。
  4. 行业内幕 + 引发好奇——通过揭露行业内幕引发用户好奇，让用户停下来验证"到底有没有这么暴利"。
  5. 简单上手 + 引起向往——让用户觉得做成某件事非常简单，唤起"我也可以"的向往。
  6. 抛出问题 + 产生共鸣——用反问句抛出对比性命题，引发用户对自身处境的共鸣。
  7. 简单上手 + 降低标准——"只要你有一双手，一台电脑，在家都可以月入过万。"
  8. 展示结果 + 呈现实力——用反差（粉丝少 vs 变现多）建立权威感。

核心心法：爆款开头 = 情绪钩子 + 认知反差 + 行动门槛降低，三者交叉组合使用。

二、内容视觉化与共鸣感的塑造

短视频是视觉化的，内容呈现也应是视觉化的。拍摄者本人也是内容的一部分。

场景选择：如果你不是专家，千万不要装成专家，否则很难获得用户的共鸣感。

共鸣感的方法：往普通事里加情感元素。

三、常用文案公式与"获得感"设计

公式一：给出结果 + 引发疑问 + 强调专业 + 解决方法

公式二：给出答案 + 解释答案 + 结尾升华

核心原则：讲得越细致，用户的获得感越强。

四、内容创作的三个关键注意事项（说群体、说好话、设槽点）

  1. 不要点名地域或群体：只说"所有人"，不点名地域/世代，避免被围攻。
  2. 用户喜欢听好的，不喜欢听不好的：告诉用户做成一件事情很简单，不要讲得很复杂很困难。
  3. 给用户美好与期待：理性会让用户思考，而感性会让用户消费。

核心结论：感性驱动消费，理性驱动思考——做内容要感性引导，做产品要感性包装。

编号 73 — 怎样提升镜头的表现力

深度总结

本节课聚焦"镜头前的表现力"——一个让很多线下能说会道的人面对镜头就哑口无言的核心痛点。

1. 表现力的定义校准

  • 现象：线下能说会道的人，面对镜头（尤其多人观看时）会紧张、无法自然表达 → 表现力不足。
  • 误区澄清：表现力 ≠ 气场很足、声音很大、字正腔圆。表现力 = 凸显真正的自己，把真实人格表现出来。

2. 表现力不足的两大原因

  • 原因一：对自己的不自信——害怕说错、被人质疑、被人反对。害怕账号做不起来、视频没人看。
  • 原因二：对表达内容不熟练——你是专业人士，但不知道如何把信息组装成自己的语言体系。

3. 解决方法一：情绪代入法

想象有一个人背叛了你，做了一件非常令你愤怒的事。让情绪慢慢上来 → 保持这种状态面对镜头 → 把想说的内容用这种情绪表达出来。

4. 解决方法二：重复拍摄法

保持当前面对镜头的状态，拍 10 遍、20 遍甚至 100 遍，直到满意为止。

5. 核心结论

表面上要解决"表现力不足"，实际只要解决"不自信"和"不熟练"两个根本问题。反复练习才是关键——表现力不是天赋，是练出来的肌肉记忆。

系统性总结

表现力不足的两大根源：①心理根源：不自信；②技术根源：不熟练。

两大解决方法：①情绪代入法；②重复拍摄法。

核心心法：

  • 表现力不是表演，是真实人格的呈现。
  • 不自信是心魔，需要反复练习克服。
  • 练习量决定熟练度：1 条视频拍 100 遍 > 100 条视频各拍 1 遍。
  • 表现力直接影响直播流量：镜头表现力 + 直播气场 → 直播间流量自然增长。

4. 进阶玩法：连麦

  • 直播中还可以开免费连麦（谁想连就谁连）。
  • 不要开付费连麦：新人知名度不高，付费没人连。
  • 连麦的本质：表面：你和用户一对一沟通解决问题；实际：直播间里所有观众都在看你讲得好不好。

这是本套课程的最后一节收官课，主题从"方法论"上升到"心态论"——成为自己的精神领袖。

1. 课程会持续更新

听完前面 17 节课程 + 按底层逻辑反复实操 → 就能拿到想要的结果。但抖音平台的算法和机制在不断更新。

2. 做好短视频和直播的心态建设

核心观点：选择抖音，就要做好 100 条视频 + 100 场直播 的准备。

这个数量的目标不是数据好看，而是：完成后，对如何做出好短视频、如何做好直播会有重新定义；越来越熟练、越来越有感觉；心态会发生天翻地覆的变化。

3. 痛苦是成长的养分

做抖音本身就是非常痛苦的事情。痛苦可以使人成长。每个人都是普通人，没有谁天生就会。

李佳琪一开始也是化妆品柜员；薇娅最早也只是一个服装店的导购。

正向循环：真诚为他人分享干货 → 用专业知识为用户解决问题 → 获得更多认可 → 成就感 → 想做好每一场直播 → 越做越好。

4. 如何面对被骂

问题：每次拍短视频、开直播都有人骂，严重影响做抖音的心情。

老师的回答：只有一种办法——不做抖音。

5. 应对被骂的两类策略

  • 类型 A：内容/直播做得很烂而被骂：能反馈出用户对你视频/直播的行为反应。这是有价值反馈。
  • 类型 B：恶意骂你：直接拉黑删除。不要争吵、不要反过来骂。

6. 终极心法

不管做短视频还是做直播，不要害怕困难，要勇于面对困难。

困难不是坏事——只有真正经历无数困难和挫折之后，才能真正成为非常厉害的人。

做抖音不靠运气，靠100 条视频 + 100 场直播 + 100 次被骂 + 100 次重来的重复积累。

2️⃣9️⃣ 爆款诱因 8 大类

适用场景：撰写爆款短视频文案开头的 8 种诱因模型。

1. 创造焦虑 + 激发认同
   "20 岁的年纪不好好赚钱，等到了 30 岁你想赚钱也没有机会了。"

2. 简单聚合 + 强调数字
   "如果你是一名职场小白，想要快速升职加薪，那么这三本书一定要去看……"

3. 观念对比 + 引起吐槽
   "我今天就告诉你不花一分钱就可以找到女朋友的方法……"

4. 行业内幕 + 引发好奇
   "眼镜行业很暴利……到底有没有这么暴利？"

5. 简单上手 + 引起向往
   "从负债累累到身家过亿，我就做对了这一件事情。"

6. 抛出问题 + 产生共鸣
   "你有没有想过，为什么别人家的小孩成绩那么好，而你家的小孩成绩却那么差？"

7. 简单上手 + 降低标准
   "只要你有一双手，一台电脑，在家都可以月入过万。"

   "虽然我这个账号只有五万粉丝，但是我每个月可以变现 200 万。"

3️⃣0️⃣ 对标账号拆解 5 步

适用场景：0 成本起步的爆款模仿方法论（找 → 看 → 抄 → 改 → 创）。

Step 1：明确赛道
当知道要做垂直内容并选好赛道后，进入下一步。

Step 2：选工具查询数据
老师推荐蝉妈妈作为主要工具。其他：新抖、抖查查、飞瓜数据。
省钱：去淘宝买 7 天/15 天/一个月短期版。

Step 3：找出前 20 个对标账号
用软件搜索你赛道（如美食、服装）→ 找到前 20 个近期变现非常不错的账号。
只要近期变现数据，不要以往的变现数据，更不要粉丝数据。

Step 4：人设匹配筛选
看这 20 个账号每个人的人设——有没有和你相似的特点和元素。
如果有相似的 → 前期就可以模仿这个账号去起号。

Step 5：拆解对标账号文案
① 制造用户痛点 → ② 加深用户痛苦 → ③ 解决用户痛点
诱因 + 新奇特 + 获得感 + 升华 = 完整爆款文案公式

【避坑】不要只模仿 1 个账号，而是找 3-5 个对标 → 提取共性 → 形成自己的风格。
